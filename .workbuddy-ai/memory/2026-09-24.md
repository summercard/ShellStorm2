## 排查「Mac 与 Windows 特效不一致」（只读诊断，未改代码）

已确证事实：
- 本机日志（`~/Library/Application Support/Godot/app_userdata/弹壳风暴2/logs/godot.log`）首行：
  `Godot Engine v4.6.2.stable` / `Metal 4.0 - Forward+` / `Apple M1`。Windows 侧预期为 Vulkan 或 D3D12 的 Forward+。
- 本机 `user://graphics_settings.cfg` 实际值：`anti_aliasing="fxaa"`、`shadow_quality="medium"`；
  而 `GraphicsSettingsManager.DEFAULT_SETTINGS` 是 `taa` + `high`。⇒ 两台机器画质档天然分叉（cfg 不进 git、每机独立）。
- `project.godot` 未关 `rendering/rendering_device/fallback_to_opengl3`（默认开）⇒ Forward+ 机器 Vulkan/D3D12 都不支持时静默退 Compatibility。
- **实现缺陷（P0 级）**：`GraphicsSettingsManager._apply_viewport_antialiasing()`（L263-276）先把 `msaa_3d` / `screen_space_aa` 全设 DISABLED，再只 `use_taa = true`；
  而 TAA 在 Compatibility 不支持 ⇒ 回退后**完全没有抗锯齿**。
- Compatibility 丢失项：TAA / SSIL / SSR / SDFGI / 体积雾（glow 与 SSAO 仍支持）。
- 已有渲染器分支：`WastelandLight3D._get_render_energy()`（L243-250）Forward+ 点光能量 ×3.0，其它 ×1.0；
  只区分 forward_plus / 非 forward_plus，**分不出 Metal 与 Vulkan**。`VfxMuzzleFlash3D._LIGHT_ENERGY=5.0` 无任何后端补偿。
- 帧率相关模拟：`VfxEffectBase3D._process` 累加 `_elapsed += delta`；`VfxShellCasing3D._on_tick`（L167-180）用变步长半隐式欧拉（dt 上限 1/15）积分重力+弹跳。

## 「颜色/发光不对」根因定位（用户确认症状为颜色/发光）

**颜色不对 = 配置问题（已确证，100% 可复现）**
- `user://postfx_tuning.json`（本机实际内容）：`debug_postfx_adjustment_enabled=true`、brightness **0.9**、contrast **1.18**、saturation **1.3**。
- 干净档位基线（`GraphicsSettingsManager._apply_environment` L362-364）：brightness 1.01 / contrast 1.07 / saturation 1.04。
  ⇒ 饱和度 +25%、对比度 +10%、亮度 −11%。Windows 若无此文件就是干净基线。
- 生效链路（无任何 debug 闸门，`_ready()` 无条件执行）：
  `scenes/Player3D.tscn` 内嵌 `FlashlightTweakerLayer/FlashlightColorTweaker`（Player3D.tscn L87）
  → `FlashlightColorTweaker._ready()` L148-149 `_setup_postfx_persist()` + `_apply_persisted_postfx()`
  → `apply_debug_postfx(data)`（L938）
  → `GraphicsSettingsManager._apply_debug_postfx_overrides()`（L372）覆盖所有已注册 Environment 的 `adjustment_*`
  → 且 `_apply_all()` 每次都重新盖上 ⇒ 玩家在画质设置面板复位**抹不掉**它。
- 文件里的 4 个 glow 键被 `debug_postfx_tv_distortion_enabled=false` 挡住，**不生效**。

**发光不对 = 渲染层（glow 参数两边完全一致，不是配置）**
- glow 真源：`TowerAtmosphere3D.configure()` L68-69 给 Environment 设 meta `presentation_glow_intensity=0.86` / `presentation_glow_hdr_threshold=0.90`；`GraphicsSettingsManager._apply_environment` L306-312 读 meta + 写死 strength 0.92 / bloom 0.08 / hdr_scale 1.65 / normalized true。两台机器同源。
- 差异来源：Mac 当前 `anti_aliasing="fxaa"`，Windows 若为默认档则是 `taa` ⇒ TAA 时域累积会把 0.16s（约 10 帧）的高亮火花与邻帧平均，峰值亮度下降、glow 越阈值像素变少；以及 Metal vs Vulkan / Compatibility 回退的后端差异。
