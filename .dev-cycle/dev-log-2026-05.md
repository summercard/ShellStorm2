# 开发日志 2026-05

## 轮次388 — 战斗打击感：HitStop 命中停顿

### 本轮摘要
**维度选择**: 战斗视觉反馈 — 打击感增强（HitStop）

**本轮核心问题**: 游戏射击命中反馈感不足，玩家无法从视觉上"感受"到每一发子弹命中的冲击力。现有反馈（伤害数字+屏幕震动+敌人闪白）都是被动表现，缺少主动的停顿感。

**技术方案**: HitStop（命中停顿）
- 利用 `Engine.time_scale = 0.0` 实现帧级停顿
- 普通命中：约3帧停顿（50ms@60fps）
- 暴击命中：约5帧停顿（83ms@60fps）
- 停顿后自动恢复 `time_scale = 1.0`，不阻塞游戏逻辑
- 暂停状态（is_paused）下不触发，避免冲突

**实现内容**:

1. **Global.gd — HitStop 基础设施**
   - 新增 `hitstop_timer`、`HITSTOP_NORMAL`、`HITSTOP_DURATION`、`HITSTOP_CRIT_DURATION`
   - 新增 `Global.trigger_hitstop(is_crit: bool)` — 触发命中停顿
   - `_process()` 中监控 `hitstop_timer`，超时自动恢复 `Engine.time_scale`
   - 常驻 `process_mode = Node.PROCESS_MODE_ALWAYS`，即使游戏暂停也能恢复

2. **EnemyBase.gd — 受击时触发 HitStop**
   - 在 `take_damage()` 末尾调用 `Global.trigger_hitstop(is_crit)`
   - 敌人被玩家子弹命中时停顿

3. **BossActor.gd — 受击时触发 HitStop**
   - 在 Boss 受击反馈中调用 `Global.trigger_hitstop(is_crit)`
   - Boss 被攻击时也有停顿感

**验证结果**:
- Godot headless --path . --quit: 编译通过 ✅

**玩家可感知结果**:
- 玩家射击命中敌人时，短暂感受到"画面卡住"的冲击感
- 暴击时停顿更明显，强化"打得好"的正向反馈
- 这个停顿非常短（3-5帧），不会造成操作不适，但足够大脑"接收到"每一次命中

**涉及文件**:
- `src/core/Global.gd` — HitStop 基础设施
- `src/enemy/EnemyBase.gd` — 命中触发 HitStop（1行）
- `src/enemy/BossActor.gd` — 命中触发 HitStop（1行）

**剩余风险/待办**:
- HitStop 期间玩家不能射击（time_scale=0 同样暂停了玩家输入），实际体验需要人类试玩验证
- 如果觉得阻塞感太强，可以把 `HITSTOP_DURATION` 从 50ms 减到 33ms（2帧）
- 可以在武器开火时也触发一次轻微 HitStop（不只是命中时），进一步增强"开枪感"
- 人类试玩验证（最高优先级）

**下一步最可能方向**: 人类试玩验证 + 枪口火光特效增强
