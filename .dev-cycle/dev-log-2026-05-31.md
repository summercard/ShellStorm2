#### DemoRoomGameMode 撤离链路终审

**R8撤离读条（_try_start_extraction → ExtractionModule.start_extraction → HUD更新）**

流程确认：
1. 玩家进入R8（`is_extraction=true`）→ `_enter_room()` → `_update_label("=== 撤离房 ===\n按 [E] 开始撤离读条")` → `_schedule_extraction_start()`
2. 1秒后 `_extraction_started=true`，玩家按E → `_try_start_extraction()` 检测status=IDLE + `_extraction_started=true` → `_extraction_module.start_extraction("STANDARD", 14.0)`
3. `ExtractionModule.start_extraction()`: status=COUNTDOWN → 每帧emit `extraction_progress_updated(progress)`
4. DemoRoomGameMode._process(): COUNTDOWN时 `_extraction_module.update(_delta)` + `_update_extraction_defense()`
5. GameUIManager: `show_extraction_room_countdown(14.0)` 显示countdown_bar+countdown_label+abort_button
6. `_connect_extraction_module_signals()`: 连接 `extraction_progress_updated→_on_extraction_progress_updated`（更新bar.value）和 `extraction_aborted→_on_extraction_aborted`
7. 受伤中断: `_on_player_hp_changed()` → `extraction_module.abort_extraction()` → `_on_extraction_aborted()`
8. 成功完成: countdown到达1.0 → `extraction_completed.emit(true, [])` → `_on_extraction_completed()` → `show_run_extraction_success()`
9. 撤离波次: `_update_extraction_defense()` 在remaining≤9s时刷mid-wave（近战+射手），remaining≤5s时刷final-wave（30%概率精英or双敌人）

**关键设计确认**
- `_extraction_started` 标志：防止重复触发（由`_schedule_extraction_start()`在进入撤离房1秒后设为true）
- `_rooms_cleared.has(_current_room_id)` 在R8永远为false（is_extraction房间never加入_rooms_cleared），不影响流程
- `RoomExtraction.tscn` 没有WaveSpawner子节点 → `_try_start_extraction()` 动态创建临时`RoomWaveSpawner`用于撤离刷怪

**命卡Tab关闭（FateCardUIController）**
- `hide_card_selection()`: `card_panel.hide() + is_visible=false + get_tree().paused=false` ✅
- `ui_cancel` (ESC) 或 `ui_tab` (TAB) 且 `is_visible=true` → `hide_card_selection()` ✅
- DemoRoomGameMode.process(): 命卡UI优先于游戏逻辑处理input（`get_tree().root.set_input_as_handled()`）✅
- 关键细节：Tab键在ui_tab分支也有相同的`hide_card_selection()`调用，避免只按ESC不按TAB时残留

**Boss HP Bar入场（GameUIManager + RoomGameMode信号链路）**

- `on_boss_defeated()`: `_hide_boss_hp_ui()` + 胜利大字动画 ✅
- R6 Boss房floor=2 → FLOOR_SCALING[2]: HP×1.4, Damage×1.2，难度适中 ✅

#### 波次系统架构确认（澄清 wave_count vs floor_level）

**Demo配置澄清**
- 所有房间 `RoomData.FloorLevel.SHALLOW` → wave_count=1（单波次）
- R1-R2（战斗房）: `enemy_count=3` + 预置怪物场景，怪物在RoomWaveSpawner.start()后生成
- R6 Boss: `enemy_count=0`，由`DemoBoss`独立处理（击败后`boss_defeated`信号触发`_on_boss_defeated_triggered`）
- R7 精英: `enemy_count=1, enemy_types=["elite"]`，单精英怪

**正式游戏波次规则（RoomGameMode._calculate_wave_counts_for_enemy_plan）**
| floor_level | wave_count |
|---|---|
| SHALLOW | 1 |
| MEDIUM | 2 |
| DEEP | 2 |
| ABYSS | 3 |

**MonsterInjector.floor → FLOOR_SCALING（独立于波次系统）**
| floor | hp_mult | damage_mult |
|---|---|---|
| 1 | 1.0 | 1.0 |
| 2 | 1.4 | 1.2 |
| 3 | 1.5 | 1.3 |
| 4 | 1.8 | 1.5 |
| 5 | 2.2 | 1.8 |

**关系**：floor决定数值缩放，floor_level决定波次数量，两者正交

#### Demo vs 正式游戏架构差异说明
- Demo的`FloorLevel.SHALLOW`是出于演示简化，不代表正式游戏的floor层级设计
- 正式游戏第一关（floor=1）应使用`FloorLevel.MEDIUM`获得2波次体验
- 本轮不修改Demo的floor_level（保持设计一致性），但在PH06文档中明确说明
