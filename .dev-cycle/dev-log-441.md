- 伤害数字（固定字号/颜色/时长）

### 本轮改动

**文件：** `src/fx/DamageNumbers.gd`

#### 1. 字号按伤害分档
```text
damage >= 100  → font_size=42（大招/狙击暴击）
damage >= 50   → font_size=34（霰弹暴击/高阶技能）
damage >= 25   → font_size=26（霰弹普攻/步枪暴击）
damage >= 12   → font_size=20（步枪普攻）
damage < 12    → font_size=16（手枪普攻）
```

#### 2. 普通命中颜色按伤害分档
```text
damage >= 50   → Color(1.0, 0.35, 0.1, 1.0)  亮红（大伤害）
damage >= 25   → Color(1.0, 0.5, 0.15, 1.0) 橙红（中大）
damage < 25    → Color(1.0, 0.3, 0.3, 1.0)   标准红（普通）
暴击（所有）   → Color(1.0, 0.92, 0.2, 1.0)   金黄（统一视觉通道）
```

#### 3. 飘字时长按伤害动态
```gdscript
var actual_duration := clampf(0.6 + damage * 0.003, 0.5, 1.2)
// 手枪12伤害 → 0.636s
// 霰弹30伤害 → 0.69s
// 大招150伤害 → 1.05s
```

#### 4. 暴击弹出缩放增强
```gdscript
var pop_scale := 1.35 if is_crit else 1.2
```

#### 5. 暴击+高伤害时触发屏幕微震
```gdscript
if is_crit and damage >= 50:
    shake.trigger(clamp(damage * 0.06, 4.0, 8.0), clamp(0.08 + damage * 0.0005, 0.08, 0.15))
```
- 霰弹暴击（50伤害）→ 3px微震，0.105s
- 狙击暴击（100伤害）→ 6px微震，0.13s
- 大招暴击（150伤害）→ 8px cap，0.155s
