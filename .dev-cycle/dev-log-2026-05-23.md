# 轮次 58 — 2026-05-23 08:16

### 维度
"枪上加枪"核心机制实现 — 主枪开火时副枪也跟随射击

### 目标
实现策划案中的核心特色机制"枪上加枪"：玩家使用"枪上加枪"命运卡片后，在主枪的 MOUNT 槽挂载一把副枪身，每次主枪开火时副枪也独立射击。这是游戏另一个独特的无厘头组合（"子弹背枪"的兄弟机制）。

### 问题分析
1. **之前的断点**：`FateCardPresets.gd` 中的 `gun_on_gun()` 预设虽然存在，但 `effect.action` 被设为 `ATTACH_TO_MOUNT`（通用挂载），FateCardEngine 中的 `_apply_attach_to_mount` 只创建一个 `ATTACHMENT` 类型节点而非 `GUN_BODY`，无法触发枪的射击逻辑。
2. **WeaponAssemblyTree 不知道主枪开火时要同步副枪射击**：原有 `_spawn_projectiles_from` 只有子弹生成逻辑，没有处理副枪射击。
3. **Bullet.gd 的挂载枪机制不能直接复用**：子弹背枪是"子弹飞行时枪自动射击"，枪上加枪是"主枪射击时副枪也射击"——时序和位置都不同。

### 玩家可感知结果
- 使用"枪上加枪"卡后，发射子弹时主枪旁边会有一把小枪同步开火
- 副枪子弹从主枪枪口偏移位置发射，朝向相同方向
- 视觉上主枪+副枪同时喷射，场面翻倍火力
- 副枪伤害和射速经过缩放（`damage_scale=0.5`，`fire_rate_scale=0.6`）

### 技术细节
- 枪上加枪的副枪是挂在主枪的 MOUNT 槽，而不是子弹上
- 每个副枪有独立的冷却追踪（通过 `_co_mounted_cooldowns` 字典，key = `"co_mounted_" + node.node_id`）
- 副枪射击从主枪枪口偏移 `direction * 15.0` 的位置发射，方向与主枪一致
- 副枪子弹不带暴击判定，减少性能开销
- 与"子弹背枪"机制完全解耦：一个是子弹挂枪（Bullet.gd 的 `_process_attached_gun_firing`），一个是枪上挂枪（WeaponAssemblyTree.gd 的 `_fire_co_mounted_gun`）
