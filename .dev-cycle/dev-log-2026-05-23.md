### 核心问题分析
交易撤离（TRADE）有完整的 ExtractionDirector + ExtractionModule + GameUIManager UI：
- ExtractionDirector.unlock_trade_extraction() 存在
- GameUIManager 的 TRADE 按钮有条件判断（货币足够）

但**触发解锁的信号链是断的**：ExtractionDirector.unlock_trade_extraction() 从未被调用。

根本原因：RoomGameMode._auto_open_merchant() 打开了 MerchantUI 商户面板，但：
1. purchase_requested 信号发出后无人处理（没有 _on_purchase_requested 连接）
2. merchant_closed 信号也没有被连接（因此无法在玩家关闭商户时解锁 TRADE 撤离）

玩家必须：进入商户房 → 购买任意商品 → 关闭商户 → 才能解锁 TRADE 撤离。

### 本轮修复
在 RoomGameMode._auto_open_merchant() 中，获取商户 UI 后连接 merchant_closed 信号：
```gdscript
if ui != null:
    ui.show_merchant(merchant_interaction._goods)
    merchant_interaction.force_set_active()
    # 连接交易成功信号 → 解锁交易撤离（单人购买即解锁，不需要等待关闭）
    if not ui.merchant_closed.is_connected(_on_merchant_closed):
        ui.merchant_closed.connect(_on_merchant_closed)
```

新增方法 `_on_merchant_closed()`：
```gdscript
func _on_merchant_closed() -> void:
    if map_manager != null and map_manager.extraction_director != null:
        map_manager.extraction_director.unlock_trade_extraction()
        print("[RoomGameMode] 商人大厅关闭 → 解锁交易撤离")
```
