### 问题分析
轮次143刚完成命运卡片UI整合（FateCardUIController + FateCardPanel + Tab键），但命中了一个关键体验问题：

### 问题分析
轮次146完成了WeaponDisplay对tree_changed的监听，解决了枪型刷新问题。但审查代码发现WeaponDisplay.gd存在以下问题：

1. **`_on_tree_changed_by_fate` 错误地重新创建了 `_body` 和 `_muzzle` 节点**：这会在每次命运卡片改造后重复创建子节点，导致节点堆积和内存泄漏
2. **`_setup_nodes()` 函数缺失**：代码调用 `_setup_nodes()` 但该函数从未定义（应该是 null pointer crash 的潜在来源）
3. **`_refresh_weapon_from_player` 重复定义**：文件中存在两处同名函数定义（行号173和行号210），GDScript会以最后一个为准，但会导致难以调试的问题

这些问题如果未修复，会导致：
- 每次命运卡片应用时Bullet.gd的set_attached_gun被调用后，WeaponDisplay枪型无法正确刷新（因为节点创建逻辑损坏）
- 游戏运行一段时间后内存泄漏

### 本轮改动

#### 1. 删除 `_on_tree_changed_by_fate` 中的错误节点重建代码
原代码在tree_changed回调中重新创建Polygon2D节点，这会导致节点堆积。
修复后回调只调用 `_update_gun_display` 刷新枪型，节点复用已在 `_ready` 中通过 `_setup_nodes` 完成。

#### 2. 添加缺失的 `_setup_nodes()` 函数
在 `_ready()` 前添加正式的节点初始化函数：
```gdscript
func _setup_nodes() -> void:
    _body = Polygon2D.new()
    _body.name = "GunBody"
    _body.z_index = 1
    add_child(_body)
    _muzzle = Polygon2D.new()
    _muzzle.name = "MuzzleFlash"
    _muzzle.visible = false
    _muzzle.z_index = 2
    add_child(_muzzle)
```

#### 3. 删除重复的 `_refresh_weapon_from_player` 定义
保留第一个定义（信号连接版本），删除第二个重复定义。
