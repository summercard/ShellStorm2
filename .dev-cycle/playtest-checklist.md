## 1. 核心射击与武器系统

### [ ] 枪口火焰（MuzzleFlash）
- 射击时 PointLight2D 是否亮起（可见的橙黄光点）
- 位置是否跟随枪口方向
- 熄灭动画是否正常

### [ ] 换弹爆炸特效（explode_on_reload）
- 获得"换弹爆炸"命运卡片后，换弹时是否触发 GPUParticles2D 爆炸效果
- 爆炸位置是否在玩家附近
- 爆炸伤害是否生效

### [ ] 换弹流程
- 按 R 换弹时是否有换弹动画/音效
- 弹药是否重置为满
- 换弹期间是否阻止射击

### [ ] 武器装配树面板（Tab键）
- 按 Tab 是否显示 WeaponAssemblyTreePanel
- 节点是否显示完整（枪身+子弹+配件）
- 点击节点是否有高亮效果
- 详情弹窗是否正确显示

## 2. 命运卡片系统

### [ ] 房间清理后提示
- 房间清理完成后是否显示"按 Tab 选择命运卡片"提示
- 提示4秒后是否消失

### [ ] Tab 选卡界面（已知缺口）
- **状态**：显示通知但无 Tab 监听器 — 玩家看到"按 Tab 选择命运卡片"但按 Tab 无响应
- 这是轮次23设计的预期缺口：Tab 处理需要接入 GameUIManager 的输入拦截
- 当前命卡选择通过改造房/商人房交互触发，不依赖 Tab

### [ ] 命卡视觉（eyes/legs/fate_scale）
- 选卡后武器外观是否有变化（眼睛/脚/放大）
- 子弹视觉是否反映命卡效果

### [ ] 命卡应用音效
- 选择命运卡片时是否有音效反馈

## 3. 怪物系统

### [ ] 6种怪物AI行为
- **近战追击型（chaser）**：是否贴脸追击玩家
- **远程弹幕型（ranged）**：是否保持距离并射击
- **召唤型（summoner）**：是否召唤小怪
- **护盾型（tank）**：是否格挡攻击
- **自爆型（bomber）**：是否靠近后爆炸
- **潜伏型（trapper）**：是否布陷阱

### [ ] 精英怪专属主动技能
- 档案精英出现后是否使用专属技能（冲锋/护盾反射/召集/狂暴等）
- 不同词缀的精英是否有不同行为

### [ ] 第二关怪物强度
- 第二关（floor=2）怪物 HP 是否比第一关高（HP ×1.4）
- 第二关怪物伤害是否比第一关高（DMG ×1.2）

### [ ] 冰霜DOT视觉
- 冰霜子弹命中敌人后，敌人 shape 颜色是否从白变蓝
- 冰冻（蓝白modulate）和冰霜DOT（蓝白色color）是否可区分

### [ ] 撤离战利品面板
