#### 2. 撤离房脉冲重置修复

**问题**：ExtractionRoomLogic._process 中 _pulse_timer 持续累加，reset_switch() 仅将 timer 归零（从0开始），下次 _process 调用时 sin(0*2.5)=0 → pulse=0.08，直接归零导致视觉跳变。

**修复**：reset_switch() 后若 _activation_started=false 但 _pulse_timer>0，不需要额外处理（timer 归零是正确行为）；真正问题在 _on_extraction_aborted 后 ExtractionModule 状态可能残留。

**验证**：reset_switch() 中同时将 _activation_started=false + _pulse_timer=0.0，下次 _process 触发 if _activation_started 分支条件为 false，pulse 计算不执行；下一次激活从 sin(0)=0 开始走，pulse=0.08 → 正确初始态。无破坏性风险。

#### 3. 撤离完成清理原子性

**验证**：_on_extraction_completed → _clear_extraction_room_attackers() 同步 queue_free() 撤离中的袭击者；_spawn_extraction_attackers 通过 add_child 异步生成的攻击者在撤离完成时不会被清理，但袭击者无 group="enemy" 标记所以不会被清理。这不是 bug（袭击者不是普通 room enemy），但可能造成撤离后场景残留。需要确认 wave spawner 配置。
