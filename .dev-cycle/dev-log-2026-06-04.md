## 本轮修复
1. Demo 相机改为跟随玩家，跨房间后不再把玩家留在镜头外。
2. Demo 接入统一 `GameUIManager`，Boss、命卡、撤离和战斗 HUD 有实际接收方。
3. 收束 Demo Tab 输入所有权，避免统一 HUD 与独立面板重复切换。
4. Demo 隐藏无地图数据的空小地图，并移动说明文字避免压住装备位。
5. 正式模式与 Demo 仅在 HP 实际下降时中断撤离，治疗不再误判为受击。
6. Demo 重试撤离前清理旧波次生成器，降低重复节点累积风险。
7. 修复命运卡与撤离中断的程序化音效降级路由。
8. 增加相机、HUD、撤离治疗和程序化音效回归断言。

## 当前内容判断
- 正式入口链路已变更为 `BaseWorld.tscn -> 任务调度室 -> 独立战局场景`，8 房间 Demo 是独立验收场景，不应替代正式入口。
- 核心搜打撤、命卡、武器装配、随机地图、Boss、精英、撤离和基地持久化已有可运行闭环。
- 当前视觉仍以程序生成色块、Emoji 和占位 UI 为主，属于可玩原型阶段。

## 剩余高价值风险
1. 多个集成验证退出时仍报告 ObjectDB、RID 或资源未释放；当前不阻断运行，但会掩盖真实生命周期问题。
2. 背景音乐未接入，`AudioManager.play_music()`、音量设置读取与保存仍为空实现。
3. 关卡选择默认全部解锁，尚未与长期进度和 Boss 击败状态联动。
4. Demo 没有 MapManager 数据，因此本轮隐藏空小地图；后续若把 Demo 作为展示版本，应提供专用路线图。
5. 多份历史设计文档仍描述 5/7 房间 Demo，与当前 8 房间实现不一致。
6. 信标在掉落池中的抽样出现率约为 42%–47%，Boss 池抽样可达 50/50，可能过早消解搜寻和撤离压力。

## 下一轮建议
优先做资源生命周期清理与背景音乐/音量设置接入，然后再进入正式美术替换和关卡解锁规则收束。

## 开放基地架构变更
- 正式入口由 `BaseMenu.tscn` 改为可编辑、可自由移动的 `BaseWorld.tscn`。
- 新增七个 `BaseFacility.tscn` 设施实例，覆盖原大厅的任务、工坊、占卜、保险柜、档案、卡牌收藏和基地管理功能。
- 基地玩家禁用射击，设施菜单打开期间锁定移动。
- 战局继续作为独立场景加载；`LevelSelectMenu` 增加地图场景路径契约，方便未来将不同地图指向不同 `.tscn`。
- 战局结束和死亡返回目标统一改为 `BaseWorld.tscn`。
- 性能边界记录于 `docs/PH13_开放基地与独立地图架构.md`。
- 实际画面复核后收紧设施布局，出生视野可直接看到主要功能区。
- `verify_base_world_flow.tscn` 通过，基地第一版共 92 个节点；全量自动验证更新为 18/18 通过。

## 主题独立关卡框架
- 四个任务入口改为四个独立 `scenes/levels/*.tscn` 场景，不再共享同一个关卡入口场景。
- 独立场景使用轻量 `ThemedLevelEntry` 注入主题并实例化共享 `Main.tscn` 运行壳，避免四套运行节点漂移。
- 新增 `MapThemeProfile` 资源契约，统一描述路径节奏、必出房间、房间权重、怪物生态、事件池与 NPC。
- `MapManager`、`MapGenerator`、`ContentInjector`、`MonsterInjector`、`RoomFactory` 已接入主题资源。
- 新增四套第一阶段主题：冷钢边境、锈蚀铸造厂、孢子深层、深渊档案库。
- 新增轻量主题 NPC 实例化与交互框架。
- 普通怪、伏击、守卫、精英与随从统一受主题生态池限制，Boss 接入主题名称和属性倍率。
- `verify_theme_level_framework.tscn` 与四张独立关卡启动验证通过；全量自动验证更新为 19/19 通过。

## 固定大世界与野外副本入口修正
- 根据设计澄清，`BaseWorld.tscn` 从小型基地 Hub 扩展为“基地 + 连续野外道路”的固定可编辑大地图。
- 新增可复用 `DungeonEntrance.tscn`，四座入口建筑分布在道路两侧并分别加载四张主题副本。
- 正式流程取消任务调度室与基地管理菜单直接选关；玩家必须在大世界中到达对应建筑门口。
- `LevelSelectState` 记录进入时的入口 ID，副本结束返回大世界时玩家会出现在原入口门外。
- 返回远处入口时会重置相机平滑位置，避免镜头从基地跨越整张地图滑动。
- 固定大世界当前为 144 个节点；实际启动、画面检查、入口返回验证及全量 19/19 自动回归通过。
