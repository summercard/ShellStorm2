## 二、词缀系统实现升级

### 6个词缀全部实现（非stub）：

#### 新增词缀：`BulletEaterModifier`（吞弹）
- 精英能存储玩家子弹伤害（最多8颗子弹）
- 每3秒向玩家方向释放吞噬的伤害
- 死亡时释放30%累积伤害
- 配合"霰弹"敌人形成"吸弹反伤"机制

#### 完善词缀：`SpawnOnDeathModifier`（分裂）
- 完整实现：死亡后生成2-5只小怪（tier控制）
- 小怪HP/DMG为基础精英的35%/55%
- 连接enemy_died信号，防止重复触发

#### 完善词缀：`ParasiteModifier`（寄生）
- 完整实现：死亡后给150px内最近的友方怪物回血+增伤
- 回血倍率：tier1=30%, tier2=40%, tier3=50%
- 伤害buff：tier1=25%, tier2=35%, tier3=45%

#### Factory补全
```gdscript
"Elite.BulletEater": return BulletEaterModifier.new(tier)
"吞弹": return BulletEaterModifier.new(tier)
```

## 三、武器种类数值差异化深化

### 目标：每种枪械有明确克制场景和弱点

#### 冲锋枪：从140 DPS → 调整为"近距离倾泻"定位
- 弹容量30发（接近步枪），但reload更快（1.8s vs 2.2s）
- spread略高(0.15)→近距离精准度下降，迫使玩家贴脸
- 与步枪定位区分：步枪=中距离全自动，冲锋枪=近距离开火

#### 狙击枪：从单发55改为58，射速从1.0→1.8
- 原来1秒只能打1发，节奏太慢
- 调整为1.8秒一枪（仍是最慢），DPS略有提升
- 添加注释说明定位：克制中高甲敌人，单发暴击价值

#### 新增枪械：轻机枪（LMG）
- `gun_lmg()`: 伤害12，射速14.0，弹容量60，spread=0.20
- **DPS = 168**，所有枪械最高
- 代价：reload 4.2秒（最慢），换弹空窗期危险
- 定位：多波次压制，撤退时掩护

#### 榴弹发射器数值微调
- 伤害38→42，fire_rate 0.8→0.75，DPS从30.4→31.5
- 新增`explosion_radius: 80.0`字段，为范围伤害提供数据基础
- 添加注释说明：单目标DPS低，范围伤害才是核心价值

#### 新增子弹类型：粘性弹（Sticky Bullet）
- `bullet_sticky()`: 命中后减速敌人30%，持续2秒
- 克制快速追击型怪物（chase类）
- 为命运卡改造提供更多子弹类型选项

## 四、玩家可感知结果

**怪物词缀（精英怪）**：
- **吞弹精英**：被击杀后反吐伤害，玩家需要注意不要站在尸体附近
- **分裂精英**：死亡后生成小怪，击杀后不能完全放松
- **寄生精英**：死亡后强化相邻怪物，增加战斗节奏变化

**武器差异**：
- 冲锋枪：近距离倾泻，换弹快但spread大（近距离有效）
- 步枪：万能中距离，弹容量和DPS平衡
- 轻机枪：持续火力压制，换弹超慢（4.2秒），波次间隙要计划好换弹
- 狙击枪：单发高伤害，精英/Boss战有价值，近战废
- 霰弹枪：近距离5弹丸扇形爆发，单发总伤害高
- 榴弹：范围AOE，清扎堆怪物有奇效
