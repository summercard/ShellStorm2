# 胖子僵尸03运行配置

内容ID `fat_zombie03`，资产ID `ENM-NORMAL-FAT-ZOMBIE03`。本配置是用户授权的新怪玩法配置，复用 Enemy3D 的12态有限状态机。生命、移动、碰撞、伤害、掉落、持久化由 Enemy3D 唯一拥有；视觉适配器仅采样已制作的13段动画，动画结束不反写状态。

## 基础规格

标准站立高2.2米，显示缩放0.7；圆柱碰撞源半径1.10米、高3.142857米，世界半径0.77米、高2.2米。圆柱覆盖躯干，张开的手臂不扩大移动碰撞。第一层无主题倍率时生命696、伤害19，生命为普通近战怪的4倍。追击速度0.60米/秒，巡逻0.30米/秒；人工光和减速仍走共用规则。旧注入器基线生命100、伤害8、速度20.5714286，用于还原楼层/主题倍率，不直接覆盖3D基线。

抱扑范围1.55米，前向半角60度，并要求共用视线检查通过；只在 attack 状态结算一次，不能隔墙或攻击背后的玩家。F0—36为1.2秒前摇，F30以后锁定朝向；F36双掌拍合结算伤害，随后1.3秒收势。命中时启动1.3秒冷却，完整攻击最短约2.5秒加状态切换物理帧；人工光额外延长冷却。根节点无突进，错过目标不追踪补拍。

普通子弹仅闪白并覆盖0.3秒上半身 hit_light，保留腿部基础动作。明确要求打断且暴击、击退≥0.8米/秒或单次伤害达到最大生命8%时进入0.8秒 stagger；轻击不能反复锁死厚血怪。死亡立即退出伤害/AI分组、清除碰撞和结算掉落，但保持原缩放播放2.6秒倒地、腹部压扁与回弹，再回收实例。

## 状态表现

| 状态 | 动作与时间 |
|---|---|
| dormant | idle首帧，暂停表现预算 |
| idle | idle循环；从休眠激活播放awaken 1.2秒；巡逻停止播放move_stop 0.6秒；原地实际转向触发turn_l/r 0.8秒 |
| patrol | move_start 0.4秒接walking 2秒循环 |
| alert | alert 0.6秒，与状态时间同步 |
| chase / search / return | running循环；实际速度影响采样步频，状态决定选段 |
| telegraph / attack / recovery | 同一attack连续采样0—1.2 / 1.2 / 1.2—2.5秒 |
| stagger | hurt 0—0.8秒 |
| dead | dead 0—2.6秒，末帧保持，其他状态复位腹部形变 |

补充动作会被更高优先级战斗状态取消。hit_light是局部替换轨道，采用导入骨骼旋转的权重混合，不生成程序姿势；攻击、硬直和死亡期间不覆盖主动作。

## 正式调用

独立实体场景：`res://scenes/enemies/fat_zombie03.tscn`。实例添加到世界后可直接使用标准默认属性；按关卡生成时先调用 `MonsterInjector.generate_box_enemy("fat_zombie03", floor, floor_level)`，再交给 Dungeon3D 既有生成路径。固定波次可写 `{"monsters":[{"type":"fat_zombie03","count":1}]}`；触发盒`spawns[].type`白名单已接纳该type。通用接口`generate_enemies({"type":"fat_zombie03","count":1,"floor":1})`也可点名生成。不会擅自加入已有随机关卡池。

可玩展示场景：`res://tests/verification/preview_fat_zombie03.tscn`，用于查看姿势、攻击与死亡。专项门禁：`verify_fat_zombie03.tscn`。未知种类返回空配置；现有通用类型的默认行为保持原值。保存/恢复沿用 Enemy3D 的enemy_data、状态时间、位置和旋转协议。

动作美术设计仍以《胖子僵尸03动作设计.md》为主，本文仅登记运行契约。修改数值时同步该文档和专项断言；不通过复制第二套状态机修复表现。
