# Q弹果冻 · 可交互半球

打开 `Q弹果冻_可交互_v001.blend`。本机已安装并启用随附的 `kawaii_jelly_interaction.py` 插件；3D 视图右侧侧栏已准备好「Q弹果冻」标签。

## 怎么玩

1. 点击 **开始鼠标互动**。
2. 左键按住果冻上半部的任意可见表面，拖动即可拉伸、倾斜或压扁。
3. 松开左键，果冻会回弹、反向摆动并逐渐停下。
4. 右键或 Esc 退出互动。滚轮和中键仍用于观察视角。

也可以直接点击「戳一下」「压扁一下」；「自动Q弹演示 / 停止」会循环施加冲量。「恢复圆滚滚」恢复静止半球。

- **弹性**：越大，回弹越快。
- **阻尼**：越小，余晃越久。默认值为弹性 48、阻尼 2.8。
- 底部整个平切面固定，包含圆周和底面中心，拉伸时不会滑动或离开托盘。
- 小眼睛、微笑、腮红和内部小气泡跟随果冻形变。

## 文件和实现

半球为封闭网格，4,610 个顶点；固定切面包含 97 个顶点及其组成的全部底面三角形。弹性控制器使用实时弹簧与阻尼、分步积分、径向体积补偿和次级晃动。它是适合可爱交互的风格化形变，不包含与任意外部物体的通用软体碰撞求解。

本体、表情、摄影展示分别归类。材质包含透光、清漆高光和少量次表面散射。渲染预览在 `renders` 中；底面锁定、弹性回摆、拖拽控制器和实时采样报告也保存在本目录。

更换电脑时：在 Blender 偏好设置的插件页面选择从磁盘安装 `kawaii_jelly_interaction.zip`，并启用插件。无需联网、无额外依赖。插件使用 Blender 自带 NumPy。更新插件前先退出互动，避免在活动的模态操作过程中热重载。

默认保存静止形态；重新打开时会恢复初始半球。实时互动不依赖时间轴播放。
