# v019 参考深化重点

授权：原17资产包 + 116_二楼地板色彩深化_资产包。依据原始参考图，继续v018，不覆盖v017/v018。

第一视觉层：床正面与沙发区。软包使用有圆润边界的低分段曲面，床罩沿前缘下垂；床下提手、窄滚边、小桌打开的书与绿植构成近景层次。沙发保留三座独立轮廓，增加倾斜靠背、斜放抱枕、有重量的织毯。上方沿原工位装饰归属重做旅行海报，并补参考图笼式暖壁灯。

第二视觉层：木地板。36排错缝长条木板；只使用原有标高内的顶面和浅倒边，单板独立，木纹属于宿主板；4种邻近胡桃木色块，纹理弱于拼板大节奏。无新增贴图、无高密度细分、无逐板碰撞。

第三视觉层：洞洞板、EXPLORE、植物。海报采用填充山峦、步道、越野车、标题与小字；工具有螺丝刀、钳子、开口扳手等不同剪影；垂藤有主茎、交替叶片与舒展冠部，控制叶片段数。

验收：保留原镜头，另用相同临时无描边材质检视灯光和相机渲染前后四视图。临时灯光与关闭描边仅用于可重复的材质检查，不写回原场景全局设置。禁止为预览改变范围外对象。
