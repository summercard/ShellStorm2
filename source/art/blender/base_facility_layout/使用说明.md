# base_facility_layout · 使用说明

## 当前正式来源

- 当前主基地母版：`source/base_facility_runtime_layout_hq_v026.blend`
- 当前模块化房间源：`assets/art/environments/base_facility_3d/source/env_base99_modular_room/env_base99_modular_room_assets_clean_v006.blend`
- 当前梯下挡板源：`assets/art/environments/base_facility_3d/source/env_base99_mezzanine_underdeck_blocker/env_base99_mezzanine_underdeck_blocker_source_v003.blend`
- 当前 L 型转角源：`component_packages/architecture/base_corner_l_5m/base_corner_l_5m_source_v024.blend`

规则：当前文件为正式基线；后续更新时创建更高的 `v###`，新文件完成后，最新版本自动成为正式来源。

## 查看当前完整基地

打开：

`source/base_facility_runtime_layout_hq_v026.blend`

如需查看历史版本，打开对应 `source/base_facility_runtime_layout_hq_v0XX.blend`。历史版本不得作为后续导入的默认输入。

## 修改当前基地

1. 从当前最高 `v###` 源复制出下一版本，例如 v027。
2. 只在 v027 上进行几何、材质或接口修改。
3. 不在当前正式版本上覆盖发布过的几何或结构。
4. 纯材质重复项清理属于基线规范化，可对当前正式源执行，但必须重新计算所有派生 SHA。
5. 完成后运行材质规范化和验证：

```powershell
blender --background --python tools\blender\normalize_current_base99_materials.py -- `
  --blend source\art\blender\base_facility_layout\source\base_facility_runtime_layout_hq_v026.blend
```

## 导出与导入

1. 从最高源版本创建同版本 `export/v###/`。
2. 运行对应导出脚本，只输出授权资产包。
3. 不覆盖历史导出；新内容使用新版本目录。
4. 更新 GLB 后运行：

```powershell
python tools\asset_pipeline\normalize_scene_facility_glb_materials.py `
  --project . --referenced-only

python tools\asset_pipeline\repair_base99_asset_lineage.py --project .

python tools\asset_pipeline\sync_base99_current_ledger.py --project .
```

5. 用 Godot 执行正式重新导入：

```powershell
godot --headless --import --path .
```

## 材质规则

当前场景/设施只允许四个材质角色：

- `01_精工金属_紫色骨架`
- `02_细腻哑光_青绿大面`
- `03_清漆反光_紫粉点缀`
- `04_柔和自发光_UI灯光`

禁止：

- `.001`、`.002` 等重复材质
- `_v018公共色盘`、`_全息增强_v022` 等版本化副本
- Godot 中出现同一角色的多个材质资源
- 布局直接实例化裸 GLB

Godot 后处理脚本必须把同一角色归并到一个材质资源，并统一绑定：

`assets/art/shared/palette/设施低亮多巴胺色盘_10x10_512.png`
