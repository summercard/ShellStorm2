# 基地99层独立资产包 v010

本目录与 `base_facility_runtime_layout_hq_v010.blend` 的末级资产 Collection 一一对应。

- 共 102 个独立资产包，其中 36 个地砖包保持 v009 坐标、几何和归属不变。
- 二楼床、床头柜、床头灯、地毯、隔断帘、沙发、茶几、坐墩、工位、办公椅、霓虹、三类收纳柜、两个收纳箱、墙面装饰和植物均单独归档。
- 西北 L 型楼梯原结构保持不变；新增表面深化仍归宿主楼梯包。东侧上行过渡楼梯为独立建筑资产包。
- 每个目录的 `asset_manifest.json` 记录对象、世界包络、材质角色、动画、预期导出名和当前导出状态。
- 公共色盘只引用 `assets/art/shared/palette/设施低亮多巴胺色盘_10x10_512.png`。
- 本批未制作独立 GLB、碰撞、LOD 或 Godot PackedScene。
