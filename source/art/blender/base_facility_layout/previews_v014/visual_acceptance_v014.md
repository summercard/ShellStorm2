# v014 楼梯及梯下设施视觉高还原验收

## 结论

本批次范围通过视觉高还原验收与技术验收。验收只覆盖左侧主楼梯、右上楼梯及左楼梯下方设施，不代表历史场景全部资产通过最新技术规范。

## 技术验收

- v014 范围：139 个网格，16,090 / 16,090 面为有效单格安全区 `PaletteUV`。
- 材质：4 个共享材质；无新增材质、无废弃材质。
- UV：活动编辑层和活动渲染层均为 `PaletteUV`，无额外 UV；材质节点显式读取 `PaletteUV`，图像插值为 Closest。
- 输出：源组件默认隐藏，整合输出默认显示；主体与自发光分离。
- 碰撞：3 个连续斜坡、2 个平台、6 个栏杆阻挡、4 个设施包围盒，全部独立且不参与渲染。
- 接口：左楼梯包围盒 `[-14.8, 8.21, 0.0]..[-4.67, 14.8, 7.128]`；右楼梯包围盒 `[12.305, 10.17, 5.996]..[14.255, 14.92, 9.34]`，与修改前一致。
