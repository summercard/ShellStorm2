## 修改当前区块00

**不要手改 `.blend` 里的实例**，也不要手改 `.layout.json`。摆位真源是脚本：

```text
_scratch/build_block00_master_office.py
```

流程：

1. 复制当前最高版本为下一版本（例如 v003），改脚本里的 `VERSION` 常量。
2. 在脚本的 `ROOMS` 表里改房间尺寸 / 门位 / `plane_priority` / `use_corner_l`。
   - **门位 `at` 必须落在 5m lane 中心（…, -2.5, 2.5, 7.5, …）**，否则门墙与墙槽对不上。
   - `plane_priority` 决定共享墙平面归哪个房间所有，**同一平面只能有一个房间声明**。
   - `use_corner_l = false` 的房间四角用 12 段直墙（B 套），`true` 才用 L 角件补角。
3. 重跑构建：

```powershell
blender --background --python _scratch\build_block00_master_office.py
```

脚本会**自己**做 5 项证据校验；只要输出里没有 `=== 结果：PASS ===` + `BLOCK00_BUILD_PASS`
就是失败，去看它打的红行（语义失败标记由 `raise` / `printerr` 打，不一定带 `ERROR:` 前缀）。

4. 重跑渲染出新的验收图。

### 改组件用量的注意

本布局**不拥有几何**，全部实例引用既有组件包。要加新件，先确认 AssetID 已在账本里 ——
**AssetID 已存在必须升级既有行，不得新增**（否则 `duplicate_asset_id`）。本版没有新增任何 AssetID。

## 库原点陷阱（改摆位必读）

Blender Collection Instance 的实例世界变换 = `empty.matrix_world @ 库对象.matrix_world`。
组件包在库里的原点**不是世界原点**，所以摆位代码必须逐包补偿：

```python
empty.location = target - Rz(rotation) @ anchor
```

且**读库对象变换必须走 depsgraph**：

```python
deps = bpy.context.evaluated_depsgraph_get()
for inst in deps.object_instances:   # 这里才是真实 matrix_world
    ...
```

`libraries.load()` 之后直接读 `obj.matrix_world` 会拿到**陈旧的单位矩阵**，算出来的包络会离谱地大。

## 命名长度陷阱

Blender ID 名上限 **63 字节（UTF-8）**，中文 1 字 = 3 字节，超长**静默截断**。
给任何集合 / 对象起中文名时，名字长度务必控制；本脚本在建集合处加了断言，超限直接报错。
