# 楼梯间原位组件拼装 v015

当前编辑源：`whitebox_tower_stairs_v015.blend`。组件JSON位于`../data/whitebox_tower_stairs_v015.json`，右侧工具读取同名场景工作副本。

以v013实际网格为原位真值，A根(-32.5,0,0)、Z旋转180°；B根(32.5,0,-9)。两个楼梯间各有32块楼板（下层18、中层6、上层6、连接板2）、31块围护/门口护栏、2跑楼梯，共130个组件。墙板以5m模数及固定收边件拼接，所有对象和分组Scale均为1。为保留原型轮廓，原围护按11.9m裁切规格制作，通用母件仍为12.9m。

一个直梯剖面母组件复用四次，另一跑旋转180°，共享23个子网格；A下跑按原源缺口隐藏一侧护栏。可编辑总高度、坡度和水平长度，调整时保持踏步厚度，不允许整件缩放。原型原点位于直梯上端。调整后需把坡脚、坡顶和相接平台重新对齐。

Blend内嵌组件JSON，网页重新打开时恢复参数化组件与当前根变换。原位核对见`../data/assembly_verification.json`，同镜头对比图见`../renders/`。未重新导入Godot。
