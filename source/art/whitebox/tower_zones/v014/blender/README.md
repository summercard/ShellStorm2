# 楼梯区白盒 Blender v014

本版已被v015原位双楼梯间拼装替代，仅供回退。历史文件为 `whitebox_tower_stairwell_components_v014.blend`，仅包含一套楼梯间装配：`01_楼板`、`02_墙壁`、`03_楼梯`。

直梯源只保留一个 `楼梯间直梯_母组件`。A跑直接实例化，B跑引用同一Collection并绕Z轴旋转180度。默认水平长度15m、坡度21.8014°、升高6m、宽6m、20级。工具侧修改水平长度或坡度时重新生成踏步，不以缩放拉伸网格。

本版仅更新白盒与制作工具，不触发Godot重新导入。v013及更早版本只用于回退和追溯。
