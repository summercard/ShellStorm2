# 战局区块通用组件库 v001

入口：[战局区块_通用组件库_v001.blend](战局区块_通用组件库_v001.blend)。来源为主路内容房02数据机房 v003，原房间及白盒未修改。

43个通用包按7类展开：服务器机柜14、工作终端4、中央设备岛3、维修与机箱10、门框与标识3、环境陈设3、环境支持6。每包具有独立 Empty 根节点，组件网格相对根节点以 XY 居中、底部 Z=0；主体与自发光网格保持分离。`01_制作组件_按设施拆分` 默认隐藏，`02_游戏输出_独立资产包_v001` 默认显示。

在其他 Blender 文件中使用时，Append `Collection` 下单个“通用包”集合；不要直接复制总陈列层。清单位于 `component_packages_v001/`。长距离墙面管线与地面线缆仍按环境支持包使用，实例化后需按目标房间重新布局，不视为固定长度建筑模块。
