# 战局区块通用组件库 v002

入口：[战局区块_通用组件库_v002.blend](战局区块_通用组件库_v002.blend)。v001保留回滚，本版统一组件朝向、移除旋转后完全相同的副本，并加入墙壁和地板分类。

所有有正面语义的组件统一面向本地 `+Y`；地板采用无正面语义的规范四分之一转角。每包独立 Empty 根节点，XY居中、底面Z=0。可通过 Append `Collection` 下的单个“通用包”使用。

82个房间来源包中，房间专属30×25m底板 `floor_base` 不作为通用模块；其余81个候选经旋转规范化后合并4个完全相同副本，最终77个包：墙壁7、地板30，其余为设施与环境支持。真实造型、损坏状态或地砖附着细节不同的变体继续保留。去重对应关系见 `component_packages_v002/deduplication_report.json`。
