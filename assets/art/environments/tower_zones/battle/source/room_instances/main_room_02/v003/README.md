## 使用与归类

- `01_制作组件` 保留可编辑源，默认隐藏；`02_游戏输出_独立资产包_v003` 默认显示。

- [磁盘目录树](component_packages_v003/tree.txt)及[总清单](component_packages_v003/catalog.json)与 Blender 末级集合对应。每包清单记录原点、方向、包络、对象和版本。
