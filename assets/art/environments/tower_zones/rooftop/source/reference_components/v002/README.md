# 天台参考组件库 v002

当前源：`天台区块_参考组件库_v002.blend`。上一版v001完整保留。

本版44包、45个整合输出网格、211个制作网格，四共享材质。新增7个带藤蔓版本：女儿墙外角/内角、房间实墙/窗墙/门洞墙、外墙实墙/窗墙。原直段挂藤墙与独立藤蔓继续保留。叶片与墙体在制作集合中可分别编辑。

门口改为实质加厚结构：门柱深1.10m、门楣深1.16m、门槛深1.55m；内侧仍保留3.68×0.18×6.8m门扇，暖灯安装到厚门楣正面。门边两盆植物在示例装配中稍微外移，避开加厚门柱。

外墙**主体**仍严格5×0.30×11.9m，未来逻辑/阻挡5×0.30×12m。挂藤总包络另含叶片，不可直接用总包络生成墙体碰撞。`structural_core_offset`和`sockets`明确记录结构基准；保持每包XY居中、底面Z=0的可编辑原点。

Blend内两个Scene：组件库（按10类独立包排列）与参考拼装展示（Collection实例）。37份原组件中，除门包之外的36份制作网格、输出网格、材质、UV、世界变换、修改器及动画签名均与v001一致。

`component_packages_v002/`与输出Collection逐包对应；原用户参考图只保留一份于`../v001/reference/rooftop_reference.png`。预览位于`renders/`，厚门口近景为`06_厚门框与藤蔓近景.png`，44件总览为`05_全部组件总览.png`。

范围、尺寸、锁区与材质证据位于`qa/`。本版未导出GLB、未创建PackedScene、未生成Godot碰撞或LOD，正式90×80m天台布局保持原状。当前交付为Blender源与模块化输出。
