# 天台参考组件库 v002

当前正式主库：`天台区块_参考组件库_v002.blend`。上一版v001完整保留。

本库保留 v002 的版本身份，但女儿墙几何已于 2026-09-20 按主人确认的方案 A 写回正式主库：直段与外角总高统一为 **0.80m（含压顶）**，厚度保持 **0.50m**；结构为基座带 0.10m + 平整墙板 0.64m + 压顶带 0.10m，取消中间密集竖向分块。直段另嵌入 DMG-A 崩顶、DMG-B 贯穿、DMG-C 塌脚三件可复用破损变种，端头带保持可拼接。

本版现为 47 包、含三件新增破损女儿墙源组件；四共享材质。原有带藤蔓版本继续保留，叶片与墙体在制作集合中可分别编辑。

门口改为实质加厚结构：门柱深1.10m、门楣深1.16m、门槛深1.55m；内侧仍保留3.68×0.18×6.8m门扇，暖灯安装到厚门楣正面。门边两盆植物在示例装配中稍微外移，避开加厚门柱。

外墙**主体**仍严格5×0.30×11.9m，未来逻辑/阻挡5×0.30×12m。挂藤总包络另含叶片，不可直接用总包络生成墙体碰撞。`structural_core_offset`和`sockets`明确记录结构基准；保持每包XY居中、底面Z=0的可编辑原点。

Blend内两个Scene：组件库（按10类独立包排列）与参考拼装展示（Collection实例）。37份原组件中，除门包之外的36份制作网格、输出网格、材质、UV、世界变换、修改器及动画签名均与v001一致。

`component_packages_v002/`与输出 Collection 逐包对应；原用户参考图只保留一份于`../v001/reference/rooftop_reference.png`。既有 `renders/05_全部组件总览.png` 是写回前的 44 件历史总览，不含三件破损变种；女儿墙当前状态以主库 Blend、47 件 catalog 与 Godot 近距验收图为准。

范围、尺寸、锁区与材质证据位于 `qa/`。女儿墙直段、外角及 DMG-A/B/C 已导出 GLB，并由 `assets/art/props/dungeon_3d/prp_rooftop_parapet*.tscn` 接入 Godot；碰撞仍由 `TowerFloorStage3D` 统一生成，Prefab 仅负责视觉。其余参考包仍按原 Blender 源与模块化输出口径管理。
