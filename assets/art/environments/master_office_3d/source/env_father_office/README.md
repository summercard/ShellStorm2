# 98F 父亲办公室 Blender 原始源

当前交付：`v002/env_father_office_source_v002.blend`。

本房间是区块00最里面的 `master_office`，对应运行时 `floor_01_exit`。沿用项目 v002 布局数据：15×20m，Blender 世界 X 为 −40～−25m、Y 为 −10～10m；东入口位于 Y=2.5m；可见墙高11.9m、逻辑墙高12m。未修改运行布局、门或开场剧情。

## 文件与编辑

- 总母版：24种组件、270个集合实例，四类共享材质，外链项目公共色盘。
- `01_制作组件`：隐藏的可编辑零件，按组件归类；圆角等修改器保留。
- `02_游戏输出_实例布局`：引用烘焙组件母版的集合实例；重复摆放不复制网格。
- `90_展示与验收`：固定全景、俯视、近景相机及灯光。
- 默认视图层以参考图方式剖视。切换到 `完整围护_接口核对` 视图层可以检查南墙、东墙和入口；渲染此层时需勾选该层“用于渲染”。默认层中的 `参考剖视隐藏墙` 集合被排除，墙体并未删除。
- `component_packages/<类别>/<组件>/`：每种组件单独的 `.blend` 与清单；打开即可查看局部原点居中的输出和隐藏制作源。

`component_plan.json` 在正式网格创建前冻结；`component_instances.json` 记录室内局部摆位，房间世界基准为 (−32.5,0,0)。正式引擎布局仍由项目原布局拥有，不自动回灌这些实例。

## 验收与范围

全景、俯视、近景见 `v002/preview_*.png`。任务验收见 `task_acceptance.json`，四材质及逐面UV验收见 `material_acceptance.json`，独立组件重开验收见 `package_acceptance.json`。

参考图的长沙发、蓝灰地毯、展示柜、枯植、倒柜、散页和坍塌墙构图已制作。房间高度按项目的11.9m契约保留，因此墙面相对于家具比参考图更高；玻璃采用四角色材质下的侧片与开放正面表现。参考图中的细微布料破损、污渍与透明玻璃厚度尚未逐像素复刻，不把技术通过等同于用户视觉确认。

此交付仅为 Blender 源；未导出GLB、未创建PackedScene、未接入Godot。资产主表登记 `ENV-BATTLE-FATHER-OFFICE-SOURCE`，状态为“Blender源已完成”。组件为该源的组成部分，无虚构Prefab登记。

v001为初次构建历史，存在越界与破墙高度问题，仅用于回溯；正式使用v002。两个版本的旧源均保留。
