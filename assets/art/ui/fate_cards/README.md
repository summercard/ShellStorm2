# 命运塔罗卡面集

命运卡（`FateCard`）的**图卡呈现**资源。功能、抽卡概率、正逆位判定与存档字段由代码负责，本目录只提供图片。

## 命名

```
ui_fate_card_<stable_card_id 去掉 fate_ 前缀>_v001.png   ← 卡面
ui_fate_card_back_v001.png                              ← 卡背（全卡共用）
```

例：`fate_gun_on_gun`（魔术师）→ `ui_fate_card_gun_on_gun_v001.png`

## 规格

| 项 | 值 |
|---|---|
| 卡面 | 统一画布 640×1024px，RGBA；卡面内容等比适配，卡外圆角区域透明 |
| 卡背 | 统一画布 640×1024px，RGBA；双兔对称无标题专用卡背，卡外圆角区域透明 |
| 格式 | PNG / RGBA |

## 呈现层

`src/weapons/FateCardView.gd` —— **只做表现**，不读写任何玩法数据。四个入口共用：

- 局内三选一 `src/world3d/Dungeon3D.gd`
- 占卜屋 `src/ui/DivinationMenu.gd`
- 工作台 `src/ui/WorkbenchPanel.gd`
- 收藏室 `src/ui/FateCardCollectionMenu.gd`

`art_for(card)` 在找不到对应文件时**返回 null**，调用方回退到程序绘制的卡面。

> **补图无需改代码。** 把图片按上面的命名放进本目录、重启编辑器完成导入，该卡即自动切换为图卡。

逆位由呈现层处理：**只把卡面图案绕中心旋转 180°**，卡下功能文字层不参与旋转，因此保持正向可读。

## 当前覆盖

48 张可玩命运卡**全量覆盖**（48 卡面 + 1 卡背）。`FateCardView.art_for()` 的缺图回退分支保留为容错——将来新增卡牌若暂无美术，仍会自动回退程序卡面而不崩。

## 来源与统一处理

- **30 张**取自用户提供的 7 张塔罗牌阵合集（每张 5×2 拆为 10 张单卡，共 70 张），按「每张牌挑最统一的一版」选取：
  - 优先中文标签系：`07 霓虹绿兔形机器人 → 06 霓虹兔机 → 04 霓虹绿兔子机器人 → 03 霓虹绿小兔 → 01 霓虹绿机械兔`
  - 兜底全息套 `05 霓虹绿全息`（唯一覆盖圣杯 / 月亮系的套系）
  - 选版分布：`07→10、01→8、05→7、04→2、03→2、06→1`

- **本轮全部替换为用户新制作的霓虹兔机塔罗牌组**：从桌面 `新塔罗牌` 目录的 8 张 5×2 牌阵中按牌面中文标题建立映射，正式接入当前 48 张运行牌；另使用 `ChatGPT 图像 2026年10月9日 11_15_56-7.png` 第二排第五张的双兔对称无标题图作为统一卡背。旧 49 张资源已备份至 `outputs/new_tarot_install/backup_old_49_png/`。

- **18 张**为按同风格补生成（历史版本说明，已被本轮用户新牌组替换）：

| 处理 | 目的 | 依据 |
|---|---|---|
| **绿色归一化** | 统一色相与峰值亮度 | 以 G 通道为亮度权重重映射到既有卡面核心绿 `#02FC8E`；黑仍黑、线稿层次保留 |
| **线条加粗**（亮度最大值滤波 size=2） | 统一线宽观感 | 生成图线条密度 0.161，既有卡面 0.389（**细 2.4 倍**）；加粗后 **0.383，差距 1.6%** |

> 后续补图请照这两步处理，否则新图会明显比现有卡面偏细偏暗。

台账登记见 `assets/registry/ledgers/ShellStorm2_UI账本_v001.xlsx` 第 22 行 `UI-ATLAS-FATE-CARD`。
