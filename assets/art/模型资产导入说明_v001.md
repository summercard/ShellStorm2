# 正式模型资产导入说明 v001

## 运行资产与源文件

- Godot 运行时只引用 `components/**/*.glb` 与 `runtime/**/*.tscn`。
- `source/**/*.blend` 是可维护源文件，并由 `.gdignore` 排除，不参与 Godot 导入及游戏打包。
- 公共色盘位于 `shared/palette/`，包含可维护 PSD 与 512×512、10×10 PNG。

## 坐标与比例

- 基地设施：底面 `Y=0`，正面朝 Godot 局部 `-Z`；放置后必须让局部正面朝房间内部。
- 枪械：根节点与 `GripSocket` 均为握把原点，枪口朝局部 `-Z`。
- 枪械统一挂点：`SupportHandSocket`、`MuzzleSocket`、`MuzzleAttachmentSocket`、`ScopeSocket`、`MagazineSocket`、`StockSocket`、`TacticalSocket`、`MutatorSocket`。
- 经游戏内比例复核，正式枪械在美术基准上统一放大 30%，全长控制在约 1.17–2.02 米。
- 交互基地设施沿用上一轮游戏内验收尺寸，高度控制在 3.28–3.60 米。
- 墙边装饰设施按 5 米地板模数重新制作：赛博储物站约 `5.00×1.62×3.90m`，复古游戏电视站约 `4.99×3.30×4.82m`，保持整套模型和附件等比例。

## 材质与 UI 色盘

- 枪械最多 3 个表面材质：金属、哑光、清漆反光。
- 设施最多 4 个材质，在上述三类之外增加柔和自发光。
- 颜色只由单一 `PaletteUV` 色盘通道控制；导出时改名为唯一 `UVMap`，使用最近邻采样。
- 自发光网格独立于主体，GLB 自发光强度固定在柔和范围，禁止白色过曝。
- 设施使用独立的低亮多巴胺色盘；大面积主体控制在约 20%–30% 明度，高亮色仅作小面积点缀，由独立 UI 自发光承担视觉焦点。

## 已接入映射

- `mission_operations` → 战术情报指挥桌。
- `weapon_workshop` → 赛博维修工作台。
- `mission_operations` 与 `weapon_workshop` 从 `v003` 起不再内嵌座椅；战术指挥椅与赛博维修圆凳分别作为 `decor_props` 独立 GLB/PackedScene，可在基地美术层单独移动、旋转或隐藏。
- `base_vending` → 科幻自动贩卖机。
- `locker_station` 与 `retro_tv_station` 使用 `v002` GLB，作为基地西侧墙边纯视觉装饰实例化；不注册 `base_facility`、不显示交互标签，也不附加碰撞盒。
- 维修工作台的大面积哑光青绿色由色板 `(3,4)` 调整为同色域更深的 `(2,4)`，自发光 UI 色块保持不变。
- 7 把现有玩法枪在 `WeaponModel3D.GUN_VISUAL_SCENES` 中映射到独立枪械场景；其余 11 把只进入未来资产池。
