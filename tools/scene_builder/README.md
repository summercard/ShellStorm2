# 场景工坊 · Godot组件场景编辑器

项目启用 **ShellStorm Component Scene Builder** 后，右侧完整栏目显示 **场景工坊**。新版面板标记为 **r6**，插件版本为1.2.0。若面板被其他标签遮住，点击右侧“场景工坊”标签；可用Godot原生停靠菜单移动或浮动。

## 从打开场景到拼装

1. 顶部 **打开 → 关卡房间**：选择“远征03”和地图种子，点“读取关卡”。工具在独立进程中运行正式场景，从真实房间提取壳体、墙高和门位；例如种子77003244产出28间2.8m矮墙房间。相同种子复现同一张生成地图，列表不等于正在运行会话的实时镜像。选中房间双击打开：已有美术直接进入，首次创建正式可编辑场景，之后保存由游戏自动按相同房间ID/尺寸/门位读取。切到 **美术场景 / 参考模板** 可浏览历史目录；rt/cr/EGT静态参考保留11.9m，不代表远征03游戏实际使用。
2. 顶部 **新建**：搜索白盒模板，例如“远征03”，选择后另存为自己的美术TSCN。此入口用于额外参考模板；优化游戏内远征03房间请用“打开 → 关卡房间”。白盒模板走新建流程，保留原文件。当前来源包括rt房间、cr通道及EGT共享参考；共享参考不变成远征03独占资产。
3. 选择组件套件和类型，点图片卡片。下方3D预览可拖动旋转、滚轮缩放和复位；卡片区与预览区之间可拖动分隔条，关闭“3D”可扩大卡片区。
4. 顶部八个小按钮选择 **选择 / 放置 / 笔刷 / 矩形 / 直线 / 擦除 / 点光 / 聚光**，当前模式高亮。操作模式使用按钮，不使用下拉菜单。
5. 在3D视图左键放置或拖刷；矩形、直线各点击两点。Q/E旋转90°，Esc返回原生选择，Alt+鼠标保留原生导航；Ctrl+Z撤销整笔。
6. 顶部 **保存** 或Ctrl+S。工作台的美术场景采用原生保存并跳过场景缩略图生成，避免Godot4.7.2已复现的缩略图保存错误。脚本编辑器或其他Godot弹窗中的快捷键仍交给原生编辑器。更多“···”提供另存为、刷新组件、重新载入工作台和操作提示。

## 常用设置

底部 **吸附** 关闭时保留真实鼠标落点，可自由摆放。打开后按间距吸附；**选项 → 放置** 可以调整间距、标高、角度、笔刷大小、格心/墙边相位、碰撞表面贴合、房内裁切与门口保护。铺满地面和检查布局也在此页。5m地砖通常使用5m间距与0.08m标高，按具体组件原点调整。

**选项 → 参考** 显示白盒已加载、隐藏、未关联或路径错误的状态；提供显示开关、透明度、关联/更换及重载。关联可撤销，保留原有组件摆位。

**选项 → 灯光** 调整创建时的能量、范围和阴影。用顶部点光/聚光按钮放下灯后，使用原生移动工具与检查器修改位置、颜色等属性；检查器与工作台可通过右侧标签切换。

组件轮廓绿色表示可放，红色表示越界或占用受保护门口。连续笔刷是组件式铺放，支持同格地砖替换、防重复及单批4096预算；不包含地形雕刻或纹理权重绘制。

## 读取反馈与恢复

打开场景和组件资源时，底部先显示进度/阶段与耗时；只有原生编辑器切换到目标场景后才显示打开成功。读取失败会给出原因和 **重试**；读取阶段可取消工具后续处理，保留当前场景。Godot开始原生实例化后不显示可强制取消的承诺。

场景列表先显示扫描状态，再后台读取元数据。缩略图按当前可见页生成，显示完成数量；切换组件只应用最后一次选择的结果。编辑器空闲时缩略图也会推进，不需要晃动鼠标。若Godot另有未处理弹窗，工作台说明原因并提供重试。

脚本更新后会检测控件树的构建标记并重建旧面板，同时保留场景、画笔参数与原生撤销。也可用“··· → 重新载入工作台”手动恢复。

## 保存、来源与维护

唯一组件目录为共享catalog。正式TSCN保存组件实例引用、摆位及作者灯光；同路径迭代Prefab后沿引用生效。r6的WhiteboxShell是实际房间结构的一部分，保留原有墙地和碰撞，允许在正式场景内迭代；额外参考模板、画笔与3D预览辅助不进入存盘，工具代码不进入发行包。缩略图缓存位于`.godot/editor/scene_builder_thumbnails/`。

场景索引来自正式room_instances目录、场景元数据与现有关卡设计源；不重命名文件、不维护第二套登记。工具输出是美术布局；flow种子和游戏玩法仍由关卡模块负责。真实房间美术沿既有静态布局入口回接到`runtime_rooms/<房间ID>_<几何签名>.tscn`；尺寸/局部门位不匹配时回退原白盒，改动不改变随机生成。不要手动移动ConnectionPorts或改来源签名；要编辑另一种门位，请重新读取对应地图。

设计：[组件场景编辑器设计](../../docs/v0.1/design/组件场景编辑器设计.md)；本轮记录：[r6实际关卡来源与回接](../../docs/v0.1/development/2026-10-29_scene_builder_runtime_source.md)。

## 验收入口

启动前隔离APPDATA与LOCALAPPDATA，输出目录使用工程外ShellStorm2-work。

```text
godot --headless --path . --script res://tools/scene_builder/test_layout_model.gd -- <测试输出目录>
godot --headless --path . --script res://tools/scene_builder/test_workbench.gd
python -X utf8 tools/scene_builder/runtime_capture.py --engine <Godot绝对路径> --job <唯一任务名>
godot --headless --path . --script res://tools/scene_builder/test_runtime_source.gd -- <测试输出目录>
godot --headless --editor --path . res://tools/scene_builder/examples/component_room_demo.tscn -- --scene-builder-test
godot --editor --path . res://tools/scene_builder/examples/component_room_demo.tscn -- --scene-builder-test --scene-builder-capture <截图绝对路径>
```

编辑器专项会真实切换到独立测试场景，验证打开/失败/取消/重试和UI重建；建议在隔离工程运行。验收结果与原工程其他并行任务的错误分别见开发记录，不能把专项断言通过等同于整工程通过。
