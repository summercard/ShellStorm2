# 办公室03 - 日式动画风格微缩办公室制作提示词

我开着 Blender，同时开着 MCP。请严格按照 `save/办公室03_参考布局/scene.json` 的 Blender Z-up 数据结构，制作一间日式现代创意公司的室内办公室微缩场景。以第三视角观察整个空间，整体像一个可以自由拖拽、旋转、缩放观看的精致三维建筑模型 / 小型办公景观，最终画面不出现任何 UI 界面元素。

画面采用高精细三渲二卡通渲染，强调清晰轮廓、干净色块和柔和明暗层次。空间基调为原木暖色、米白、浅灰与低饱和石墨色，点缀抹茶绿、雾蓝、樱粉和暖橙灯光。整体兼具日本动画中的安静治愈感与现代创意办公室的秩序感：有人长期使用、正在运转，但此刻没有人物，像加班结束后被定格的一幕。

## 固定元素 - 布局约束，必须严格遵守

以下 `98` 个固定组件的数量、类型、坐标、尺寸、旋转和缩放必须完全由布局数据决定，不得移动、删减、复制、替换类型或改变实际空间参数。只允许在原型包围盒内优化造型、材质和结构细节。

- `36` 块固定地板：每块 `5m x 5m x 0.1m`，组成 `30m x 30m` 办公室地面。设计为浅灰暖调办公地砖与局部原木导向带，保留每块地砖边界和细微接缝。
- `11` 面固定墙壁：包括四面外墙和七面功能隔断。墙面为米白细砂质感，下半部可加入浅木护墙条、踢脚线、玻璃提示条和门牌，但墙体包围盒不得改变。
- `7` 张固定办公桌：日式现代浅木桌面、深灰金属桌架、圆角收边、抽屉柜和完整线缆槽。桌面可增加键盘、鼠标、便签、文具、文件托盘和小型绿植。
- `13` 把固定办公椅：雾蓝或石墨灰人体工学椅，带网布靠背、坐垫、五星脚和脚轮；会议椅与工位椅可以通过面料配色区分，但尺寸与锚点不变。
- `7` 台固定显示器：薄边框办公显示器、金属支架与底座，屏幕呈现抽象低亮工作界面或待机渐变，不显示真实软件 UI 和可读隐私数据。
- `3` 个固定文件柜：浅灰金属与浅木混合柜体，带抽屉分缝、标签夹、拉手和少量分类色标。
- `3` 组固定书架：原木框架、开放式层板，陈列项目资料册、建筑与设计书、档案盒、样品盒和少量绿植。
- `4` 台固定打印机：白灰或深灰一体式办公打印机，包含纸盒、出纸口、扫描盖板、待机灯和少量纸张。
- `1` 台固定饮水机：米白机身、半透明蓝灰水桶、冷热水龙头、接水盘和纸杯收纳。
- `1` 张固定会议桌：原木或木灰复合桌面、深灰底座，桌面布置会议资料、便签、马克笔、无线会议扬声器和水杯。
- `2` 块固定白板：铝灰细框、米白板面、笔槽和磁吸圆点；一块承担行政排期，一块承担会议讨论，可绘制抽象流程线与无敏感信息的色块便签。
- `2` 樘固定门：日式现代浅木门扇、窄玻璃观察窗、金属门把和清晰门框，保留主入口与行政入口的方向。
- `4` 扇固定窗：东侧连续采光窗，原木与深灰混合窗框、玻璃和可动百叶 / 纱帘，形成午后斜射光。
- `1` 张固定休息桌、`2` 把固定休息椅、`1` 个固定休息区矮柜：形成西南角安静茶歇位，桌面可摆茶杯、杂志和一小碟点心。

## 空间功能与布局叙事

办公室主体位于画面中心，并严格遵循布局中的空间分区：

- 北侧为行政与支持区：保留左上独立工位、北侧文件柜、打印机、白板、饮水机和行政入口，表现资料管理、打印补给和日常排期功能。
- 东侧为多人协作工位区：两组双人工位与一组南侧工位沿东窗布置，保持显示器、桌椅朝向一致；增加桌下理线槽、插座模块、耳机架、项目便签和统一桌面收纳。
- 中央为资料检索区：三组书架与中央文件柜形成低密度资料岛，保留环形通道；通过书脊色标、档案盒标签和少量展示样品形成视觉焦点。
- 南侧中部为独立会议室：会议桌、六把会议椅和会议白板严格按数据摆放，加入桌面会议扬声器、散落但有秩序的笔记、磁吸便签和一只未喝完的咖啡杯。
- 西侧中部为打印与文件支持区：打印机、文件柜和隔断形成后勤工作带，地面保持通畅。
- 西南角为小型休息区：休息桌椅、矮柜和辅助打印机按照固定位置组成茶歇角，可加入咖啡罐、陶瓷杯、杂志、纸巾盒和藤编收纳篮。
- 南侧主入口与北侧行政入口之间保留清晰主通道；中央资料岛、会议室入口和东侧工位之间不得被自由装饰堵塞。

## 增加的办公室专属内容

在不改变固定元素的前提下，增加以下非固定细节，保持克制且不喧宾夺主：

- 入口处的木质公司铭牌、伞架、访客拖鞋架和小型迎宾绿植。
- 工位桌下的理线槽、插线板、束线带、主机箱、脚踏板和个人收纳盒。
- 显示器旁的键盘、鼠标、触控板、耳机架、保温杯和手机支架。
- 文件柜与书架上的分类标签、档案盒、样品册、装订资料、印章盒和快递文件袋。
- 白板上的抽象项目进度、时间轴、流程箭头、磁吸圆点与不同颜色便签，不出现真实品牌、真实姓名或隐私信息。
- 打印区的备用纸包、回收纸箱、订书机、胶带座和待处理文件托盘。
- 饮水区的纸杯、茶包盒、咖啡罐、小毛巾和一盆耐阴绿植。
- 会议室的无线扬声器、马克笔、会议本、玻璃水杯、桌面走线盖和墙面吸音软包。
- 东窗下的窄窗台、百叶帘、玻璃反光、几盆小型绿植以及被阳光照亮的地面光带。
- 若干不遮挡动线的落地盆栽、低矮地毯、软木公告板、灭火器箱、挂钟、空气净化器和纸篓。

不要人物，但必须有充分的使用痕迹：稍微错开的键盘、摊开的会议本、杯中残留的茶色、打印机出纸托盘上的几页文件、椅背搭着的薄外套、带折角的便签、档案盒的使用磨损、地砖上的柔和反光、窗边百叶投下的条状阴影。空间应显得真实被使用、专业而不冰冷。

## 美术风格

重点强调高精细建模、日式三渲二轮廓、清晰但不过重的描边、简洁而有层次的木材、金属、织物、纸张、玻璃、陶瓷与塑料材质。室内暖色灯光与东侧窗外偏冷的天光形成对比；原木和米白负责亲和感，浅灰与石墨色提供办公秩序，抹茶绿、雾蓝和樱粉仅用于局部软装与状态提示。

## 制作要求 - 必须严格执行

制作流程必须分为两个阶段：

第一阶段，读取布局信息。首先读取 `scene.json`，确认 `blender-z-up` 坐标系、米制单位、角度制旋转、`30m x 30m` 空间边界、地面基准、外墙与隔断朝向；随后逐一读取全部 `98` 个固定组件的名称、类型、组、坐标、长宽高、旋转和缩放。对于布局文件中没有直接尺寸字段的办公家具，必须读取项目原型代码中的真实包围盒尺寸。未经读取和记录，不得开始放置任何固定元素。

第二阶段，按数据建模、样式自由美化。固定根节点必须直接使用布局数据中的位置、欧拉角和缩放，并锁定变换；所有固定组件的最终世界包围盒必须与原型尺寸和布局缩放一致。固定元素的任何造型优化都必须限制在对应局部包围盒内。绿植、文具、线缆、文件、灯具、软装、公告板等自由元素可自行设计，但不得遮挡固定设备的核心使用面、窗门开启面、会议座位或主通道。

## 动态效果

加入克制的基础动效，使办公室像正在安静运行：

- 东窗外天光缓慢移动，百叶窗投影和地面光带随时间轻微平移。
- 顶部线性灯与桌面台灯存在非常轻微的亮度呼吸，不得明显闪烁。
- 显示器呈现低亮度待机呼吸光或缓慢变化的抽象色块。
- 打印机待机灯周期性呼吸，偶尔有一张纸缓慢推出少量距离。
- 饮水机水桶内高光轻微移动，接水区状态灯缓慢变化。
- 空调或空气净化器出风口附近的绿植叶片轻微摆动。
- 窗边百叶 / 纱帘被微风轻轻带动，东窗外偶尔有飞鸟影子掠过。
- 会议桌上的咖啡杯升起很淡的热气，墙上挂钟秒针稳定转动。

最终效果应像一个功能完整、可自由观察的三渲二日式现代办公室微缩世界：布局严格、分区清楚、细节丰富、光线充足、安静治愈，同时具有真实办公生活的温度。
