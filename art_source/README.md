# 当前美术制作源

所有当前可编辑美术源集中在这里。目录参与 Git，母版通过 Git LFS 保存；`.gdignore` 禁止 Godot 导入和打包。

分类和版本规则见 [美术源目录规范](../docs/ART_SOURCE_LAYOUT.md)。从 [当前源索引](../assets/registry/current_source_index.json) 找到母版；旧位置到新位置见 [迁移清单](../assets/registry/art_source_migration.json)。

正式导入资源仍在 `assets/art` 的原路径。临时导出、截图、验收日志写入工程外 `ShellStorm2-work`。
