# 战局区块通用组件库 v001

来源仅限 `ENV-BATTLE-L01-ROOM-MAIN-02` v003 的设施与环境支持包。原房间的墙、地面和布局锁定，不在原文件内移动任何对象；本组件库以独立副本将43个包转换为局部原点并分类陈列。

范围包括服务器机柜、工作终端、中央设备岛、维修托盘与控制柜、设备箱、东西门框、数据旗帜、绿植、固定纸张、四面墙体管线与跨地电缆。房间专属墙段和30块地砖不进入通用库，避免把30×25m空间结构误当成任意房间通用组件。

每包用 Empty 根节点提供局部原点，主体与自发光保持分离。制作源默认隐藏，输出可见；组件库不生成碰撞、GLB或Godot场景。四共享材质及项目公共外链色盘沿用源房间，不复制色盘。
