# 局内关卡01 · 入口安全房 15×15m 正式美术 v006

入口：[Blender 美术源](局内关卡01_入口安全房_15x15m_正式美术_v006.blend)。资产身份 `ENV-BATTLE-L01-SAFE-ENTRY`，属 `battle`，设计范围见 [DESIGN_SCOPE 摘要](#范围与契约)。

v006 是 v003→v005 之后的**换范式版本**：房间不再自持墙与地砖模块，改为引用 `common_components/v003` 通用组件库。

## 范围与契约

- 房间为 **15×15m** 内净空，墙中线 ±7.35m，墙内脸 7.2m / 外脸 7.5m，墙厚 0.30m。
- 视觉墙高 **11.9m**（逻辑层高 12.0m，顶部 0.10m 留给上层楼板）；可行走面 z=**0.30**，结构板顶 z=**0.26**。
- 运行时布局（权威）：北 3 实墙；南 实墙+门+实墙；东 实墙+门+实墙；西 3 实墙。两门洞切向中心均为 0，净宽 **2.2m**、净高 **2.5m**。
- 网格 5.0m；地砖模块 4.94m 见方 + 0.06m 勾缝。

来源：运行时探针实测（`_probe_safe_room_door.txt`），非从旧模型或效果图反推。

## 使用与归类

- `01_制作组件` 保留可编辑源，默认隐藏；资产包输出默认显示。
- **24 个独立资产包**（[目录树](component_packages_v006/tree.txt) / [总清单](component_packages_v006/catalog.json)）：13 设施 + 5 墙面装饰 + 4 支持件 + 1 承重底板 + 1 地面装饰。主体与 UI 自发光分离。
- 视图层：`01_完整结构_交付` 保留完整 11.9m 墙体；`02_剖切展示_隐藏近侧墙` 供展示，未删除墙体。
- 材质遵循四共享角色，唯一色盘外链 `assets/art/shared/palette/设施低亮多巴胺色盘_10x10_512.png`；不要单独搬走 Blend，否则相对贴图路径失效。

## 范式 B · 可替换组件契约

**墙体与地面不再是房间资产。** 房间只保留槽位（placement）与引用，几何由 `common_components/v003` 提供：

| 用途 | 通用组件 | 数量 |
|---|---|---|
| 实墙 | `wall_standard_5m`（5.0×0.3×11.9） | 10 |
| 带门洞墙 | `wall_door_5m`（2 门垛 + 1 门楣） | 2 |
| 门扇 | `door_5m`（2.2×0.18×2.5） | 2 |
| 地砖 | `floor_tile_r01_c01` / `r01_c02` | 5 / 4 |

共 23 个槽位、36 个槽位对象。构建时已**显式移除**房间自有的 15 个墙/地模块（`WALL_*` 6 + `FLOOR_TILE_*` 9）与 16 个旧包；`qa/task_validation.json` 的 `removed_wall_floor_modules` / `removed_room_owned_packages` 记录清单。

例外：**承重底板**（对象 `FLOOR_BASE`，15×15×0.26）由房间自持，归 `floor_base` 包。理由：通用库没有底板；参考房间 `main_room_02/v003` 同样保留 `floor/floor_base` 包。它的顶面正是 5m 地砖 60mm 勾缝下露出的面。

碰撞归属：所有墙/地槽位声明 `collision_owner = godot_0p30m_structural_proxy`、`room_owned_geometry = false`；碰撞、门状态机、导航全部仍归引擎，GLB 只负责视觉。
