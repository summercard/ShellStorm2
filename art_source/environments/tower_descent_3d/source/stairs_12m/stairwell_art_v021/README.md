# 双楼梯间美术源 v021

源文件：`env_tower_stairwell_dual_art_source_v021.blend`，Blender 4.2 原生压缩保存。

本版以 v020 的完整楼梯间为母体，建立两个独立装配根：楼梯A对应 100→99 层，楼梯B为完整复制件并用于 99→98 层。两个装配体保持同一套墙、地板、楼梯和装饰内容，按区块设计合同反向布置。

- 楼梯A：`楼梯A_100至99层_装配根`，位置 `(-32.5, 0, 0)`，Z旋转 `180°`。
- 楼梯B：`楼梯B_99至98层_装配根`，位置 `(32.5, 0, -9)`，Z旋转 `0°`。
- `component_packages/`：继续使用 3 个通用组件和 7 个装饰组件；另附两个装配根清单。
- `renders/`：双楼梯俯视/全景及 A、B 单体实景验收图。
- `qa/`：复制构建脚本、逐件配对记录、结构验证和严格材质/UV结果。

两套楼梯间各含 382 个独立输出网格，网格数据没有共享写入风险。公共色盘仍外链项目唯一文件，不在本目录复制或打包。v020 原源保留为回滚版本。

本轮只更新 Blender 美术源，不包含 GLB、碰撞、LOD、PackedScene 或 Godot 运行时替换。
