# 塔4 v010 · 圆形屋面升层与塔4-2远景合景

以v009继续迭代，保留历史文件。`塔4_圆形屋面升层与旋转楼梯_v010.blend` 是可编辑塔4母版：顶部圆形屋面从25m升至30m，新增一层规整窗墙、楼板和28级旋梯；原连廊入口切开4m护栏缺口。3693范围外对象签名一致。

`塔4与塔4-2_远景优化合景_v010.blend` 为独立远景优化文件，共583247可见三角形，无隐藏高模。塔4-2高精区域另见 `../../tower_04_2/v002/`，不焊入塔4。

`component_packages/` 管理母版2051独立包、47组件定义；`far_component_packages/` 管理远景塔楼组件，庭院实例链接自己的23种定义。远景超过约10m的历史网格已空间切分；新增升层和楼梯组件≤8m。

`previews/塔4与塔4-2_高精合景预览.png` 是两份高精母版临时装配的预览；实际远景效果看 `塔4与塔4-2_远景合景.png`。旋梯接口另有近景。

已登记场景账本，结构及PaletteUV自检通过。仅Blender资产源；未导入Godot、未完成碰撞/导航及运行性能验收。详细证据在 `qa/`，设计和开发记录见 `docs/v0.1/design/tower04_ground_court.md` 与对应development记录。
