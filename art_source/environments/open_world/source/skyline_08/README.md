主体32×24m；8层×4m，天台Z=32m。广告牌、SKYLINE灯泡招牌、空调风管和机房为重点。源组件集合默认隐藏，输出资产包可见；切换两组Collection即可编辑制作源。

四个共享材质，色彩通过外链公共色盘的PaletteUV选择。重复楼层共用链接网格；改变单层几何前可先将网格设为单用户。原始文字对象及嵌入字体保留在制作源中。

这是独立美术源；尚未制作Godot运行包装或碰撞。v001/v002/v003为迭代回滚文件。

用户灰阶修订：最浅白灰两档均下调两档，几何与展示灯光保持。
