# 枪械开火反馈：后坐回弹 + 弹性压扁（两轮返工）

时间：2026-11-02 17:5x｜事务：WEAPON-COMBAT｜状态：已实现，观感待主人实机确认

## 要的是什么

一：「增加枪开枪的时候的向后弹一下 然后扩大压缩的动画，让枪更加有反馈」
二（第一版上线后）：「目前没有看到变化，是不是动画速度太快了？我希望的是一个由弹性压扁然后弹回去的动画」

= 枪身自己的开火形变，**不是**角色动作（角色那边是 Blender 剪辑 `sidearm_fire_idle`，另一条线）。

## 第一版为什么失败（核心教训）

**不是速度问题，是量纲问题。** 我在实战相机（43°/−52° / 1920×1080）下量到枪口→枪根在屏幕上只有 **15.8 px**。
第一版 `punch=0.09` ⇒ 缩短 `0.09 × 0.62 × 15.8 ≈ 0.9 px`；位移 2 px；压扁相位 30~60 ms。
**不到一个像素、两三帧就没**，调多慢都看不见。

⇒ 以后任何「枪身视觉反馈」的定值，先跑 `tools/probe_weapon_fire_feedback.tscn` 量屏幕像素，别凭物体空间感觉给数。

## 最终方案

两条下界（由实测反推，写进门禁）：
- `punch ≥ 0.31` ⇐ `punch × 0.62 × 15.8 ≥ 3 px`
- `punch_hz ≤ 10` ⇐ 半周期 `1/(2f) ≥ 50 ms`（3 帧 @60fps）

| 项 | 值 |
|---|---|
| 手枪 punch / punch_hz | 0.62 / 3.4 |
| 霰弹 | 0.78 / 2.8 |
| 狙击 | 0.72 / 2.7 |
| 机枪（连射） | 0.36 / 4.6 |
| 压扁公式 | `scale=(1+a, 1+a, 1−0.62a)` + `rotation.z −= a×roll` |
| 压扁阻尼 | ζ=0.50 ⇒ 过冲 16.3%，会「拉长变细」再回正 |
| 位移阻尼 | ζ=0.42 ⇒ 过冲 23.6% |
| 连射语义 | `punch = max(punch, peak)`（刷新，不累加） |

**实测**：15.8 px → 6.4 px（短 9.4 px / **−59%**），衰减到峰值 10% 耗时 **100 ms ≈ 6 帧**。

## 连射为什么不能累加（算给主人看）

旧「`punch += peak×0.55`，封顶 1.35×」：机枪 12 发/秒、间隔 83 ms、ζ=0.5 → `ζω=18.85`，
每发衰减 `exp(−18.85×0.083)=0.209` ⇒ 稳态 `0.55/(1−0.209)=0.695 × peak`。
**连射比单发还弱**，方向是反的。改成刷新语义，上界恒为 peak，也不可能鼓成气球。
