### 根因

`_ready()` → `_bind_existing_city_material.call_deferred()`，`call_deferred` 至少隔一帧才执行。
地基要轮询最多 120 帧等程序城市 `CityBuildingSilhouettes`。

带**未完成续局**的存档启动时：`StartupLoadingScreen` → 引导用的 `TowerDescent3D` 整栋建起来
→ 同一帧里 `TowerDescent3D._resume_expedition_runtime_scene()` 又 `change_scene_to_file` 一次
→ **引导场景在第 1 帧被顶掉**。此时地基已出树，轮询刚醒 → `get_tree()` 返回 null → `.root` 抛错。

探针实测：`tree null at frame=1 inside_tree=false`。

### 修法（关键点：只判返回值不够）

```gdscript
for _frame in range(BIND_POLL_FRAMES):
    if not is_inside_tree():   # ← 必须先用这个挡
        return
    var cities := get_tree().root.find_children(...)
    ...
    await get_tree().process_frame
```

**`Node::get_tree()` 自身带 `ERR_FAIL_NULL_V`** —— 出树时哪怕只读返回值，它也会先打一条
`ERROR: Parameter "data.tree" is null.`。所以不能写成 `var tree := get_tree(); if tree == null: return`。
`is_inside_tree()` 是纯读标志位，无副作用。

改动文件：`assets/art/environments/open_world/runtime/open_world_landscape_foundation/landscape_visual_material_binding.gd`

### ⚠️ 踩到一个真坑：`node_modules` 是 symlink，`core.symlinks=false` 时会被整个吞进提交

`_scratch/boss014_ledger/node_modules` 与 `boss015_ledger/node_modules` 都是**符号链接**，
指向 `/c/Users/zhuangmenghong/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules`。

- `git config core.symlinks` = **false** → git 不认 symlink，把它当**真实目录**遍历，
  一次 `git add _scratch/boss014_ledger` 就吐出 **322 KB 的 warning**（`node_modules/lucide/dist/esm/icons/*.js`
  逐条），把数万个包文件全加进暂存区。
- `find -type f` 查它返回 **0 文件** —— 因为不跟随符号链接，**这会把危险藏起来**，不能靠它判断。
  用 `ls -la` 看类型（`lrwxrwxrwx`）才看得出来。
- 修法：仓库根 `.gitignore` 补 `node_modules/`（原来只有 `tools/3Dgame-design/.gitignore` 局部有这条）。
  加完 `git check-ignore -v` 命中，`git add -An` 复验泄漏数 = 0，ledger 目录只入库 22 个真实文件。
- 教训：**`_scratch` 下任何东西提交前，先 `git add -An` 看清单，别直接 `git add` 整个目录。**
