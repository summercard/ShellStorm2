## 三、一个我先怀疑、后自查推翻的「缺陷」（已闭环，结论：不是缺陷）

29 件 GLB **字节变了**，但 `ledger_split_baseline.json` 里对应的 `PRP-BLOCK00-*`
条目摘要**未变** —— 我一度怀疑账本哈希列没跟着刷新，并把这个怀疑写进了
`dbdd748f` 的提交信息。**随后自查推翻了它。**

### 查证过程（这道题值得记）

1. `_row_digest` 覆盖 `CONTENT_COLUMNS = 1..25 去掉 (18,19)`（18/19 是查重键/查重结果
   两个派生公式列），所以 **col 20 确实进指纹** —— 怀疑成立不下去。
2. `check_asset_registry.py:252-253` 定死口径：**col 15 = 文件路径，col 20 = 该文件 sha256**；
   `:276-280` 是门禁本体 —— 唯一存在路径 + sha 合法时，`actual != recorded` 即报
   `sha_mismatch`。
3. 装 openpyxl（托管 python，`pip install openpyxl` 3.1.5）逐条实测 98F 那 33 行
   （`ENV-BLOCK00-*` + `PRP-BLOCK00-*`，账本行 839~871）：
   **一致 33 / 不一致 0**。
4. 于是打印 col 15，答案出来：
   ```
   PRP-BLOCK00-SOFA   → assets/.../runtime/prp_block00_sofa/prp_block00_sofa_root.tscn
   PRP-BLOCK00-RUG    → assets/.../runtime/prp_block00_rug/prp_block00_rug_root.tscn
   ENV-BLOCK00-WALL-FRACTURED → .../runtime/env_block00_wall_fractured/..._root.tscn
   ```

**结论：账本登记的是 runtime 根 prefab `.tscn` 的 sha，不是 `components/*.glb` 的字节。**
本轮只有 `.glb` 变了、`.tscn` 没变 ⇒ 账本**本该不变**，`ledger_split_baseline`
不动是正确的。

### 这条设计本身是好的，值得记

把身份锚点放在**稳定的 prefab 根 tscn** 上、而不是**频繁重导的 `.glb` 字节**上：
`.glb` 会因色盘整合、优化、重导出不断变化，若让它进账本身份哈希，
账本会天天要改、且每次都要跑一遍写表脚本。放在 `.tscn` 上则「资产身份不变」
就等于「路径与装配契约不变」，正好是账本想守的东西。

**教训（对我自己）**：我这次差点在提交信息里把「未验证的怀疑」写成结论。
好在写的是「需查取样列后确认」而非断言 —— **但也应该先查完再写**。
下一次：**指控一个不一致之前，先把口径查到 `check_*.py` 的哪一行**。

### 改动实质

`_configure_fate_card_focus_navigation()` 给三张命运卡指定左右邻居（首尾环绕）时，
原无条件 `button.get_path_to(previous/following)`。**焦点覆盖层重建期间按钮尚未接入
场景树**时，`get_path_to()` 找不到公共父节点，引擎刷 `common_parent is null` ——
典型**只在特定时序出现、功能表面看不出、但污染日志并干扰日志门禁**的报错。

新增 `_safe_fate_focus_neighbor_path()` 四层守卫（返回**空 NodePath** 是有意的）：
null / `not is_instance_valid` / `not is_inside_tree()` / **两侧不同树或树为空**。
空路径的语义是「回退引擎自动邻居推导」，所以退化期**不丢焦点、也不留坏路径**。

**验证完整性的自查**：`grep get_path_to` 确认改动后该文件**已无未受保护的转路径点**
（唯一调用点就在新守卫函数里）。小改动的「改完是否还有同类漏网」值得每次都查一遍 ——
只补一处、别处照旧的修法，下次换个入口又会复现。

### 一个可复用的判据：「同一函数/文件的同类调用有几处」

- 修运行时防护（null 守卫、越界守卫、时序守卫）时，先 `grep` 同族调用点，一次补全；
- 修完后 grep 复查**剩余调用点是否都在守卫内**，这比「跑一遍没报错」可靠得多
  （时序类 bug 恰恰是「跑一遍碰不到」的那种）。
