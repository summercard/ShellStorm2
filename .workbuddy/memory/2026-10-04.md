### ⚠️ 本轮最大的坑：junction 快照差点把真实资产复制进库

`_scratch/fat_zombie03/baseline_project/` 和 `retirement_baseline/` 是「整项目对照快照」。
它们里面的 `assets` / `scenes` / `data` / `tests` **不是拷贝，是 `New-Item -ItemType Junction`
挂到真实目录**。git 会顺着 junction 把真实资产按**影子路径**再加一份（实测 22 个文件，
含 8 MB 级 `.blend`）—— 既是垃圾又浪费体积。

同样漏网的还有三类：
- `_scratch/cloud_static_appdata_20261003/`、`_20261004/` —— 目录名把 appdata **夹在中间**，
  原规则 `_scratch/*_appdata/`（要求结尾）和 `_scratch/**/*_appdata/` 都匹配不到。
  里面是 Godot `shader_cache` 与 `pipelines.forward_plus.nvidia_geforce_rtx_4060_ti.cache`
  （单文件 15.7 MB，含本机 GPU 型号串）。
- `isolated_render/`、`isolated_baseline_full/`、`isolated_final_verify_*` —— 隔离 APPDATA 工作区，
  里面是 `Godot/app_userdata/<项目>/` 的日志、`base_save.json` 副本。**目录名不含 appdata**，
  规则同样匹配不到。

**新增三条规则**（纯收紧）：
```
_scratch/**/*appdata*/      # 名字把 appdata 夹中间的
_scratch/**/*baseline*/     # 整项目 junction 快照（baseline_project / retirement_baseline）
_scratch/**/isolated_*/     # 隔离 APPDATA 工作区
_scratch/**/app_userdata/   # 兜底
```

**教训**：`_scratch` 下的目录名**花样很多**，只靠 `*_appdata` / `*_before_*` / `*_backup/`
这种后缀规则堵不干净。**推之前一定跑一次 `git add -An --ignore-removal .` 看全量清单**，
别只看 `git status`（`git status` 把未跟踪目录折叠成一行，看不见里面有什么）。

  键是 SHA256(配置 + 布局 + 扩张包络)，`_candidate_cache` 是 static 跨实例共享。
- 验收：**30 组视角 × 时段对照全部 `changed_pixels = 0` / `peak = 0`（像素级完全一致）**，
  每组含重复跑证明确定性。性能 main 27.176 → 25.071 ms（**-7.75%**）、
