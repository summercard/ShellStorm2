# ShellStorm2 外挂特效库导入与追踪

## 1. 查规则、找素材

- 以包含 `project.godot` 的 `ShellStorm2/` 为 Godot 工程（当前目录已经是该工程时不再拼接 `ShellStorm2/`）；先读 `docs/ART_SOURCE_LAYOUT.md`、`docs/v0.1/14.6_特效系统与制作规范.md`，核对 `assets/registry/ledger_index.json` 和实际触发代码。账本登记按项目资产行事务规范执行。
- 当前机器的外部索引：`H:/BaiduNetdiskDownload/YQ12983/outputs/Godot_VFX_Asset_Library/Index.html` 和同目录 `Asset_Manifest.json`；Godot 原工程：`H:/BaiduNetdiskDownload/YQ12983/Godot工程_特效课程_结果版/`。其他机器由 `SHELLSTORM_VFX_CATALOG`（索引目录）和 `SHELLSTORM_VFX_SOURCE`（含 `project.godot` 的源目录）指定；不可达时说明缺源，不从预览视频反制特效。
- 按视觉用途、触发阶段和 2D/3D 筛选；记录库编号、精确场景、源哈希及许可状态。预览视频、海报、目录、演示场景不可当运行依赖。完整库只留工程外，不装进 Git、Godot `res://` 或发行包；不把绝对源路径写入任何游戏运行脚本。

## 2. 锁定用途和最小依赖

- 先确定游戏正式 AssetID、Prefab、实际调用方和宿主：全局池、投射物附件、常驻场景、自持玩法宿主或 UI。列清本轮新增/替换项和保持不动的项；查清共享调用，不能仅凭已登记或预载宣称已接入。
- 从所选原生 `.tscn` 追传递依赖：Godot `ResourceLoader.get_dependencies`（含二进制 `.res` 与 UID）、相对脚本和 shader 引用、运行时拼路径加载的贴图/资源、必要 `.uid` 与保画质的 `.import`。主库渲染脚本按 `asset_key` 读取 `Assets/tex_<key>.res`，并使用精确版共享数学脚本；两套目录不能分别盲裁。检查 `.import` 仅作为导入参数保留，不搬 `.godot` 缓存。
- 只将经过核对的依赖按原相对层级落到 `assets/art/vfx/library/`，只重映射必要资源路径；保留供应商原颜色、粒子参数和时间曲线，按需在宿主外层调缩放、朝向或颜色。未选中的资源不复制。已错导的资源按本轮明确范围可逆移出至工程外，记录路径和哈希；不要动其它会话或存量资产。发现外部引用、未知动态依赖或二进制依赖时先保留并复核。

## 3. 接入和登记

- 保留已有 AssetID 和正式入口；先从代码确认命中、跟随、地面高度、时序和回收契约。池化时关闭库自播，激活时重启，提前 finish、预热取消、离场和复借都需停净；不要在 `activate()` 内同步回收；库内置音效/灯不得与宿主重复。持续危险的半径、伤害、时长归玩法宿主。
- 在特效分账本主表与专表记录素材编号、场景、版本、SHA、使用范围、适配参数、授权与验证状态；新增行同步公式、下拉范围、域日志及无损基线。不为绕过门禁修改无关历史记录。已有资源纯目录瘦身、正式入口与哈希不变时不刷资产版本。
- 每次迁移在 `ShellStorm2-work/` 建独立证据目录，记录驱动入口→游戏 Prefab→库源、完整保留清单、移出清单、变更前后文件数/字节数、渲染和导出日志。未选、已接入、已专项验证、已通过目标设备性能验收分别记录。

## 4. 性能与交付门禁

- 性能规则从 `docs/v0.1/13_技术施工_性能优化与热管理.md`、特效规范和使用关卡预算取值。不要把资产分账本当性能实测账本；先查现有正式性能记账入口，若无独立 VFX 性能账本，本轮至少保留独立性能记录并明确缺口。以同一资产 ID/版本记录工程外证据，正式账本只引用证据、不虚填通过。
- 运行性能核查入口：`tests/verification/verify_3d_performance_budget.tscn` 验证节点、局部灯和流送等预算；游戏 `0` 键性能面板可作现场诊断；发布设备按规范运行 `scripts/run_target_device_gpu_profiler.sh`。规范中的持续 CPU P95 ≤8 ms、GPU P95 ≤12 ms 是整场景发布预算，不是每个特效各自可用的额度。
- 暖机后用同一构建、设备、渲染器、分辨率、画质、机位和固定场景，对照旧版/新版；覆盖单次触发及实际峰值并发（例如连续开火、多怪同屏）。记录并发、活粒子/灯、透明覆盖、Draw Call、CPU/GPU 帧时间 P95、显存/内存、回收后池/节点基线、发布包增量。未知值写 `N/A`，无头与固定帧率录屏不能充当运行性能。桌面 Compatibility 不能替 Android 真机。
- 运行专项和正确渲染器画面检查；检查对象池、换场、实际触发、基础对照（普通弹等不应变化）。执行 `scripts/check_export_runtime_refs.py --check`，实际导出目标包或明确记录阻塞，核对包内运行依赖以及无目录、演示和未使用场景。产品性能门槛不因新特效放宽；目标设备未跑不得写已验收。
