# Blender 场景、关卡组件与设施制作规范

## 适用边界

此 skill 仅处理三类资产：

- **场景与关卡组件**：地板、墙、楼板、门洞、楼梯、栏杆和可拼接建筑模块。
- **固定设施**：自动贩卖机、储物柜、工作台、终端和固定在场景中的大型装置。
- **设施的固定展示附件**：不需要独立拾取、装备、物理移动或手持动画的组成部分。

枪械和近战武器使用 `game-weapon-model-pipeline`；可拾取、库存、可投掷、可手持或可独立物理移动的道具使用 `game-prop-model-pipeline`。不要把武器、座椅、独立道具或角色可交互附件焊进设施输出。

为一个物件制作可维护源文件和游戏输出。颜色只由色盘 UV 控制，金属、哑光、反光和自发光质感只由材质角色控制。

## 必须执行的流程

1. 检查参考图、参考镜头、源集合、对象层级、实际尺寸、修改器、材质、PBR参数、自发光强度和展示专用几何体。用户指定参考效果图时，将其作为主要视觉真值：先还原可见结构、比例、轮廓、位置、朝向、间距、材质、标识、灯光和视觉密度，再用文字补充功能与不可见结构；不得用功能相同但外形不同的自由设计替代。
2. 在局部深化前建立范围清单：明确可修改设施、直接附着细节、锁定结构和参考摄像机。保存修改前文件，并记录锁定对象的名称、类型、世界变换、尺寸、网格、材质、修改器和动画签名。不得借局部任务调整范围外的地板、墙、阁楼、楼梯、栏杆或其他设施；如任务只允许重新归类，可只改变被授权的 Collection 归属。
3. 保留有意义的结构细节；只删除非物件组成的展示地面、底台、背景、相机和灯光。
4. ShellStorm2的场景、关卡组件与固定设施只允许引用项目级公共色盘`assets/art/shared/palette/设施低亮多巴胺色盘_10x10_512.png`。不得在资产目录新建、复制、打包或改名保存色盘；Blender图片数据块必须外链该文件，所有色盘节点使用同一数据块和`Closest`插值。导出GLB时设置`export_image_format="NONE"`，禁止每个GLB再次内嵌色盘。贴图固定为512×512、10×10纯色格；第10列固定为冷调灰阶，按第1行至第10行由深蓝灰连续过渡到浅蓝灰，不得混入暖灰。每个面的 `PaletteUV` 必须保留为有面积的小型UV岛，完整放在单一色格的安全内区，不能压成点。`PaletteUV` 必须同时设为当前编辑层和活动渲染层；纯色色盘资产默认删除输出网格上的 `UVMap/UV贴图` 等旧层，确需保留时必须记录用途且不得成为活动层。
5. 默认仅使用四个共享材质角色：精工金属、细腻哑光、清漆反光、柔和自发光。颜色变化不得增加材质球。
6. 先给制作组件统一材质并清除废弃材质，再生成游戏输出，避免材质列表残留旧球。
7. 对单体设施的修改器求值后合并输出：非自发光面可合成主体网格，自发光面合成独立网格；保留面材质索引和 `PaletteUV`。场景总合集不得把多个独立设施、多个地砖或建筑模块焊成一个不可拆分网格。
8. 单体资产的游戏输出在X/Y居中、底面位于Z=0；场景布局母版保留游戏内世界坐标，并在每个独立资产包内记录局部原点、世界位置、正面方向、包络和版本。不得为了单体居中而破坏场景母版坐标。
9. 制作组件保持可编辑并默认隐藏；游戏输出默认显示。每个可独立导入、替换、复用或维护的设施建立独立资产包，不得把“阁楼下方设施”“南面设施”等区域总集合当成最终设施包。语义独立的椅子、附件、武器或小道具必须成为独立资产，不得因画面组合而焊进主设施。
10. 场景资产包必须同时整理 Blender Collection 与磁盘目录；二者一一对应。地面统一归入地面系统，每块地砖与其压边、螺栓、检修盖、标识、磨损等直接附着深化内容组成一个独立地砖包。灯带、屏幕、标签、控制面板等不可分割附属件归宿主设施；跨设施管线、全局灯光和环境动效归独立支持包。每个末级包必须非空、对象唯一归属并带清单。
11. 保存固定参考摄像机，使用相同构图、焦距/正交尺度、分辨率、渲染引擎、色彩管理和关键灯光渲染前后对比图；另渲染俯视图与修改区域近景。修正误读、重叠、穿插、比例、结构缺失、发黑、塑料感、过曝和自发光泛白。
12. 保存新版本，不覆盖原始文件；先运行任务级场景验收，再运行 `scripts/validate_game_prop.py`。任务级验收至少检查范围锁定签名、设施包唯一归属、空包、磁盘清单、关键坐标/包络和旧误读对象；材质验收必须逐面确认UV岛具有面积、全部 loop 位于同一个色格安全内区，并检查活动层、渲染层、材质 UV Map 节点、Closest 插值、废弃材质和输出集合。单点UV、只检查UV层名称或只凭渲染图均不算验收。

## 模块化建筑与楼梯附加流程

当资产是地板、墙、楼板、楼梯、栏杆或门洞模块时，必须把连接关系当成同一资产包验收：

1. 先记录楼层基准、平台顶面、目标楼层、门洞、入口缺口、水平包络和对接坐标，再修改几何。不得只凭视图缩放。
2. 高度改变时联动楼板、所有相接楼梯、落地平台、栏杆和出口；保留踏步厚度、栏杆高度和结构截面。禁止对整件资产做纵向非等比缩放来凑高度。
3. 墙体高度契约固定为9m：墙体模块的逻辑高度、原点/基准点和游戏阻挡（碰撞）均保持原规则不变。阻挡使用9m高度，底部仍位于原基准点，不得为了视觉避让而移动或缩短阻挡。视觉墙体网格按8.9m制作，底部与原基准点对齐，顶部停在基准点上方8.9m，顶部预留0.1m空隙以避免与上层地板共面闪面；不得用整件纵向缩放替代该尺寸契约。
4. 游戏碰撞与可见踏步分离：可见模型保留踏步细节，游戏包装使用连续简化斜坡和独立栏杆阻挡。逐级盒碰撞不得作为角色主行走面。
5. 栏杆碰撞只覆盖真实栏杆，入口必须保留明确缺口；坡脚、平台和坡顶应轻微重叠，不能留下角色胶囊会撞住的竖边或缝隙。
6. 对低于项目镜头净高的楼板/楼梯标注 `camera_clearance` 或同等元数据，供游戏包装采用专用镜头规则；不得依靠删除遮光面解决镜头问题。
7. 建筑组件、栏杆和屋顶默认真实投影。只有明确的编辑器参考、预览辅助或纯UI几何可以关闭投影。
8. 同一母版同时保留制作组件与独立输出根；每个模块有稳定资产ID、局部原点、尺寸、方向和版本。渲染整包预览，并分别核对每个输出根包围盒。

## 材质角色基线

| 角色 | 金属度 | 粗糙度 | 清漆 | 用途 |
|---|---:|---:|---:|---|
| 精工金属 | 0.80–0.92 | 0.22–0.32 | 0.10–0.25 | 框架、护边、螺栓、轨道、工具 |
| 细腻哑光 | 0.00–0.05 | 0.62–0.78 | 0 | 大面积喷漆板、橡胶、桌面 |
| 清漆反光 | 0.10–0.25 | 0.10–0.18 | 0.55–0.80 | 屏幕玻璃和焦点装饰 |
| 柔和自发光 | 0 | 0.30–0.45 | 0 | UI图形与灯带，通常强度1.0–1.6 |

不要仅凭对象名称中的 `screen`、`display` 或 `UI` 判断自发光；必须存在明确自发光材质或非零发光强度。

## 美术方向

- 使用深紫金属作为结构骨架，青绿或湖蓝哑光作为大面，紫粉反光作为小面积点缀，青色、橙色或黄色用于灯光焦点。
- 大面积主色控制在2–3种；高饱和暖色只作焦点。
- 参考面积比例：哑光45–60%、金属20–35%、反光8–18%、自发光不超过10%。根据物件结构调整，不机械套用。
- 避免近黑金属在常规环境中失去结构，避免自发光强度过高导致图形变白。

## 中文集合与命名

```text
物件名_中文资产管理
├─ 01_制作组件_已统一材质        （默认隐藏）
├─ 02_游戏输出_整合模型          （默认显示）
│  ├─ 物件名_主体_金属哑光反光
│  └─ 物件名_UI灯光_柔和自发光
└─ 90_展示环境_灯光相机          （可选）
```

场景总合集使用以下语义层级；编号可按项目调整，但层级职责不得混淆：

```text
场景名_中文资产管理
├─ 01_制作组件_按设施拆分              （默认隐藏）
├─ 02_游戏输出_独立资产包_v###          （默认显示）
│  ├─ 01_建筑结构
│  │  └─ 单个墙体／阁楼／楼梯_资产包
│  ├─ 02_地面系统
│  │  └─ 地砖_R##_C##_资产包
│  ├─ 03_区域固定设施
│  │  └─ 单个主门／柜体／终端_资产包
│  └─ 04_环境支持
│     └─ 跨设施管线／全局灯光／环境动效_资产包
└─ 90_展示与验收_灯光相机              （不进入游戏输出）
```

区域层只用于浏览和分组，末级“资产包”才是未来导入、替换和导出的边界。完整的组件归属、目录镜像、清单与锁区验收规则见 [references/specification.md](references/specification.md)。

## 交付内容

- 可维护 `.blend` 源文件。
- 含整合输出集合的 `.blend`。
- 公共512×512色盘只交付一份固定路径引用；单件资产不得附带色盘PNG。用户要求维护色盘时更新公共色盘及其分层PSD，不复制到模型目录。
- 近景和完整物件预览PNG。
- 材质数、输出对象数、删除的展示几何和验证结果。
- 场景总合集还需交付独立设施目录树、每包清单、任务级验收报告、参考镜头全景、俯视图和修改区域近景。

实施或审核精确验收标准时，完整读取 [references/specification.md](references/specification.md)。

验证命令：

```powershell
blender --background "asset.blend" --python "scripts/validate_game_prop.py" -- --max-materials 12 --shared-palette "<项目>/assets/art/shared/palette/设施低亮多巴胺色盘_10x10_512.png"
```

多资产总合集没有单一 `02_游戏输出` 集合时，使用 `--all-meshes` 对合集内全部网格执行同等严格验收。
