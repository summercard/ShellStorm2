# S4 · 运行时接入与状态映射

```text
账本 → S1 契约反推 · 双母版 → S2 导出中转 → S3 Godot 包装 → 【S4 状态映射】 → S5 验收 → S6 台账推进
```

**入口**：S3 交接的稳定 PackedScene，账本行 `制作状态 = validated`。
**出口**：表现适配层已接线，状态能被真实动作采样；`制作状态 = active`。

**动手前必读** [references/state-binding-rules.md](references/state-binding-rules.md)——三域状态集与禁止项。

## 核心原则：箭头方向

```text
状态机（输出状态 + 进度）  ──→  表现适配层（选择 / 采样动作）  ──→  Prefab 视觉节点
        ↑ 拥有玩法权威                                    ✗ 不得反向回写
```

**状态机是消费者，不是被 Prefab 打包的原料。** 若把状态机打包进 Prefab，Prefab 立刻退化成「一个角色配一个专属状态机」，复用与换装随即崩溃。功能逻辑、碰撞、交互和状态机**不写进纯视觉 GLB**。

## 三套状态集（各域独立，不得互相套用）

| 域 | 状态集合 | 数量 | 权威文件 |
|---|---|---|---|
| 玩家 | `idle / moving / dashing / hurt / locked / falling / landing / dead` + `walking / armed_*` 变体 | 8 + 4 | `src/player3d/Player3D.gd` |
| 怪物 | `dormant / idle / patrol / alert / chase / search / return / telegraph / attack / recovery / stagger / dead` | 12 | `src/enemy3d/Enemy3D.gd` 的 `VALID_STATES` |
| NPC | `idle` + `talk` | 2 | NPC 控制器（本期新增） |

状态 ID **逐字取自代码**。美术侧不得另起名字；改名属于运行时系统改动，必须同时改消费者与测试。

> 16.1 结尾已写明：敌人/NPC/Boss 遵循相同双文件流程，但**各自建立骨架 ID、动作表和适配器**，不套用 Bunny 骨名或玩家八态。

## 第 1 步 · 建立表现适配层

1. 状态机侧只暴露**状态**与**真实进度**；适配层据此选择动作并采样。
2. 适配层是唯一的转换点：状态 → 剪辑名 → `AnimationPlayer` 播放；进度 → 播放位置/混合权重。
3. **玩家侧严格模式**：身体、头、耳、手、脚的姿势只能由已登记的 Blender 剪辑采样。程序层**不得**再生成呼吸、步态、后坐、换弹、蓄力、近战、击飞或手部覆盖姿势。
4. **怪物侧迁移中**：`EnemyAvatar3D.gd` 当前只做 bob 起伏、`scale` 压扁、`rotation.y` 自转与 emission 脉冲——它**记录 `ai_state` 但从不采样动作**。这层「状态→动作映射」在怪物侧**尚不存在**，需要新建；未完成前必须在账本登记，不得伪报为已完成。
5. **NPC 侧**：本期只需 `idle` 与 `talk` 两态的切换，不引入移动与战斗态。适配层按可扩展方式写，为未来状态留入口。

## 第 2 步 · 挂点与武器对齐

- 瞄准 yaw、武器开火、伤害判定归**玩法层**。
- 但武器表现节点只能从属于**已采样的角色握持手**：保持枪口局部方向契约，把角色侧 `WeaponSocket` 对齐右手掌心——**不能反向覆盖双手关键帧**。
- 角色侧不新增每件资产专用的补偿。

## 第 3 步 · 缺动作时的兜底（必须登记，不得静默）

| 缺失 | 允许的临时做法 | 必须做的事 |
|---|---|---|
| 双手长枪动作 | 复用 `armed_idle` / `armed_walking` / `armed_moving` 单手剪辑 | 诊断报告须明示「单手兜底」，**不得伪报双手握持已完成** |
| 射击 / 换弹 / 蓄力 / 重近战 | 保持当前基础剪辑与玩法功能 | 禁止悄悄恢复程序姿势；把精确 Action 需求写入中转 JSON 与账本 |
| 怪物动作整体缺失 | 暂保留程序动画 | 账本登记后续替换项，标注未完成 |

**玩家不得回退**；尚未迁移的怪物可暂留程序动画，但必须在账本留下替换登记。

## 第 4 步 · 状态映射自检

- [ ] 状态 ID 逐字取自代码，无自造名称
- [ ] 适配层是唯一转换点，Prefab 内没有状态机
- [ ] 动作**不**写玩法根变换、碰撞、伤害或存档
- [ ] 动作播放结束**不**改变功能状态
- [ ] 玩家侧无程序姿势覆盖；已退役的旧驱动处于关闭状态
- [ ] 挂点/武器对齐方向未反向覆盖关键帧
- [ ] 兜底项已在中转 JSON 与账本登记，诊断未伪报

## 交接给 S5 的东西

1. 已接线的表现适配层与其入口脚本路径
2. 状态 → 动作映射表（含兜底项与未完成项）
3. 账本行：`状态/动画`、`功能脚本路径`、`制作状态 = active`
