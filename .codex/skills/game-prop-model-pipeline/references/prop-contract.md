# 道具运行时契约

## 道具模式

| 模式 | 视觉根与锚点 | Godot 包装职责 |
|---|---|---|
| `static` | `ItemRoot` 位于稳定摆放基准 | 仅视觉；按需要有世界碰撞，无拾取逻辑 |
| `pickup` | `ItemRoot`；可选 `HoldAnchor` | 独立拾取触发器、库存/交互接口、可选世界碰撞 |
| `physics` | `ItemRoot` 位于物理稳定基准 | 刚体和实体碰撞与拾取触发器分离 |
| `held` | `ItemRoot` + 必需 `HoldAnchor` | 由角色 socket 持有；手持碰撞和世界碰撞按状态切换 |

## 锚点与动画边界

- `HoldAnchor` 是道具本地握点，不是角色骨骼，也不代替世界根。默认朝向为右 `+X`、上 `+Y`、前 `-Z`。
- 道具仅提供自己结构的局部动画。角色的手、IK、拾取、投掷和使用动作由角色与玩法系统负责。
- 道具动画可声明需要的运行时事件，但库存数量、消耗生效、投掷产生的实体和交互结果不能仅由视觉帧决定。
- 若一个对象需要与角色手势、命中判定和武器状态深度耦合，应重新分类为武器，而不是用道具 skill 模拟武器。

## 最小验收

1. GLB 不含临时展示内容、角色骨骼、碰撞或交互脚本。
2. PackedScene 的视觉、实体碰撞、拾取触发器和物理节点职责分离。
3. `ItemRoot` 在世界/物理模式下正确；手持模式通过 `HoldAnchor` 对齐，不缩放共享根。
4. 自身动画、材质、贴图和可选发光在正式 Godot 导入中正确。
5. 资产台账可追溯类型、版本、运行时包装、使用场景和回滚文件。
