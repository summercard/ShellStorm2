# 武器手持、动画与验收契约

## 手持锚点

- `WeaponRoot` 是资产的稳定运行时根，缩放必须为 `1,1,1`。
- `GripAnchor` 是唯一的主手对齐接口。默认与根重合；若项目采用不同根原点，必须在台账记录根到 `GripAnchor` 的固定变换，并仍由包装场景统一对齐该锚点。
- `SupportHandAnchor` 是副手 IK 目标，不是第二个把武器父级绑定给手骨的节点。副手不存在、单手武器或项目不使用 IK 时可省略。
- `MuzzleAnchor`、`AimAnchor`、`EjectAnchor`、`MeleeHitBase`、`MeleeHitTip` 都是明确可见的变换节点，保留在最终 GLB 和 PackedScene 中。
- 默认轴向为右 `+X`、上 `+Y`、前 `-Z`。项目不同则以项目契约为准，并对所有锚点一致执行。

## 动画职责

| 归属 | 包含 | 不包含 |
|---|---|---|
| 武器 GLB | 枪机、扳机、弹匣、折叠/旋转部件、武器局部骨骼与剪辑 | 手臂、手指、角色骨骼、角色移动、角色 IK |
| 角色动画系统 | 持握姿势、拔枪/收枪、装填手部动作、瞄准、后坐力、近战挥击、IK、状态与同步 | 针对每件武器的网格补偿变换 |
| 运行时玩法系统 | 发射、装填成功、弹药、伤害、攻击窗口和网络权威 | 仅依据视觉动画时间自动裁定玩法结果 |

角色动画可与武器局部剪辑以同名状态或显式事件映射同步。事件的名称、时序和是否由服务端权威以项目契约为准；缺少该契约时，先交付可播放武器局部剪辑和事件候选表，不臆造玩法脚本。

## 最小验收

1. GLB、PackedScene 和版本记录可独立定位、加载与回滚。
2. 角色真实 `WeaponSocket` 对齐 `GripAnchor` 后，无额外单件偏移脚本。
3. 双手武器的 `SupportHandAnchor` 可被副手 IK 到达，且不会要求缩放武器根。
4. 枪口、瞄具、抛壳与近战扫掠点均在真实功能位置。
5. 武器局部动画不会驱动角色骨骼；角色动画不会被烘焙进武器 GLB。
6. 材质、贴图、发光、比例、法线与碰撞在 Godot 正式导入和实际关卡中正确。
