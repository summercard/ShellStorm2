# Godot 模型资产导入验收清单

## 1. 输入确认

- 已读取项目资产文档、命名规则、单位、坐标和版本规则。
- 输入来自明确的游戏输出集合，不含展示地面、相机、灯光或整屋内容。
- 主体、自发光和独立附件的资产边界已经确认。

## 2. GLB导出

- 使用二进制GLB。
- 仅导出选定对象。
- 应用导出副本变换，保留源文件可编辑性。
- 三角化导出副本并成功生成法线、切线和UV。
- 贴图已嵌入或使用稳定项目路径。
- 材质命名无 `.001` 等无意义复制后缀。

## 3. 坐标与比例

- Godot根节点缩放为1。
- 设施底面贴地，正面方向正确。
- 武器握把原点、枪口方向和挂点统一。
- 包围盒尺寸与项目目标或用户批准值一致。
- 实际关卡摆放没有穿地、穿墙、遮门或相互重叠。

## 4. 材质与自发光

- 设施通常不超过4个材质，武器通常不超过3个非自发光材质。
- 色盘贴图使用最近邻采样。
- Godot中的颜色与DCC预览一致，没有过亮、发黑或塑料化。
- 自发光网格独立，强度不泛白。

## 5. 独立场景

- 每个资产单位拥有独立GLB和PackedScene。
- 包装场景根、视觉节点、碰撞、挂点和元数据职责明确。
- 纯装饰物没有玩法碰撞、交互脚本或设施分组。
- 座椅等独立附件没有留在主设施GLB中。

## 6. 版本与登记

- 新版本文件已创建，旧版本仍可回滚。
- 包装场景、关卡、代码映射、清单和测试已指向正确版本。
- 已搜索旧路径并解释仍保留的引用。
- 清单记录稳定ID、中文名、GLB、源文件、包装场景、包围盒、方向、版本和用途。
- 资产台账记录哈希、来源、状态和维护人。

## 7. Godot验收

- `godot --headless --import` 成功。
- `.import` 文件存在且时间与新GLB一致。
- 独立加载、材质预算、比例方向和节点契约测试通过。
- 正式关卡实际摆放测试通过。
- 已检查资产墙和实际场景截图。
- 交付报告包含文件路径、版本、尺寸、材质数、测试与回滚说明。

## 常见故障

| 故障 | 检查 |
|---|---|
| Godot颜色错乱 | UV通道、最近邻采样、色彩空间、GLB材质因子 |
| 自发光泛白 | 发光强度、色盘颜色、环境曝光、Bloom |
| 朝向错误 | DCC正面、GLB轴向转换、包装场景旋转、关卡父节点旋转 |
| 比例错误 | DCC单位、导出比例、根节点缩放、旧包装场景覆盖值 |
| 多出Box | 展示底台、默认立方体、碰撞可视化或错误导出集合 |
| 椅子仍在设施里 | 是否仍引用旧GLB；输出集合是否真正删除座椅；关卡是否实例化独立座椅 |
| 材质过多 | 颜色是否错误地通过材质球区分；源组件是否残留旧材质 |
| 更新后场景没变化 | `.import`是否刷新；所有运行时引用是否已切到新版本 |
