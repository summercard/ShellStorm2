# 状态 → 动作 映射规则（三域对照）

`04-character-state-binding` 的细则。核心是**箭头方向**与**三套状态集不得互相套用**。

## 1. 箭头的方向

```text
┌──────────────────────┐         ┌────────────────────┐        ┌──────────────────┐
│ 状态机（玩法权威）      │ ──输出──▶ │ 表现适配层（唯一转换点）│ ──采样──▶ │ Prefab 视觉节点    │
│ Player3D / Enemy3D    │  状态+进度 │ state → clip 映射    │  AnimationPlayer│ 骨骼 / 节点层级   │
│ 拥有移动/碰撞/AI/伤害   │         │                    │        │ 挂点 / 武器 socket │
└──────────────────────┘         └────────────────────┘        └──────────────────┘
          ▲                                                          │
          └──────────────  禁止反向回写  ──────────────────────────────┘
```

- 状态机**输出**状态与真实进度；表现层**只选择、采样**对应动作。
- 动作**不得**写玩法根变换、碰撞、伤害或存档。
- 动画播放结束**不得**改变功能状态。
- 把状态机打包进 Prefab，等于「一个角色配一个专属状态机」——复用与换装立刻崩溃。

## 2. 三套状态集

### 玩家（`src/player3d/Player3D.gd`）

```text
基础八态： idle · moving · dashing · hurt · locked · falling · landing · dead
表现变体： walking · armed_idle · armed_walking · armed_moving
```

- v021 起 12 动作库全部来自 Blender。
- **程序层不得再生成**呼吸、步态、后坐、换弹、蓄力、近战、击飞或手部覆盖姿势。
- 验收须直接证明：旧驱动为关闭状态、动作名称来自当前版本库、程序 action transform 为零、慢走/正常移动映射正确。

### 怪物（`src/enemy3d/Enemy3D.gd` 的 `VALID_STATES`，12 态）

```text
dormant · idle · patrol · alert · chase · search · return · telegraph · attack · recovery · stagger · dead
```

| 状态 | 表现职责 |
|---|---|
| `dormant` | 未激活前不表现；不消耗视觉预算 |
| `idle` | 呼吸 / 轻微起伏 |
| `patrol` | 沿巡逻点位移；朝向跟随路径 |
| `alert` | 锁定可疑目标；身体抬升 / 视线上抬 |
| `chase` | 朝玩家追击；步频随速度切换 |
| `search` | 丢失目标后在最后已知位置环视 |
| `return` | 脱离战斗归巡逻点 |
| `telegraph` | 出手前蓄力前摇，**必须可读** |
| `attack` | 判定生效帧与挥击/发射表现对齐 |
| `recovery` | 攻击后硬直 |
| `stagger` | 受击打断；闪白 + 位移 |
| `dead` | 倒地 / 瓦解；播放结束即回收 |

**现状**：全部为程序驱动。`EnemyAvatar3D.gd` 只记录 `ai_state`，从不采样动作 → **映射层不存在，需新建**。

### NPC（本期新增，2 态）

```text
idle · talk
```

- 静态交互定位，**不引入移动与战斗态**。
- 适配层按可扩展方式编写，为未来状态留入口。

## 3. 挂点与武器对齐

- 瞄准 yaw、开火、伤害判定归**玩法层**。
- 武器表现节点**从属于已采样的角色握持手**：保持枪口 local `-Z` 与真实 `aim_direction` 的角度契约，把角色侧 `WeaponSocket` 对齐右手掌心。
- **不能反向覆盖双手关键帧**；角色侧不新增每件资产专用的补偿。

## 4. 兜底与未完成项登记

| 缺失 | 临时做法 | 必须登记 |
|---|---|---|
| 双手长枪动作 | 复用 `armed_idle` / `armed_walking` / `armed_moving` 单手剪辑 | 诊断须明示「单手兜底」，**不得伪报双手握持已完成** |
| 射击 / 换弹 / 蓄力 / 重近战 | 保持基础剪辑与玩法功能 | 禁止悄悄恢复程序姿势；精确 Action 需求写入中转 JSON 与账本 |
| 怪物动作整体缺失 | 暂保留程序动画 | 账本登记后续替换项 |

**玩家不得回退**；未迁移的怪物可暂留程序动画，但必须留下替换登记。

## 5. 映射层自检

- [ ] 状态 ID 逐字取自代码，无自造
- [ ] 适配层是唯一转换点；Prefab 内无状态机
- [ ] 动作不写玩法根变换 / 碰撞 / 伤害 / 存档
- [ ] 动画结束不改功能状态
- [ ] 玩家侧程序姿势已退役；怪物侧未建立映射的事实已登记
- [ ] 挂点/武器对齐未反向覆盖关键帧
