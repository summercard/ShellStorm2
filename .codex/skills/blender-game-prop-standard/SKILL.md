# Blender 游戏资产制作规范

为一个物件制作可维护源文件和游戏输出。颜色只由色盘 UV 控制，金属、哑光、反光和自发光质感只由材质角色控制。

## 必须执行的流程

1. 检查参考图、源集合、对象层级、实际尺寸、修改器、材质、PBR参数、自发光强度和展示专用几何体。
2. 保留有意义的结构细节；只删除非物件组成的展示地面、底台、背景、相机和灯光。
3. 创建或复用 `多巴胺色盘_10x10_512.png`。贴图固定为512×512、10×10纯色格；第10列固定为冷调灰阶，按第1行至第10行由深蓝灰连续过渡到浅蓝灰，不得混入暖灰。每个面的 `PaletteUV` 必须保留为有面积的小型UV岛，完整放在单一色格的安全内区，不能压成点。`PaletteUV` 必须同时设为当前编辑层和活动渲染层；纯色色盘资产默认删除输出网格上的 `UVMap/UV贴图` 等旧层，确需保留时必须记录用途且不得成为活动层。
4. 默认仅使用四个共享材质角色：精工金属、细腻哑光、清漆反光、柔和自发光。颜色变化不得增加材质球。
5. 先给制作组件统一材质并清除废弃材质，再生成游戏输出，避免材质列表残留旧球。
6. 对修改器求值后合并输出：非自发光面合成一个主体网格，自发光面合成一个独立网格；保留面材质索引和 `PaletteUV`。
7. 游戏输出在X/Y居中，底面位于Z=0；应用或记录展示变换和正面方向。
8. 制作组件保持可编辑并默认隐藏；游戏输出默认显示。语义独立的椅子、附件、武器或小道具必须成为独立资产，不得因画面组合而焊进主设施。
9. 渲染近景材质预览和完整物件预览，修正发黑、塑料感、过曝、自发光泛白、重叠、比例或结构缺失。
10. 保存新版本，不覆盖原始文件；最后运行 `scripts/validate_game_prop.py`。验证必须逐面确认UV岛具有面积、全部 loop 位于同一个色格安全内区，并检查活动层、渲染层、材质 UV Map 节点、Closest 插值、废弃材质和输出集合；单点UV或只检查UV层名称均不算验收。

## 材质角色基线

| 角色 | 金属度 | 粗糙度 | 清漆 | 用途 |
|---|---:|---:|---:|---|
| 精工金属 | 0.80–0.92 | 0.22–0.32 | 0.10–0.25 | 框架、护边、螺栓、轨道、工具 |
| 细腻哑光 | 0.00–0.05 | 0.62–0.78 | 0 | 大面积喷漆板、橡胶、桌面 |
| 清漆反光 | 0.10–0.25 | 0.10–0.18 | 0.55–0.80 | 屏幕玻璃和焦点装饰 |
| 柔和自发光 | 0 | 0.30–0.45 | 0 | UI图形与灯带，通常强度1.0–1.6 |

不要仅凭对象名称中的 `screen`、`display` 或 `UI` 判断自发光；必须存在明确自发光材质或非零发光强度。

## 美术方向

- 使用深紫金属作为结构骨架，青绿或湖蓝哑光作为大面，紫粉反光作为小面积点缀，青色、橙色或黄色用于灯光焦点。
- 大面积主色控制在2–3种；高饱和暖色只作焦点。
- 参考面积比例：哑光45–60%、金属20–35%、反光8–18%、自发光不超过10%。根据物件结构调整，不机械套用。
- 避免近黑金属在常规环境中失去结构，避免自发光强度过高导致图形变白。

## 中文集合与命名

```text
物件名_中文资产管理
├─ 01_制作组件_已统一材质        （默认隐藏）
├─ 02_游戏输出_整合模型          （默认显示）
│  ├─ 物件名_主体_金属哑光反光
│  └─ 物件名_UI灯光_柔和自发光
└─ 90_展示环境_灯光相机          （可选）
```

多武器文件必须在源组件和游戏输出下分别建立每把武器的中文子集合。每把武器通常使用三个非自发光材质；只有真实灯光几何体才增加共享自发光材质。

## 交付内容

- 可维护 `.blend` 源文件。
- 含整合输出集合的 `.blend`。
- 512×512色盘PNG；用户要求维护色盘时同时提供分层PSD。
- 近景和完整物件预览PNG。
- 材质数、输出对象数、删除的展示几何和验证结果。

实施或审核精确验收标准时，完整读取 [references/specification.md](references/specification.md)。

验证命令：

```powershell
blender --background "asset.blend" --python "scripts/validate_game_prop.py" -- --max-materials 12
```

多资产总合集没有单一 `02_游戏输出` 集合时，使用 `--all-meshes` 对合集内全部网格执行同等严格验收。
