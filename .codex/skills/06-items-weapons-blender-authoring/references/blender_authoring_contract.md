# Blender 原始文件制作契约

本文件是 `06-items-weapons-blender-authoring` 的字段与参数口径。

## 1. 集合层级

```text
<前缀>_<中文资产名>_中文资产管理
├─ 01_制作组件_已统一材质      hide_viewport=True, hide_render=True, 不导出
├─ 02_游戏输出_整合模型        导出源
├─ 10_骨骼与动画               tier_1 / tier_2 才有内容，参与导出
├─ 80_挂点_交互接口            空对象，参与导出
└─ 90_展示环境_灯光相机        hide_render=True, 不导出
```

- 集合名固定，编号即职责，不得改名或调换编号。
- 末级容器即未来导入、替换、导出的边界；一个资产单位一份 GLB、一份 PackedScene。
- 禁止把多件独立资产焊成一个网格；语义独立的附件必须独立。

## 2. 命名

| 对象 | 规则 |
|---|---|
| 源文件 | `<资产逻辑名>_source_v###.blend`，小写 snake_case |
| 根集合 | `<前缀>_<中文资产名>_中文资产管理`（前缀 `PRP_` / `WPN_`） |
| 制作组件 | `<中文资产名>_制作组件_<部位>` |
| 输出网格 | `<前缀>_<资产逻辑名>_<材质角色>_<部位>` |
| 材质 | 本分支固定角色名；禁止 `.001`、`_v018`、`_修订版` 类后缀 |
| 挂点 | 项目契约名（见 §5） |
| 骨骼 | 语义名，全资产唯一 |
| 动画动作 | 稳定语义名，与运行时事件对齐 |

文件名与目录名不带版本号；`v###` 只在 `source/`。

## 3. 材质角色与参数基线

**道具分支（上限 4）**

| 角色 | 金属度 | 粗糙度 | 清漆 | 用途 |
|---|---:|---:|---:|---|
| `01_精工金属_道具骨架` | 0.80–0.92 | 0.22–0.32 | 0.10–0.25 | 框架、金属件、钥匙齿、铰链 |
| `02_细腻哑光_道具大面` | 0.00–0.05 | 0.62–0.78 | 0 | 大面积本体、橡胶、塑料 |
| `03_清漆反光_道具点缀` | 0.10–0.25 | 0.10–0.18 | 0.55–0.80 | 玻璃、焦点装饰 |
| `04_柔和自发光_道具UI` | 0 | 0.30–0.45 | 0 | 指示灯、屏幕图形，强度 1.0–1.6 |

**枪械分支（上限 3，不含自发光）**

| 角色 | 金属度 | 粗糙度 | 清漆 | 用途 |
|---|---:|---:|---:|---|
| `01_精工金属_枪身骨架` | 0.80–0.95 | 0.18–0.30 | 0.15–0.30 | 枪身主体、枪管、机匣 |
| `02_细腻哑光_枪身大面` | 0.00–0.05 | 0.60–0.75 | 0 | 握把、护木、大面聚合物 |
| `03_清漆反光_枪身点缀` | 0.15–0.30 | 0.08–0.18 | 0.60–0.85 | 瞄具镜片、装饰亮面 |

- 颜色只由 PaletteUV 控制；颜色变化不得增加材质球。
- 自发光网格与主体分离，独立成网格对象。
- 不使用带 Blender 复制后缀的材质名。

## 4. 色盘与 PaletteUV

- 唯一色盘：`assets/art/shared/palette/设施低亮多巴胺色盘_10x10_512.png`。
- 图片数据块必须**外链**该文件（相对路径以 `//` 开头），不得内嵌、不得复制到资产目录。
- 采样 `Closest`，512×512、10×10 纯色格，第 10 列为冷调灰阶。
- 每个输出网格有且只有 `PaletteUV` 一层；不保留 `UVMap` / `UV贴图` 旧层。
- `PaletteUV` 必须同时是活动编辑层与活动渲染层。
- 每个面的 UV 岛**必须有面积**，完整落在单一色格的安全内区，不压成点、不跨格。

## 5. 挂点契约

**道具分支**

| 挂点 | 必需性 | 说明 |
|---|---|---|
| `ItemRoot` | 必需 | 稳定根；普通静态/掉落道具以接地或物理平衡点为原点 |
| `HoldAnchor` | 仅可手持道具 | 标出掌心/握点与朝向；默认右、上、前为 `+X`、`+Y`、`-Z` |

**枪械分支**

| 挂点 | 必需性 | 说明 |
|---|---|---|
| `WeaponRoot` | 必需 | 原点=主手稳定握持位置 |
| `GripSocket` | 必需 | 默认与 `WeaponRoot` 同位同向；对齐角色 `WeaponSocket` |
| `MuzzleSocket` | 枪械必需 | 真实弹道出口，朝 `-Z` |
| `SupportHandSocket` | 双手武器 | 副手目标点，IK 由角色系统计算 |
| `MuzzleAttachmentSocket` | 有配件槽时 | 枪口配件 |
| `ScopeSocket` | 有瞄具时 | 瞄线可用位置 |
| `MagazineSocket` | 有弹匣时 | 弹匣插槽 |
| `StockSocket` | 有枪托时 | 枪托插槽 |
| `TacticalSocket` | 有战术槽时 | 战术配件 |
| `MutatorSocket` | 有变异槽时 | 变异件 |
| `MeleeHitBase` / `MeleeHitTip` | 近战必需 | 连续扫掠两端，覆盖实际攻击刃/头 |

挂点名称以项目契约为准，**不得**同时创建 `GripAnchor` / `MuzzleAnchor` 这类同义第二套命名。

## 6. 动画三档的具体做法

### tier_0_static

不建骨架、不建动画、不建 `10_骨骼与动画` 内容。该档建骨架视为负债，验收判失败。

### tier_1_articulated

1. 每个可动件与固定件分离为独立对象。
2. 单轴简单件（盖子、折页、按钮滑块）用对象级动画；多轴或联动件（枪机、抛壳、折叠托）用局部骨架。
3. 骨架只含本资产局部骨骼，不含人形、手臂或手部骨骼。
4. 动画动作名与运行时事件对齐：
   - 枪械：`fire`、`reload_eject`、`reload_insert`、`reload_chamber`
   - 近战：`melee_damage_begin`、`melee_damage_end`
   - 通用可动件：`<部位>_open` / `<部位>_close` / `<部位>_toggle`
5. 动画只表达表现时点；伤害、弹药与状态权威由运行时逻辑决定。

### tier_2_deform

骨骼 + 蒙皮，只对确需形变的部位建骨骼。权重必须可复现，不烘焙角色身体、手臂或动作。

### 明确排除

拾取动作、放入库存、拿起、投掷、角色手势、角色 IK、瞄准姿势、后坐力叠加、状态机。

## 7. 坐标与原点

- 单位米，源文件根缩放恒为 1。
- 道具：`ItemRoot` 为原点，底面贴地或取物理平衡点。
- 枪械：`WeaponRoot` 位于握把；右、上、前为 `+X`、`+Y`、`-Z`。
- 枪口位于真实弹道出口；瞄具锚点在可用瞄线上；近战扫掠两端覆盖实际攻击范围。
- 展示地面、底台、相机、灯光、角色手、场景装饰不进入导出集合。

## 8. 自检

模板级校验（每次新建源后跑一次）：

```bash
blender --background --factory-startup --python scripts/blender/validate_items_weapons_template.py -- \
    --kind prp --template "<...>/<资产逻辑名>_source_v001.blend"
```

判据 `PRP_TEMPLATE_VALIDATE_OK` / `WPN_TEMPLATE_VALIDATE_OK`。

通用美术验收（沿用场景规范脚本，按资产类型调整材质上限）：

```bash
blender --background "<资产逻辑名>_source_v001.blend" --python \
    "~/.workbuddy/skills/blender-game-prop-standard/scripts/validate_game_prop.py" -- \
    --max-materials 4 \
    --shared-palette "<项目>/assets/art/shared/palette/设施低亮多巴胺色盘_10x10_512.png"
```

## 9. 门禁速查

| 检查 | 失败判据 |
|---|---|
| 集合层级 | 缺少或多出固定编号集合；模板示例对象残留 |
| 材质 | 出现未登记角色；枪械超过 3 个或出现自发光；带复制后缀 |
| 色盘 | 内嵌图片；非 `//` 外链；采样非 `Closest`；色盘 PNG 出现在资产目录 |
| PaletteUV | 层缺失；非活动编辑层或活动渲染层；UV 岛无面积或跨格 |
| 挂点 | 缺失、多余、命名不一致、创建同义第二套 |
| 动画 | `tier_1` 及以上无动画；`tier_0` 建了骨架 |
| 坐标 | 根缩放不为 1；用缩放凑尺寸 |
| 越界 | 碰撞体、玩法脚本、角色动作进入导出集合 |
