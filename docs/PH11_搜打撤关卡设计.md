# Phase 11：搜打撤关卡设计 — 大地图 + 房间设施 + 警觉AI

## 目标
从"一堆怪物在房间中间"升级为"有空间感的大地图"，玩家可以在房间之间搜索、绕路、规划撤离。怪物有区域意识，不会无脑冲脸，而是会发出警觉、追击、伏击。

---

## 阶段目标一句话

> 构建一个有房间网络的关卡大地图，每个房间有明确功能（搜刮/战斗/事件），怪物AI有警觉半径和追击逻辑，命运卡片作为环境触发器嵌入地图，怪物掉落货币，玩家目标是找到撤离点并活着出去。

---

## 一、大地图结构

### 1.1 地图节点图
- 当前用 `NodeGraph` 生成多叉树地图
- 升级为**带房间类型的连通图**，节点代表房间，边代表通道（门）
- 每张地图有 8~15 个房间节点
- 房间分**入口/出口**，有路径依赖关系

### 1.2 房间类型
| 房间类型 | 英文标识 | 功能 |
|---|---|---|
| 出生房 | SPAWN | 玩家初始位置，有初始装备箱 |
| 普通搜刮房 | LOOT | 箱子、容器、少量小怪 |
| 普通战斗房 | COMBAT | 中等怪物密度，标准掉落 |
| 精英房 | ELITE | 高难度，1只精英+小怪，高品质掉落 |
| 事件房 | EVENT | 随机事件（诅咒/交易/祝福/赌局） |
| 商人房 | MERCHANT | NPC商人，消耗货币买装备/卡片 |
| 改造房 | WORKSHOP | 工作台，可重装配武器 |
| 撤离房 | EXTRACTION | 已解锁的撤离点 |
| Boss房 | BOSS | 大型敌人，胜利后开放深层或触发撤离 |
| 储藏室 | STORAGE | 隐藏房，需要钥匙或特殊条件 |
| 陷阱房 | TRAP | 环境危险，怪物埋伏 |

### 1.3 房间尺寸分类
| 尺寸 | 英文 | 用途 |
|---|---|---|
| 小 | SMALL | 1v1战斗、单向出口 |
| 中 | MEDIUM | 标准战斗房 |
| 大 | LARGE | 多波次精英战 |
| 超大 | ARENA | Boss战、事件爆发 |

### 1.4 房间几何布局
每个房间有可视化几何形状（Rectangle/Arena/Corridor），玩家可以绕障碍物走位，怪物也有掩体逻辑。

| 铁箱 | Strongbox | 高品质掉落，需要开启时间 |

## 三、怪物AI警觉系统

### 3.1 核心设计原则
**怪物不直接冲向玩家**，而是根据距离和状态进入不同AI模式。

### 3.2 AI状态机
```
IDLE（空闲）
  ↓ 玩家进入感知范围
ALERT（警觉）
  ↓ 确认威胁或丢失目标
CHASE（追击）
  ↓ 目标死亡/撤离/丢失
SEARCH（搜索）
  ↓ 多次未找到
PATROL（巡逻）
```

| 状态 | 行为 | 视觉表现 |
|---|---|---|
| IDLE | 原地小范围移动，不主动攻击 | 眼睛正常 |
| ALERT | 停止、看向玩家方向、发出警告音 | 眼睛变黄，头上出现 `?` |
| CHASE | 全速追击玩家，攻击间隔缩短 | 眼睛变红，头上出现 `!` |
| SEARCH | 在最后看到玩家的位置徘徊 | 眼睛黄+问号 |
| PATROL | 沿固定路线巡逻 | 无特殊标志 |

### 3.3 感知系统（Awareness）
| 感知类型 | 范围 | 说明 |
|---|---|---|
| 视觉 | 350px | 直线传播，被掩体遮挡时大幅降低 |
| 听觉 | 250px | 玩家移动、射击时积累 |
| 警报 | 联动 | 一个怪物ALERT，周边怪物感知到并降低警觉时间 |

### 3.4 警觉等级（Alert Level）
每个怪物有自己的警觉等级，影响行为：

| 警觉等级 | 触发条件 | 行为 |
|---|---|---|
| 0 | 无目标 | IDLE/PATROL |
| 1 | 轻微声音/间接证据 | SEARCH，向可疑位置移动 |
| 2 | 视觉确认 | ALERT，发出警告，计时 3s |
| 3 | 持续看到目标 | CHASE，攻击玩家 |
| 4 | 目标脱离视线 | SEARCH + ALERT 继续计时 |

### 3.5 区域性刷怪
怪物不是全局漫游，而是在各自房间内活动：

- 每个房间有自己的一组怪物（spawn group）
- 怪物不会主动离开自己所属的房间（除非进入 CHASE 状态）
- **警戒范围扩展**：怪物 CHASE 时会通知相邻房间的怪物，让它们进入 ALERT（区域性增援）
- 玩家逃离房间后，追击怪物在房间边界停下，回到 SEARCH → PATROL

### 3.6 不同怪物的警觉特性
| 怪物类型 | 感知范围 | 警觉速度 | 追击持续时间 |
|---|---|---|---|
| 近战追击型 | 250px视觉 | 快（1s） | 长（无限） |
| 远程弹幕型 | 400px视觉 | 慢（2s） | 中（10s后返回） |
| 潜伏型 | 100px视觉 | 极慢 | 极长（埋伏策略） |
| 精英怪 | 400px+听觉 | 中 | 无限 + 通知队友 |

## 四、命运卡片与地图触发机制

### 4.1 环境命运卡片触发器
地图中散布命运卡片触发器，触发后应用对应效果：

| 触发器类型 | 触发条件 | 效果 |
|---|---|---|
| 击杀×N | 击杀N个敌人后 | 触发命运效果（强化/召唤/状态） |
| 开箱×N | 开启N个容器 | 触发命运效果 |
| 货币×N | 拾取N次货币 | 触发命运效果 |
| 进入房间×N | 进入第N个房间 | 触发命运效果 |
| HP低于×% | 生命低于阈值 | 触发命运效果（反杀/逃跑/爆发） |
| 时间 | 局内存活时间 | 随时间推进触发效果 |
| 精英击杀 | 击杀精英后 | 触发高价值命运效果 |

### 4.2 命运效果示例（环境触发）
| 效果 | 触发条件 | 表现 |
|---|---|---|
| 敌增援 | 连续击杀3个敌人 | 波次外额外刷怪 |
| 幸运发现 | 开第5个箱子 | 箱子物品品质提升（蓝+以上） |
| 亡者祝福 | HP<30%后存活30s | 获得30s 10%伤害加成 |
| 诅咒降临 | 进入第7个房间 | 全局怪物伤害+15%，持续到本房间清理 |
| 货币雨 | 累计拾取200魂 | 获得一次随机货币掉落（50~100魂） |
| 命运标记 | 击杀第10个敌人 | 获得一张随机命运卡片 |
| 地图揭示 | 进入新房间 | 小地图显示周围3格房间类型 |
| 撤离加速 | 持续战斗2分钟 | 撤离读条时间减少2秒 |

### 4.3 怪物与命运卡片的互动
- 精英怪有概率掉落**命运卡片残页**
- 环境命运效果会让怪物获得额外词缀（临时）
- 部分命运效果会影响地图生成（如"本局多一个商人房"）

## 六、撤离点系统

### 6.1 固定撤离点
- 地图生成时在随机房间放置一个固定撤离点
- 玩家需要移动到撤离点并读条
- 读条期间：刷怪概率提高，不能再次移动

### 6.2 条件撤离点
| 类型 | 条件 |
|---|---|
| 精英撤离 | 击杀精英后解锁 |
| Boss撤离 | 击败Boss后解锁 |
| 信标撤离 | 消耗1个信标道具，任意位置可召唤 |
| 交易撤离 | 向商人支付资源 |

### 6.3 撤离流程
```
抵达撤离点 → 选择撤离方式 → 读条（5~10秒） → 撤离成功/被打断
```
读条期间玩家不能移动，可以被打断（受击、怪物攻击）。

## 八、关键技术实现要点

### 8.1 怪物AI状态机
每个敌人类有一个 `_ai_state: AIState` 枚举，在 `_physics_process` 中根据状态决定行为：
```
IDLE → 听到/看到玩家 → ALERT
ALERT → 超过警戒时间 → CHASE / SEARCH
CHASE → 目标丢失 → SEARCH → 多次未找到 → PATROL
PATROL → 看到玩家 → CHASE
```

### 8.2 区域感知（房间边界）
- 每个房间实例有自己的 `room_bounds: Rect2`
- 怪物在 `room_bounds` 之外时会减速并尝试返回
- 跨房间追击时有"走廊限制"，不能直接瞬移

### 8.3 命运触发器的配置驱动
环境触发器用数据配置表驱动，不写死在代码里：
```json
{
  "trigger_type": "kill_count",
  "threshold": 10,
  "fate_card_id": "fate_mark_enemy",
  "cooldown": 30
}
```

### 8.4 区域性刷怪（不再用全局波次）
RoomWaveSpawner 改为每个房间独立管理：
- 房间有 `spawn_group: Array[EnemyData]`
- 房间清理完第一波后，间隔 N 秒刷第二波（房间级，不是全局）
- 不同房间可以同时刷波次

## 九、预期玩家体验

### 9.1 探索节奏
1. **出生** → 打开附近箱子，获得初始模块
2. **规划** → 看小地图决定去哪个房间（搜刮还是战斗）
3. **遭遇** → 进入房间，怪物先警觉（发出声音），玩家有反应时间
4. **战斗** → 清完怪物后搜刮，触发命运效果
5. **决策** → 继续深入还是带东西撤离
6. **撤离** → 到达撤离点，读条，成功带出货

### 9.2 怪物体验
- 玩家走进房间边缘时，怪物会"注意到"（从IDLE变ALERT）
- 玩家可以利用警觉：引怪、绕后、分批击杀
- 精英怪会主动呼叫增援（不是简单刷怪，而是让相邻房间降低警戒时间）
- 击杀后货币直接飘到玩家（不需要跑过去捡）
