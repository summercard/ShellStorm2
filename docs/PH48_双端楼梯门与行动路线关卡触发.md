# PH48｜双端楼梯门与行动路线关卡触发

## 一、玩家路线问题

PH47虽然把98层入口大厅移动到了楼梯下接口，但垂直连接仍沿用一个共享边状态：
玩家在99层打开上端交通门时，98层入口大厅的下端门也会同时打开。角色沿楼梯下降
期间一直归属于99层房间，走到底后缺少一次明确的“开门进入98层”动作，因此视觉和
关卡节奏仍像从楼梯直接走到空楼板。

楼梯墙镜头也存在两处判定缺口：

- 运行时楼梯围护碰撞体名为 `StairwellWall_*Body`，PH46分类器没有把它识别为墙。
- PH47使用门中心6.5米圆形旁路，范围覆盖楼梯门厅和部分梯跑，导致靠近门的楼梯墙
  同样失去镜头响应。

## 二、双端门状态

每个垂直楼梯间固定具有两扇独立实体门：

1. **上端门**：属于当前楼层；打开后只启用楼梯间和上端门。
2. **下端门**：属于下一层入口大厅；上端门打开时仍保持关闭和实体碰撞。
3. 玩家沿楼梯抵达下层门前，当前房间仍是上层房间。
4. 玩家在下端门前按 `E`，下端门打开并立即调用下一层入口大厅的进入逻辑。
5. 入口大厅成为当前房间、自动点亮顶灯、保持安全区并刷新楼层HUD。
6. 再打开入口大厅到战斗枢纽的门，才触发本层命运卡和首个战斗房。

已开启的上下端门在本局内保持开启，允许原路返回；“独立”指开门时机和关卡触发
独立，不额外引入自动关门夹住角色的风险。

## 三、门槛镜头旁路

门洞不再使用圆形半径。只有同时满足以下条件才暂停墙体镜头响应：

- 门已经打开；
- 角色位于门的局部门板宽度内，横向距离不超过 `2.15m`；
- 角色距离门平面前后不超过 `0.90m`；
- 角色与门的垂直差不超过 `2.0m`。

这形成一条只覆盖门槛的短矩形通道。角色在楼梯平台、梯跑或门旁墙边时，楼梯墙仍
正常触发PH46抬升收拢；真正跨门的短时间内保持固定镜头，避免过门顿挫。

## 四、楼梯墙碰撞

- `StairwellWall_Lateral_A/B` 与 `StairwellWall_Outer` 全部加入相机墙分类。
- 门侧、远端、外侧三面围护继续使用规则Box碰撞，厚度 `0.30m`、高度 `9m`。
- Blender资产另有一块带门厅缺口的 `EnclosureWall_Inner`；只为这块内侧墙恢复
  同形三角网格碰撞，补齐此前可穿透的第四面墙。
- 楼梯连接启用期间，四面墙碰撞必须全部启用；进入下层大厅后连接仍保持启用。
- 其余三块导入 `EnclosureWall` 继续只做视觉，避免重复碰撞封死门口。
- `Walkable`同形碰撞继续负责梯跑和平台承重。
- 安全大厅地面增加一条贯穿上下门的发光路线带和两条门槛线；它们只负责让15米
  大厅和下一扇门在固定镜头下可读，不生成额外碰撞或家具障碍。

## 五、验收路线

以99F→98F为标准路线：

1. 99层上端门关闭时阻挡玩家，98层下端门也关闭。
2. 在99层打开上端门后，楼梯出现，但98层下端门仍关闭。
3. 玩家按11个路径点下楼，在下端门前被实体门阻挡，不能直接进入98层大厅。
4. 靠近楼梯围护墙时，镜头能够识别规则墙与内侧墙碰撞并抬升/收拢。
5. 玩家不能横向穿过四面楼梯围护墙，内侧门厅缺口保持可通行。
6. 玩家在下端门前按 `E` 后，门打开并立刻进入 `floor_01_entry`。
7. HUD显示“98层·楼梯入口大厅·安全区”，顶灯开启、战斗输入关闭。
8. 98层大厅到战斗枢纽的门保持关闭；打开时出现一次命运卡。
9. 进入战斗枢纽后恢复战斗并生成敌人。
10. 98→97、97→96、96→95以及楼顶→99层全部使用相同双端门契约。

## 六、验收结果

- 99层基地南墙保持原响应：墙距 `1.05m`，镜头收拢到 `Z=0.153m`。
- 已开启门槛内镜头恢复至约 `(0,8,5.487)`；门槛外楼梯平台重新识别
  `StairwellWall`，实测墙距 `3.03m`、镜头抬至 `8.30m`并收拢到 `Z=0.153m`。
- 楼梯三面规则墙射线全部命中实体碰撞，Blender内侧墙同形碰撞也已启用；
  11点真实下楼路线仍可通行。
- 楼顶→99层和99层→98层的下端门均先阻挡玩家；98层使用真实 `E` 输入开门，
  开门前当前房间保持99层，开门后切换到 `floor_01_entry`。
- 98层安全厅顶灯、路线带、双门槛标识和安全区状态正常；大厅命运门与45米战斗
  枢纽刷怪正常。
- 塔楼主流程节点数 `2374`；性能专项为生成 `496.0ms`、最重房间 `42.1ms`、
  完整探索节点 `2950`、持续段 `6.90ms`，保持在既有预算内。
- 塔楼主流程、真实楼梯镜头、OpenGL视觉采样、360°视野输入、完整3D战局、
  垂直物理、性能和运行安全专项全部通过。
