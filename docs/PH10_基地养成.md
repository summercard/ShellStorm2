# Phase 10：基地养成

## 目标
提供长期目标，解锁更多模块、卡片和挑战，但不破坏局内随机性。

---

## 基地建筑
| 建筑 | 功能 |
|---|---|
| 枪械工坊 | 解锁新枪身、新槽位预览 |
| 弹药温室 | 解锁新子弹池 |
| 配件垃圾场 | 解锁奇怪配件 |
| 命运占卜屋 | 解锁命运卡片池与初始抽卡机会 |
| 保险柜 | 增加撤离保险格 |
| 黑市 | 出售高风险高收益带入物 |
| 怪物档案室 | 查看怪物弱点与掉落 |

---

## 长期解锁内容
- 解锁新模块，不直接给永久数值碾压
- 解锁更多命运卡片类型
- 解锁更高风险地图
- 解锁初始构筑选择
- 解锁挑战契约

---

## 单局任务
- 使用挂载枪击杀30个敌人
- 成功带出一张红色命运卡片残页
- 在不撤离的情况下击败两名Boss
- 用一个子弹同时挂载两种配件
- 使用失控组合完成撤离

---

## 长期任务
- 收集所有枪身蓝图
- 解锁所有子弹变种
- 击败污染层Boss
- 完成一次零带入撤离
- 制作一次五层武器树

---

## 与搜打撤的关系
基地养成是"局外长期目标"，与局内搜打撤决策互补：玩家在局内用强力构筑追求收益最大化，局外用积累的资源解锁更多可能性。

## 2026-05-23 修复记录
- 保险柜从“仅查看持久物品”推进为局前决策入口：玩家可把保险柜物品加入下局带入清单，也可取消。
- 基地存档版本提升到 `1.1`，新增 `pending_loadout_items` 保存下局带入计划。
- 当前策略是启动任务时消耗带入计划并从保险柜移除对应物品，符合轻度搜打撤的风险/收益关系。
