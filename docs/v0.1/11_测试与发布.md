结构、到达门、运行性能、网格、光照墙体和Metal塔楼画面专项均通过；新增唯一精英、独立Boss和真实三区段专项。`WeaponInstance`现递归释放未入SceneTree的整棵`AssemblyNode`数据树，复跑原告警用例退出日志不再出现ObjectDB/resource引用残留。

## 3. 分层测试

<span style="color:#1565C0">**[执行规则｜2026-08-13]** 分钟级/小时级浸泡和目标设备GPU Profiler不再作为交互开发任务的同步验收方式。日常改动只运行短专项、核心回归和明确性能预算；长测移至独立发布/CI步骤异步执行并落盘日志，后续任务只读取结果，不在对话中持续轮询。</span>

| 层级 | 目标 | 典型证据 |
|---|---|---|
| 数据校验 | ID、字段、引用、数值范围、存档 schema | 数据库扫描、公式错误扫描 |
| 领域单测 | 状态、伤害、生成计划、精英唯一性、结算 | 无场景脚本测试 |
| 场景集成 | 玩家、门、房间、敌人、设施、UI | `tests/verification/*.tscn` |
| 生成性质测试 | 多种子、多楼层不变量 | 重叠、可达、组件对齐报告 |
| 可视回归 | Mesh、材质、灯光、相机、动画 | 固定机位 PNG |
| 性能回归 | 节点、Draw Call、对象池、流送 | 性能预算场景 |
| 长时热浸泡 | CPU/GPU帧时间、RSS、物理查询、热状态、进程残留 | 30/60分钟实机报告 |
| 存档破坏测试 | 中断、备份、迁移、幂等 | 临时用户目录与故障注入 |
