# 《Enter the Gungeon》随机关卡生成机制 · 资料页

> **这不是本工程的设计。** 本页是外部作品的公开资料整理，用于给[远征关卡03 设计](../../design/远征关卡03设计.md)提供**可核对的对照样本**。
> 与本工程设计页冲突时，一律以设计页为准。

## 1. 这份资料是什么

《Enter the Gungeon》的地牢生成系统（游戏代码里叫 `Dungeonator`）已被完整反编译。
本页把三条来源的结论合成一条五段管线，并用**从游戏数据直接导出的 28 张 flow 骨架图**做实测统计。

整理时间：2026-10-27。

## 2. 来源与可信度

| 来源 | 拿到了什么 | 可信度 |
|---|---|---|
| **Boris the Brave** 反编译分析（2019-07-28） | 五段生成管线、复合对象算法、回溯上限、走廊长度、注入机制、flow 数量 | **高**（对着代码写的，附 28 张 flow 原图） |
| **Boris 附带的 flow 图包** | 全部 28 张 flow 的 PDF（已转 PNG 入库） | **高**（直接从游戏数据导出） |
| **EtG Modding Guide**（社区 mod 文档） | 游戏内部 API：`DungeonFlow`、`RoomCategory` 枚举、两层注入字段、`GameLevelDefinition` 全部字段 | **高**（mod 作者直接调游戏类） |
| **wiki.gg** `Secret_Rooms` | 隐藏房 90%、按权重选房、NPC 隐藏房独立抽取、`EMPTY` 权重 0.8 | 中高（玩家侧统计 + 数据挖掘；权重表在折叠区，未能二次核验） |

> 俄文转载（habr 462377）与机翻站是同一篇的二次转载，只作交叉验证，不作为引用源。
> 网上流传的中文"生成规则总结"（`sousou.com` 一类）是编的 —— 所谓 5 层结构、`Obsidian Vault`、DAG 强制主线、127 种模板，全部与反编译结果对不上，**不可用**。

## 4. 被本工程实际采用的部分

只有下面这些数字进了设计页，其余（枪械、道具、敌人等）未采用。

| 参考值 | 数值 | 用到哪 |
|---|---|---|
| 第一层 flow 张数 | 6 | 远征03 的骨架池 = 6 张 |
| 单张骨架房间数 | 16 / 17 / 17 / 17 / 17 / 18，均值 **17.0** | 远征03 六张骨架逐张对齐（§3.3） |
| 每张骨架的固定房 | 1 入口 + 1 出口 + 1 Boss 前厅 + 1 Boss + 1 商店 + 2 奖励房 = **7** | 远征03 的"固定开销 = 7"（§3.3） |
| `NORMAL` 逐张 | 7 / 8 / 7 / 8 / 7 / 8 | 远征03 每张骨架的 `NORMAL` 数 |
| `HUB` 逐张 | 2 / 1 / 2 / 2 / 1 / 2 | 同上 |
| `CONNECTOR` 逐张 | 0 / 1 / 1 / 0 / 2 / 1 | 同上 |
| 房型类别数 | 9 类（ENTRANCE / EXIT / BOSS / BOSS FOYER / REWARD / SHOP / NORMAL / HUB / CONNECTOR） | 远征03 的 9 类 `kind`，一对一映射（§3.1） |
| 注入规则四要素 | `{注什么, 注在哪, 概率, 条件}` | 远征03 的注入表结构（§6） |
| 隐藏房出现率 | 90%，落死胡同优先，1/5 概率挂任意房间 | 远征03 注入规则第 1 条 |
| 回溯重抽上限 | 3 次 | 远征03 阶段 A 的摆位重试预算 |

**没有采用的部分（明确写下，避免后人误以为抄全了）**：走廊长度 4~30 单位、每层 4~8 张 flow 的区间、
`bossDpsCap` 数值、房间模板总数约 300、NPC 隐藏房 `EMPTY` 权重 0.8 的具体取值 —— 这些属于 Gungeon 的数值，
本工程要么口径不同（远征是单层、没有"下一层"），要么还没到定数的阶段。
