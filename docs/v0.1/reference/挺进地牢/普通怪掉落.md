# 《挺进地牢》普通怪掉落结构（第一层）

> 本文只记录**原作事实**，不写我们的实现。用于对照 `docs/v0.1/design/怪物设计.md` §T8。
> 采集时间：2026-10-29。来源与可信度逐条标注，**没有来源的数字一律不写**。

## 1. 三条硬规则（可直接照抄）

| # | 规则 | 原文 | 来源 |
|---|---|---|---|
| ① | **普通怪不掉装备** | 装备来自宝箱 / 商店 / Boss；wiki 的敌人条目里没有任何「drops a gun」类描述 | `enterthegungeon.wiki.gg/wiki/Cult_of_the_Gundead`（全表逐条描述，无一条提到掉装备） |
| ② | **自爆的敌人不掉铸币** | “All enemies that will self-destruct will not drop shells.” | `enterthegungeon.wiki.gg/wiki/Pickups` |
| ③ | **弹药是清房结算，不是逐只怪** | “Upon clearing a room, there is a chance that ammo may spawn.” | 同上 |

②还包括一条推论：**被玩家触发的陷阱击杀（吊灯、爆炸桶）掉更少的铸币**。我们目前没有这类击杀来源，先不做。

## 2. 铸币（Shells）

- **掉落时机**：死亡时，概率掉落（“often dropped by enemies upon their death”）。
- **拾取方式**：留在地上，战斗结束后会滑向玩家；掉进坑里会重生在玩家脚下并自动拾取。
- **面额**：1 / 5 / 50 三种。
- **总量参照**：「每一层平均的金币收益大概是 59 左右」—— 社区统计，**非官方**，仅作量级参考。
- **例外**：自爆怪不掉；陷阱击杀更少。

> ⚠ 具体**掉率百分比**没有权威来源。wiki 只说 “often”。所以「每只怪 N% 掉 M 枚」这组数字**不能声称来自原作**。

## 3. 清房结算（两个独立判定）

两层结构，**各自独立掷骰**：

| 判定 | 概率（一层） | 内容 |
|---|---|---|
| ① 拾取物 | **20%**（联机 30%） | 从权重表抽一个 |
| ② 弹药 | **6%**（联机 ×1.5；受诅咒影响 ×(1+curse/20)） | 50% 普通弹药 / 50% 扩散弹药 |

拾取物权重表（`enterthegungeon.wiki.gg/wiki/Pickups`，原文数值）：

| 类别 | 权重 |
|---|---|
| 半颗心 | 36.06% |
| **钥匙** | **24.36%** |
| 整颗心 | 4.345% |
| 护甲 | 6.09% |
| Glass Guon Stone | 9.1176% |
| Blank | 10.64% |
| 弹药 | 3.045% |
| Hegemony Credit | 6.09% |
| Silver Shell | 0.1479% |
| Gold Shell | 0.1479% |
| Map | 0.03045% |
| Supply Drop | 0.03045% |

> 另外还有一条与「清房掉落」无关但常被混淆的机制：EGT 有 **Coolness（炫酷值）**，
> 影响清房掉落清算的**保底累积**（初始 1%，每次清房没有任何掉落就 +（1+Coolness）%，上限 80%，
> 直到下一次掉落才重置）。这解释了「为什么体感掉率比 20% 高」——但它是保底机制，
> 不是单次概率变大。我们**不做**这条（无 Coolness 系统）。

## 4. 两只逃跑怪的招牌掉落（必定）

| 怪 | 掉落 | 原文 |
|---|---|---|
| Keybullet Kin | **1 把钥匙**（jammed 变种 2 把） | “drop a key upon death”；“If a Keybullet Kin is knocked into a pit, it will not drop a key.” |
| Chance Kin | **1 个随机拾取物**（jammed 变种有机会双倍） | “drop a random pickup upon death” |

两者的共同前提：**没在限时内被打死就会传送消失**，消失不掉任何东西。
「打不打得死」本身就是掉落的一部分 —— 不是「打死必掉」，而是「只有打死才掉」。

## 5. 我们拿不到的数据

| 项 | 状态 |
|---|---|
| 铸币单只掉率 | **缺**。wiki 只有 “often”。社区统计只给层总量（≈59） |
| 铸币单只掉落数量 | **缺**。只有面额（1/5/50） |
| 清房拾取物的具体配置是否随层变化 | wiki 表中「一层」与「2/Oub/3/Abbey」列只在**弹药概率**上有差别（6% / 8.5% / 9%），拾取物权重表未分层 |

> 因此本工程实现时，「铸币必掉」这一条是我们自己的裁定（业主 2026-10-14：
> 「所有被击败的怪 100% 必掉货币」），**不是原作**。本文明确区分这两者，
> 免得后来的人把我们的裁定当成原作事实引用。
