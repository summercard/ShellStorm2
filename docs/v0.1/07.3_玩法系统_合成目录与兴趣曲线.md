# 玩法系统｜合成目录与兴趣曲线 v0.1

功能ID：`RUN-SYNTHESIS`（依附 `RUN-FORGE`）。状态：**旧定向碎片方案退役；当前契约只保留随机工坊与两条近战定向规则**。适用游戏工程：`0.1.0`。更新日期：2026-11-24。

> 旧版目录共九条定向配方：七条消耗蓝图碎片，两条消耗近战武器。现仅保留后者；旧碎片兴趣曲线、`bp_charge` 保底及钥匙流量不再适用。历史背景见 [旧保底开发记录](development/2026-10-18_synthesis_pity_settlement.md) 和 [变更日志](development/CHANGELOG.md)。

## 1. 当前范围

- 九种蓝图碎片不再是实物，也不再进入掉落、搜索、宝箱/容器、商店、剧情奖励、保底、背包、保险或合成材料。
- 普通房间钥匙不再是实物，也不再进入开局、清房、搜索、掉落、箱子、商店、保底或合成；普通房间门改由清房、事件或其它非物品门闸条件处理。
- 保留 `bp_` 枪械装配 ID、枪械工坊的金币升级/解锁与既有已解锁档案。`bp_` 在枪械/装配语境中是稳定 ID，不表示可拾取蓝图碎片。
- 保留武器改造台的随机 R1/R2/R3：重铸、融合、随机合成。随机配方不读取已退役碎片，也不以新物品替代碎片。
- 保留两条近战定向路线：棒球棍 → 巨型工业断刃 → 攻城裂甲斧。定向材料是实际近战武器，不是钥匙物品；其金币费用、解锁条件和产出必须沿现有工坊/改造台契约，不新增第三条近战路线。
- 教皇 `fate_sun_key` 稳定 ID 仅保留历史快照与合法读档兼容；正位、逆位均不再投放、不发普通钥匙。其它尚未施工的钥匙牌不在本轮自创替代效果。

## 2. 随机工坊契约

武器改造台仍按[武器改造台](07.2_玩法系统_武器改造台.md)执行：任意**仍为合法存量的非空物品**可作为材料，武器作为蓝本；退役蓝图碎片、普通房间钥匙及其历史字典不得重新进入材料池。

| 配方 | 条件 | 结果 |
|---|---|---|
| R1 重铸 | 1 把武器且燃料熔炼值 ≥ 3 | 原枪身随机重掷品质/弹种等允许字段 |
| R2 融合 | ≥ 2 把武器 | 从投入武器中随机选蓝本并生成一把新实例 |
| R3 随机合成 | 0 把武器且燃料熔炼值 ≥ 6 | 从当前工坊已解锁枪身池随机生成；数量仍受现行上限约束 |

R1/R2/R3 继续按金币费用公式成交，失败时投入物、金币和盘面原子回滚。具体熔炼值、品质、费用、弹种和事务规则唯一见[武器改造台](07.2_玩法系统_武器改造台.md)，本页不复制常量。

## 3. 两条近战定向规则

近战定向不是“钥匙配方”，而是现有近战武器之间的明确升级入口：

| 方向 | 输入 | 输出 | 约束 |
|---|---|---|---|
| 近战定向一 | `weapon_baseball_bat` + 合法材料 | `weapon_greatblade` | 只消费实际棒球棍实例；按现行金币/熔炼事务结算 |
| 近战定向二 | `weapon_greatblade` + 合法材料 | `weapon_waraxe` | 只消费实际断刃实例；不新增钥匙物品或碎片 |

两条规则都必须保留完整 `weapon_instance_id` 事务语义；输入销毁与输出新实例同一事务完成，失败不得丢失输入。定向产物沿原枪械装配 ID、已解锁档案和普通售卖/存档规则流转。

本轮不新增近战第三级、不新增替代钥匙、不把任意消耗品伪装成定向凭据。

## 4. 枪械工坊与档案边界

- 枪械工坊仍以金币解锁枪身、弹药和配件的长期许可；解锁是永久档案状态，不是掉落实物，也不是蓝图碎片库存。
- 工坊已解锁档案继续作为 R3 随机枪身池和其它合法枪械产出的过滤条件；未解锁内容不得因退役碎片被替换或自动解锁。
- 原 `bp_pistol`、`bp_shotgun`、`bp_rifle`、`bp_machinegun`、`bp_sniper`、`bp_launcher`、`bp_charge` 等 ID 在枪械装配、性能和档案引用中保持稳定；其“碎片”解释、掉落成员和合成钥匙解释全部失效。

## 5. 退役项与旧存量

| 退役项 | 当前处理 |
|---|---|
| 九种蓝图碎片实物 | 合法读档边界过滤；不生成、不掉落、不搜索、不交易、不入合成 |
| `synthesis_pity.bp_charge` | 退役；合法读档时过滤该退役计数，不直接编辑用户存档 |
| 七条消耗碎片的 `SYN-*` 定向配方 | 退役；不迁移为其它配方，不补发替代物；两条近战定向规则保留 |
| 普通 `item_room_key` | 合法读档边界过滤；不再消费、返还、出售或保底 |
| 教皇 `fate_sun_key` | 稳定 ID 保留兼容；正逆位不投放、不发钥匙 |
| Boss 下行权限、剧情稀土钥匙、非物品门闸 | 按各自现行关卡/剧情契约保留，不得误删为普通钥匙 |

“过滤”只发生在合法读档/迁移事务形成新内存快照的边界；本轮不直接改正式用户存档文件，不动其它资产和物品。

## 6. 验收边界

验收应分别核对运行时、存档迁移和内容导航：

1. 当前奖励、搜索、箱子、商店、保底和普通门流程没有蓝图碎片或普通房间钥匙的活跃产出语义。
2. 掉落池移除退役成员后，其余成员按原权重归一；不出现替代物或隐式补发。
3. R1/R2/R3 仍可按金币完整结算；两条近战定向仍保留，且不依赖碎片/普通钥匙。
4. `bp_` 装配 ID、已解锁档案和合法枪械实例不被退役迁移误删。
5. 太阳钥印只保留稳定 ID 兼容，不进入当前投放、不发普通钥匙；未施工钥匙牌不产生自创效果。
6. 不以本文档门禁结果宣称运行时、XLSX、真实关卡或用户存档已经测试完成。
