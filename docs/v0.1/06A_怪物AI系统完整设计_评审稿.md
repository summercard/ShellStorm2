## 1. 设计目标

怪物 AI 必须让玩家能够观察、预测、利用和反制，而不是依靠读取玩家世界坐标制造伪智能。

1. **可信感知**：怪物只根据实际看见、听见、受击、受光、盟友传递和脚本事件行动；墙、门、楼板和投影必须有效。
2. **规则一致**：所有怪物共享目标合法性、房间隔离、打断、脱战、导航失败和性能规则。
3. **个体鲜明**：同一刺激对不同怪物产生不同回答，例如追光、避光、护卫、伏击或召唤。
4. **状态可读**：每次强行动都具有准备、执行、恢复三个表现阶段；玩家应能从姿态、朝向、音效和特效识别意图。
5. **参数优先**：距离、时间、权重和倍率能够表达的差异不得复制新 AI；只有改变决策结构或产生新交互时才建立专属行为。
6. **可诊断**：任意时刻可以回答“它感知到了什么、为何选择这个目标、为何进入这个状态、为何没有移动”。

### 1.1 非目标

- 怪物不读取未被感知的玩家实时位置。
- 普通怪不使用全图共享视野，也不跨未激活房间追击。
- AI 不直接控制掉落、门、存档或 Boss 下行权限。
- 不用提高转向速度、取消前摇或穿墙移动来伪装难度。
- 不让随机数每帧改变决策；随机只用于一次性候选打破平局，并由遭遇随机流提供。

## 2. 从大到小的系统结构

```text
关卡/遭遇层
├─ 房间激活、门状态、战斗边界、生成计划、允许参与战斗的玩家
└─ EncounterBlackboard（本次遭遇的共享事实，不保存全知玩家坐标）
   ↓
全局 AI 调度层
├─ MonsterAIManager（登记、错峰更新、预算、决策快照）
├─ MonsterPerceptionSystem（视觉、近距存在感、声音、受击、光照、盟友事件）
├─ MonsterTargetEvaluator（合法性、威胁值、目标锁定与切换迟滞）
└─ MonsterSquadCoordinator（有限告警、站位槽、攻击令牌、支援请求）
   ↓
个体决策层
├─ MonsterBrain（优先级仲裁、Utility评分、行为策略）
├─ MonsterMemory（最后已知位置、刺激、目标置信度、短期冷却）
└─ MonsterBehaviorProfile（通用行为块 + 物种参数 + 精英修饰 + Boss阶段）
   ↓
执行层
├─ 顶层状态机（生命周期与战斗大状态）
├─ 行动状态机（移动、瞄准、前摇、攻击、恢复、硬直）
├─ NavigationAgent3D（路径、局部避障、失败恢复）
└─ EnemyCombatExecutor（命中、投射物、召唤、护盾、伤害）
   ↓
表现层
└─ EnemyAvatar3D（动画、材质、轮廓、音效、VFX、头顶调试信息）
```

### 2.1 模块所有权

| 模块 | 拥有 | 禁止拥有 |
|---|---|---|
| 关卡/遭遇 | 房间边界、激活权、门、生成与清房 | 怪物具体攻击选择 |
| 感知系统 | 可验证刺激与置信度 | 移动、攻击、生命修改 |
| 目标评估 | 目标合法性、威胁分、锁定 | 直接写 Transform |
| Brain | 行为选择与原因码 | 命中结算、动画细节 |
| 状态机 | 转换、打断、计时、行动完成 | 扫描整个场景树找目标 |
| 导航 | 可达路径、速度建议、卡住恢复 | 穿墙或传送兜底 |
| 表现 | 动画/VFX/音效/UI | 决定伤害和感知事实 |

## 3. AI 数据分层

最终参数由下列层按顺序合成，禁止反复乘写基础值：

```text
通用规则
→ 物种 BehaviorProfile
→ 楼层/主题修饰
→ 精英 Modifier（如有）
→ Boss Phase（如有）
→ 瞬时状态（光照、减速、硬直、技能冷却）
→ FinalRuntimeProfile
```

### 3.1 BehaviorProfile 最低字段

```text
profile_id / archetype / locomotion_style
vision_range / vision_angle / proximity_awareness_range
hearing_threshold / alert_share_radius
memory_duration / target_lock_duration / target_switch_margin
preferred_range_min / preferred_range_max / retreat_range
move_speed / turn_speed / acceleration
attack_set[] / attack_cooldowns / telegraph / recovery
interrupt_resistance / stagger_duration
light_response_policy
squad_role / attack_token_cost / support_priority
leash_radius / search_duration / disengage_duration
```

参数只改变数值时复用同一策略；以下变化才允许新增策略 ID：

- 改变输入事实，例如埋地状态只能通过受光、近距或受伤揭示。
- 改变行动拓扑，例如召唤单位、正面护盾、死亡碎片。
- 改变目标类型，例如治疗盟友、寻找阴影而非追玩家。
- 改变阶段结构，例如 Boss 阶段技能表和场地规则。

## 4. 感知系统

### 4.1 感知事实统一格式

```text
stimulus_id / type / source_instance_id
world_position / direction / intensity
created_at / expires_at
line_of_sight / occlusion_kind
room_id / confidence
shared_by_instance_id? / reason_code
```

刺激类型：

| 类型 | 来源 | 是否给出玩家位置 | 基线有效期 |
|---|---|---:|---:|
| `visual_contact` | 视锥、距离、物理无遮挡 | 是，持续更新 | 看见期间 + 1.15秒记忆 |
| `proximity_contact` | 4.8m内存在感知且未隔墙 | 否，只给当前调查点 | 0.6秒 |
| `damage_contact` | 实际伤害上下文中的攻击者 | 是 | 8秒锁定 |
| `flashlight_contact` | 真正命中的玩家手电光束 | 是，来自灯光所有者 | 1.5秒 |
| `sound_contact` | 枪声、爆炸、脚步、门、技能 | 否，只给事件位置 | 依响度0.6–4秒 |
| `room_light_changed` | 房间灯开关 | 否，只给灯具/区域 | 4秒搜索 |
| `ally_alert` | 盟友有限传播 | 只给最后已知点 | 1.5秒 |
| `sun_exposure` | 太阳直射 | 否 | 受光期间 |

### 4.2 视觉

- 水平视锥固定采用120°基线，视距由怪物自身所处光照动态决定：黑暗8.5m、人工灯13.5m、太阳直射15.5m；物种可在此基础上参数化调整。
- 4.8m内的侧后方接近属于存在感知：通过墙体/门遮挡检查后只进入警惕并朝刺激点调查，不取得玩家节点；只有玩家落入真实视锥后才升级为视觉确认和战斗。
- 目标使用脚部、躯干、头部采样；至少一个有效采样点无遮挡才算看见。
- 玩家进入完整掩体后停止实时追踪，只保留最后已知位置。
- 视觉置信度持续看见时上升，失去视线后衰减；低于阈值转搜索，不在墙后跟随实时坐标。

### 4.3 声音

声音是位置刺激，不是视觉目标。建议基线传播半径：脚步3m、冲刺6m、门6.5m、开启容器8m、消音枪8m、普通枪14m、爆炸20m。实际半径乘声音强度、怪物听觉倍率和墙/门衰减。

- 实墙大幅衰减；关闭门中度衰减；同房间无遮挡不衰减。
- 怪物先转向并调查声音位置，看到玩家后才进入视觉追击。
- 连续枪声在短窗口内合并，禁止每颗子弹创建长期刺激。

### 4.3.1 动态警戒与进入战斗规则

AI 的警戒层与战斗层必须分离，`engagement` 稳定值为 `idle / alert / combat`：

| 刺激 | 进入层级 | 是否获得玩家目标 | 行为 |
|---|---|---:|---|
| 房间大灯照到 | `alert` | 否 | 朝灯具/受光区域调查；未被照到的怪物不响应 |
| 玩家近距离进入侧后方 | `alert` | 否 | 停顿转向0.42秒，再调查刺激点 |
| 开门、开容器等交互声 | `alert` | 否 | 按声音半径和墙体衰减朝事件点调查 |
| 真实视锥确认玩家 | `combat` | 是 | 进入战斗并持续更新可见位置 |
| 玩家前向探照灯真实命中 | `combat` | 追光型获得灯主；避光型获得生存任务 | 追击灯主或寻找暗区 |
| 武器实际命中 | `combat` | 是 | 无视普通视距，锁定攻击者8秒 |

开灯行为本身不得把整房怪物拉入战斗；只有受光采样确认被该灯覆盖的怪物响应。警惕阶段禁止读取玩家实时坐标，调查途中若获得视野则升级战斗；调查超时则搜索并回到巡逻。

### 4.4 受击与光照

- 受击是最高置信度的攻击来源，忽略普通视距和视锥，锁定攻击者8秒；攻击者无效、死亡或离开合法遭遇后立即清除。
- 手电命中能追溯灯光所有者。追光型获得目标，避光型获得灯位、来光方向和暗区搜索任务。
- 房间大灯开启只能触发区域搜索，不能凭空得到玩家位置。
- 太阳不会暴露玩家；它只产生环境生存刺激与持续伤害。

### 4.5 盟友传播

告警不是全房间瞬间共享。怪物发出一次有限半径事件：

- 直接看见玩家、受到伤害或死亡时可以广播。
- 盟友只收到事件发生点、粗略方向和事件年龄，不收到玩家节点引用。
- 墙与关闭门削弱传播；未激活房间拒绝接收。
- 同一刺激在0.5秒内去重，避免群怪回声式无限广播。

## 5. 目标选择与威胁系统

### 5.1 目标合法性硬条件

目标必须同时满足：实例有效、仍可战斗、处于同一合法遭遇/可达边界、不是无敌剧情对象、不是已隔离房间对象。硬条件失败立即清除，不受锁定时间保护。

### 5.2 威胁评分

```text
ThreatScore =
  感知可信度
  + 最近8秒对自己的伤害占比
  + 最近5秒对盟友的伤害占比 × 群体关心系数
  + 距离适配分
  + 当前可攻击分
  + 手电刺激分（追光型）
  + 保护对象受威胁分（护卫型）
  - 路径不可达惩罚
  - 超出战斗边界惩罚
  - 目标切换成本
```

单人游戏仍使用该结构，保证未来多人或诱饵目标不需重写。目标切换只有在新目标分数超过当前目标至少25%，或当前目标失效时发生；防止怪物每帧左右摇摆。

### 5.3 决策优先级

优先级由上到下，先过硬门，再在同层做 Utility 评分：

| 优先级 | 类别 | 规则 |
|---:|---|---|
| P0 | 生命周期 | `dead / despawn / room_inactive / scripted_lock`，不可被低级行为覆盖 |
| P1 | 不可取消行动 | 已进入命中生效帧或 Boss 阶段事务时完成原子动作；死亡例外 |
| P2 | 强制打断 | 硬直、击退、控制、阶段转换；记录可恢复上下文 |
| P3 | 环境生存 | 避光型离开太阳/强灯、爆炸体安全引爆判断、伏击体揭示 |
| P4 | 当前可执行攻击 | 目标合法、距离/角度/冷却/空间全部满足才进入前摇 |
| P5 | 紧急防御/支援 | 举盾、撤退、治疗低血盟友、召唤补位 |
| P6 | 追击与占位 | 接近、侧移、保持距离、包抄、保护队友 |
| P7 | 调查与搜索 | 最后已知点、声音、灯光变化、盟友告警 |
| P8 | 非战斗 | 回巢、巡逻、待机 |

优先级不代表必定执行。例如 P4 下存在多个攻击时，使用评分选择：命中概率、距离适配、风险、冷却、重复惩罚、队友占位和阶段权重共同决定。

### 5.4 决策稳定性

- 一般决策最短承诺0.25秒，移动策略最短承诺0.45秒。
- 新决策只有分数高出当前至少15%才抢占，同优先级使用稳定实例 ID 打破平局。
- 攻击进入前摇后遵循各技能取消窗口；禁止因目标在边界轻微抖动无限重播前摇。
- 目标丢失后先完成短期记忆，再搜索；搜索结束才回巢。

## 6. 通用状态机

### 6.1 顶层逻辑状态

```text
Dormant（房间未激活）
  → Idle → Patrol
  → Suspicious（低可信刺激）
  → Alert（确认威胁/反应前摇）
  → Combat（由行动子状态机执行）
  → Search（失去目标）
  → Return（脱战回巢）
任意可打断状态 → Stagger / Controlled
任意存活状态 → Dead
```

| 状态 | 进入条件 | 执行 | 退出条件 |
|---|---|---|---|
| `dormant` | 房间未激活或隔离 | 停止导航、攻击和常规感知 | 房间正式激活 |
| `idle` | 无刺激且位于职责区 | 低频观察、保持姿态 | 巡逻计时或新刺激 |
| `patrol` | 有巡逻点/守卫区 | 路径移动、停顿观察 | 刺激、超时、到点 |
| `suspicious` | 声音/灯变/盟友告警 | 转向、停顿、选择调查点 | 视觉/受击升级或置信度耗尽 |
| `alert` | 确认目标 | 播放警觉表现、广播一次 | 反应时间结束进入战斗 |
| `combat` | 有合法目标或生存任务 | 运行行动子状态机 | 丢失、脱战、死亡 |
| `search` | 失去目标但有记忆 | 搜索最后点及有限邻点 | 重获目标或搜索超时 |
| `return` | 超出职责区/搜索失败 | 返回 HomeAnchor、恢复编队 | 到达后待机 |
| `stagger` | 有效硬直 | 停止普通行动，执行受击位移 | 硬直结束恢复上下文 |
| `dead` | HP≤0 | 单次死亡、掉落与清房事件 | 不退出 |

### 6.2 战斗行动子状态机

```text
SelectAction
├─ Reposition → MoveToRange / Strafe / Flank / Retreat / SeekCover / SeekDark
├─ Defend → FaceThreat / RaiseShield / GuardAlly
├─ Support → Heal / Summon / Buff
└─ Attack → Aim → Telegraph → Active → Recovery
```

- `Aim` 只调整朝向和有限预判，不锁死玩家未来位置。
- `Telegraph` 必须暴露攻击类型、危险方向和生效时刻。
- `Active` 是唯一可产生伤害/投射物/召唤的窗口。
- `Recovery` 禁止立即重选同一强攻击；允许规定的受击打断。
- 行动完成、失败、超时、路径不可达都必须返回明确结果码。

### 6.3 打断矩阵

| 当前阶段 | 普通受伤 | 重击/控制 | 太阳伤害 | 死亡 | 房间停用 |
|---|---:|---:|---:|---:|---:|
| 移动/搜索 | 可打断 | 强制打断 | 不打断，仅触发生存策略 | 强制 | 强制暂停 |
| 瞄准/前摇前段 | 依抗性 | 强制打断 | 依物种 | 强制 | 强制暂停并取消 |
| 前摇后段 | 通常不取消 | Boss/重装依抗性 | 不取消原子攻击 | 强制 | 强制取消且不结算 |
| 生效帧 | 不取消本次已生成结果 | 不回滚已生成结果 | 不回滚 | 后续帧停止 | 不允许跨房生成 |
| 恢复 | 可打断 | 强制打断 | 不打断 | 强制 | 强制暂停 |

## 7. 移动、导航与空间规则

- 以 `NavigationAgent3D` 为正式路径来源，直接向目标写速度只用于短距离冲刺的已验证直线路段。
- 导航目标必须位于当前战斗边界或允许连接区；门关闭时路径不可通过。
- 近战使用环形接敌槽，远程使用射击槽，避免所有怪物挤到同一点。
- 同一目标默认同时拥有2个近战攻击令牌、2个远程强攻击令牌；其他怪物移动、压迫或换位，不同时无提示出手。
- 局部避障不能把怪物推出房间、墙体或楼板。
- 连续0.8秒期望移动但位移小于0.15m记为卡住：先重算路径，再换候选槽，最后回到最近有效导航点；禁止直接穿墙传送。
- 回巢半径由房间和物种定义。追击达到 Leash 边界后停止扩大范围，转搜索或回巢。

## 8. 光照与 AI 的统一规则

光照状态和 AI 状态正交：`暗/亮/太阳`描述环境事实，`追击/搜索/攻击`描述行为。

| 光照状态 | 全局战斗效果 | 追光型 | 避光型 |
|---|---|---|---|
| 黑暗 | 基线100% | 正常决策 | 正常决策/可进入伏击 |
| 人工灯 | 移速与攻击频率40% | 探照灯命中则追灯主；大灯只调查 | 优先寻找暗区，保留必要防御 |
| 太阳 | 每秒最大HP 2%伤害 | 维持目标，必要时阶段规则覆盖 | P3环境生存优先寻找投影 |

暗区候选必须同时满足：导航可达、目标点预估不受当前主导光照、不会跨房间边界、不会落入玩家不可见的非法几何。若无暗区，避光型先远离主导光方向，再使用掩体；不能瞬移。

## 9. 通用行为块

| 行为块 | 作用 | 关键参数 |
|---|---|---|
| `Approach` | 进入有效距离 | 目标距离、速度、接敌槽 |
| `HoldRange` | 维持区间 | 最小/最大距离、径向权重 |
| `Strafe` | 横向制造弹道变化 | 方向承诺、切换冷却 |
| `Flank` | 选择侧后候选槽 | 角度、路径成本、队友占位 |
| `Retreat` | 目标过近时后撤 | 触发距离、最远距离 |
| `FaceThreat` | 正面对准威胁 | 转向速度、容许角 |
| `TelegraphedAttack` | 前摇—生效—恢复 | 三段时间、取消窗口 |
| `BurstVolley` | 参数化多发弹幕 | 数量、夹角、间隔、预判 |
| `MeleeLunge` | 直线近战突进 | 距离、冲速、命中宽度 |
| `Guard` | 举盾/保护方向 | 防御角、移动倍率 |
| `HealAlly` | 治疗合法盟友 | 半径、低血阈值、冷却 |

## 10. 六种普通怪专属规则

以下为首轮建议数值，评审后再冻结到内容数据库。所有距离单位为米。

### 10.1 小菌猪｜近战追击者 `melee_chaser`

定位：基础压迫、迫使玩家移动；作为其他怪物行为的标尺。

- 复用：`Approach + Flank + MeleeLunge + Investigate`。
- 目标距离0–1.9；进入1.9m且拥有近战令牌时前摇0.38秒，短突进后恢复0.42秒。
- 两只以上时，一只直线压迫，其他个体优先选择±55°侧翼槽；不读取玩家背后位置瞬移包抄。
- 受手电命中属于追光型：锁定灯主，但人工灯减速仍生效。
- 连续两次冲刺失败后降低突进权重，改为重新占位，避免贴墙抖动。
- 参数变体可做：快但脆、慢但硬、长前摇高伤；不需要新状态机。

### 10.2 孢子射手｜远程施法体 `ranged_caster`

定位：中距离弹道压力，引导玩家利用掩体。

- 复用：`HoldRange + Strafe + Retreat + BurstVolley + SeekDark`。
- 理想距离6.0–8.5；小于4.0优先后撤，大于9.5接近。
- 三连发每发间隔0.18秒；第一发锁定当时位置，后两发只做有限速度预判，禁止持续追踪。
- 同方向横移至少维持0.8秒，切向冷却1.4秒，避免左右抽搐。
- 人工灯/太阳下属于避光型；寻找暗区优先于普通射击，但若玩家已进入3m危险圈，先执行一次后撤再寻暗。
- 参数变体可调弹数、散布、理想距离和预判系数。

### 10.3 蜂巢怪｜召唤支援体 `summoner`

定位：改变敌群结构，必须成为玩家可识别的战术目标。

- 复用：`HoldRange + Retreat + HealAlly + Summon + SeekDark`。
- 理想距离6.5–9.0；不主动进入近战槽。
- 决策顺序：危险后撤 > 太阳/强灯避光 > 低血关键盟友治疗 > 战场缺员召唤 > 普通压制。
- 治疗只选择12m内、可见或共享告警中的盟友；优先HP比例最低者，禁止治疗自己和已死亡对象。
- 召唤必须由遭遇系统批准：每个召唤者同时存活召唤物上限3、房间总增援上限由 EncounterPlan 决定。
- 召唤前摇0.9秒并有明显声光；被强打断时不消耗名额，进入50%冷却。
- 属于避光型；进入暗区后才提高召唤权重。

### 10.4 壳甲卫兵｜护盾重装体 `shielded`

定位：方向性防御与阵型支点，不是单纯高血量。

- 复用：`FaceThreat + Guard + Approach + MeleeLunge`。
- 正面护盾角建议110°；举盾时移速65%、转向受限，但正面防御有效。
- 有后排盟友时优先站在“玩家—盟友”连线中间的合法槽；无盟友则稳定推进。
- 攻击前必须短暂放低护盾形成输出窗口；盾击前摇0.55秒、恢复0.65秒。
- 玩家持续绕侧时，先转身而非滑步保持正面；重装转向必须可见且可利用。
- 属于追光型；手电可诱导其改变朝向，为侧击制造机会。
- 参数变体可调护盾角、转速、守护半径和盾击距离。

### 10.5 炸弹果｜爆破体 `exploder`

定位：移动危险区和空间驱赶；死亡碎片与主动爆炸必须区分。

- 复用：`Approach + TelegraphedAttack`，专属爆炸与死亡碎片执行器。
- 到达2.85m且路径清晰后进入0.9秒充能；充能期间减速并以音高、闪烁频率、地面危险圈表达剩余时间。
- 前摇前50%可被重击打断；后50%进入不可取消引爆，但死亡改为较弱死亡碎片，不产生完整主动爆炸伤害。
- 友军爆炸伤害默认关闭，但爆炸会产生告警刺激；避免敌群连锁自毁失控。
- 属于追光型，可被手电引向玩家；人工灯减速为玩家提供处理窗口。
- 参数变体可调引爆距离、前摇、爆炸半径和碎片数，不能取消危险提示。

### 10.6 地刺虫｜伏击体 `ambusher`

定位：利用黑暗和注意力制造短促伏击，而非永久隐形伤害。

- 复用：`BurrowAmbush + MeleeLunge + Retreat + SeekDark`。
- 黑暗中可埋伏；人工灯/太阳真实照射、4.4m近距存在感或受到伤害会强制揭示。
- 揭示后先播放0.46秒破土前摇，再突进；不能在未显形时直接命中。
- 一次突进结束后拉开2.5–4m；在连续2秒未被看见、位于暗处且距玩家大于5m时允许重新埋伏，冷却至少6秒。
- 重新埋伏必须使用可达地面点，不能越墙、钻过关闭门或脱离房间。
- 属于避光型；照明是克制手段，但人工灯40%速度/频率乘数与显形不能重复叠乘。

## 11. 精英 AI 规则

精英不是第七种基础 AI。每只精英由“基础物种 + 一个核心机制 + 最多一个成长机制 + 档案记忆”构成。

### 11.1 修饰器挂接点

```text
PerceptionModifier
TargetScoreModifier
ActionCandidateProvider
DamageReactionModifier
DeathActionModifier
PresentationModifier
```

现有修饰对应建议：

| 修饰 | AI挂接规则 |
|---|---|
| 巨大化 | 只调体型、占位半径、抗打断和动作时间，不复制 Brain |
| 分裂 | 仅挂死亡行动，生成仍受遭遇预算约束 |
| 反弹 | 挂伤害反应/投射物规则，不改变全局目标选择 |
| 寄生 | 死亡时强化合法盟友，目标选择可提高靠近盟友权重 |
| 抢枪 | 将夺取内容翻译为受预算限制的技能候选，不复制玩家整枪 DPS |
| 吞弹 | 增加吸收/反击候选及独立冷却，仍遵守前摇和攻击令牌 |

成长只能提高权重、数值或解锁一个新候选，不得逐局堆叠到无前摇、无限召唤、全角防御或不可打断。

## 12. Boss AI 规则

Boss 使用同一感知、目标合法性、导航与打断框架，但拥有独立阶段图和场地职责。

### 12.1 通用阶段结构

| 阶段 | 生命区间 | 战斗目的 | 建议变化 |
|---|---:|---|---|
| Phase 1 | 100%–65% | 教会基础招式 | 单发/小范围、召唤少、恢复较长 |
| Phase 2 | 65%–30% | 组合压力 | 多发、位移与召唤组合，冷却×0.82 |
| Phase 3 | 30%–0% | 收束战斗 | 新组合、场地压力、召唤一次性强化 |

- 阶段转换优先级P2，单次触发，短暂无敌只用于防止跨阶段重复结算，不清除玩家造成的合法持续效果。
- 阶段转换不重置目标、三态受光、掉落事务或下行权限事务。
- Boss 不因人工灯完全失能：仍承受40%速度/频率，策略选择保持；太阳持续掉血。
- 每阶段使用技能袋：近期使用过的技能降低权重，禁止连续随机同一高压技能。
- 强技能同时占用远程/场地攻击令牌，召唤物不应与 Boss 无提示大招在同一时间叠满玩家无解空间。

### 12.2 当前通用 Boss 待深化方向

当前“阶段弹幕 + 周期召唤”保留为基础模板。正式每个五层 Boss 必须拥有独立 `boss_content_id`、阶段技能表、场地交互和验收场景；仅修改血量、弹数和颜色不能算新 Boss。

## 13. 状态机表现规范

逻辑状态和表现标签分离。逻辑可快速切换，但表现必须遵循可读性契约：

| 意图 | 姿态/动画 | VFX/UI | 音效 | 玩家读到的信息 |
|---|---|---|---|---|
| 可疑 | 停步、转向刺激 | 轻微方向提示 | 短促疑问音 | 怪物听到了但未看见我 |
| 警觉 | 抬头/展开 | 短闪或轮廓变化 | 警觉音只播一次 | 已确认威胁，即将行动 |
| 近战前摇 | 重心后移、朝向锁定 | 地面扇区/冲刺线 | 蓄力音 | 攻击方向与时间 |
| 远程前摇 | 枪口/施法点聚能 | 弹道起点和颜色 | 充能音 | 即将发射的类型 |
| 召唤/治疗 | 明确指向盟友/生成位 | 连线或生成圈 | 独立技能音 | 应优先打断谁 |
| 举盾 | 盾面朝向目标 | 防御角轮廓 | 金属展开音 | 哪个方向不能硬打 |
| 避光 | 遮眼/收缩后移动 | 短暂暗区方向提示 | 畏光音 | 灯光正在改变其策略 |
| 硬直 | 后仰/停顿 | 命中反馈 | 受击音 | 攻击成功打断 |
| 搜索 | 降速、分段转向 | 调试版显示最后已知点 | 搜索音低频 | 已丢失我的准确位置 |

原则：伤害判定不得早于危险表现；动画缺失时使用程序姿态和VFX兜底，但时序不能缺失。头顶`暗/亮/太阳`是测试标识，发布版是否保留由后续 UI 评审决定。

## 14. 房间、遭遇与群体规则

- 开门预创建不等于激活；`dormant` 怪物不移动、不攻击、不传播刺激。
- 玩家正式进入房间后，同一 EncounterPlan 中的怪物按规则激活；已开邻房不会自动共享实时目标。
- 清房只统计本遭遇拥有的存活敌人和批准召唤物。
- 召唤、分裂和死亡生成均请求遭遇预算，失败要返回原因且不能卡住攻击状态。
- 同群怪共享有限黑板：最后告警点、支援请求、占用槽与攻击令牌；不共享玩家实时 Transform。
- 房门关闭或区段隔离后，目标合法性重新验证。非法目标立即脱战，不隔墙攻击。

## 15. 性能预算

- 管理器错峰8–10Hz更新普通感知；受击、手电命中、目标失效、房间切换强制刷新。
- 视觉先距离/视锥粗筛，再对少量候选发射物理射线。
- 声音使用事件总线和空间桶，不让每只怪遍历全部声音源。
- 暗区、掩体和站位候选分帧计算并缓存短时间；环境变化时失效。
- 远离当前房间的实例进入 dormant，不保留运行导航查询。
- 目标、灯光、盟友引用使用实例 ID + 有效性检查；场景卸载时立即清理。
- 30只活跃怪为基础验收，Boss+召唤物为峰值验收；不允许同帧集中重算所有路径和射线。

## 16. 调试与可观测性

每只怪快照至少包含：

```text
logic_state / action_state / state_time
state_enter_reason / last_interrupt_reason
target_id / target_score / target_lock_remaining
perception_stimuli[] / selected_stimulus
last_known_position / confidence
selected_action / action_score / rejected_top_actions[]
path_status / path_age / stuck_time / occupied_slot
attack_token / cooldowns
illumination_state / light_response_policy
room_id / encounter_id / runtime_active
species_profile / elite_modifiers / boss_phase
```

调试显示分三级：

1. 简洁：血条前`暗/亮/太阳`、当前大状态。
2. 个体：目标线、视锥、最后已知点、路径、选中行动和原因码。
3. 遭遇：站位槽、攻击令牌、告警传播、预算和激活边界。

正式构建默认关闭详细显示，但快照接口保留给自动化测试。

## 17. 自动化与实机验收

### 17.1 通用必测

- [ ] 玩家在视野内且无遮挡会被发现；背后、超距、隔墙不会被视觉发现。
- [ ] 4.8m内从侧后接近会触发近距存在感，隔墙仍不触发。
- [ ] 任意距离实际命中后怪物锁定攻击者8秒并产生真实接近位移。
- [ ] 枪声只让怪调查声音位置，不泄露墙后玩家实时坐标。
- [ ] 追光型被手电照中后追向灯主；避光型选择可达暗区。
- [ ] 房间开灯只触发搜索；太阳不暴露玩家。
- [ ] 目标绕进掩体后进入最后已知点搜索，不贴墙实时跟随。
- [ ] 关闭门、房间停用、玩家死亡和场景卸载会清理目标与引用。
- [ ] 前摇、命中、生效、恢复和打断时序一致，不出现无前摇伤害或重复结算。
- [ ] 路径不可达和卡住能够恢复，不穿墙、不瞬移、不永久原地攻击。
- [ ] 近战槽和攻击令牌限制群怪同时出手，仍保持持续压迫。
- [ ] 固定随机种子下，目标与行动选择可复现。

### 17.2 单怪必测

- [ ] 小菌猪单只直压、群体侧翼且不挤成一点。
- [ ] 孢子射手维持距离、过近后撤、三连发有可躲弹道。
- [ ] 蜂巢怪遵守治疗/召唤目标与房间增援上限，打断不吞名额。
- [ ] 壳甲卫兵正面防御、转身弱点和护卫站位可读。
- [ ] 炸弹果主动爆炸、被打断与死亡碎片严格区分。
- [ ] 地刺虫只被真实光照/近距/受伤揭示，可达条件满足后才重新埋伏。
- [ ] Boss 三阶段只各触发一次，技能袋避免连续高压重复，受光不重置阶段。

### 17.3 压力必测

- [ ] 30只普通怪持续战斗10分钟无感知/路径集中尖峰。
- [ ] Boss、召唤物、灯光切换、门开关同时发生时无悬空引用和重复攻击。
- [ ] 连续进出房间、跨楼层和区段卸载后，旧怪不继续运行或传播告警。

## 18. 实现量级与施工优先级

### 18.1 量级判断

完整实现本设计属于**中大型系统改造**，不是一次简单的怪物参数调整。现有工程已经具备可复用基础：统一 `Enemy3D`、全局 `MonsterAIManager`、独立视野与三态受光、受击/探照灯刺激、基础追击/搜索、六类怪物攻击入口和 Boss 阶段入口。因此不需要推倒重做；但统一刺激记忆、目标评分、双层状态机、正式导航、群体站位、攻击令牌、物种专属策略、精英挂点及 Boss 技能表仍是主要工程量。

量级按“程序实现 + 自动化测试 + 实机调参”估算：

| 范围 | 量级 | 说明 |
|---|---:|---|
| P0 可玩闭环 | 中等 | 在现有 AI 基础上补齐感知可信度、目标合法性、状态转换和导航兜底；解决不响应、隔墙追踪、原地卡死和无提示攻击等基础问题 |
| P1 战术差异 | 中大型 | 六种普通怪行为块、站位槽、攻击令牌、声音、有限盟友告警，需要多怪组合反复调参 |
| P2 内容扩展 | 大型 | 精英修饰、Boss 阶段技能表、独立 Boss 内容以及大量表现资源，工作量随怪物和 Boss 数量线性增长 |
| 全部完成 | 中大型至大型 | 建议按里程碑逐段交付，禁止一次性替换现有 AI 后再统一找问题 |

优先级含义：

- **P0 必须先做**：决定 AI 是否可信、是否稳定，未完成前不扩展新怪物和 Boss。
- **P1 核心体验**：建立群怪节奏和物种差异，是正式战斗体验的主体。
- **P2 内容深化**：建立精英与 Boss 的可扩展生产线，不阻塞基础关卡验证。
- **P3 发布验收**：性能、诊断、长时稳定与回归门禁；各阶段都要执行，最终集中收口。

### 18.2 P0：可信感知与稳定战斗闭环

| 顺序 | 实现项 | 当前基础 | 依赖 | 阶段验收 |
|---:|---|---|---|---|
| P0-1 | 冻结状态 ID、原因码、`BehaviorProfile`、刺激与决策快照契约 | 部分已有 | 无 | 所有状态转换能输出明确原因；测试不读取私有临时变量猜测状态 |
| P0-2 | 统一 `Stimulus/Memory` | 已有视觉、受击、探照灯、房间灯的分散实现 | P0-1 | 刺激具有来源、位置、置信度和有效期；墙后不泄露实时玩家坐标 |
| P0-3 | 目标合法性、房间/楼层边界和失效清理 | 已有单玩家目标入口 | P0-2 | 玩家死亡、关门、跨层、场景卸载后目标引用立即失效；不隔房攻击 |
| P0-4 | 顶层状态机与行动子状态机 | 现有扁平状态可迁移 | P0-1～3 | `Dormant/Idle/Alert/Combat/Search/Return/Dead` 与 `Aim/Telegraph/Active/Recovery` 时序稳定，不产生无前摇伤害 |
| P0-5 | 正式导航与卡住恢复 | 当前主要是直线移动 | P0-4 | 会绕过墙和桌面；0.8秒卡住可恢复；不穿墙、不瞬移、不在墙后永久攻击 |
| P0-6 | 基础激活与刺激唤醒门禁 | 已有同层38米预激活、远程受击/受光唤醒 | P0-2～5 | 屏幕外同层怪物可响应真实刺激；其他楼层保持隔离；休眠怪无完整 AI 性能开销 |

P0 完成定义：任意一种基础怪在标准房间内可以被发现、被刺激、追击、丢失、搜索、返回、攻击、受控和死亡，过程中不存在隔墙全知、卡死、重复结算或房间越界。

### 18.3 P1：群体战术与六种普通怪

| 顺序 | 实现项 | 依赖 | 阶段验收 |
|---:|---|---|---|
| P1-1 | 枪声、爆炸、脚步、门等声音刺激 | P0 Stimulus | 只调查声音位置，不直接获得墙后玩家目标；短时间连续枪声合并 |
| P1-2 | 有限盟友告警 | P0 Memory | 只传播事件位置与粗略方向；墙、关门和距离会衰减；无无限回声 |
| P1-3 | ThreatScore、目标锁定迟滞 | P0 目标合法性 | 新目标优势不足15%时不切换；目标失效立即切换；行为可复现 |
| P1-4 | 近战/远程站位槽与攻击令牌 | P0 导航 | 同时最多2个近战、2个远程强攻击，其余保持压迫和换位，不挤成一点 |
| P1-5 | 通用行为块 | P0 双层状态机、P1-4 | `Approach/HoldRange/Strafe/Retreat/Guard/Summon/SeekDark` 可组合、可测试 |
| P1-6 | 六种普通怪逐只落地 | P1-1～5 | 每个物种至少一份独立场景验收；差异来自策略组合与参数，不复制六套 Brain |
| P1-7 | 表现契约 | P0/P1 行为 | 可疑、警觉、前摇、生效、恢复、避光、硬直均有姿态/VFX/音效兜底，玩家能读懂意图 |

P1 推荐落地次序：小菌猪近战模板 → 孢子射手远程模板 → 壳甲卫兵防御模板 → 炸弹果危险区模板 → 地刺虫伏击模板 → 蜂后怪召唤支援模板。先覆盖通用移动与攻击，再处理专属行为，减少并行变量。

### 18.4 P2：精英、Boss 与内容生产线

| 顺序 | 实现项 | 依赖 | 阶段验收 |
|---:|---|---|---|
| P2-1 | 精英修饰挂点 | P1 通用行为块 | 修饰只改变感知、评分、候选动作、受击/死亡反应或表现，不复制 Brain |
| P2-2 | 现有精英修饰迁移 | P2-1 | 巨大、分裂、反弹、寄生、抢枪、吞弹分别有独立测试；生成与召唤受房间预算限制 |
| P2-3 | Boss 阶段技能表 | P0 双层状态机、P1 攻击令牌 | 阶段只触发一次；技能袋避免连续重复；受光不重置阶段与冷却事务 |
| P2-4 | 独立 Boss 内容 | P2-3 | 每个 Boss 具有独立 `boss_content_id`、技能表、场地交互、表现资源和验收场景，不以改血量冒充新 Boss |

### 18.5 P3：性能、诊断与发布门禁

| 顺序 | 实现项 | 执行时机 | 验收标准 |
|---:|---|---|---|
| P3-1 | AI 快照与调试显示 | 从 P0 开始持续维护 | 可查询感知、目标、状态、动作、路径、令牌、光照、房间和原因码 |
| P3-2 | 自动化矩阵 | 每完成一个 P0/P1/P2 项立即补 | 通用规则、六种怪、精英和 Boss 均有功能测试；固定种子结果可复现 |
| P3-3 | 30怪压力测试 | P1 群体系统完成后 | 30只普通怪持续战斗无同帧感知/路径尖峰，无明显帧时间抖动 |
| P3-4 | 峰值与长时测试 | P2 完成后 | Boss、召唤、灯光和门同时变化时无悬空引用、重复攻击、跨房运行和进程泄漏 |

### 18.6 推荐交付里程碑

1. **里程碑 A｜AI 骨架稳定**：完成 P0-1～P0-4；保留当前移动实现作为临时执行器。
2. **里程碑 B｜空间行为可信**：完成 P0-5～P0-6；通过标准房间、门、遮挡、跨层和刺激唤醒测试。
3. **里程碑 C｜群怪可玩**：完成 P1-1～P1-5；先用近战与远程两种模板验证群体节奏。
4. **里程碑 D｜六怪完成**：完成 P1-6～P1-7；逐只验收，不同时重做全部物种。
5. **里程碑 E｜精英与 Boss 扩展**：完成 P2；每增加一个内容单元就补独立测试和表现验收。
6. **里程碑 F｜发布门禁**：完成 P3 全量压力、长时和房间隔离回归。

任何里程碑都必须保持上一阶段测试通过。若需要缩小首版范围，最低可发布目标应为“完整 P0 + P1 的近战/远程模板、站位槽与攻击令牌”，声音、盟友告警、全六怪专属深化、精英与 Boss 内容可以顺延，但目标合法性、状态时序、导航恢复和房间隔离不能删减。

## 19. 本轮需要主设计者确认的设计点

1. 枪声是否应成为正式感知来源；本稿建议“会调查声音位置，但不直接获得玩家目标”。
2. 群怪是否采用攻击令牌；本稿建议同一玩家同时最多2个近战强攻击、2个远程强攻击，其余负责移动压迫。
3. 地刺虫是否允许战斗中重新埋伏；本稿建议满足暗处、脱离视线和6秒冷却后允许。
4. 炸弹果被击杀时是否保留较弱死亡碎片；本稿保留现有特色，但与完整主动爆炸分离。
5. 普通怪是否具有有限盟友告警；本稿建议有，但只共享事件位置，不共享玩家实时坐标。
6. 人工灯下移动与攻击频率均为40%，太阳每秒2%最大生命伤害继续作为全怪统一基线；Boss不免疫。
