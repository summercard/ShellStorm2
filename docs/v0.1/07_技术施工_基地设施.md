# 技术施工｜基地设施 v0.1

系统编号：5  
上级设计：[游戏设计文档 §10](README.md#10-核心系统五基地设施)  
相关内容表：`武器`、`命运卡`、`精英怪`、`掉落物品`

## 1. 职责与边界

基地系统负责长期成长的操作入口：准备行动、处理带出物、解锁蓝图、管理保险、选择命运预兆、查看精英档案和进入训练/远征。设施场景只显示与交互，业务规则由独立服务处理，最终写入由存档系统执行。

## 3. 设施统一契约

<span style="color:#EF6C00">**[Codex补充]** 每项设施实现以下领域接口。</span>

```text
FacilityDefinition
  facility_id
  display_name
  unlock_condition
  level_rules
  menu_id

FacilityQuery
  get_availability(profile_snapshot)
  get_summary(profile_snapshot)

FacilityCommand
  validate(command, profile_snapshot)
  execute(command, transaction_context)
  return FacilityResult(success, changes, reason)
```

`BaseFacility3D` 只发出设施 ID 和交互请求。`BaseWorld3D` 只打开对应 UI/场景并刷新摘要；它不能实现工坊、保险或精英档案规则。

## 4. 长期进度数据

当前 `BaseData` 保存局数、撤离、击杀、七类建筑解锁与等级、蓝图 Tier、资源点、保险柜、命运预选、下局带入和撤离战利品。

- <span style="color:#2E7D32">**[已实装]** `BaseManager` 提供读取、修改和保存接口。</span>
- <span style="color:#EF6C00">**[Codex补充]** 设施命令返回变更集，由一次存档事务统一提交；菜单不能连续多次写盘造成部分成功。</span>
- <span style="color:#EF6C00">**[Codex补充]** 解锁成本、升级成本和功能参数逐步迁移到数据库/配置资源，代码只验证公式与上限。</span>

## 5. 设施专项要求

### 5.1 枪械工坊

读取 `武器` 表的蓝图 Tier 和资源成本。解锁后只改变长期蓝图许可；实际局内掉落由掉落服务根据许可过滤。

### 5.2 命运占卜屋

保存稳定命运卡 ID，而不是当前运行时 `fate_card_####`。行动开始消费预选后，要么成功注入本局，要么回滚到基地档。

### 5.3 保险柜

区分长期保险柜、单局保险格、下局待带入和撤离待处理四种集合。移动物品使用事务 ID，避免重复领取或同时存在于两个集合。

### 5.4 怪物档案室

- <span style="color:#1565C0">**[用户设计]** 展示 12 只唯一精英的独立档案、成长、夺取枪械与历史。</span>
- <span style="color:#EF6C00">**[Codex补充]** 对未发现精英只显示轮廓和传闻；已发现后显示稳定信息，具体当前出现位置只在获得情报时展示。</span>

### 5.5 基地灯光与交互

- <span style="color:#2E7D32">**[已实装]** 99 层灯光开关位于入口侧并与开门交互保持距离；开关切换同一组灯的能量。</span>
- 开关关闭再开启必须恢复初始能量、范围、阴影和地面照度，不通过删除/重建灯节点实现。
- 相邻门和开关同时可交互时由玩家交互候选优先级解决。

## 6. 施工阶段

1. 为八项设施分配稳定 `facility_id` 与统一查询/命令接口。
2. 将菜单内的业务修改收敛到设施服务。
3. 将蓝图、卡片、物品和精英引用改为数据库稳定 ID。
4. 实现物品集合转移事务与重复领取防护。
5. 将怪物档案室接入正式 3D 精英名册服务。
6. 建立设施独立场景与存档回归测试。

## 7. 验收标准

- [ ] 八项设施可分别启用、禁用和测试，不依赖基地场景中的硬编码节点名执行业务。
- [ ] 工坊解锁、升级和资源扣除是一次原子结果。
- [ ] 命运预选使用稳定卡 ID，行动注入失败不会吞掉选择。
- [ ] 保险柜、保险格、带入和撤离战利品之间没有复制或丢失。
- [ ] 训练场离场不修改资源、背包、局数、设施和精英档案。
- [ ] 怪物档案固定显示 12 个槽位并读取正式精英存档。
- [ ] 基地灯关闭再开启后，固定采样点地面照度与初始状态一致。
- [ ] 门与灯开关不会一次按键同时触发。
- [ ] 设施菜单关闭后玩家输入锁定完整释放。
- [ ] 任一设施保存失败时显示原因并保留旧档。
