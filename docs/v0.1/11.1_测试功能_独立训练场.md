# 测试功能｜独立训练场 1.0

功能ID：`TRAINING-RANGE`。功能版本：**1.0**。状态：**[已完成]**。适用游戏工程：`0.1.0`。更新日期：2026-09-12。

独立训练场是开发与玩家共用的武器组合验证入口，用于在不推进正式行动、不结算战利品的条件下检查枪身、弹药模块、近战武器、伤害反馈与操作手感。1.0范围以当前正式场景和专项验收为准；以后增加伤害分析、移动靶编辑或自动压测时另升功能版本。

## 1. 边界与数据关系

| 项目 | 1.0契约 |
|---|---|
| 状态所有者 | `TrainingRange3D`持有本次训练的装备选择、命中、伤害和击破统计 |
| 只读数据 | 从`BlueprintRegistry`读取99层可用枪身和弹药模块；复用正式`Player3D`和武器实现 |
| 长期数据 | 进入时读取`BaseData`隔离快照用于验收，不写资源、蓝图、背包、局数、设施或精英档案 |
| 场景入口 | `scenes/TrainingRange3D.tscn`，可独立启动 |
| 退出 | 测试模式只显示退出反馈；正式入口返回`BaseWorld3D.tscn` |

训练装备只存在于训练场玩家实例。选择枪架不会生成永久物品、消耗魂或修改行动快照；训练靶统计也不进入正式战绩。

## 2. 1.0现有功能

- 10种枪身：7种远程、3种近战；8种弹药模块。
- 远程枪身与弹药模块形成56种组合，3种近战作为无弹药组合，共59种有效组合。
- 标准、装甲、移动三类靶标；装甲靶具有减伤，移动靶持续移动。
- 命中次数、累计伤害和击破数量即时显示；暴击有独立反馈。
- 重置站恢复全部靶标并补满当前远程武器弹匣，统计继续累计。
- 独立退出设施、正式暂停菜单、实际战斗操作提示和画质档响应。
- 训练环境包含射击道、装备墙、照明和雾效，并复用正式武器模型与战斗实现。

## 3. 命令、查询与事件

| 类型 | 接口 | 作用 |
|---|---|---|
| 命令 | 训练枪架`selected(item_id, category)` | 更新枪身或弹药选择并装备有效组合 |
| 命令 | `equip_combination_for_test(gun_id, bullet_id)` | 专项逐项装备59种组合 |
| 命令 | 重置站`activated` | 重置靶标和弹匣 |
| 命令 | 退出设施`exit_requested` | 离开训练场，不提交训练数据 |
| 查询 | `get_training_snapshot()` | 返回枪架、组合、靶标、环境、重置与退出入口状态 |
| 查询 | `is_base_data_unchanged()` | 对比训练拥有的长期字段，证明训练未污染基地档案 |

## 4. 失败与退出规则

- 枪身或弹药ID无效时拒绝装备，不修改长期数据。
- 近战武器不接受弹药模块；选择弹药而当前没有远程枪时使用默认手枪形成可用组合。
- 暂停期间不继续世界交互；再次按暂停键恢复。
- 退出时不保存训练统计、不发放物品、不改变资源和蓝图。
