# 测试功能｜独立训练场 1.1

功能ID：`TRAINING-RANGE`。功能版本：**1.1**。状态：**[已完成]**。适用游戏工程：`0.1.0`。更新日期：2026-10-19。

独立训练场是开发与玩家共用的武器组合验证入口，用于在不推进正式行动、不结算战利品的条件下检查枪身、弹药模块、近战武器、命运卡效果、实战手感与刷怪压力。1.0 范围以当前正式场景和专项验收为准；以后增加伤害分析、移动靶编辑或自动压测时另升功能版本。

**2026-10-19 规则调整（不升功能版本）**：弹药模块手动更换在全游戏关闭，靶场背包同样不提供换弹；军械库的弹药选择是测试专用的整枪重装入口，保留。

**1.1 相对 1.0 的变化**：入口从基地地面设施牌移到 Esc 暂停菜单；新增军械库取用区、刷怪触发台、命运卡组装台、补给箱、**完整装备界面与背包界面**；地面由程序化方块改为 10×10 块 5m 地砖并四周封边；进场清空由 `clear_weapon()` 改为 `clear_all_equipped_weapons()`（前者只清手上呈现，武器槽仍在）；入口判据改按 `is_player_inside_facility()`，退出改为原路返回；靶标补齐完整受击契约；新增本场背包与世界命运宿主。

## 1. 边界与数据关系

| 项目 | 1.1契约 |
|---|---|
| 状态所有者 | `TrainingRange3D`持有本次训练的装备选择、命中、伤害和击破统计 |
| 只读数据 | 从`BlueprintRegistry`读取99层可用枪身和弹药模块；复用正式`Player3D`、武器实现与`FateCardGameBridge` |
| 长期数据 | 进入时读取`BaseData`隔离快照用于验收，不写资源、蓝图、背包、局数、设施或精英档案 |
| 场景入口 | **Esc 暂停菜单**；可用性 = 场景根的 `is_player_inside_facility()`（99F 基地安全区）；`scenes/TrainingRange3D.tscn` 仍可独立启动 |
| 退出 | 测试模式只显示退出反馈；正式入口**原路返回进入时的场景**（登记来源），未登记时回落 `TowerDescent3D` 主场景基地并登记 `ABORT_RETURN_99F` + `SPAWN_BASE_99F` 入口意图 |

### 入口与退出的口径（两处易错点）

- **"在基地"不能按类名判断。** 玩家的基地是 `TowerDescent3D`（主场景，99F 基地营地），`BaseWorld3D` 只是历史「兼容基地」——`TowerDescent3D._ready` 里对此有明确注释。按 `root is BaseWorld3D` 判会让入口在真基地里永远不可用。
- **退出不能回落 `GameDesignConfig.BASE_SCENE_3D`。** 那是兼容基地，玩家不是从那出发的。退出走"登记来源 → 原路返回"；回主场景时必须登记 `GameEntryFlow` 入口意图，否则主场景会把它当成冷启动或普通恢复，把玩家送去别处或续上旧行动。

两条口径各由 `verify_pause_menu_training_range_entry` 的用例 C/D/F/G 钉住。

### 装备 / 背包界面的按键分区（必须与外面一致）

| 键 | 打开 | 说明 |
|---|---|---|
| `Tab` | 武器装配树 `WeaponAssemblyTreePanel` | 外面同款脚本，它自己在 `_process` 里轮询 `ui_tab` |
| `I` | 背包 `InventoryUI` | 外面同款组件，`standalone_mode` 自建完整界面 |

两个键**不能混用**：`InventoryUI.accept_tab_shortcut` 必须保持 `false`，否则它会和装配树抢 Tab，两个面板互相顶掉。

其余与外面一致的行为：
- 打开背包时锁玩家输入（`set_input_locked`），但**不暂停世界** —— 与外面局内相同。
- 换枪会整体替换 `weapon_tree`（每把枪有独立 runtime tree），此时两个面板都要重新 `set_weapon_tree()`；漏掉会让装备界面一直显示上一把枪的构筑。
- **保险柜区保留显示但标注「测试环境不可用」**：靶场没有撤离流程，靶场不做静默隐藏 —— 少一块会让界面与实战不一致。标注必须延后一帧设置，因为 `InventoryUI` 在发出 `inventory_open_changed` 之后还会 `_refresh_insurance_ui()` 把标签刷回「保险柜」。
- **子弹模块在背包里也是只读的**：2026-10-19 起手动更换总闸关闭，靶场背包左键与拖武器格同样被拒；装备界面弹药标题显示「锁定」。要换弹种请回军械库重新选组合（测试专用例外），不要试图在背包里换。

由 `verify_training_range_equipment_ui` 覆盖。

### 靶标的受击契约（加入 enemy_3d 就必须完整实现）

靶标进了 `enemy_3d` / `damageable_3d` 分组，就会被整套战斗系统当成敌人对待，各调用方的参数个数并不统一：

| 调用方 | 调用形态 |
|---|---|
| `Projectile3D._hit_target`（回退路径） | `take_damage(damage, critical, direction, hit_knockback)` — **4 参** |
| `WeaponModel3D`（近战） | `take_damage(damage, critical, forward, knockback, ?)` — **5 参** |
| `Projectile3D`（首选路径） | `take_projectile_damage(damage, critical, direction, tags, behavior, shooter, knockback)` — **7 参** |
| `PlayerMeleeCombat3D` / `Enemy3D` 各分支 / `DeathBlastZone3D` | 3 参 |

`Object.call()` 按**声明参数个数上限**校验：默认参数可省略，但**不能多给**。所以签名必须写成全量（对齐 `Enemy3D`），并补 `take_projectile_damage`：

- 2026-10-16 前靶标只写了 3 参 → 子弹命中抛 `Invalid call to function 'take_damage' ... Expected 3 argument(s)`。
- 同批还修了一个静默缺口：靶标原先不在 `damageable_3d` 分组里，**近战武器在靶场砍不到靶子**。
- `Projectile3D` 会先探 `take_projectile_damage`；不实现它就只能走 4 参回退路径，弹种标签与命运行为全部丢失 —— 补上之后「穿甲强化」这类卡在靶场才有可观察差别。

这三条由 `verify_training_range_fate_loadout` 的用例 ① 钉住。

训练装备只存在于训练场玩家实例。取用枪械与弹药不生成永久物品、不消耗金币、不扣库存 —— 军械库没有库存概念，取用无限次。训练统计与命运卡装配都不进入正式存档。

**进出隔离（核心契约）**：进场调用 `player.clear_all_equipped_weapons()` 收回全部武器槽，基地带入的装备一律不带入；场内配的枪、弹药与命运卡只写在运行时武器树上，离场随场景释放。基地存档因此原样不变 —— 出来就回到进去前的状态与物品。

这条契约没有类型系统兜底，靠两条会失败的断言盯着：`verify_training_range_isolation`（取枪+装卡+刷怪后逐键比对存档快照）与 `verify_training_range_3d_flow` 的 `is_base_data_unchanged()`。

## 2. 1.1现有功能

- **军械库**：全部枪身与全部弹药各占一个货架格（`TrainingArmoryBay3D`），走近按 E 即装备；取用不限次数、不消耗、不落存档。枪身与弹药可分别独立选取，支持不同弹药切换。**这是测试专用的「整把枪重新装配」入口，不是手动换弹**：它调用 `equip_combination_for_test` 重建一把新枪，不走 `install_bullet_module_to_weapon_slot`；2026-10-19 手动更换关闭后，靶场里唯一能试不同弹种的入口就是这里。
- **命运卡组装台**：摊开 `FateCardPresets.playable_presets()` 全量卡牌（基地工作台是随机三选一，此处不随机、无解锁门槛），点击即装配到当前武器命运槽（默认 8 格）。需先装备武器；缺图卡自动回退为程序绘制卡面。
- **刷怪触发台**：3 个触发区，分别点名 `melee_chaser` / `ranged_caster` / `fat_zombie03`，覆盖近战、远程、肉盾三类行为。踏入即刷一波，清场后离开再进入可再次触发；也可按 E 手动重刷。数值走 `MonsterInjector.generate_box_enemy()`，与远征关卡同源。
- **本场背包**：`InventoryModule`，容量与外面局内一致（40 格），仅内存。击杀敌人、开启补给箱、丢弃后拾回都会进出它。
- **完整背包界面**：直接复用外面局内的 `InventoryUI`（`standalone_mode`），**不是精简版**。按 `I` 打开。含装备槽、背包格、快捷栏、保险柜区、角色预览与拖拽整理。
- **完整装备界面**：直接复用外面的 `WeaponAssemblyTreePanel`（武器装配树）。按 `Tab` 打开。换枪时会重新绑定玩家当前武器树，不会停留在上一把枪的构筑。
- **补给箱**：兑现宝箱类命运卡（幸运宝箱 / 额外战利品 / 太阳品质 / 太阳额外掉落），同时发一小批不同物资 —— 让背包界面一开就有内容可拖、可装备。
- **地面掉落**：背包界面里「丢到世界」走外面同一条链路生成 `GroundLootPickup3D`，可以走回去捡回来；不是静默删除。
- **世界命运宿主**：`TrainingWorldGameMode3D`（group `room_game_mode`）。14 张 WORLD 卡全都要它，缺了会一律返回 `world_owner_unavailable`。分工是：能真做的真做（增援直接刷一波怪；焦土/试炼/诅咒的下一波倍率真的喂给新生成的敌人），做不了的记成可查询的待结状态（宝箱品质、额外掉落、钥匙、揭示、赏金、撤离时限）并由补给箱/HUD 兑现，而不是假装成功。
- 标准、装甲、移动三类靶标；装甲靶具有减伤，移动靶持续移动。
- 命中次数、累计伤害和击破数量即时显示；暴击有独立反馈。
- 重置站恢复全部靶标、清空刷怪台并补满当前远程武器弹匣，统计继续累计。
- 独立退出设施、正式暂停菜单（**靶场内部不再显示靶场入口，避免自嵌套**）、实际战斗操作提示和画质档响应。
- 场地为 10×10 块 5m 地砖棋盘格铺满 50×50m，四周 40 段 5m 标准墙封死；三条射击道、军械库货架、12 盏废土灯与雾效。地砖与墙体直接实例化「战局区块通用组件库 v004」正式美术件，自带碰撞。

## 3. 命令、查询与事件

| 类型 | 接口 | 作用 |
|---|---|---|
| 命令 | 军械库货架`selected(rack, item_id, category)` | 更新枪身或弹药选择并装备有效组合 |
| 命令 | `equip_combination_for_test(gun_id, bullet_id)` | 专项逐项装备注册表推导出的全部组合（当前75种） |
| 命令 | 刷怪台`spawn_wave()` / `clear_wave()` | 刷出一波 / 清空本台存活敌人 |
| 命令 | 组装台`FateCardGameBridge.apply_card_with_source_selection(card, host)` | 把指定命运卡装配到当前武器 |
| 命令 | 重置站`activated` | 重置靶标、刷怪台与弹匣 |
| 命令 | 退出设施`exit_requested` | 离开训练场，不提交训练数据 |
| 查询 | `get_training_snapshot()` | 返回枪架、组合、靶标、刷怪台、组装台、环境、重置与退出入口状态 |
| 查询 | `is_base_data_unchanged()` | 对比训练拥有的长期字段，证明训练未污染基地档案 |
| 查询 | `PauseMenu3D.is_training_range_available()` | 靶场入口可用性（仅基地为真） |

## 4. 失败与退出规则

- 枪身或弹药ID无效时拒绝装备，不修改长期数据。
- 背包里的子弹模块不能手动装到枪上（2026-10-19 总闸关闭）；换弹种只走军械库组合。近战武器不接受弹药模块；选择弹药而当前没有远程枪时使用默认手枪形成可用组合。
- 未装备武器时装配命运卡会被拒绝并显示原因，卡片保留。
- WORLD 卡在靶场必须落地：宿主覆盖全部 14 张，任何一张返回 `world_owner_unavailable` 都算回归。
- 刷怪台上一波存活时再次触发会先清掉旧波，不会无限累积。
- 世界命运的增援落在第一个刷怪台上；`spawn_elite` 在靶场退化为"多加一只"（精英装配端需要遭遇上下文，靶场没有）。
- 背包不被重置站清空；清空走 `clear_backpack()`。
- 暂停期间不继续世界交互；再次按暂停键恢复。
- 退出时不保存训练统计、不发放物品、不改变资源和蓝图。
