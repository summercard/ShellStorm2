## 1. 职责与边界

玩家系统拥有输入意图、移动、生命、顶层状态、临时覆盖状态、交互许可和武器操作桥。武器数值属于战斗系统；墙、地砖和门坐标属于关卡系统；存档和死亡结算属于系统 7。

<span style="color:#1565C0">**[用户设计]** 玩家只持有当前装备枪械的实例引用，不拥有枪械构筑。角色作用域命运卡可以改变本局角色规则，但武器作用域卡、配件和强化道具不得把构筑写入玩家属性。</span>

<span style="color:#2E7D32">**[已实装并验收]** 正式 `Player3D` 与兼容 `Player` 均通过完整物品字典装备 `WeaponInstance`，运行时装配树只从实例投影；卸装前会同步弹药与装配快照，武器命运升级写回实例，角色/世界命运状态不占枪槽。</span>

## 2. 当前结构

- <span style="color:#2E7D32">**[已实装]** `Player3D` 是正式玩法根，`PlayerAvatar3D` 是视觉装配根，独立胶囊负责角色碰撞。</span>
- <span style="color:#2E7D32">**[已实装]** 顶层状态：`idle / moving / dashing / hurt / locked / falling / landing / dead`。</span>
- <span style="color:#2E7D32">**[已实装]** 覆盖状态：`low_health / silenced / invincible / reloading / firing / charging / knockback`。</span>
- <span style="color:#2E7D32">**[已实装]** 基线：移动 5.0m/s；冲刺 16.5m/s、0.204s、冷却 2.2s；冲刺无敌 0.24s；生命 100。</span>
- <span style="color:#2E7D32">**[已实装]** 玩家前向主灯、环境溢光和角色柔光不对玩家自身产生阴影；太阳与室内灯正常照射玩家并投影。</span>

## 3. 输入动作契约

| 动作 | 默认输入 | 发送意图 | 拒绝条件示例 |
|---|---|---|---|
| 移动 | WASD / 方向键 / 移动摇杆 | `move(Vector2)` | `locked`、`dead` |
| 瞄准 | 鼠标 / 右摇杆 | `aim(Vector2/Vector3)` | `dead` |
| 主攻击 | 鼠标左键 / 射击按钮 | `primary_attack_pressed/released` | `silenced`、`locked`、`dead`、99层基地室内；远程解释为开火/蓄力，近战解释为挥砍/连段缓存 |
| 技能 | 鼠标右键 / 技能按钮 | `skill` | 冷却、`locked`、`dead` |
| 冲刺 | Shift / 冲刺按钮 | `dash` | 冷却、`hurt`、`locked`、`dead` |
| 交互 | E / Space | `interact` | 无目标、模态 UI、`dead` |
| 换弹 | R | `reload` | 满弹、正在换弹、`dead` |
| 背包 | I / Tab | `inventory` | 不允许打开的过渡状态 |
| 主/副武器 | 1 / 2 | `select_weapon_slot(0/1)` | 目标槽空、死亡、独占模态 UI |
| 快捷物品 | 3 / 4 | `use_quick_item(0/1)` | 未绑定、数量为0、当前状态不允许使用 |
| 楼层大地图 | M | `toggle_floor_map` | 其他独占模态 UI |
| 探照灯 | F | `toggle_flashlight` | `dead` 或场景禁用 |
| 暂停 | Esc | `pause` | 由全局暂停栈裁决 |

<span style="color:#EF6C00">**[Codex补充]** 键鼠和触屏适配器不得直接调用冲刺、开火或交互实现，只能提交上表意图；这样回放、AI 控制、无障碍映射和自动测试可以复用同一入口。</span>

### 3.1 双武器与快捷物品新契约（2026-08-06）

<span style="color:#2E7D32">**[已实装并验收｜2026-08-11]** 玩家拥有主武器与副武器两个独立实例槽；左槽为主武器、右槽为副武器。只有当前激活槽投影到运行时装配树，另一把枪保持完整 `WeaponInstance`、弹药和命运槽数据。角色背部使用三个同级独立语义挂点：背包居中，主武器竖挂左侧，副武器竖挂右侧；枪口朝下、枪身朝后，且不占用背包挂点。</span>

<span style="color:#2E7D32">**[已实装并验收｜2026-08-06]** 快捷物品槽只绑定可主动使用的物品 ID，不把物品移出背包。整理、堆叠或换位不会失效；按3/4时从背包消耗1个对应物品，只有效果成功后才扣除数量。空槽不创建3D预览，绑定后才复用背包的同源模型图标。</span>

### 3.2 背包快捷键与模态状态契约（2026-08-06回归修复）

<span style="color:#2E7D32">**[已实装并验收｜2026-08-06]** `I` 是正式背包主快捷键，塔楼场景同时接受 `Tab`。一次有效按下只允许切换一次；键盘长按产生的 `echo` 重复事件必须忽略，不能造成“刚打开又关闭”。打开后 `InventoryUI.inventory_open_changed(true)` 锁定玩家移动、开火和场景交互；再次按 `I/Tab` 或关闭界面后发出 `false` 并只解除背包来源的输入锁。</span>

<span style="color:#EF6C00">**[Codex补充]** 背包专项不得再直接调用 `set_inventory_panel_open(true)` 代替输入验收；必须通过真实 `InputEventKey` 覆盖按下、长按重复、释放、二次关闭及玩家锁恢复。物品格点击同样必须走按下+释放完整生命周期，避免拖拽协议变化后出现“自动化通过、玩家点不动”。</span>

### 3.3 背包装备位与背部表现（2026-08-06）

<span style="color:#1565C0">**[用户设计]** 角色装备栏增加独立背包槽，只接受 `type=equipment / subtype=backpack`。背包物品从普通格左键或拖入即装备；装备中的背包可拖回空格、拖入丢弃区或拖出界面。容量降低造成的溢出物必须落在角色当前房间，而不是被删除。</span>

角色视觉根增加稳定语义挂点 `BackpackSocket`，位于背部中央并与左右 `StowedWeaponSocketPrimary/Secondary` 分离。装备状态通过 `backpack_equipment_changed` 同步到该挂点；2/4/8格背包使用同源内容ID但不同体积、配色和附袋数量的代码Mesh占位。替换正式美术时只替换挂点子场景，不改变背包容量与物品事务代码。

<span style="color:#2E7D32">**[已实装并验收｜2026-08-06]** 正式角色与备用角色视觉场景均已增加 `BackpackSocket`；装备背包后由 `Player3D` 在该挂点生成同源代码Mesh，卸下时移除。装备页背包槽、左键/拖拽装备、拖回基础格、拖到地面、12+2/4/8动态容量和扩展格异色边框均已接入。</span>

### 3.4 角色体型调试契约（2026-08-13）

<span style="color:#1565C0">**[用户设计]** 当前先用 `+ / -` 调试角色缩放，之后再转换为对应正式功能。每次变化必须是初始基础尺寸的10个百分点，而不是按变化后的当前尺寸继续乘10%。因此档位固定为100%、110%、120%……，不能出现121%。</span>

<span style="color:#2E7D32">**[已实装并验收｜2026-08-13]** `Player3D` 以整数档位保存调试状态，主键区和小键盘 `+ / -` 每次增减一档，忽略键盘长按回声；范围限制为10%—300%，默认100%，本阶段不写存档。视觉根及其武器/背包装配随体型同比缩放，独立胶囊的半径、高度和中心同步缩放以保持底部贴地；玩家根、固定镜头、准星、手电筒、移动速度与其他玩法数值不缩放。HUD会显示当前百分比。</span>

正式功能不得直接累乘节点当前 `scale`，必须复用整数档位或以不可变基础尺寸计算绝对比例。若未来需要把体型纳入成长、命运卡或装备效果，应另行定义来源叠加顺序、保存字段、门洞/楼梯可通过性、攻击受击范围、移动速度及相机策略；本次调试入口不预先绑定这些平衡规则。

## 4. 状态机施工约束

1. 每帧只有一个顶层状态拥有移动决策权。
2. 状态转换使用 `request_transition(target, reason, context)`；转换成功发出 `player_state_changed`。
3. `dead` 只能由生命系统进入，由结算/复活系统批准退出。
4. `locked` 必须携带锁来源；同一来源解除时不能清除其他模态锁。
5. `falling → landing` 只处理落地动作，不执行死亡、楼层切换或存档。
6. 换弹和蓄力是覆盖状态；冲刺是否取消它们由战斗策略明确返回。
7. 近战是独立动作子状态机，不增加第九个移动顶层状态；固定状态为 `ready → windup → active → recovery`，三段连击只改变动作上下文、时长和命中参数。
8. `active` 是唯一允许生成近战伤害的状态；进入该态同时生成一次挥砍弧光和挥砍音，每个实际目标生成命中爆点，一次攻击只播放一个命中主音。每个攻击实例对同一目标最多结算一次。`windup/recovery` 只负责动作与连击缓存，不能偷跑伤害或命中反馈。
9. `hurt / dashing / locked / falling / landing / dead`、沉默、禁射区及换武器会取消近战动作并回到 `ready`；`idle / moving` 允许启动和继续连段。

## 5. 与其他系统的接口

| 接口 | 方向 | 内容 |
|---|---|---|
| `WeaponCommandPort` | 玩家 → 战斗 | 瞄准、主攻击、蓄力释放、换弹、近战连段缓存与取消 |
| `InteractionQuery` | 玩家 → 场景 | 当前候选、距离、优先级、提示文本 |
| `DamageReceiver` | 战斗/环境 → 玩家 | 伤害、来源、方向、类型、击退 |
| `PlayerPresentationState` | 玩家 → UI/动画 | 顶层状态、覆盖层、生命、弹药摘要 |
| `DeathRequest` | 玩家 → 结算 | 死亡原因、位置、行动快照 ID |
| `RevivalResult` | 结算 → 玩家 | 是否复活、位置、生命比例、无敌时间 |
| `TransitionOccupancySnapshot` | 玩家 → 关卡生命周期 | 角色完整碰撞体是否已离开门夹区并进入隔离间；只报告位置事实，不开门或卸载楼层 |

到达门生成和隔离区段提交期间，玩家可以在安全侧移动，但同一门的重复交互、拾取/丢弃和跨门冲刺由关卡事务明确锁定。不得把玩家设为无碰撞或瞬移穿门来掩盖生成等待。

## 6. 相机、墙体与灯光边界

- <span style="color:#2E7D32">**[已实装]** 塔内固定斜俯视相机使用墙体专用查询层检测角色与镜头后方的满高墙。</span>
- <span style="color:#2E7D32">**[已实装]** 玩家贴近需要交互的水平墙时，相机会抬升和向墙内侧收回；墙体 Mesh 本身保持不透明。</span>
- <span style="color:#2E7D32">**[已实装｜2026-08-10]** 楼梯间上下两跑斜楼板使用独立 `camera_stair_slab` 语义碰撞。镜头期望高度穿过任一楼板时只沿Y轴立即下压到楼板下方，保持水平后移、朝向和FOV；离开后平滑恢复。普通房间楼板、走廊、门和未标记碰撞不参与该探针。</span>
- <span style="color:#EF6C00">**[Codex补充]** 玩家系统只提供位置、朝向和遮挡目标，不识别“南墙/门墙/楼梯墙”；是否属于相机墙由关卡组件元数据决定。</span>
- <span style="color:#EF6C00">**[Codex补充]** 随身灯的自投影隔离必须基于渲染层，而不是运行时关闭玩家 Mesh 阴影；否则太阳和室内灯也会失去玩家投影。</span>

## 9. 99F基地开火区域契约（2026-08-07）

<span style="color:#1565C0">**[用户设计]** 只有99F基地的30×30m室内属于禁射区。基地东西两侧门洞、门外走廊、楼梯间、天台和全部探索/战斗房都允许开枪；玩家跨出建筑外墙后立即恢复开火，跨回室内后立即锁定。</span>

- 正式3D以玩家相对`facility`房间中心的位置计算：`abs(x) <= 宽×0.47`、`abs(z) <= 深×0.47`且垂直偏差不超过1.8m时禁射。
- 禁射判断只读取空间位置，不读取门的开关动画、房间触发器、路线授权或当前HUD房名。
- 基地门是独立表现逻辑：E键只负责开门；玩家确实跨到外墙另一侧后门板自动关闭，但路线授权保持有效，之后可再次从任一侧开门。
- 门正在开/关、门已关闭或角色站在门外，都不能把门的状态误当作禁射条件。

验收：基地中心`combat_enabled=false`；从任一门跨过外墙后为`true`；返回室内后为`false`；连续往返和重复开门不改变该规则。

## 10. 手电筒与电量契约（2026-08-07）

<span style="color:#1565C0">**[用户设计]** 玩家随身手电筒拥有独立电量数值与状态。99F基地内始终满电且不计消耗；离开基地进入塔内后，开启手电筒会按时间持续降低电量，关闭手电筒时立刻停止耗电；HUD 常驻显示当前电量百分比与状态颜色；电量耗尽后手电筒自动关闭，需要消耗电池类物品或返回基地才能继续使用。</span>

### 10.1 电量规则

- 初始状态：每次进入 99F 基地时立即补满至 100%，离开基地时不重置，按当前数值继续。
- 消耗触发：仅当手电筒处于"开启"状态、且玩家处于 99F 基地 30×30m 室内**之外**时按秒耗电；基础模块满电可持续 300 秒（5 分钟），每次按 2% 电量一格扣除。
- 停止触发：手电筒关闭瞬间停止耗电；进入基地室内瞬间停止耗电且下一次进入基地补满。
- 耗尽行为：电量降至 0 时手电筒自动关闭，发出一帧淡出与 HUD 闪烁提示；HUD 状态切为空档标识。
- 死亡与结算：局内检查点保存当前电量和已装备模块；成功撤离不恢复电量；返回基地后再次补满。没有可续行动检查点时，死亡按常规结算返回基地。
- 开关记忆：手电筒当前"开/关"状态不因跨越房间门而改变，只在死亡或玩家手动改变时切换。

### 10.2 HUD 与状态颜色

- 位置：主 HUD 右侧、电量指示与 HUD 弹药条目同侧；不遮挡小地图、交互提示与命运栏。
- 形状：复用头像下方的三格战术指示器作为电芯显示，右侧仅显示剩余时间/关闭/耗尽状态；不再使用右上独立电池面板。
- 颜色档位：
  - 100%–60%：青色（满电档）
  - 59%–30%：黄色（正常档）
  - 29%–10%：橙色（低电档，HUD 标签轻微闪烁）
  - 9%–1%：红色（危险档，闪烁频率提高）
  - 0%：灰色（耗尽档，图标显示斜杠）
- 反馈：消耗电池或从非满电状态返回基地补满时播放一次电充音效；耗尽自动关闭时播放一次低电提示音。

### 10.3 关联道具

- <span style="color:#1565C0">**[用户设计]** `battery_s`（小型电池）：消耗品，恢复 25% 电量；可在 99F 基地自动贩卖机、关卡内搜索容器与精英掉落中获得。
- <span style="color:#1565C0">**[用户设计]** `battery_l`（大型电池）：消耗品，恢复 75% 电量；稀有度高于小型电池；关卡内出现于储藏房、地下室与少数精英掉落。
- <span style="color:#1565C0">**[用户设计]** `cell_pack`（能量包）：稀有消耗品，恢复 100% 电量；只能通过带出、精英悬赏或命运卡获得。
- 三类电池均为普通背包物品，可绑定快捷物品槽，按 3/4 直接对自身手电筒使用，不对其他玩家或友军生效；未使用电池通过保险柜和待带入栏跨局，不维护额外的“绑定电池”计数。
- 使用电池不增加手电筒开关状态，使用期间手电筒保持当前开关，按恢复后的数值继续耗电或待机。

### 10.4 身上装备与升级

- <span style="color:#1565C0">**[用户设计]** 基地工坊提供常驻的 `flashlight_module` 装备控制位，默认装备基础模块；长期装备选择决定手电筒灯光范围、亮度、伏击揭示半径与每秒耗电速率。
- 三档基础模块（v0.1 暂为占位 ID）：
  - `flashlight_module_basic`（基础）：功耗 1.0×，光照范围 1.0×；默认装备。
  - `flashlight_module_advanced`（加强）：功耗 0.7143×，满电续航 420 秒（7 分钟），光照范围与伏击揭示半径 1.20×、亮度 1.10×；需要解锁蓝图后在基地工坊选择。
  - `flashlight_module_efficient`（节能）：功耗 0.50×，满电续航 600 秒（10 分钟），光照范围与伏击揭示半径 0.85×、亮度 0.90×；稀有实体模块仅精英/Boss掉落，必须带回基地安装一次，安装后永久解锁。
- 模块切换仅在 99F 基地内可执行；进入塔内后模块锁定直到返回基地。
- 模块槽与电池消耗相互独立：模块降低每秒耗电倍率但不改变电池单次恢复量。

### 10.5 与其他系统接口

- 玩家 → HUD：每帧推送 `flashlight_charge_ratio`（0.0–1.0）、`flashlight_state`（on / off / depleted）与 `flashlight_module_id`。
- 玩家 → 战斗/怪物 AI：手电筒开启时提高玩家对伏击怪、地刺虫与精英的揭示半径；耗尽或关闭时使用玩家基础轮廓提示。
- 玩家 → 存档：电量数值与模块 ID 随局内行动检查点写入；永久解锁列表和已装备模块 ID 写入长期存档。
- 玩家 → 基地：返回基地立即补满；基地工坊只切换已解锁模块，保险柜可保存未使用电池，使成果跨局带入。

### 10.6 验收标准

- [ ] 玩家在 99F 基地内打开/关闭手电筒电量始终为 100% 且不下降。
- [ ] 离开基地后开启手电筒电量按固定速率每秒下降；关闭后立即停止。
- [ ] 进入基地室内瞬间停止耗电，再次离开基地时电量保持当前值。
- [ ] 电量降至 0 时手电筒自动关闭、HUD 切换为耗尽档、提示音播放一次。
- [ ] HUD 电量颜色按 60/30/10 阈值切换，闪烁频率随档位变化。
- [ ] 使用 `battery_s / battery_l / cell_pack` 后电量按设定比例恢复；开关状态不改变。
- [ ] 装备 `flashlight_module_advanced` 后每秒耗电下降到 0.7143×（满电 7 分钟）、光照范围和伏击揭示半径 1.20×。
- [ ] 死亡保留电量百分比；成功撤离不恢复；返回基地后补满。
- [ ] 跨房间门不改变手电筒开关状态；HUD 数值与场景灯状态保持一致。
