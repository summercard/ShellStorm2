## v0.1 冻结口径

- 正式体验是 3D 塔楼向下探索，不再把旧 2D 基地当作主入口。
- 关卡空间使用 1 Godot 单位 = 1 米；塔楼组件使用 5m 网格。
- 普通战斗房为 30×25m，即 6×5 个标准格；标准层高为 9m。
- 场景墙、地砖、门墙、拐角和楼梯必须由可复用 Mesh 组件装配，碰撞和交互跟随组件坐标。
- 玩家、武器、敌人和道具的逻辑根与视觉根分离；视觉替换不得改变碰撞和玩法契约。
- 太阳和房间灯照亮玩家并产生玩家投影；玩家随身三盏灯不得对玩家自身产生投影。
- 旧 2D 运行栈只作为兼容与玩法参考，不继续新增内容。
