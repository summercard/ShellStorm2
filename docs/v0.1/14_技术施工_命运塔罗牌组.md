## 1. 牌组总量与分类

总量固定为 **78张**，遵循塔罗牌的 `22张大阿尔卡那 + 56张小阿尔卡那`。大/小阿尔卡那是主题与内容编组，星/月/日是运行时所有者，两者不可混为一个字段。

| 牌组 | 数量 | 主要用途 |
|---|---:|---|
| 大阿尔卡那 | 22 | 改变核心规则、构筑轴或一段行动的方向 |
| 权杖 | 14 | 枪械结构、射速、弹体行为；全部为星星命运 |

最终作用域分布：`★ 星星命运/WEAPON = 36`、`☾ 月亮命运/CHARACTER = 21`、`☀ 太阳命运/WORLD = 21`。星星牌数量更多是因为枪械构筑是本游戏的主要局内决策，不代表其单张抽取权重更高。

## 2. 正位与逆位的硬规则

1. 先抽取 `stable_card_id`，再独立抽取 `orientation`；`UPRIGHT` 和 `REVERSED` 各为 `0.50`。
2. 概率对每个出场卡位独立生效，不因稀有度、作用域、玩家当前生命或枪械构筑动态偷改。
3. 同一次三选一允许出现0–3张逆位。不做“至少一张正位”的暗保底，否则单卡不再真正50/50。
4. 抽取结果由 `run_seed + fate_offer_id + card_slot_index` 确定；关闭再打开、暂停或读取同一事务不得重投正逆位。
5. 正/逆位共用同一卡名、稀有度、收藏条目和 `stable_card_id`；结算记录额外保存 `orientation / orientation_roll / effect_params_snapshot`。
6. 星星牌无论正位或逆位都占目标枪1个永久命运槽，且都随枪械实例移动；月亮/太阳牌均不占枪槽。
7. 逆位不等于“纯惩罚”。它必须是同一主题的反向策略、节奏交换或风险/回报改写，不允许只把所有正数改成负数。
8. 满槽兑魂价格只读稀有度，不因正/逆位改变。

## 3. 翻牌与逆位表现

### 3.1 出场时序

```text
0.00s  三张卡背面朝向玩家，不显示名称与效果
0.10s  从左到右每张间隔0.08s开始绕Y轴翻转
0.24s  到90°薄边时替换为已抽取的牌面
0.42s  正位整卡收束为0°；逆位整张正面卡牌绕Z轴转至180°
0.50s  卡面完成显示；逆位说明内容已替换为逆位效果，且随整卡保持180°倒置
0.62s  才开放点击，避免玩家在未看清朝向时误选
```

翻转使用代码创建的 `Control` 变换、透视缩放、遮罩与描边，不依赖预烘焙帧图。开启“减少动效”时改为0.15秒交叉淡入，但最终方位必须与普通动效一致：正位0°、逆位整卡180°。

### 3.2 可读性和交互

- 逆位反转整张正面卡牌；中央图案、内外框、卡名、天体专名、方位标签、效果文字、数值、目标与槽位信息的相对位置全部随卡面旋转180°，不得单独把文字旋回正向。
- 逆位卡使用同一卡名，但说明内容必须读取 `reversed_description / reversed_effect`，不能把正位说明倒置后继续显示。
- 逆位额外使用向下三角与双线边角，不能只靠倒置或颜色区分。
- 悬停只做轻微上浮与辉光，不把逆位卡旋回正向。选中时卡牌先短暂回到薄边，再飞入对应的枪械/角色/世界所有者区域。
- 卡牌完成翻面前禁用点击；Esc可在动画中安全退出，不应用卡牌。

## 6. 数据契约

```text
stable_card_id                 # 78张牌各自唯一；正逆位不拆ID
tarot_number                   # 0–XXI，或 ACE/2–10/PAGE/KNIGHT/QUEEN/KING
arcana                         # MAJOR / MINOR
suit                           # MAJOR / WANDS / SWORDS / CUPS / PENTACLES
scope                          # WEAPON / CHARACTER / WORLD
upright_probability            # 0.50
reversed_probability           # 0.50
upright_effect                 # 正位执行器参数
reversed_effect                # 逆位执行器参数
orientation                    # 本次出场结果；不写回卡牌定义
orientation_roll               # 可回放的随机结果
orientation_rule_version       # 平衡迁移用版本
```

不得为逆位复制一个 `*_reversed` 收藏ID，也不得通过改卡名、稀有度或作用域伪装成新卡。

## 7. 抽取与平衡规则

- “每张牌的正逆位概率相同”不等于“78张卡的身份抽取权重全相同”。牌身份仍先按层深、稀有度和卡池条件抽取，方位始终是50/50。
- 三选一中同一 `stable_card_id` 不重复；同名卡不会同时出现一张正位和一张逆位。
- 新增30张在执行器、UI、存档和自动测试完成前不得进入正式可玩卡池；数据表中必须继续标记“设计完成/待施工”。
- 旧存档中已刻印的48张卡按 `stable_card_id` 迁移为新塔罗名称的正位，不重投逆位，避免已有枪械构筑被暗中改写。
