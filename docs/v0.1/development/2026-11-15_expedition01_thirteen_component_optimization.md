# 远征01十三组件五分之一减面候选

日期：2026-11-15。功能：ASSET-PIPELINE / WORLD-PLAN。设计依据：[远征01设计](../design/远征关卡01设计.md)、[制作源布局](../../ART_SOURCE_LAYOUT.md)。工程版本不变。

## 授权与边界

用户要求对当前运行组件排名中剔除既有优化件后的13件，沿用方形化、减少弧线和小细节、保持大效果的要求，逐件优化到原三角面数五分之一并自检。本批只制作候选，不覆盖原始源、正式GLB/Prefab、碰撞或房间布局，不做正式Godot重导入，不改玩法/存档/AssetID。

冻结基线及全部过程证据由 `scripts/workspace_paths.py` 输出到工程外 `outputs/expedition01_optimization/batch13_20261115/`。`baseline.json` 冻结13源、13GLB、13Prefab、177房间TSCN及公共色盘哈希；最终真源为 `final_report.json` 的13条路径，浏览入口为 `review.html`。

## 方法与结果

同输出集合、同单位统计三角形；预算 `T_after <= floor(T_before / 5)`，减面率 `R = 1 - T_after / T_before`。逐连通块确认六向平面/箱壳或规则直杆后方形重建，保留部件摆位、包络、主体与发光分离以及原始材质/色格。斜杆使用端盖轴框架，不以世界AABB抹平；未识别形体保留。不使用整件固定比例Decimate，不按最近面重新猜色。

## 自检与真实边界

- 13件最终路径分别由新Blender进程重开，运行现有严格 `validate_game_prop.py`，预算设置4材质、逐面PaletteUV有面积且单色格安全内区、活动编辑/渲染层、公共色盘外链、Closest、主体/发光分离等检查均通过，退出码0。原验证器未修改。
- 冻结原源/正式GLB/Prefab/177房间/色盘哈希前后一致。部件对象变换和集合偏移保持；输出包络未发生可测量超过1e-5m的整体漂移，逐件实际值在报告中。
- 六视角（正/背/左/右/俯/斜游戏视角）固定源相机、光照和尺度对比；数据库设施另有局部近景。主代理逐件查看图，未见大面塌陷、主体结构丢失；方形化后边缘高光更硬、平台端柱暗面和杆角局部覆盖增加，属于可见取舍，不宣称像素一致。
- 首轮机柜候选擅自补了型号差异与材质角色，主代理拒收。重新从各原始源制作保留原样的v033，未凭显示名称修补四份历史源本身的几何相似性。拒用v032的8份文件移到工程外 `rejected_scope_changes/`，归档哈希见 `rejected_archive.json`，正式源树不保留拒用试算。
- 修正版首次渲染因本地化Background节点名查找失败，退出2；改为节点类型查找后同套渲染完成，退出0，不改资产或校验阈值。
- 自检不是Godot正式接入验收。未导出/导入本批稳定GLB，未验证游戏内碰撞、阴影、通行、帧率、移动端或整关。采样表面距离不是严格Hausdorff上界。
