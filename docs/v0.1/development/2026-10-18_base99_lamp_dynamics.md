## 三个必须先讲的设计决定

**① 写入口只有一个，且必须让位给开关。**

`BaseFixtureGlow3D` 已经是这些材质的唯一所有者：墙面开关写 `0 / 原值`，4.2s 启动序列写
`0 / 0.16 / 1.0`。如果新脚本直接写绝对值，谁后写谁赢，会出现「关灯了还在呼吸」或者
「启动序列里莫名抖动」。所以本脚本只在它**静止**的时段写 `baseline × motion_factor`，
并在它重新接管时把当时的能量读回当新 baseline。

N11 专门验这条：启动序列 70 帧里，受控能量**只**落在 `{0, 0.16b, b}` 三档，越界 0 次。

**② 事件必须错开，霓虹有「预约」特权。**

业主说「时间错开」。六个通道共用一道闸门：同时最多 2 个事件、相邻起始 ≥2.9s、
进场景后首个事件分别排在 1.8 / 7.5 / 10.0 / 13.5 / 17.0 秒。

但霓虹有硬指标（8~15s），实测一开始有 **24%** 的霓虹事件被闸门推到 15s 以上 ——
那等于在改业主给的节拍。所以给霓虹预约权：它下一次起始时刻一确定，其余通道让路。
改完后区间回到 **8.05~14.92s**、中位 12.02s。

**③ 常态不能改美术外观。**

显示器屏幕原本是 `03_清漆反光` 面、`emission_enabled=false`、靠反光显色（深蓝暗屏）。
我第一版为了「看得见」给它常态加了自发光，结果把深蓝屏变成亮蓝屏 —— 那是**改外观**，
不是加动态。改成「常态 0，只在事件里亮起来抖」，实测常态静默占比 98%。

## 实测纠正的三处「名字对、东西不对」

这一节是本次最花时间的地方，也是最容易再踩的坑。

| 原先以为 | 实测是 | 怎么发现的 |
|---|---|---|
| `42_柔和自发光_v019_001` = 电脑屏幕 | **台灯的发光头** | 逐面染色后拍图：它只覆盖台灯头那块黄色灯条 |
| 电脑屏幕是某个自发光面 | **`42_主体` 的 surface 2**（`03_清漆反光`，emission 关着） | 把 surface 2 单独染成洋红，整块屏面变洋红 |
| 台灯「往上加亮度」做呼吸 | **必须往下沉** | 灯罩在 filmic 下已纯白过曝：×1.10 无变化，×0.90 有 32614px 变化 |

判定手法记一下：**逐 surface 染色 + 开关切换取差异包围盒**。
只看节点名和材质名会错，因为 GLB 导出的 mesh 名与美术语义不对应。

## 参数是怎么定出来的（不是凭感觉）

每个幅度都先跑「梯度实验」：把倍率按 1.0 / 0.9 / 0.72 / 0.55 / 0.42 … 逐档渲染，
统计与 1.0 的差异像素数。结论：

- 霓虹 0.72 → 25% 像素变化（够明显，所以保留业主的 8~15s 与 -28%）
- 床头灯 ×1.10 → 几乎 0；×0.90 → 32614px ⇒ 呼吸改向下沉
- 门警示灯 ×0.93 → max 6/255（读不出来）；提到 ×0.87 → max 207
- 屏幕（旧目标）常态就在过曝区，0.55/0.45/0.35 三档单帧几乎同值

## 踩坑记录（都是验证脚本自身的错，不是产品的问题）

1. **规划和拍摄用了两个实例** ⇒ RNG 序列不同 ⇒ 拍到的「极值时刻」其实落在静息相位上，
   两张图完全一致。改成单实例 + `reset_for_test(seed)` 重放。
2. **`_process` 在 `set_process(false)` 之前已经推进过时钟**，而采样索引按
   `clock = index × STEP` 推 ⇒ 整体错位，N6 截到事件窗口之外。加复位。
3. **频闪频率乘了归一化时间 `t`（0~1）而不是秒** ⇒ 实际频率变成
   `f / 事件时长 ≈ 40Hz`，既不是设计值也进了光敏风险区。改乘 `elapsed`。
4. **envelope 乘了两次**（jitter 里一次、外面一次）⇒ `envelope²` 把两端压平，
   0.27s 窗口里凑不出一个完整周期，频闪起不来。只乘一次。
5. **`emission_operator` 忘了改**：材质原本是 `MULTIPLY`，清空贴图后自发光被乘成 0，
   差异直接归零。改 `ADD`。
6. **关灯态判据写成「屏幕必须全黑」**：场景里还有不受控的墙面/天花灯带，环境光也会
   照亮几何 ⇒ 误报 506365 个「仍发亮」像素。改成「平均亮度落差 ≥3.0 + 最亮不增加」。
7. **GDScript 格式串里 `%%）` 这种混排会让整条格式化失效**（打印出字面模板还看不出来），
   改写成 `percent` 全 ASCII。
