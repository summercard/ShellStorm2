# 远征01 暗门可布位点普查与 S4 改址

日期：2026-10-18
触发：业主「去对应的几个房间都过一遍，把远征01 的几个房间可以布暗门的位置再过一遍，然后做一次测试」

## 一、做了什么

1. 新增只读普查探针 `tests/verification/probe_secret_site_candidates.gd`，
   对远征01 **每一间主路房**逐墙逐槽跑判据，产出「可布 / 不可布 + 原因」清单；
2. 跨 3 个种子重跑，验证「固定槽位」方案是否真的不随种子漂移；
3. 按普查结果修掉唯一一处硬伤：`S4` 原来落在 `room_10` 与 `room_09` 的**共用墙**上；
4. 跑正式验收 `verify_secret_branch_flow`（20 条断言）复绿。

## 二、判据（三条，全部用运行时几何）

| # | 判据 | 说明 |
|---|---|---|
| 1 | 槽位合法 | `lane = ±(墙半长 − 7.5 − 5k)`，与模板 `wall_lane_table` 逐值同源，但按**运行时**墙长现算 |
| 2 | 不压主路门洞 | 与场上任一 `Door_*` 门扇中心距 `≥ 2.3 m`（两块 2.2m 门并排就重叠） |
| 3 | 朝外是真外墙 | 沿外法线 0.5 / 1.5 / 3.0 m 三个探针都不落进别的房间体内 |

判据 2 是硬伤口径（压门 = 堵路）；判据 3 是「像不像暗门」的口径（贴邻房不堵路，
但木板会嵌在共享墙上）。

## 三、结果

12 间主路房，**合法位点合计 201 个**。逐房分布见
[设计 §3.2.1](../../design/支线秘密房间设计.md)。

跨 3 个种子（77001199 / 20261018 / 1234）：

```
稳定可布 200 项 / 稳定不可布 88 项 / 波动 6 项（压门 0 · 贴邻房 6）
门槽跨种子不一致：0 / 12 间
```

- **压门波动 0** —— 不存在「这个种子不撞、那个种子撞门」的槽，「写死一个位置」站得住；
- **主路门槽 12/12 跨种子一致** —— 前提成立（门槽本身不漂移）；
- 6 项贴邻房波动是真实的邻接变化（某种子下邻房贴上来），选点避开即可。

## 四、修掉的硬伤：S4 挂在共用墙上

原来 `S4` 写 `room_10 / north +2.5`。`room_10` 运行时被转到 270°，`north` 落到**东墙**，
而东墙正是 `room_10` 与 `room_09` 的共用墙 —— 木板钉在两间主路房的隔墙上。

改址：`room_10 / south -7.5` → 运行时西墙 `-7.5`，离最近主路门 **21.5 m**，朝外净空 3.0 m。

为什么选 `-7.5` 而不是更远的 `+7.5`：静态断言 A3 用**设计源坐标**判「朝外是否撞房」，
而设计源里 `room_10` 在 `(50,-45)`、`boss` 在 `(95,-45)` 压着 `x≥55` 一带；
`south +7.5` 的静态点 `(57.5,-30)` 正好落进 `boss`，A3 会报红。
`south -7.5` 静态点 `(42.5,-30)` 与运行时落点都干净，两套口径同时满足。

## 五、三个坑

1. **lane 相位不是 `0/±5`**。模板是 `±(墙半长 − 7.5 − 5k)`：
   30×40 房间是 `±7.5 / ±2.5`，40 宽是 `±12.5 / ±7.5 / ±2.5`。
   用 `0/±5` 会把 `S1` 的 `south+2.5` 判成「不在槽上」，整张表都错半格。
2. **运行时 `rotation_deg` 是 90/180/270，不只有 0/180**。端口对接链会把房间整体转向。
   拿运行时 `wall` 做跨种子 key 会得到 11/12 间「假波动」；必须用 `−rotation_deg`
   反算回**作者系**再比，立刻降到 0。
3. **静态 A3 与运行时几何不是一套坐标**。设计源 `center_m` 是示例版图，
   实机位置由 `FloorPlanGenerator` 重排（`room_10`：设计 `(50,-45)` → 实机 `(55,-250)`）。
   A3 只能当「图纸自洽性」检查，不能当「实机不撞房」的保证 —— 后者由 A20 与入房实测负责。

## 七、已知限制

- **入口房 `entry` 未参与普查**：它是楼梯间，不装配成可交互的 `DungeonRoom3D` 节点，
  探针按节点枚举时收不到。若以后要在入口房布暗门，需要单独处理它的位点解析。
- **A3 仍是静态判据**：只保证图纸上不撞房，不保证实机不撞房。实机保证靠 A20（不压门洞）
  与普查探针（朝外净空）。若要把「实机不贴邻房」也变成运行时断言，需要给 A20 加一条
  运行时邻接检查。
- **普查是只读的**：不改产品代码，也不自动挑点。新增位点仍然要人工从表里选、写进关卡数据。
