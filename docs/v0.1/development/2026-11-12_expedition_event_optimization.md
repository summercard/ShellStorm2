# 远征与地牢事件帧优化

2026-11-12 · 游戏 0.1.0 · PERFORMANCE-RUNTIME、WORLD-ENTRY、ENCOUNTER-EVENT、WORLD-LOOT、SAVE-PROFILE。

## 工程范围

远征01、02、03和后续登记的远征共用读取页、战斗基类和房间流送。旧基地四个独立地牢原先直接切换场景。冷钢边境、锈蚀铸造厂、孢子深层和深渊档案库现在由原传送门提供目的地，经过同一读取页。装配、存档恢复和预热完成后才交还处理和输入。塔楼子类仍负责提交自己的楼层、连通门和黑幕。训练场沿用设施自己的入口。

## 探针口径

Windows，Godot 4.7.2、Vulkan Forward+、RTX 4060 Ti，1280×720。正式读取页、启用持久化，Autoload 启动前隔离用户目录，保留驱动与工程导入缓存。运行期间同机另有编辑器和游戏进程。夜间内存紧张时的124超时样本没有完整帧数据；不能与早晨样本混算。

探针走实际开门/进房处理，使用测试入口推开门并将角色放到目标房，跳过钥匙交互和手动寻路。自然遭遇与末尾受控加怪分别统计。真实弹体要有命中信号和扣血记录。首箱用正式出箱入口，随机掉落结算另计。长路线沿相邻房间折返；返回帧也进入预算。测量窗口既覆盖调用本身，也包含之后数帧。渲染CPU/GPU计时可能滞后，禁止将其与墙钟直接相加。

最终探针等待入场演出释放输入，再开始采样。敌房覆盖落门和延迟出怪，宝箱覆盖完整0.84秒展开；实绘后的首箱报告模型与灯组是否来自读条。旧探针只等待节点恢复处理，在远征入场仪式仍接管输入时就可能开始计时。两种口径单列。

### 远征03深路线与首次精英

种子41021首次进入 n05 的同步回调只用19.0 ms，随后的帧却达1218.7 ms。重测把墙钟拆到绘制前、绘制信号之间及绘制后，2292.2 ms 长帧中有2055.4 ms 已在绘制前发生。随后在工程外副本给同步方法逐层计时，定位到 `_retry_roaming_elite → _spawn_enemy_batch → configure_from_enemy_data → configure_elite_content → _cached_scene`。夺械者首次表现场景读取占该次插桩延迟派发约83%；插桩会放大绝对耗时，仅用于识别调用链。同期还能观察到精英预约、确认、检查点的档案写入。原始独立诊断在 `slow_scope_2vw60_ms/engine.log`。

公共读条现在收集游荡规则和各房点名的精英，按正式场景去重，实际绘制后由关卡持有。首次演员接手原场景实例，武器、AI、受击盒、出生时机与跨局预约由原系统负责。进房时重试命运奖励只有在成功落地后才追加自动存档。交易写盘继续原子替换并读回；SHA-256与本进程上次确认的完整文件相同时复用已验证版本号，文件变化时重新解析并检查原校验。写后比对实际文件与已生成封套的完整字节，存档格式和旧档兼容路径沿用原设计。

独立飞行探针曾在平静路线命中、战斗路线连续三次漏记。探针现按正式玩家发射上下文明确指定敌我、目标组及掩码，发射前从活动碰撞体中心确认净空射线。只有命中指定敌人并观测到扣血才记通过。在精英预热的第一轮对照里，远征03三发均实际扣1点血。

### 首箱渲染与现场条件

02 的 55.0 ms 首箱帧中，正式建箱调用0.53 ms，绘制信号之间42.88 ms，下一次返回的渲染线程CPU计时41.36 ms。相邻的表面管线计数从221增至223。晚间单独把预热视口的抗锯齿与玩家视口对齐，仍新增2条表面管线，已撤回试改。当时系统只剩约506 MiB可用物理内存，单次读入超9400页/秒；该轮首箱679.7 ms，绘制前已耗612.1 ms，不用于计算优化收益。

游戏使用隐藏的中文 `ChestPrompt` 兼容既有交互查询。独立 Vulkan 用例在空场景依次新建两个相同的隐藏 `Label3D` 再转移首个节点，表面管线增量分别为1、0、0。正式预热按两档宝箱保存已初始化的提示，首箱沿用原节点，按实际箱体更新颜色与提示文字。画面仍用原互动圆点。专项在 `hidden_label_irus11vu/console.txt`；它只说明隐藏提示本身产生的开销。

在正式远征02复验 `expedition_02_abqbbuxk` 中，首箱首次渲染新增的表面管线由2条降到0条，首帧绘制信号之间为1.93 ms。该窗口277帧的P95为3.51 ms、P99为5.58 ms，仍有2帧超过50 ms、峰值140.51 ms。同进程静止窗口也出现742.7 ms、读条195.0秒；这组保留为内存压力下的完整记录，不能据此宣布首箱墙钟达标。读条26/26、池化弹真实扣血、引擎错误0，预算退出7。

检查范围还包括存量文档链接、关卡解耦、运行时资产命名和脚本语法。关卡解耦零违规、资产命名门禁通过；文档门禁有11个存量失效链接。远征01的遭遇节奏在测量期间另有正式设计变更，5个触发房现在采用60秒固定战斗窗口、第2秒首批及末批循环。刷怪验证按最新设计逐项检查波次与上限。
