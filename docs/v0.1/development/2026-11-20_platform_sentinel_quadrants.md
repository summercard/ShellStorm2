# 武装平台错峰待机、分区掌拍和枪阵覆盖

日期 2026-11-20。FeatureID 为 BOSS-STAGES / WORLD-PLAN。01 和 99 使用同一遭遇与部件逻辑。规则见[首领战设计](../design/远征01武装平台首领设计.md)。

- 将轮流抽一臂一枪的待机改成每个单位持续分相运行。每座枪的升降节、云台偏航和仰角都有变化，枪阵周期约 2.85–3.87 秒。大臂的肩、肘、腕按约 3.45–3.96 秒错峰。空档运动不写攻击时钟。正式起手只接管参与攻击的部件，其他存活部件继续运动。
- 以平台中心的两条轴线将甲板分成四区。起手保存实际可达的落点，锁定后按既有前摇、触地和收招时轴完成。延伸按源骨长解算肩肘腕，手掌保持平落。掌拍半径由 3.05 米扩到 3.80 米。离开命中区时照常落掌和回位，玩家躲过伤害。
- 敌方枪阵用甲板全域位置选择已就绪的枪架。优先选朝向和距离合适的安装点，首段实体卡住枪口时换下一座。常规、对边与全周弹体飞行距离分别调整到 40、34、29.5 米。世界碰撞继续挡弹。只会继续飞离甲板方向的弹体仍保留，且不阻滞下一轮攻击。
- 机械臂三节随骨胶囊半径从 0.72／0.68／0.72 米改为 1.40／1.24／1.32 米，掌部另有半径 1.60 米的实体受击体积。大臂保留独立血量，台面高度可辅助瞄准的低位臂段来自同一个实际受击体。
