## 一、业主口径与本版的对应关系

> 「V3 版本还是很多地方用方块和多边形替代，没有把组件物体的结构制作精致来，包括车子，路灯等。细节颗粒度要达到 0.1 米范围的零件颗粒。0.1 米以下的物体可以不用，但是 0.1 米的颗粒度的东西都要表达清晰。」

这句话拆成三条可执行判据：

1. **0.1m 是零件的最小可辨识尺度**。螺栓、铰链、把手、锁扣、格栅条、反光片、铭牌、卡扣、辐条——全部要做，尺寸落在 0.06–0.20m。
2. **不允许「一个盒子代表一个功能块」**。车门 = 窗下墙 + 窗上沿 + A/B/C 柱 + 玻璃 + 门缝 + 把手 + 锁孔 + 防擦条 + 裙板。
3. **每根杆都要有「根」**。法兰盘 + 地脚螺栓 + 垫片 + 灌浆缝 + 检修门 + 接地端子。没有根的杆在近景里就是插在地上的管子。

「0.1m 以下可以不做」不是「可以偷工」，而是明确**停止线**：再往下（0.03m 的焊点、0.01m 的划痕）不做，把预算全部花在 0.1m 这一档上。

## 二、先做度量：把「颗粒度」变成门禁

这是本版最重要的一步。v003 的验收靠「近景渲染看着还行」，结果就是建筑做到 6.7k 面、旁边轿车只有 176 面。**凡是不能量化的验收标准，最后一定退化成「我觉得还行」。**

新增 `scripts/blender/audit_granularity.py`，对每个资产包：

| 指标 | 定义 | 门槛 |
|---|---|---|
| `islands` | 按顶点连通拆出的独立零件数 | ≥ `max(12, 8 × L)` |
| `fine_count` | 尺寸 ≤ **0.20m** 的零件数（0.1m 级零件的直接计数） | ≥ `max(6, 4 × L)` |
| `p50` | 零件尺寸中位数 | ≤ 0.90m（仅道具类，L ≤ 6m） |

`L` = 组件包围盒最大边长。4.7m 的轿车 → 至少 38 个零件、其中 19 个 0.1m 级；7m 的路灯 → 56 / 28。

**指标口径改过一版，必须记下来**：第一版用「面数 / 外表面积」做面密度，跑出来所有组件失真——项目里的零件是独立闭合盒叠出来的，内部重叠面全部计入 `calc_area()`（药店 4145 面算出 2180 m²，而外表面只有约 600 m²）。**内部面积不可度量，所以不能用面积归一化**，改成按尺寸归一化。

## 三、这一版实际做了什么

### 3.1 三栋建筑：加「预埋件层」而不是重写

建筑已在 v002/v003 按颗粒度重写过，主体结构是对的。审计不过的是 `fine_count`——酒店 34/114、背景楼 2/122。也就是说**大体量有了、小零件没有**。

重写会破坏已验收的立面，代价太大。改成在原 builder 之后**追加一层真实立面上本来就有的固定件**（`ug_props_v004_grain.py`）：

- 立面锚板 + 膨胀螺栓（1.7m × 1.45m 网格，0.12m 见方）
- 女儿墙压顶分仓缝（1.15m 一道，0.05m 宽）
- 落水管卡箍（2.3m 一个，含 2 颗螺栓）
- 避雷带支架（1.35m 一个）

这些不依赖窗洞位置（网格均匀，真实立面的预埋件本来也按结构模数排），所以对任何一栋楼都成立，也不会与已验收的窗框打架。

### 3.2 车子：两个硬错误（近景渲染才暴露）

第一版写完看着没问题，渲染出来才发现：

1. **车轮被侧板包住**。侧板区间是 `(0.95,1.95)` 与 `(-1.95,-0.95)`，而轮心恰在 `x=±1.45`——侧板正好盖在轮子上，四个轮子一个都看不见。
2. **侧窗玻璃埋在窗下墙里**。窗下墙 `y∈[1.045,1.095]`，玻璃 `y∈[1.048,1.058]`，玻璃整体在墙体内部 → 侧窗全黑。

修法：侧板分 3 段、**轮拱处留空**（`x∈[±1.00,±1.84]`），轮拱用 `arc_xz` 做轮眉、`prism_xz` 做内衬；车窗按「暗腔 → 玻璃（与外墙齐平并外凸 0.004）→ 窗框」分层，玻璃一定在最外层。

拆件清单：胎面/内外胎壁/轮辋盘/凸缘/5 根斜辐条/中心盖/车标盖/5 颗轮毂螺栓/气门嘴/轮拱内衬/轮眉；格栅内腔+上下框+左右框+9 竖条+2 横条+车标座；大灯（灯碗/灯罩/4 螺栓）×2、转向灯×2、雾灯×2；门槛压条/腰线饰条/3 道门缝/门把手+锁孔×2/防擦条；尾灯 3 格+分隔条+镀铬边×2、牌照+4 螺栓、排气×2+吊耳×2；前后保险杠各含中段+左右防撞块+橡胶条+端头+镀铬条+拖车钩。

### 3.3 蒸汽：改了 6 版，最后承认做不到「雾」

这是本版唯一没有彻底解决的东西，过程必须写清楚。

| 版本 | 做法 | 渲染结果 |
|---|---|---|
| ① v002 继承 | 5 颗等距竖直球团 | 一摞**白碗**（球面完整、间距相等） |
| ② | 逐层放大 + 锥形收尖 | 一堆**蘑菇/伞**（锥体必有轮廓） |
| ③ | 低矮扁八边形雾片 | 悬浮的**荷叶**（薄片必有边界） |
| ④ | 7 层 × 7 颗严重重叠的球 | 一坨**岩石**（轮廓毛了，但体量太大） |
| ⑤ | 230 颗小粒 + 锥顶 | 一串**碎石**（有尖顶、有空隙） |
| ⑥ **采用** | 520 颗 0.05–0.10m 圆润碎粒，间距小于粒径 | 远看是汽柱，近看是密集碎粒 |

**根因**：在「纯几何 + 4 角色材质（无 alpha）+ 暗场景」约束下，蒸汽做不出「雾」。任何闭合体在近景都会读成实体。唯一出路是颗粒必须**远小于观察距离**、靠数量堆到不透光——这正好落在 0.1m 粒度区间内。

所以这一版的取舍是：**把蒸汽的「源」做完整**（井圈/法兰/4 地脚螺栓/6 道格栅/暗腔，全 0.1m 级），汽团做到「远看成立、近看不穿帮」即可。要真正的雾，需要给这套材质体系加 alpha 通道或体积雾，那是材质层决策，不在本次范围。

### 3.4 主体朝向：柜体门朝错方向

配电柜 / 售货机按「正面 +Y」写完，而项目约定是「正面 +X」。实例 `rz=0` 时门朝向沿街，镜头只看到背板——近景整柜全黑。加 `_face_plus_x()` 做 −90° 旋转（`(x,y) → (y,-x)`，**旋转不改 winding，法线不用重算；镜像会翻面**）。

## 四、布局修正

售货机柜 `(-9.1, -8.4)` 与配电柜 `(-9.0, -8.6)` 几乎重合，两者互相穿模（近景实测：售货机整个埋在配电柜里，只露出一个角）。这是 v001 起就存在的布局冲突。

售货机沿墙挪到 `(-9.1, -11.6)`——药店与酒店之间的实墙段，那里没有蒸汽柱、没有配电柜、没有消防梯。（先试过 `-4.2`，正好压住蒸汽柱。）

## 五、配色

严格沿业主口径：**暗部只走邻近色、只动亮度，跳色只给自发光**。

道具统一压在同一列（色盘 R6 蓝紫 `#051128`→`#718195`，lum 16→127），镀铬/玻璃拿灰阶列（col 9），橡胶拿最暗格。

**车身明度重排过一次**：第一版全车压在 M2–M4（26/35/43），近景像素值只有 8–15，等同于黑块。改成车身 M7(86) / 车顶 M8(97) / 裙板 M3(35) / 铬件 127–150 / 胎 6——跨度 6→150，靠大反差出层次。

同时给车补了两盏低功率面光：车停在 `(-2.6,-16)`，正好是这条街最暗的一段（两侧建筑都高、又不在任何灯下）。

## 七、已知限制

1. **仍是纯 Blender 源**：无 GLB、无 PackedScene、无碰撞/导航，不写入《3D-场景通用》。
2. **蒸汽做不到「雾」**：见 3.3。要真雾需材质体系加 alpha 或体积雾。
3. **颗粒度门槛是「下限」不是「上限」**：33/33 通过只说明每个组件的零件数与 0.1m 级零件数达标，不代表每个零件的造型都对。车身的 A/B 柱偏细、挡风玻璃边缘有一道缝，属于这一类——已记录，未修。
4. **`p50` 门槛只对道具（L ≤ 6m）生效**：建筑允许有整面墙这种大零件，所以只判零件数与细颗粒数。
