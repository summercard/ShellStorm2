# 精英档案预览、收租人体型与电弧补光

日期为 2026-11-04，工程 0.1.0。FeatureID 为 UI-HUD、ELITE-ROSTER、ENEMY-AI 和 VFX-POOL。规则见[UI-39](../design/UI与UX全局设计及全界面清单.md#ui-39-怪物生态图鉴界面monsterarchivemenu)、[收租人契约 r10](../design/精英02收租人状态与动作契约.md)和[特效规范](../14.6_特效系统与制作规范.md#311-收租人屏幕放电与身体干扰)。

## 正式行为

档案页右栏使用独立 3D 世界，加载所选精英的正式表现包装。收租人通过现有采样接口显示待机，静态精英显示正式模型。相机根据当前姿势的模型包围范围取景，切换条目时释放旧模型，同一档案数据刷新时保留预览。状态区读取档案服务，显示成长状态、最近结果和已有的上次记录生命。首次遭遇、逃脱、夺物和重载均通过原服务更新。UI 场景版本更新为 v002。

收租人专属体型系数从 1.6 调整到 2.0，实际画面比改前增大 25%。这项系数乘在精英原有基础倍率上，模型、移动圆柱和 16 个跟骨受击盒共用实例变换。最低靴底仍采用 1 毫米地面内嵌，读档重建采用当前体型。

电弹与定身电弧升为 v002，可见几何和身体周围的电弧横向包络均放大到首版 2 倍。弹体自带青蓝光，峰值能量 0.85、范围 2.6 米。定身时身体补光能量 1.05、范围 3 米。灯随宿主，启用距离淡出，回收、结束与复借时重置。实际弹体命中球仍为 0.12 米。注册路径与资产 ID 沿用原项。
