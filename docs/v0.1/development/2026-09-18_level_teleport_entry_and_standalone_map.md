## 变更与原因

**问题**

工作区代码已把关卡入口改为“基地内传送 + 切换地图”（中央远征情报室 → `RogueMapSelectMenu` → `RogueMap01TowerSegment3D.tscn`），但 `docs/` 目录零改动，且存在**明文冲突**而非单纯缺失：

- [05](../05_技术施工_关卡生成与爬楼.md) 原写「`boss_descent_gate` 后必须是真实 `post_boss_stairwell`，不能以传送或地图按钮替代」，以及「下行楼梯大厅……不能是地图图标或瞬移假出口」「不得用透明墙、瞬移或假门掩盖残缺布局」。
- [07](../07_技术施工_基地设施.md) 原把 `mission_operations` 描述为「展示四条野外道路与副本入口说明」的信息设施，工程实际已改为 `ACTION_MENU` + 菜单场景。
- [README](../README.md) 主循环仍以「楼顶进入塔内 → 98F 到达门逐层下潜」为唯一入口。

**最终行为（本次确立的设计口径）**

关卡入口分为两条并存路线，共用同一套房间、门、走廊、楼梯、组件坐标、美术、敌人与掉落实现：

1. **正式主线｜基地传送 + 切换地图**：99F 基地中央远征情报室（圆形全息设备平台，`facility_id = mission_operations`）交互 → `RogueMapSelectMenu` 选关 → “传送进入副本”执行场景切换 → 独立关卡场景 → 出生在入口安全房原入口门口 → 撤离房间（撤离信号塔）或死亡 → 独立副本结算 → 返回 99F 基地。
2. **隐藏关卡｜塔楼连续爬楼**：100F 天台 → 99F 基地 → 98F 到达门 → 逐层生成 → 94–90F / 89–85F 区段 → 隔离间卸载。**本轮不改动其行为与数字**，作为后续隐藏关卡保留。

**本轮新确认、尚未施工的设计（不得记为已具备）**

- 独立关卡**单层化**：只保留一层完整关卡，不再向下逐层。
- 独立关卡**撤离房间与撤离信号塔**：房间类型 `EXTRACTION`，信号塔沿用 `res://assets/art/props/dungeon_3d/prp_extraction_beacon_root_top3d.tscn`；撤离走“成功返航”语义（物品全保留、返回 99F 基地）；可达性纳入提交验证。
