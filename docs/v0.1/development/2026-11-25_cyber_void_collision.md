# 赛博虚空可选物理开口

日期 2026-11-25。归属 VFX-POOL，角色接入复用 PLAYER-STATE。预制体 FX03-04 / `VFX-ENV-VOID-EROSION-3D` v006。工程 0.1.0。

## 改动前实测

在独立预览场景中对洞内地板做向下射线检测。盒内 `(-6, -0.02, -5)` 在进度 0 和 1 都命中同一个共享地板碰撞。GDScript 当时只安装和撤下渲染覆盖，正式暗门与远征 01 的实例使用这条视觉路径。玩家已有着地移动、重力下落、落地和坠落 15 米安全回位。

## 实现

- `VfxVoidErosion3D` 持有可选物理开口，默认关闭。光栅开口与碰撞裁切使用同一个旋转盒和展开尺寸。选用碰撞根后可以覆盖独立的承重层。原运行场景中的实例继续使用默认值。
- `VoidCollisionCut3D` 保留原静态体与碰撞形状所有者。静态盒用凸体保留洞外部分，静态三角网沿盒面裁切并保留背面碰撞配置。其他形状仅支持整块移除。多个效果从同一原形状计算洞口并集，最后一个请求撤销时恢复原资源。形状所有者原有的开关仍由宿主管理。
- 保留 Player3D 的下落、落地和安全回位，零新增存档字段。特效账本主表第 86 行、预制体页第 276 行、变更日志 v0.1.67 与对应的无损基线签名同步。
