# 2026-09-22 P0 验收基线与隔离修复

## 范围

本批先处理工程审计中会阻断所有后续结论的 P0：验收运行器隔离、已迁移运行时契约的专项验收、当前发布楼层边界，以及角色 v021 动作分支的状态反馈回归。资产登记表的逐项来源核验保持独立批次，禁止以“批量接受当前哈希”掩盖来源。

## 已完成

| 项目 | 修复 | 验收口径 |
|---|---|---|
| `.godot` 隔离 | runner 在临时工程内克隆导入缓存并强制刷新；不再链接正式工程 `.godot` | 冷/热 class cache 均通过 `verify_verification_runner_contract` |
| 批量复验 | runner 新增 `batch`，一次隔离导入后连续运行指定场景 | 每场景保留独立退出码并汇总失败项 |
| 训练场 | 从 `BlueprintRegistry` 推导枪体、弹种、组合数 | 当前 19 架、67 组合全量可装备 |
| 战斗 VFX | 敌人飘字、近战斩击/命中改验正式 `VfxPool3D` AssetID | 不再用已迁出的旧池/父节点扫描制造假红 |
| 正式普通怪 | 组件数按 `formal_normal_asset` 契约判断 | `melee_chaser`、`ranged_caster` 均验证正式两组件包装 |
| 发布楼层 | 验收读取 `DEEPEST_PLANNED_FLOOR=98` | 不再把保留设计中的 95F/94F/85F 当成本次发布运行事实 |
| 玩家 v021 | Blender 动作分支恢复 locomotion 周期记账、锁定环和低血量环更新 | 保留“状态机输出 → 表现层采样”职责边界 |
| 楼板 | 按正式砖 AABB 原点契约计算可视顶面 | 99F 与 100F 承重面专项通过 |
