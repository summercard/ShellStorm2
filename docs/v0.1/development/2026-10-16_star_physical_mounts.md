# 星星命运实体构筑：战车、魔术师、力量

日期：2026-10-16；功能ID：FATE-RULES、WEAPON、VFX-POOL；工程版本：0.1.0。
设计依据：[命运塔罗牌组 FATE-RULES r3](../14_技术施工_命运塔罗牌组.md)、[特效契约](../14.6_特效系统与制作规范.md)。代码基线：`1d5df70a1`；交付状态：工作区，未提交。

## 本次改变

- 战车：沿用正式点击卡牌→选择真实装备来源→事务提交链路，冻结完整来源装配，弹体上创建 `BulletWeaponSocket` 和独立 WeaponModel3D。携枪从自身枪口持续射击；近战模型循环挥击并进行范围/前向/遮挡判定；逆位将携带武器旋转180°。来源武器不消耗、不被修改。来源面板仍覆盖当前与副装备槽，包含近战，不扩展背包来源规则。
- 魔术师：追加内部挂载枚举 MOUNT_2…MOUNT_8，旧枚举编号不变。副武器按应用顺序横排，闲置/背负尺度0.22，开火0.14s内尺度0.65；逆位锚定角色身后局部 `(x,0.85,0.65)`。同型号副枪通过唯一运行节点ID区分，不再错误共用第一个副枪的发射点。手持、背负、物品预览均复用原 WeaponModel3D 路径。
- 力量：稳定ID仍为 `fate_armor_pierce`；新应用变为滚石。弹速×0.5为用户指定；射速×0.5、碎裂3m/6m·s⁻¹为本轮可调工程初值。落地按真实物理碰撞滚动，逆位撞怪/障碍碎裂并径向击退，不额外造成范围伤害。碰撞半径0.18m，石头模型滚动不带着携枪翻滚。
- 修复结构问题：挂载/卸载递归维护深度；根树注册全部子节点；最大深度按待挂子树相对深度计算；默认目标优先主枪及其直接子弹；失败的整棵来源复制树彻底释放，避免只free根节点泄漏。完整来源结构保留，嵌套超过深度5时拒绝并回滚，不截断来源。
- 新应用的三张牌记录 `effect_version=3`；旧存档不重放新预设，保留既有数值快照。来源的前序构筑进入冻结副本，之后的改动不反写此前副本。魔术师复制已带副枪的主枪时会复制已有嵌套，受深度限制。
- `FX01-22 / VFX-FATE-ROCK-3D` 与 `FX01-23 / VFX-FATE-ROCK-SHATTER-3D` 各自独立Prefab；前者随弹体，不进特效池，后者走VfxPool3D。特效分账本主表/3D分页、受控基线与内容数据库三张牌同步；旧资产行及原3D分页非空单元格与改前逐格一致。没有批量接受既有哈希漂移。
