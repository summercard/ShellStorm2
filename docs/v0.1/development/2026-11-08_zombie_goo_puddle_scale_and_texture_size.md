# 僵尸死亡地面液体：随机尺寸收到 0.6~1.2、贴图降到 128²

- 日期：2026-11-08
- 范围：`src/vfx/VfxGooDeathBase3D.gd`（C 段地面液体）、`assets/art/vfx/textures/vfx_zombie_goo_puddle_floor.png`、源侧构建脚本
- 业主口径（当日两次）：「放大 1.5-2 倍的那个，改成 1-1.5」→「贴图变成 128，然后大小缩放到 0.6-1.2」

## 改动

1. **随机尺寸区间**：`PUDDLE_SIZE_ROLL_MIN/MAX` 由 `1.5 / 2.0` → `1.0 / 1.5` → **`0.6 / 1.2`**（当前值）。
   公式不变：`side = size × PUDDLE_SIDE_BASE(0.72) × PUDDLE_SIDE_SCALE(2.0) × roll`
   ⇒ size=1.0 时边长从 **2.16~2.88m** 变成 **0.864~1.728m**（胖子僵尸 size=2.0 时 1.728~3.456m）。
   `roll < 1` 是允许的：0.72 这个基准本来就大于贴图的设计尺寸，所以下限仍略大于 11-05 那版（0.62~0.84m）。
   仍是「出生点 + 下标」murmur3 `fmix32` 确定性伪随机，池化复借与停留段逐位冻结的约束不变；
   可用区间由 0.5 变成 0.6，四块极差判据（≥0.10）不用改。
2. **贴图尺寸**：`build_puddle_texture.py` 从同一张源图重出 **128²**（512² → 256² → 128²），
   只改 TARGET，抠白 / 去灰孤岛 / despill / 源图 24px 描边全部沿用。
   代价：源图 24px 描边折算到 128² 上约 3.6px，世界里的描边由约 3.9cm 降到约 2.4cm（细了约四成），
   轮廓仍在但比 256² 那版软一些。128² 实测「边缘/中段亮度比 0.39」（上限 0.75）、四角 alpha 全 0。
3. **验收口径同步**（未运行）：`verify_zombie_goo_death_vfx.gd` 的
   `EXPECTED_PUDDLE_ROLL_MIN/MAX` → `0.6/1.2`；边长底线改为
   `0.72 × 2.0 × 0.6 = 0.864`（旧的「至少 3 倍原规格」在新区间下不成立，已删）；
   `PUDDLE_TEXTURE_MIN_SIDE` 512→256→128；`RIM_PROBE_RATIO` 0.025→0.02（128 上算得 4px，实测仍主要落在描边上）。
