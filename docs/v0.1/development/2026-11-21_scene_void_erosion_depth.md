# 虚空体素断面与动态绕拍

日期 2026-11-21，资产 `VFX-ENV-VOID-EROSION-3D` v002，工程 0.1.0，基线 `73bcaa3f` 加首版虚空组件。范围与参数见[侵蚀设计 r2](../design/scene_void_erosion.md)。

射线从原模型上的开口出发，在局部体素网格中遍历，求与幸存方格向内延伸的侧壁交点。断面深度按格变化，粗粒缺口影响边缘轮廓，细网格随网格面和侧壁分别投影。断面以冷紫主体、少量暖粉峰值组织明暗。

深空云雾按射线在三维密度场中积分。方块按各自旋转坐标求交，沿轴下沉、带侧向漂移，远端逐渐淡出。三种面密度与冷暖色方向交错分布，每块仅有自身表面。场景附着、物理状态和退出清理沿用首版契约。
