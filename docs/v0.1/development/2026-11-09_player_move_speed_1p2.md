# 2026-11-09 玩家移速整体 +1.2 m/s

> 业主原话：「所有的数值增加 1.2」。范围按上一轮对话确认的四档行走速度（空手 / 手枪 / 长枪 / 机枪），
> 落地方式是把基础常速 `SPEED` 抬 1.2、持枪惩罚量**不动** —— 于是四档同时 +1.2，
> 与「逐档各加 1.2」等价，但只改一个常量，不会出现四份平行真源。

## 1. 落地值

| 档位 | 改前 | 改后 | 差值 | 来源 |
|---|---:|---:|---:|---|
| 空手 / 收枪 | 4.5 | **5.7** | +1.2 | `Player3D.SPEED` |
| 手枪（`sidearm`） | 4.0 | **5.2** | +1.2 | `5.7 − 0.5` |
| 长枪（`longgun`） | 3.7 | **4.9** | +1.2 | `5.7 − 0.8` |
| 机枪（`machinegun`） | 3.4 | **4.6** | +1.2 | `5.7 − 1.1` |

落地位置：`src/player3d/Player3D.gd:35`，`const SPEED := 4.5` → `5.7`。
`WEAPON_FAMILY_MOVE_PENALTY`（0.5 / 0.8 / 1.1）与 `MIN_MOVE_SPEED_MPS = 0.5` 未动。

公式不变：

```
v = max(0.5, SPEED − 武器族惩罚) × 命运移速倍率 × 近战多段倍率
```

## 2. 派生影响（按公式推的，不是感觉）

- **位移量**：每秒多走 `1.2 m`，相对 **+26.7%**；同样距离通行时间 **−21.1%**（`4.5/5.7 = 0.789`）。
- **冲刺相对价值下降**：`DASH_SPEED = 16.5`、`DASH_DURATION = 0.204 s`、位移 `3.37 m` 全部未改，
  所以冲刺/常速倍率由 `16.5 / 4.5 = 3.67×` 掉到 `16.5 / 5.7 = 2.90×`。冲刺仍是唯一的瞬时爆发位移，
  但「跑一段靠冲」的性价比变低。若业主想让冲刺继续保持同等相对强度，需要把 `DASH_SPEED` 提到
  `16.5 × 5.7 / 4.5 ≈ 20.9`；**本轮未做，因为业主只说增加 1.2**。
- **敌弹相对威胁下降**：敌方弹速（`Enemy3D.DEFAULT_ENEMY_PROJECTILE_SPEED = 7.0`、各 profile 的 5.0 / 6.5 / 3.5）
  当年是以「玩家 4.5 m/s」为锚定的。以通用 5.0 为例：改前 `5.0 / 4.5 = 1.11×` 玩家步速，改后 `5.0 / 5.7 = 0.88×`
  —— 已经慢于玩家横移，侧向躲弹变容易；6.5 那档从 `1.44×` 掉到 `1.14×`。这是本轮**未纳入改动范围但客观发生**的
  平衡位移，需要业主单独决定是否上调敌弹速度或缩短敌人出手前摇。
- **慢走阈值 3.2**：三档 5.2 / 4.9 / 4.6 全部仍高于它，持枪移动动画不受影响（改前同理）。
- **乘算链路**：命运卡 `move_speed_multiplier`、椅子 `ride_speed_multiplier = 1.3`、近战 `movement_multiplier()`
  都是百分比乘在北移后的 base 上，无需改动，但它们的**绝对增量**随之放大（例：+12% 从 +0.54 变成 +0.68 m/s）。
- **单位换算尺子漂移**：`docs/v0.1/04_技术施工_战斗与局内成长.md` § 单位尺子记的
  `1 原作单位 = 4.5 / 6.5 ≈ 0.6923 m` 是基于旧 4.5；按新速度算是 `5.7 / 6.5 ≈ 0.8769 m`。
  该换算自 2026-10-31 起**已不参与任何弹速推导**（业主改口直接点名米数），故只在这里记漂移，不去改那份历史推导。
