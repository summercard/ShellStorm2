# 99F 返航火球修复

日期 2026-11-20。功能归属 WORLD-ENTRY、VFX-POOL。基线提交 `62569a55`。工程版本 0.1.0。生命周期见[特效规范 §5.2](../14.6_特效系统与制作规范.md#52-生命周期阶段)。

## 根因与修改

截图中的橙色火球与胖子僵尸破门入场特效 `VFX-FAT-ENTRY-BREACH-3D` 的摄像机朝向粒子面片吻合。前几次修复清理的是上一场景正在播放的实例。返航读条在目标场景已创建后新建预热实例，队列归零只表示都已借出。破门实例的播放时长为 3.65 秒。Forward+/Vulkan 对照里，预热尺寸参数为 0.0008，开圈时粒子仍覆盖数百像素。

读取页在恢复目标处理与开圈之前结束这轮预热，提前退出也会清理。池内还在播放的预热件走原有退还信号，队列中的件取消。已复用为正式特效的实例由原调用方继续使用。99F 的主动退出入口进入已有的战局特效清理路径，和成功撤离、战败一样在目标坐标交接时清理。

## 验证

- `verify_vfx_pool_lifecycle`、`verify_fat_entry_breach_vfx --logic` 均退出 0，未见脚本错误。池测试覆盖重复结束预热、取消队列、隐藏并回池及同实例正式复借。破门表现专项 2291 项通过。
- Godot 4.6.3 Forward+/Vulkan 开圈对照使用正式读取页收尾和正式破门特效配合轻量场景。关闭清理作为故障注入，开圈时预热队列为 0，破门实例为 1，画面出现橙色火球。启用清理后仍完成 14 项特效预热，开圈全程破门实例为 0，池内可复用实例为 1，火球消失。两组退出 0，未见脚本错误。截图与日志放在工程外 `probes/2026-11-20_return_vfx/`。
- 正式 99F 场景探针在资源加载阶段达到 240 秒时限，退出 3，退出期间有依赖预载错误，未取得正式落地画面。现有 `probe_expedition_loading_runtime` 增加真渲染返航开圈断言，完整远征往返、战败及主动退出仍未完成端到端验收。
- 关卡解耦与运行资产命名检查各退出 0。文档门禁基线与本次均退出 1，报相同的既有断链和 BOSS-STAGES 验证登记错误。
