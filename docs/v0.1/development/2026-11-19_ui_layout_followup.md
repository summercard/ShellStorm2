## 当前实现

| 部位 | 实现与边界 |
| --- | --- |
| K 武器构建 | 首条连线由真实竖分隔线接首巢左中，滚出止于卡巢视口边界。箭头的点击区域不随页移动；完整武器构建内容（枪械、规格、卡轨）出屏后更换只读快照，再从对侧进入，标题/关闭常驻。快速反向、缩放、关闭用布局原点重算，不拿动画中途坐标当归位位置。 |
| 命运购卡 | 上排候选与操作不随枪械翻页；下方共用构建页整块滑动。预览不改变实际持枪与购买目标。有效确认进入购买流程前取消翻页并回到事务目标视图，随后仍用现有飞卡。 |
| 四角 HUD | `Dungeon3D` 保存基准锚偏移，用独立动画进度合成位置；受击偏移叠加、清除时不覆盖模态偏移。仅在模态消失后回到原锚点；购卡期间单独保留本局金币。减少动效设置直接落到最终位置。节点与 Presenter 契约保留。 |
| 装备窗 | 外框贴合，无中央条；基准左/右约 65/35，右侧受 8 列棋盘最小宽度约束。左窗等宽三列「主枪／角色／副枪」，枪格嵌无常驻文字的弹药图标，下排为缩略卡轨与 3×2 配件。角色下方左背包、右特殊道具、下一行快捷道具，左窗底部为月亮命运。配件、快捷、背包装备、特殊道具按钮及图标容器统一 50×50 UI 单位；HP 不显示。 |
| 卡轨与拖放 | 复用 K 页卡巢组件、交错连接、半透明暗背与正逆牌面，按实例真实永久槽数可横向滚动，说明不超过 5 字。月亮牌用真实图，太阳命运仍可查询。右侧背包/保险规则不变；原中间丢弃区移到左窗底部独立空白热区，无效装备拖放不会变为丢弃。 |
