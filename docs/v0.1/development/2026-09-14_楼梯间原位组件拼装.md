# 楼梯间原位组件拼装与参数编辑

功能：WORLD-PLAN / ASSET-PIPELINE；工程版本0.1.0；主设计：`05.1_关卡区块设计.md` §3.1.1。来源：用户要求恢复原坐标及原结构、通过固定墙板拼装，楼梯使用高度/坡度调节。

v014错误地以原点重搭一套楼梯间，已由v015替代。新源恢复v013的A/B根变换、楼板边界/标高、门口缺口和四跑楼梯网格。每个楼梯间32块楼板、31块围护、2跑直梯，总计130组件。完整5×5m下层地砖每间18块；其余平台及墙体使用标准模数与固定收边件，保持原边界。公共墙母件仍12.9m，本次旧围护裁切高度11.9m。

工具禁止墙板、楼梯及包含它们的分组缩放；墙板尺寸只读。直梯增加总高度输入，与坡度/水平长度联动重建。修复复制楼梯丢失参数和父组、网页/Blender楼梯方向不一致、远距离场景被相机裁剪，以及窄面板隐藏属性入口。Blend内嵌JSON支持重新打开恢复参数化组件，普通导入场景保持原兼容路径。

当前源配套130份组件清单、catalog和目录树，位于v015/data/component_packages；末级包非空且对象唯一归属。工具实际保存的Blend重新读取后，130组件的变换与楼梯参数完全保留（本次最大变换差0），证据为v015/data/roundtrip_verification.json。后台BlenderMCP附加组件的不可启动提示属于预期背景模式提示，无非预期脚本错误。

验收：原位20项墙板包络检查与4跑逐顶点检查通过，最大误差0.0000714m，所有对象Scale=1；单母组件共享23个子网格。6项工具测试、生产构建通过（原有体积提示仍存在），退出码均为0。Blender材质检查首次发现默认启动材质残留，清除后重验通过，217个网格、1302个面均通过UV检查，仅1个标准哑光材质。开发期间一次包络检查暴露踏步偏移及A护栏差异，已修正并复验。真实渲染前后全景/俯视/近景已输出。浏览器实际修改总高度6→7m，坡度自动21.801→25.017°，缩放锁定；验收后恢复6m并成功保存Blend。未执行Godot重新导入及运行时通行测试。
