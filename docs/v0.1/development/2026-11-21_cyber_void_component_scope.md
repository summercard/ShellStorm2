# 赛博虚空场景组件覆盖

日期 2026-11-21。工程 0.1.0，归属 `VFX-POOL`，设计 r5，资产 v005。基线为 `73bcaa3f` 上的赛博虚空 v004 工作树。[现行设计](../design/scene_void_erosion.md)

独立预览曾把覆盖目标限定在 `Stage`，图中与破口相交的栏杆位于同级 `Foreground`。现在预制体在 `Target Roots` 为空时以父节点为目标根，递归绑定同一组件树下的网格，继续按现有的盒形遮罩逐片元显示蚀边和内部虚空。预览栏杆穿过边界，便于观察同一构件的两种状态。

显式目标和排除设置继续由宿主维护。接缝标记通过独立补面分支参与，互斥和释放保持原约定。组件覆盖只是视觉处理，墙地和栏杆碰撞仍由宿主管理。

Godot 4.7.2 Forward+/Vulkan 与 Compatibility/OpenGL 均退出 0。默认宿主树绑定 148 个网格，显式限定 `Stage` 绑定 141 个。同机位默认与显式目标的差异集中在跨界栏杆，两个渲染器的取样差异分别为 1.14% 和 1.08%。关停、移除后画面差异为 0，上一轮洞内墙板的 1512 点对照仍为 0。更新原资产至 v005。[赛博空间同场景混用](2026-11-21_cyber_space.md)
