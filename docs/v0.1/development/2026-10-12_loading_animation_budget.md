# 过图读取动画与布局修复

日期：2026-10-12。工程版本：0.1.0。FeatureID：WORLD-ENTRY / UI。来源：用户两张实际读取页截图，要求动画读取期间不卡住、读取地图文字移到角色左侧、剪影缩小 50%。
依据：[入口设计](../design/远征全息城市交互设计.md)、[装配与读取契约](../05_技术施工_关卡生成与爬楼.md)。本轮保留同期组件资产与生成脚本修改，未提交 Git。

## 实际改变

读取页舞台由 360×400 改为 180×200；正交相机与角色母版保持，画面内角色高宽均为原来的 50%。状态文字和重试按钮移动到舞台左侧。真实渲染证据在工程外 session 的 visual 子目录。

目标 PackedScene 原已使用 load_threaded_request，但房间路径字符串触发同步资源读取，装配、首次渲染仍可阻塞动画。LoadingResourceWarmup 由原生后台加载接口逐资源预读模型/贴图，请求/轮询分帧（返基地仅预读纹理，避免把整套基地逐模型等待）；依赖扫描每 3ms 交还线程。房间先预读资源并持有强引用，再在主线程逐间装配，楼层与天台重放也使用分帧入口。普通入口/test_mode 不切换为异步流程。

Tower 的 loading_bootstrap_pending 是初始化所有者：提前到达的 deferred 持久化激活延后到完整装配结束。目标主视口 3D 和物品预览视口在读取期间暂停，兔子独立视口保持；内容淡出、黑罩覆盖后再恢复目标显示并预热真实渲染，完成门禁后释放处理/输入与开圈。记录原可见性、视口模式与处理模式，退出读取页也归还主视口渲染标记。失败沿用读取重试或返航接口，不改数值、资产几何、角色剪辑、结算、存档 schema 或入口来源。

本轮复用现有读取页与角色，不增加视觉资产或改 GLB/贴图/账本哈希。新增脚本路径稳定无版本号。

## 运行证据与限度

原窗口探针进入远征出现约 2.285s 连续帧间隔，返航约 1.096s；旧探针混入截图 readback 并直接跳过结算，因此原值仅作为故障复现，不能和最终统计作严格同条件性能对比。最终探针分开截图与帧统计，返航走真实 _finish_run(true) 成功事务；同时检查锁内输入/处理、装配前禁止持久化、房间逐帧推进、就绪后位置稳定、最终地板碰撞与开圈。

final10 不截图真实 Forward+ 窗口：读取页进入 4.449s、开圈 0.549s；返航读取 6.685s、开圈 0.558s。内容完全可见期间进入远征 95% 帧间隔不超过 31ms，最大 115ms，未再测到秒级整段停顿。返基地 95% 不超过 28ms，但首次初始化仍有一次 1327ms 帧间隔；**返基地完全无卡顿尚未完成**，不能因流程退出 0 报告全程 60fps。分批预热以更长的冷读取时间换取前台更新机会，本轮未宣称读取速度变快。
