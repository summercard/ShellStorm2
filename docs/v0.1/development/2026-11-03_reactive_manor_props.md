# 公馆书架与盆栽的受击状态

日期：2026-11-03；功能ID：WORLD-INTERACTIVE-CLUTTER / ASSET-PIPELINE；工程版本：0.1.0。
设计依据：[可交互物件设计 r8](../design/场景可交互低模物件设计.md)；代码基线：本次工作区，未提交。

## 交付行为

四件原有稳定Prefab接入`ReactiveProp3D`，正式房间和工坊共用；原美术源、GLB、尺寸、摆位及v017美术版本保留。默认书架耐久300、大盆栽90、小盆栽/红花各60，倒塌伤害50；均为工程可调初值，来源不是用户指定数值。

书架阻尼弹性受击，每两次命中掉两本书（最多八本）；耐久耗尽或1.25秒窗口连续十次有效命中倒塌。绕底边向入射方向的前后轴一侧倒下，0.85秒落地。包络以真实网格、旋转与非均匀缩放计算，落地定向矩形范围仅结算一次伤害；存活者优先挤向最近可通行边，碰到墙则尝试其他边，致死走原角色死亡链路。倒后保留落地残骸阻挡，不保留竖直旧阻挡。

三种盆栽受伤抖动，耐久耗尽碎裂，留下陶片、泥土与倒伏叶片；走路接触不扣血、不破坏。四件不接小易碎件的金币掉落。运行时退役各正式布局内的旧`LayoutCollision`，避免流送重新启用shape后出现幽灵阻挡。

实例只拥有状态转换；房间拥有相对路径键的`reactive_props`账本；Dungeon3D捕获/恢复可选字段。受损耐久、累计命中、掉书和最终破坏态保存；恢复不发破坏事件、不重伤害。倒塌中的快照恢复为落定态。旧档缺字段兼容，layout_id不变。四条资产行的状态、说明与新包装SHA已同步，3D分页及房间登记原值逐格不变。
