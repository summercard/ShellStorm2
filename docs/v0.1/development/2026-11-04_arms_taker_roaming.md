# 收租人连续遭遇、夺取档案与独立清房

FeatureID：ELITE-ROSTER / ENEMY-AI / SAVE-PROFILE / WORLD-PLAN / ASSET-PIPELINE。工程版本 0.1.0；日期 2026-11-04；设计为[收租人契约 r5](../design/精英02收租人状态与动作契约.md)。基于 `3004502d0c06471b609dfc35a0d4aeda499fc9e2` 及本会话既有未提交改动。先更新正式设计与怪物技术施工规则，再实施。保留用户的新版模型、接地、步态和 1.6 倍体型成果。

## 实现与正式入口

- 初始生命在此前同配置结果上乘 20。每次现身累计实际生命伤害达到最大生命的 10% 时撤离，阈值向上取整；致死伤害优先死亡。实例快照保存累计伤害、撤离标志与进度。
- 无限公馆通过 `monster_rules.roaming_elite` 启用连续遭遇；通用容器不含关卡 ID 分支。首次在前五间首次访问的可战斗内容房随机出现；后续选择尚未访问的候选房；目标 3–5 次。`RoamingEliteRunDirector` 拥有确定性计划、出现次数、固定最大生命、剩余生命与本次累计伤害。流送或再现身实体从同一账恢复。
- 中间撤离保留同一名册预约，不重复计算跨局遭遇和成长；最终撤离才结算一次成长。致死终止再现身。死亡保存失败保留 `pending_outcome`，重试不重复发布击杀和奖励事件。
- 收租人击杀玩家的既有离场出口也提交连续遭遇终局，将账设为 finished 后再移除实体，避免续档出现没有实体的 active 记录。
- 实际近战伤害后掷 50% 夺取；成功后在可用的物品、货币分支中等概率选取。物品扣背包或快捷栏一件并保留完整数据；货币扣当前余额的 10%，向下取整且正余额最少扣一枚。`EliteRosterService` 记录 `stolen_items/stolen_currency/rent_receipts/roaming_encounter`；玩家扣除、档案收据和战局快照通过 `BaseManager` 一次落盘，失败整体回滚。
- 所有唯一精英排除在房间存活数、波次推进、清房和开门条件之外。覆盖直接刷怪、召唤预约、延迟刷怪、Encounter Event 的计数、流送恢复与离场。普通敌群清完即可结算、开门，精英继续在场。自身击杀、赏金和条件撤离仍走原有出口。旧队列中的精英单独波也会在出场后继续推进。
- 双脚盒局部尺寸由 `0.051×0.125/0.126×0.043` 调整为 `0.058×0.142/0.143×0.049`，约增加 14%；盒底继续逐帧贴各自靴底。移动圆柱和最低靴底入地 1 毫米的契约保留。

正式操作路径为远征入口选择无限公馆，进入候选房、交战、撤离与再次现身。数据正本补入 `art_source/design/whitebox/tower_zones/expedition_03/v001/data/level_plan.json`，投影至 `data/level_plans/expedition_03/level_plan.json`，并登记投影清单。此前工作区没有该关卡的此份制作源，本轮从既有运行计划建立正本，只新增连续遭遇能力段；未重生成房间或改几何。原塔楼 94–92F 与远征99定点投放保留。
