## 药店楼的颗粒度细化（本轮追加）

对象：`pharmacy_shop_block_10x8_01`（参考图左下角那栋「藥」）。原版 12 个盒子，远看是「一个带窗洞的方块」；本轮做到 3 859 面。

**根因不是「细节不够」，是「立面被自己的墙挡住」**。原做法把墙做成 10×8×7.5 的**实心大盒子**，窗、卷帘、门、玻璃、发光面全画在盒子内部 —— 除了窗框，立面其余构件在渲染里根本不可见。所以第一件事是把外壳改成**带洞拆分**：

- 外壳 = 0.40m 厚表皮（`_wall_holes` / `_wall_holes_y` 按洞的 z 边切横带、再按 y 跨度切竖段）+ 内退暗核；
- 每个洞自带 0.40 进深侧壁，斜俯视有阴影、正面看有厚度；
- 橱窗再往西掏 0.95m 做真实进深，货架退进洞里。

其余按「12–30m 外仍能分辨」的尺度重排：一级基座石砌（0.94 错缝）→ 四道壁柱（柱身三道凹槽 + 柱头柱础托块）→ 四开间一层（橱窗 1:1.2:1.6:0.85 不同宽窄，避免一排等宽盒子）→ 卷帘（22 道帘片 + 卷轴箱 + 导轨 + 门楣射灯）→ 腰线（三道线脚 + 檐下阴影）→ 藥字灯箱 → 二层双樘窗（双扇 + 上亮子 + 窗台滴水 + 窗下降雨痕）→ 三级叠涩檐口 + 托块 → 女儿墙（分仓缝 + 避雷带）→ 屋面（水箱 + 爬梯 + 2 台排风机 + 楼梯间 + 天线 + 悬垂电缆）→ 街面（台阶 / 防滑条 / 地垫 / 排水格栅 / 雨水口）→ 实墙段（配电箱 + 表箱 + 明装线管 + 护角）。

**配色口**（按业主要求：暗部走邻近色 / 同暗度，亮暗之间可以跳，不用跳色堆砌）：暗部色相全部压在色盘 #051128→#425972 这一列（蓝紫 235–245°），只动亮度；立面跨度按 9 → 86 排（洞内 9 / 墙 17–26 / 线脚 43–56 / 压顶受光 70–86）。**上一版把 5 个暗色全挤在 lum 17–30，等于同一个色，任何线脚都不出形**。跳色只留给自发光（橱窗冷白、门头暖光、招牌字）。

**藥 字是几何笔画**，三条硬约束都踩过坑：
1. **必须方形**。先用 w=1.12 / h=2.02（竖向拉长 1.8 倍），横画全变成独立长条，远看是「梯子」；
2. **笔画表结构要对**。艹 的竖画必须穿过横画（否则读成「工」），幺 必须是「上横 + 斜笔 + 下横」的 Z 形折（只有两横一竖会读成字母「I」）；
3. **留白要够**。字缩到 1.52 见方（面板 2.40），否则笔画缝（0.05m）被 2.4 强度的自发光溢出糊平；笔画色降到 `E_ICE #5D6E82` 而不是纯冷白，暗底 + 中亮笔画才有硬边。

斜笔不能用 `beam`：`beam` 的截面方向按「轴线 × up」算，轴线落在 y–z 平面时得到的截面带 x 分量，与灯箱面板法线同向，斜笔会被面板压扁到看不见（实测 幺 的折笔与 木 的撇捺全部消失）。改用 `_slant` 直接拉平行四边形棱柱。

另外修掉两处「构件互挡」：横向电缆桥架原来整条横穿招牌下三分之一（把 木 字底挡了），改成在招牌 y 跨度处断开；雨棚出挑从 0.86 收到 0.58（0.86 时 20m 外 18° 斜俯视会把整排橱窗盖死）。

洗墙光也是坑：Area 灯的欧拉角按 `Rz·Rx` 分解，`(58°, 0, −90°)` 实际指向 **+X**，照的是街心湿地而不是立面 —— 结果立面没亮、水洼被打成一块白板。改成朝 −X 并降到 42W / 16W 掠射，只擦亮凸出线脚。

## 蒸汽为什么是几何而不是半透明

四共享材质角色体系（`01_精工金属 / 02_细腻哑光 / 03_清漆反光 / 04_柔和自发光`）配公共色盘 + `Closest` 采样，**没有可依赖的 alpha 通道**；v001 的 `05_环境柔雾_青白蒸汽`（alpha 0.035）在本版未启用，因为它会引入第五个材质角色，触发验证器的 `body_has_at_most_three_materials` 边界并让色盘单格安全岛的判据复杂化。本版改用**纯几何碎团**，代价是远景读成"白团"而不是"雾"，收益是材质体系与 UV 判据保持干净。

实测踩过两个形态坑（写进脚本注释了）：
1. 一摞等宽薄盘 → 斜俯视读成「石柱 / 一摞盘子」；
2. 单段圆台（下宽上尖）→ 近景读成「白色尖锥水晶」。
只有「下窄-中宽-上窄」三段圆台在任意角度都像一个团。
