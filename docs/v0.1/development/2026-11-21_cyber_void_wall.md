# 赛博虚空墙面连贯性修复

日期 2026-11-21。工程 0.1.0，归属 `VFX-POOL`，设计 r4，资产 v004。基线为 `73bcaa3f` 上的赛博虚空 v003 工作树。[现行设计](../design/scene_void_erosion.md)

近景复现中，左墙接近侵蚀盒侧面。旧素材把蚀边宽度同时用于已侵蚀面，墙上的网格因此延伸到整个洞内。墙板凹槽和拼缝的小侧面也触发了断面射线，使原有板缝和墙地边线一同亮起。

修复后墙地各片元以相机射线上的统一基准采样深空。贴面网格留在幸存区域，开口内只保留交界描边。断面射线限制在开口附近，预览盒覆盖左墙的完整厚度。隐藏的补面标记用于跨过真实拼缝，复制面仅在被侵蚀区域绘制深空，保持原场景深度、墙板模型和碰撞。

## 验收

- Godot 4.7.2 Forward+/Vulkan 与 Compatibility/OpenGL 均退出 0，各绑定 141 个原有网格。使用与用户截图相同的停驻机位，在保持虚空开启时隐藏对应墙板，两个渲染器的洞内 1512 个采样点均无可见差异。关闭进度与卸载后的画面差异均为 0。无本项 Shader 或脚本错误。
- 同一近景关闭断面厚度后，Forward+ 与 Compatibility 分别有 1.42% 和 0.96% 的取样点变化，说明真实破口仍有侧壁。断面测试使用能清楚看到侧壁的近景，并沿用原 0.3% 门槛，洞内墙缝单独用墙板显隐对照检查。
- 实机录像位于工程外 `outputs/scene_void_erosion/20261121_141241_686496_camera.mp4`。特效账本原条目 FX03-04 升至 v004，同步主表第 86 行、3D 分页第 276 行和域日志 v0.1.58。功能追溯与运行资产命名退出 0，文档总检查仍报告 20 条既有断链。正式关卡挂接、全仓套件及移动端性能未执行。
