# 2026-10-17 僵尸出弹、双眼红光与底色修复

- FeatureID：ENEMY-AI / ASSET；工程版本 0.1.0。
- 来源：用户要求核验强化保安子弹与高度、所有僵尸清晰双眼红光、胖子先保持正常原色再由机制发光。
- 主设计：[怪物设计](../design/怪物设计.md)。本次更新红眼适用范围与视觉标定；伤害、血量、弹速倍率和射程倍率保持原契约。

## 原因与修复

1. `Enemy3D._perform_attack` 直接按完整 enemy_kind 分支，强化保安掉入默认近战。改用既有 `_table_kind()` 归一到原怪攻击分支，也修正强化同族的攻击派生。出弹仍使用世界空间脚底上方 0.92m，三发水平散射，不受 1.5 倍体型影响。
2. 旧红眼仅覆盖强化怪，体积很小且没有独立柔光晕。整头最前顶点还会把眼点推到脸前 0.2–0.3m，正面图看似对齐，俯视时落到下巴。现在普通/强化三类僵尸均有两只红眼，取双眼附近脸部窄带深度，半径 0.04/0.05m；保留跟头骨运动，增加共享 shader 的双独立柔光晕，降低溢光灯能量到 0.05，关闭 bloom 仍可读。遵守深度遮挡，不穿墙显示。
3. 胖子底色文件原图正常，导入设置 `compress/normal_map=1` 强制按法线压缩，实际导入纹理失去蓝色通道，显示黄绿。改为 2（禁用法线处理）并重新导入。原图、模型及既有受击/机制事件未重做，身体待机无常驻自发光。
