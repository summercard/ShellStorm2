# 硬边写实向三维场景 · 提示词标准模版 v1.1

> 来源：v1.0（2026-10-19 像素风版，TOWER DISTRICT 任务书提炼）。
> 本版按主人 2026-10-20 的要求改造：**去掉像素化风格**，保留九段骨架与「分区表四要素」「颗粒四档」「开机 / 交稿双清单」。
> 适用：Blender + EEVEE、低亮多巴胺色盘 + 四材质角色、交给 Codex / CLI 编码代理执行。
> 与 v1.0 的差异只集中在三处：造型语言（第 4 节）、文字做法（第 4 节）、颗粒口径（第 4 节）；其余骨架不动。

---

## 0. 怎么用（三步）

1. **填 A–C**：目标、排除项、构图尺度。这三段决定「做成什么样」，不能省。
2. **填 D 分区表**：一个区域一行，参考范围用米（首选）或像素，必做元素不少于 6 项。区域数量按场景定：街区 10–16 区、室内 6–9 区。
3. **E–K 基本不改**：几何、材质、灯光、组织、检查、交付是全项目通用的工程约束，只在颗粒档或时长上按场景微调。

> 原则：**能被验收的才写进去**。"有细节""要有氛围"不算要求；"桥沿保留一条连续暖色亮边""主牌字用逐笔几何笔画"才算。

## 1. 模版正文（直接复制，替换 `{{}}`）

```text
执行任务：根据提供的 {{场景名}} 参考图，在 Blender 中制作可编辑的三维场景。

一、参考依据与制作目标

以参考图为主要视觉依据，还原画面中的构图、空间层次、建筑比例、设施分布、遮挡关系、标识文字、照明与雾气。
保留完整 {{场景类型：街区/室内/通道}} 环境，排除 {{排除项：全部人物、人形剪影、人群替代物}}。

制作硬边造型语言的三维场景：以长方体为基本体，轮廓靠直角与台阶转折表达；
管道、储罐、轮胎、拱券等圆柱类构件允许使用低段数圆柱 / 圆台（≥8 段）与拱形棱柱表达，
但**不使用平滑细分、曲面建模、样条曲线、连续倒角**。造型可以低模，但**细节密度必须接近参考图**，
不能简化为空旷的低密度场景。

图像原尺寸为 {{W}}×{{H}}；有效场景画幅约为 x={{x0}}–{{x1}}、y={{y0}}–{{y1}}，即 {{Wv}}×{{Hv}}。
{{黑边/边框说明：上下黑边不属于实体场景。}}

先完成逐区域分析与制作清单，再正式建模。参考中无法直接判断的背面、厚度与画外连接结构，
允许按可见结构合理补足，并标记为「制作推定」。

二、构图、尺度与空间坐标

采用 {{机位描述：斜俯视 / 低机位 / 一点透视}}，{{可见范围：能同时看到主招牌正面与街面纵深}}。
画面{{垂直分区：上部由 XX 主导 / 中部为 XX / 下部为 XX}}。

初始空间尺度：
- 可见 {{宽度/进深}} 约 {{N}} 米。
- {{关键结构}} 约位于 y={{N}} 米。
- 地面以 z=0 为基准。
- 远景延伸至 y={{N}} 米附近。
- 近景延伸至 y=-{{N}} 米附近。
- 画面内主视觉对象的投影高度不低于画幅的 {{N}}%（占比不足就等于没做细节）。
- 根据参考构图微调模型比例和镜头，不能只依赖这些推定尺度。

固定参考摄像机，以同一画幅持续比较建模和灯光结果。
机位必须先用投影反算验证：把每个主视觉对象投到 NDC，确认 u/v 落在 [0,1] 内再出图，不靠目测调。

三、分区域建模

{{按 D 表逐区展开，每区一段，格式见下}}

NN {{区域名}}
参考范围：x={{a}}–{{b}}，y={{c}}–{{d}}。
制作 {{元素 1}}、{{元素 2}}、{{元素 3}}、{{元素 4}}、{{元素 5}}、{{元素 6}}。
补充 {{次级细节 1}}、{{次级细节 2}}、{{次级细节 3}}。
{{该区专有的表现约束：如"入口保持深暗，但通过重复框架与墙灯表现纵深，不能用单块黑面替代"}}
{{该区专有的禁止项}}

四、几何颗粒与建模方法

使用直接网格构建方式批量生成长方体与低段数柱体。根据对象语义组织模型，保留可编辑性。
**开洞必须真开**：墙体的窗、门、通道口要用「带洞拆分」建成真实洞口（表皮分段 + 内退暗核），
不允许在实心体内部放玻璃与发光面 —— 那会被墙自身挡死，等于没做。

颗粒尺度分级（按投影尺寸取档，不按绝对美观取档）：
- 大型建筑结构：约 {{0.8–2.0}} 米。
- 主体与设备轮廓台阶：约 {{0.15–0.35}} 米。
- 墙砖、板缝、线脚与中型表面细节：约 {{0.06–0.15}} 米。
- 螺栓、灯管、细线与雨丝：约 {{0.015–0.05}} 米。

大型结构用大块建立轮廓，小颗粒只用于可见细节；**同一区域内必须同时存在两级以上颗粒**，
否则会读成"均匀铺满"，失去疏密。
圆柱意象（管道、储罐、轮胎、拱券）用低段数柱体与拱形棱柱表达，段数不低于 8，保留可见棱面。

标识文字用**几何笔画**：按字形结构逐笔排矩形（横、竖、斜笔分别用盒体与平行四边形棱柱），
笔画宽度按「目标视距下不少于 4 像素」反算，字形必须方形且笔画之间留缝。
禁止贴图字体、禁止用一摞等宽横条冒充汉字（那样远看是梯子）。

实体模型保持硬边，不使用平滑细分、连续倒角与曲面对象。灯光和体积允许连续的光学衰减。

五、材质与色彩

以参考图的颜色为准：
{{主色 1}}、{{主色 2}}、{{主色 3}}、{{点睛色}}、{{小面积点缀色}}。

共享 {{N}} 种表面角色：
- {{金属}}。
- {{哑光表面}}。
- {{湿漆与反光表面}}。
- {{自发光表面}}。

颜色通过共享色盘和 PaletteUV 控制。色盘采样采用 Closest。
每个面的 UV 岛必须有面积，并位于单一色格内部。
通过材质角色区分金属度、粗糙度、清漆和发光强度。保持颜色和表面质感的职责清楚。

暗部用**邻近色 + 同暗度的亮度梯度**，色相不跳；亮暗之间可以拉开跨度（本项目实测可用 9→86）。
若暗部所有颜色挤在 15 个亮度单位以内，等于同一个色，线脚再多也不出形。
跳色只留给自发光，且发光面积占画面比例不超过 {{5}}%。

六、灯光与雾气

先建立明暗关系，再调整局部光源。

主要光色关系：
1. {{主导光源}}。
2. {{焦点光源}}。
3. {{边界光}}。
4. {{小面积次级光}}。
5. {{暗部与远端处理}}。
6. {{前景处理}}。
7. {{地面/反射处理}}。

使用局部灯光补充发光体对周围结构的照明。控制发光强度，保留发光体本身的形状和颜色。
洗墙光必须**朝向被照立面**（欧拉角朝 +X 还是 −X 要按 Rz·Rx 分解核对，写反了就是照亮街心而不是墙）。
洗墙光用低功率掠射，避免整面刷成一片浅色。
雾气应有空间分布和疏密变化。保留暗部，避免全画面均匀发亮。
避免 {{禁用项：大面积紫染、纯白过曝、雾气遮平所有结构}}。

七、场景组织与执行

创建独立的 {{场景名}} 场景。操作前保存原 Blender 会话副本。
生成脚本只管理属于本任务的对象和数据块。使用确定的随机种子，使细节散布可以复现。

按 {{集合划分}} 组织集合。
{{动画对象}} 通过独立控制根管理动画。相机、展示灯光和体积环境保持可单独调整。
构件之间的遮挡关系必须在脚本里显式让开（例：横向桥架遇到竖招牌要断开），
不允许靠"渲染时看着还行"。

八、渲染与检查

使用 EEVEE 渲染。最终参考画幅为 {{Wv}}×{{Hv}}。采用 AgX 色彩管理，根据参考控制曝光和对比度。

依次检查：
{{按重要性排序的 8 条检查项，见 4 节清单}}

渲染全景与局部近景后继续修正。发现穿插、缺件、比例错误、发黑、塑料感或过曝时，回到对应几何、材质或灯光修改。
```

## 2. 分区表（D 段怎么写）

| 编号 | 区域 | 参考范围（米 / 像素） | 必做元素（≥6） | 颗粒档 | 专有约束 |
|---|---|---|---|---|---|
| 01 | 远景天际 | x −26…26, z 12–30 | 楼群、窄条窗、水箱、设备、风道、广告支架 | 大 | 窗灯稀疏，不能比主体亮 |
| 02 | 主招牌阵列 | | 牌箱、分层边框、内凹背板、卡扣、检修缝、支座 | 小 | 字形用几何笔画，不能用贴图字体 |
| … | | | | | |

**每条区域必须写清四件事**（缺一条执行者就会自己发挥）：

1. **范围**：米制框（首选）或像素框，至少给一个。
2. **必做元素清单**：能数出来的东西，不少于 6 项。
3. **颗粒档**：大 / 中 / 小 / 极小，对应第四节的四档。
4. **专有约束**：这一区最容易做错的地方，加禁止项。例：
   - 通道："不能用单块黑面替代纵深"
   - 招牌："不能用贴图字体直接替代几何笔画"
   - 路面："不能整片呈均匀镜面"
   - 立面："窗必须是真洞口，不能在实心墙里贴玻璃"

> 分区数量经验值：街区 10–16 区，室内 6–9 区。少于 6 区通常交代不细，多于 16 区执行时会丢区。

## 4. 自检清单

### 开工前（写提示词时）

- [ ] 有效画幅的像素框写了吗？（黑边不算场景）
- [ ] 排除项写了吗？（人物、动物、人形剪影、LOGO 水印）
- [ ] 每个区域都有范围 + 元素 + 颗粒 + 禁止项？
- [ ] 有没有至少 5 条「能被数出来」的验收点？（窗格数量、设施层数、车辆数、帘片数）
- [ ] 主视觉对象的投影高度占比写了吗？（低于 25% 就得改机位，而不是加细节）
- [ ] 镜头固定要求写了吗？（同画幅持续对比 + NDC 反算验证）
- [ ] 开洞方式写了吗？（带洞拆分，不是实心体内贴面）
- [ ] 交付清单写全了吗（源文件 / 静帧 / 近景验收图 / 清单 / 脚本 / 检查记录）？

### 交稿前（看渲染图时）

按这个顺序看，前面不过不用看后面：

1. 大结构比例与主镜头构图。
2. 主视觉元素（招牌/主灯/主结构）的位置与间距。
3. 中部设备带的密度与层次。
4. 纵深结构（通道/走廊/街道）的重复框架。
5. 两侧次要区域是否缺件。
6. 前景遮挡物的尺寸、遮挡关系与边缘光。
7. 小面积点缀（红灯、绿灯）位置是否正确。
8. 湿路反射、雾气散射、暗部是否还留有结构。

**常见退稿原因**：穿插、缺件、比例错、发黑、塑料感、过曝、雾气遮平、细节均匀铺满没有疏密、**立面构件被自身墙体挡死**。
