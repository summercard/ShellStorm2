# 2026-10-19 合成表现：兔子闸门（关下 → 眼睛发红 → 3 秒后开启换物）

功能 ID：`RUN-SYNTHESIS`。设计主源：[07.3 §5 合成目录](../07.3_玩法系统_合成目录与兴趣曲线.md)。

## 业主口径

> 制作对应的合成表现效果，点击合成后 一个带有兔子logo的闸门关下，遮住中间的界面，这个闸门就在中间界面范围里，然后兔子眼睛发红，过了约3秒 闸门打开 里头的东西被替换成合成的东西

## 新增文件

`src/ui/SynthesisGateVeil.gd`（约 560 行，纯表现层）。挂在 `WorkbenchPanel` 的**炼炉那一栏**上，矩形由 `_layout_body()` 逐帧同步成 `_body_tray_column` 的 position/size。

| 状态 | 时长 | 做什么 |
|---|---|---|
| `closing` | 0.60s | 整块板从上方压下来，smoothstep 缓动，落底时抖 1~2px（`land` 衰减） |
| `hold` | 2.40s | 闸门保持闭合；0.12s 后眼睛从熄灭拉到全红（0.22s ramp），红晕脉动 |
| `opening` | 0.60s | ease-in 卷起（先慢后快），眼睛同步缩回 |
| `linger` | 1.40s | 台面完整展示产物，最后 35% 淡出 |

**「约 3 秒」的落点**：业主说的是"闭合后到开始上升"，即 `CLOSE + HOLD = 3.00s`。整段动画 5.00s。

## 结构：为什么闸门必须是**后加的子节点**

`_draw()` 的输出排在所有子节点**之前**。如果闸门画在 `SynthesisGateVeil` 自己的 `_draw` 里，它会被台面（子节点）盖住 —— 那样闸门等于关不上。所以闸门单独做成 `ShutterLayer`（同一层里后加的兄弟节点画在上层），只负责转发绘制。

同时 `clip_contents = true`：板子顶边在矩形上方（`offset = -h × (1 - progress)`），不裁就会盖到页头。

## 三个真实踩到的坑（都是截图看出来的，不是想出来的）

### 一、剧透：闸门还关着，页脚和背包已经把答案摆出来了

第一版在关闸**之前**就 `_refresh_all()` 并写了结果文案。截图里一眼看穿：闸门盖着炼炉，而页脚写着「熔炼完成：蓝｜豌豆手枪」，背包里那把枪也摆在那儿了。

那等于把揭晓提前剧透，3 秒等待变成一个空转的过场 —— **这正是"做了动画但没做表现"的典型形态**。

改法：
- `_execute_forge` 成功分支**不再刷新界面**，只把报告塞进 `_pending_forge_report`，文案改成「内容置换中 · 闸门开启后揭晓」；
- 刷新 / 写结果 / 发信号全部挪到 `_finish_forge()`，由 `_on_gate_finished` 触发；
- 背包另加一层 `BagSeal`（不透明深底 + 「INVENTORY SEALED / 仓门封闭中」），因为产物**确实已经进包了**（事务先行），不封住就挡不住。

### 二、竖缝 + 横节 = 看成一整块网格

闸门原本同时画"两道竖向拼板缝"和"每 22px 一道横节"。截图里这两套线一叠，读起来就是一张网格 —— 和底下那块 5×5 棋盘长得一样，看起来像闸门是半透明的。

删掉竖缝，改用一道宽的斜向高光 + 左右导轨（10px 亮边 + 内侧暗缝 + 每 26px 一颗螺栓）+ 一条横贯的加固带把圆牌"装"上去。导轨是关键：它让闸门看起来是"卡在框里上下走"的，而不是一块贴在中间的板。

### 三、升起来只有 0.6 秒能看清产物

`opening` 结束时立刻 `visible = false`，产物只在闸门上升的 0.6 秒里被瞥一眼，随即露出空盘面。业主的规格是"里头的东西被替换成合成的东西"—— 那个**替换结果**必须给够时间读。

加 `linger` 段 1.4s，台面（`SYNTHESIS COMPLETE` + 3D 模型图标 + 名字 + 品质/弹种）完整停留，最后 35% 淡出（硬切回空盘面会有一下"东西凭空消失"的突兀）。

台面背景同时改成**不透明**：0.95 时底下那块还带着材料的盘面会透上来，台面上同时有"新材料"和"旧材料残影"，看起来像没换干净。

## 兔子徽标的画法

纯 `_draw` 几何，不用贴图：
- 一块铆死（8 颗螺栓）的金属圆牌，牌面内侧一圈更暗的凹陷 —— 它是门上的一枚**封印**，不是贴纸；
- 兔子的耳朵先画、头盖上去（接缝自然），下巴一道暗弧给平面剪影一点体积，三对胡须；
- 眼睛最后画，红光压在毛色之上。全亮时四层同心圆做辉光（各层透明度按 1/layer 衰减），芯部提亮到近白 —— **红光没有芯会脏成"暗红点"**；
- 两只眼用不同相位脉动（`sin(clock × 7.4 + side × 1.7)`），避免"整块板在闪"；
- 眼睛亮起时牌面泛红、顶部铭牌条的状态灯一起转红。只有两个红点会像贴图动效。

## 交互边界

| 段 | 可点掉？ | 为什么 |
|---|---|---|
| `closing` | **不行** | 那一瞬间画面还没被盖住，跳过会露出揭底的半帧 |
| `hold` | 可以 | 不想等 3 秒时有个出口 |
| `opening` | 不行 | 已经在动了，没有必要 |
| `linger` | 可以 | 产物已经看清，这只是"还想再看一眼"的余地 |

`abort()` 用于切页 / 关闭面板：立刻收起，**不发 `finished`**（它表示"播完了"，不是"收掉了"）。但收掉时必须 `_flush_pending_forge_report()` 把还欠着的那次收尾补上 —— 否则界面会永远停在"盘上还摆着那批材料"的旧画面上，而材料其实早就销毁了。

`_busy` 在闸门期间保持 true：闸门盖着盘面时再点熔炼只会读到空盘面。

## 音效

复用既有事件，不新增资产：关闸 `door_close`（-3dB / 0.80）、落底 `melee_heavy_impact`（-5dB / 0.55）、眼睛点亮 `facility_activate`（-8dB / 0.86）、开闸 `door_open`（-4dB / 1.02）、揭晓 `item_pickup`（-7dB / 1.05）。眼睛的点亮音用 `_eye_cue_played` 只响一次 —— `_eyes` 到 1 之后每帧都满足条件，不设闸会连响几十次。

## 验收

新增 `verify_synthesis_gate`（`core`）。时间用**手动驱动 `_process(dt)`**，不真等 5 秒：动画的全部时间来源是 `_time`，所以 `set_process(false)` 之后逐帧调 `_process` 就能把整条时间轴压进几十毫秒，且完全确定性。

覆盖 6 组：

1. **几何**：闸门矩形与炼炉栏**逐像素重合**；与背包矩形**不相交**；被主体区 `encloses`；`z_index > 4`（棋盘物品是 4）。
2. **初始态**：不播、不可见。
3. **时间轴**：0.30s 正在下降且眼睛未红 → 0.65s 落底 `progress == 1` → 1.00s 眼睛 `== 1` → 3.25s 进入 `opening` → 升到底后进 `linger` 且台上仍有产物 → `LINGER_SECONDS >= 1.0` → 结束 `idle` / 收起 / 隐藏 / `finished` 恰好一次。
4. **交互**：关闸段点击不跳段；保持段点击立刻进 `opening`。
5. **abort**：立刻收起且**不发** `finished`。
6. **端到端**：真熔炼一次 → 闸门自己开始播 → `_busy` 为 true → 封条可见且层级不低于闸门 → 状态栏**不含**「熔炼完成」→ 台上就是背包里那把枪 → 播完放开 `_busy`、撤掉封条、状态栏写出结果。

`SYNTHESIS_GATE_OK`，exit 0。
