# 入口安全房（STAIR_LOBBY）运行时内容清单

> 记录时间：2026-09-17
> 覆盖范围：`DungeonRoom3D` 在运行时为 `room_type == "STAIR_LOBBY"` 的房间生成/实例化的**全部**内容，
> 含代码生成件与美术资产件。塔楼侧（`TowerFloorStage3D` / `TowerDescent3D`）为该房间额外做的也一并列出。
> 所有路径、尺寸、颜色均为代码实测，不是设计意图。

---

## 0. 生效条件

安全房不是无条件生效的。`DungeonRoom3D._can_build_safe_room_shell()` 四条全满足才走 v007 单一方位布局：

1. `dimensions.x == dimensions.y`（正方形）
2. `dimensions.x == TowerGeometry3D.COMBAT_STAIR_LOBBY_SIZE_M`（**15.0 m**）
3. `doors.size() == 2`（恰好两扇门）
4. `_safe_room_rotation_steps() >= 0` —— 实际门向集合必须是 {南, 东} 经 0/90/180/270° 旋转后的四种组合之一

任一条不满足 → 回退到普通塔楼拼装 `_build_tower_wall_v2()`，下面所有 v007 内容都不产生。

构建时机分两档（`set_stream_state`）：

| 状态 | 触发 | 产出 |
|---|---|---|
| `STREAM_SHELL_READY`(1) | `ensure_shell_built()` → `_build_shell()` + `_build_trigger()` | A 节 + B 节 + D 节 |
| `STREAM_ACTIVE`(2) | `ensure_detail_built()` → `_build_content()` | C 节（挂在 `RuntimeDetail` 下） |

## A. 壳体层 —— v007 正式美术（`_build_safe_room_shell()`）

全部挂在 **`SafeRoomArtRoot`**（Node3D）下，整房绕 Y 轴旋转 `rotation_steps × 90°`，所以资产只有一套、不分方位版本。

### A1. 墙与门墙 12 件

槽位表 `SAFE_ROOM_WALL_SLOTS`，每项 = `[局部x, 局部z, rotation.y_deg, 是否门墙, 原生方位]`：

| 节点名 | 局部位置 | rot y | 门墙? |
|---|---|---|---|
| `SafeRoomWall_North_Solid` ×3 | (-5,-7.5) (0,-7.5) (5,-7.5) | 180° | 否 |
| `SafeRoomWall_South_Solid` ×2 | (-5,7.5) (5,7.5) | 0° | 否 |
| `SafeRoomWall_South_Door` ×1 | (0,7.5) | 0° | **是** |
| `SafeRoomWall_East_Solid` ×2 | (7.5,5) (7.5,-5) | 90° | 否 |
| `SafeRoomWall_East_Door` ×1 | (7.5,0) | 90° | **是** |
| `SafeRoomWall_West_Solid` ×3 | (-7.5,5) (-7.5,0) (-7.5,-5) | -90° | 否 |

- 实墙 prefab：`assets/art/environments/tower_zones/battle/runtime/common_components/wall_standard_5m/wall_standard_5m_root_top3d.tscn`
- 门墙 prefab：`.../common_components/wall_door_5m/wall_door_5m_root_top3d.tscn`（含 2.2×2.5 门洞）
- 上游 GLB：`.../components/common_components/wall_standard_5m/wall_standard_5m_visual_top3d.glb` 等
- 台账：`ENV-BATTLE-L01-SAFE-ENTRY`（v007），`3D-场景通用` r86/r87
- **碰撞**：沿用组件自带 `collision_owner=self` 的 0.30m 结构碰撞，代码不再叠加代理
- **视高**：实测墙件 5.00 × **11.90** × 0.30 m（逻辑 12m）

### A2. 地砖 9 件（3×3 棋盘）

`_build_safe_room_floor_tiles()`，`(row+col)` 偶数用 c01、奇数用 c02；

- prefab：`.../floor_tile_5m/floor_tile_r01_c01_root_top3d_v004.tscn` / `..._c02_...`
- 节点：`SafeRoomFloorTile_R01_C01` … `R03_C03`
- 间距 `SAFE_ROOM_FLOOR_GRID_M = 5.0`
- Y 由组件自带 `snap_to_walk_plane_offset_m` 决定（c01 = −0.056、c02 = −0.081），**不是硬编码**
- **碰撞**：`_disable_static_collision_descendants()` 把自带 StaticBody 全部 `collision_layer=0` + shape `disabled`（承重归 `TowerFloorStage3D._build_support()`）

### A4. camera-only 门墙代理

南北向门墙各补一个 `CameraOnlyDoorWall_*`（纯 `StaticBody3D` + `BoxShape3D`，**无任何视觉几何**），供 `TowerDescent3D` 的镜头探针 `_camera_wall_expectation` 使用。东西向门**不产生**。

### A5. 门扇 2 件（`_build_door()`，挂在房间根、不在 ArtRoot 下）

- 节点 `Door_<方位>`，容器 prefab：`assets/art/props/dungeon_3d/prp_room_door_3d.tscn`（`RoomDoor3D`）
- 门扇美术：`.../common_components/door_5m/door_5m_root_top3d.tscn`（**仅 `room_type == "STAIR_LOBBY"` 走这个分支**）
- 门扇落在 **±7.5** 边界网格线（v007 门洞切向偏移 = 0）
- 门扇自带静态碰撞被 `_disable_static_collision_descendants()` 关掉，通行归 `RoomDoor3D` 自己的升降碰撞
- 门扇视觉尺寸实测 2.20 × 2.50 m

## B. 触发区（`_build_trigger()`）

- 节点 `RoomTrigger`（`Area3D`，`collision_layer=0` `collision_mask=1`）
- `BoxShape3D` 边长 = 房间尺寸 − `ROOM_OWNERSHIP_BOUNDARY_INSET_M × 2`，高度按 `ROOM_OWNERSHIP_MIN/MAX_LOCAL_Y_M`

### C3. 顶灯

- 节点 `RoomCeilingLight`，脚本 `WastelandLight3D`
- prefab `assets/art/props/dungeon_3d/prp_wasteland_light_root_top3d.tscn`
- 能量 `theme.fixture_energy × 1.85`，范围 `max(theme.fixture_range × 1.72, min(15,15) × 0.94)`
- 因为塔楼模块房 `tower_module_shell` 为真，灯位 Y 被抬到 `FLOOR_HEIGHT_M − 2.72`
- 加入组 `wasteland_light_3d`

### C4. 灯光开关

- 节点 `RoomLightSwitch3D`，prefab `prp_room_light_switch_root_top3d_v001.tscn`
- `starts_on = true`（`room_type in ["FACILITY", "STAIR_LOBBY", "BOSS"]`）
- 摆位 `_place_light_switch()`：按 `room_seed % 4` 选边，边距 `min(4.2, dim × 0.22)`

### C5. 导航面

- 节点 `RuntimeNavigationRegion3D`（`NavigationRegion3D`）
- 单四边形，内缩 1.45m，`y = 0.08`

### C6. 随机家具 / 服务终端 / 危险区：**全部不生成**

- `prop_count = 0`（`room_type == "STAIR_LOBBY"` 显式置零）
- `ServiceStation3D` 只在 `MERCHANT` / `UPGRADE` / `EVENT`
- `HazardField3D` 只在 `TRAP`
- 垂直通道标记只在 `STAIRS_DOWN` / `STAIRS_UP`

## D. 通用结构处理

- `_keep_structural_physics_active(self)` —— 保证墙/门框/楼板碰撞不被流送关掉
- `_set_collision_enabled(self, true, true)` on every stream state change

## E. 房间之外 —— 塔楼侧为安全房额外做的

| 位置 | 内容 |
|---|---|
| `TowerFloorStage3D._stair_lobby_visual_holes()` | 为每个 STAIR_LOBBY 注入 `Rect2(room.x−7.5, room.z−7.5, 15, 15)`，**从通用可视地砖里挖掉 9 格**（承重碰撞不变）；记账字段 `_additional_visual_hole_tile_count` |
| `TowerDescent3D._build_corridor()` | 房间之间生成水平走廊连接件 `Blocks/Battle/Corridor_NN`，内含 `ImportedCorridorFloorGrid5M`（MultiMesh）+ `ImportedCorridorWallGrid5M` |
| `TowerDescent3D._build_stair_approach_corridor()` | 楼梯口接驳走廊地板 `StairApproachFloor_Upper/Lower_I00…`（逐块 instantiate 地砖） |
| `TowerDescent3D._build_corridor()` 中的 `_add_imported_stairwell_visual()` | 楼梯间 `ImportedStairwellGeneric12M` / `ImportedStairwellRooftop12M`（tower_descent 美术，v002） |
