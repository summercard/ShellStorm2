**日期**：2026-10-17
**范围**：`scenes/StartupLoadingScreen.gd`

## 业主原话（三轮迭代）

**第一轮**：
> 打开游戏这个界面，帮我设计成这种的，名字是大号的字体，放大，斜着富有张力。然后下面是进度条。其它信息不要。

**第二轮（纠偏）**：
> 我的红线不是要装饰的东西 而是告诉你logo名称要斜着摆放

⇒ 红线是**标注**，不是画面元素。第一版把红线画进屏幕是理解错误，已全部删除。

**第三轮（本轮）**：
> 装修一下 和主面板hud的风格一致，然后进度条也要歪的， 要加上粉色和蓝色的赛博干扰的边缘效果

⇒ 三点要求：① 对齐主面板棱镜风格；② 进度条跟名字一起斜；③ 粉/青赛博边缘干扰。

## 最终形态

纯黑底（`#06080B`）→ 边缘故障带 → 名字 + 斜进度条。屏幕上没有第三样东西。

| 层 | 内容 | 关键参数 |
| --- | --- | --- |
| 底 | 近黑冷调实底 | `BACKDROP_COLOR = (0.024, 0.032, 0.043)` |
| 故障带 | 四边粉/青晕带 + 随机撕裂碎片 + 下行扫描带 | 带宽 54px，alpha 0.17 二次衰减；碎片 10–18 条 / 0.46s |
| 主体 | 名字三遍叠绘（粉左上 / 白中 / 青右下） | 140px，`-13°`，偏移 4.2px，色层 alpha 0.88 |
| 底座 | 同坐标系斜进度条 | 字块宽 72%，7px，左端对齐字块左缘 |

## 实现要点（改这张屏前必读）

1. **旋转只能走 `draw_set_transform`，不能是节点 `rotation`，也不能是字形斜切。**
   ```gdscript
   art.draw_set_transform(center, deg_to_rad(-13.0), Vector2.ONE)
   ... 画名字、画进度条 ...
   art.draw_set_transform(Vector2.ZERO, 0.0, Vector2.ONE)   # 必须复位
   ```
   - 节点 `rotation` 会把子控件排版盒一起带走，条与字的对齐立刻散掉；
   - 绕**字块中心**旋转天然居中，不需补偿位移；
   - 中文竖笔多，字形再斜切一次会让竖笔倾斜翻倍、字面散架（`TITLE_SKEW = 0`）。

2. **进度条必须在同一个旋转坐标系里画**，不是自己算个角度。
   条在局部坐标里是水平矩形，被坐标系带歪 —— 这样它和名字的角度**恒等**，
   将来改 `TITLE_ROTATION_DEG` 一处，两者一起变，不可能对不上。

3. **只允许统一缩放，不做分轴缩放。**
   ```gdscript
   return minf(box.x / DESIGN_SIZE.x, box.y / DESIGN_SIZE.y)
   ```
   旋转过的图形按 x/y 分别缩放会把角度拉歪（宽屏上 -13° 就不是 -13° 了）。这是保角度的唯一办法。

4. **进度条宽度取字块宽度 72%，左端对齐字块左缘。**
   早先用"屏宽 44% + 居中"时，条会甩出字块右端、跟名字看着不是一体。
   条是名字的**底座**，锚在字块上才成立。

5. **进度条的色散偏移必须减半**（`0.55 × CHROMA_OFFSET`）。
   7px 细条上用满偏移会缝成三条平行线，进度反而读不出来。
   同理空槽底要抬到 10%、描边抬到 34% —— 太淡就读不出"还剩多少"。

6. **`Root/Progress` 节点保留但 `visible = false`。**
   视觉改成自绘斜条后，ProgressBar 只剩数值载体作用；
   保留节点路径是为了不打断任何按 `Root/Progress` 读进度的探针。
   代价：数值变化后必须手动 `queue_redraw()`，这条已写进 `_update_ui()`。

7. **故障碎片用固定 seed 的 RNG**（`0x5E115702`），每次运行图案一致、可复现，
   不会出现"这次特别花"的观感漂移。
