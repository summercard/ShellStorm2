# 玩法系统｜枪械工坊 v0.1

功能ID：`BASE-WORKSHOP`。状态：**[核心事务已完成，表现继续开发]**。适用游戏工程：`0.1.0`。更新日期：2026-09-23。

枪械工坊是基地长期成长玩法，用魂解锁枪身、弹药和配件蓝图，并管理已解锁的手电模块。蓝图升级已收口为一次原子事务；UI只提交命令并渲染结果，不再分步扣款与写Tier。

## 1. 当前功能

- `weapon_workshop`设施通过统一`BaseFacility3D`交互进入`WorkshopMenu`。
- 枪身、弹药、配件各有Tier 0–3；UI显示当前Tier、星级进度、下一级成本和资源不足状态。
- 当前升级成本：枪身80/200/500，弹药60/150/400，配件50/120/350。
- 蓝图Tier写入`BaseData.blueprint_gunbody_tier / blueprint_bullet_tier / blueprint_attachment_tier`，局内掉落与训练场读取许可后过滤内容。
- 手电模块面板显示基础、加强、节能三档耗电和揭示倍率；只允许切换已解锁模块，并同步当前基地玩家。

## 2. 所有者与数据链

| 层 | 当前职责 |
|---|---|
| `WorkshopMenu` | 展示Tier和成本；只调用`upgrade_blueprint`与模块切换命令 |
| `BlueprintUpgradeService` | 蓝图类别、Tier上限、成本与失败原因的纯规则所有者；不读UI/存档 |
| `BaseManager` | 拥有资源余额、蓝图Tier、幂等日志、模块解锁及装备状态，并负责一次写盘/回滚 |
| `BlueprintRegistry` | 根据Tier提供可用枪身、弹药和配件定义 |
| `BaseData` | 保存长期Tier与手电模块字段 |

正式链路为`weapon_workshop → WorkshopMenu → BaseManager → BaseData → BlueprintRegistry/PlayerFlashlight3D`。模型场景不持有价格或解锁规则。

## 3. 当前接口与事务契约

查询为`get_extraction_points()`、`get_blueprint_tier(category_id)`、`get_blueprint_upgrade_cost(category_id, current_tier)`、`is_flashlight_module_unlocked(module_id)`和`get_equipped_flashlight_module_id()`。工坊蓝图升级的唯一正式命令为：

目标命令统一为：

```text
upgrade_blueprint(category_id, expected_tier, transaction_id)
→ 校验类别、当前Tier、上限和成本
→ 在BaseData副本同时扣魂并提升Tier
→ 一次写盘和回读确认
→ 成功后发blueprint_tier_changed
```

失败时返回稳定原因：`invalid_category / stale_tier / max_tier / insufficient_currency / save_failed`，并保持余额、Tier和幂等日志同时不变。相同`transaction_id`在当前进程或重载后重放均返回`duplicate=true`，不再扣魂或写盘。`set_blueprint_tier()`仍保留给“拾取蓝图”等非工坊、无付费来源，不是工坊UI入口。
