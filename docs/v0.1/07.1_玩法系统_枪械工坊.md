# 玩法系统｜枪械工坊 v0.1

功能ID：`BASE-WORKSHOP`。状态：**[开发中]**。适用游戏工程：`0.1.0`。更新日期：2026-09-12。

枪械工坊是基地长期成长玩法，用魂解锁枪身、弹药和配件蓝图，并管理已解锁的手电模块。本文记录当前可用功能和继续施工契约；当前UI仍直接编排部分业务，组合事务与独立故障验收未完成。

## 1. 当前功能

- `weapon_workshop`设施通过统一`BaseFacility3D`交互进入`WorkshopMenu`。
- 枪身、弹药、配件各有Tier 0–3；UI显示当前Tier、星级进度、下一级成本和资源不足状态。
- 当前升级成本：枪身80/200/500，弹药60/150/400，配件50/120/350。
- 蓝图Tier写入`BaseData.blueprint_gunbody_tier / blueprint_bullet_tier / blueprint_attachment_tier`，局内掉落与训练场读取许可后过滤内容。
- 手电模块面板显示基础、加强、节能三档耗电和揭示倍率；只允许切换已解锁模块，并同步当前基地玩家。

## 2. 所有者与数据链

| 层 | 当前职责 |
|---|---|
| `WorkshopMenu` | 展示Tier和成本、接收升级与模块切换操作 |
| `BaseManager` | 拥有资源余额、蓝图Tier、模块解锁及装备状态，并负责写盘 |
| `BlueprintRegistry` | 根据Tier提供可用枪身、弹药和配件定义 |
| `BaseData` | 保存长期Tier与手电模块字段 |

正式链路为`weapon_workshop → WorkshopMenu → BaseManager → BaseData → BlueprintRegistry/PlayerFlashlight3D`。模型场景不持有价格或解锁规则。

## 3. 当前接口与未完成事务

当前查询为`get_extraction_points()`、`get_blueprint_tier(category_id)`、`is_flashlight_module_unlocked(module_id)`和`get_equipped_flashlight_module_id()`。当前命令为`spend_extraction_points()`、`set_blueprint_tier()`和`set_equipped_flashlight_module()`。

蓝图按钮目前先调用资源扣除，再调用Tier写入，两步分别保存。单次扣款已有失败回滚，但“扣款+升级”尚不是一个原子提交；这是E04剩余工程，不能标为完成。

目标命令统一为：

```text
upgrade_blueprint(category_id, expected_tier, transaction_id)
→ 校验类别、当前Tier、上限和成本
→ 在BaseData副本同时扣魂并提升Tier
→ 一次写盘和回读确认
→ 成功后发blueprint_tier_changed
```

失败时返回稳定原因：`invalid_category / stale_tier / max_tier / insufficient_currency / save_failed`，并保持余额和Tier同时不变。
