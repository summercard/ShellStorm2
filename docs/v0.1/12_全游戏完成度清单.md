## 10. 下一阶段开发顺序

1. **P0｜稳定 ID 与数据事实源**：命运卡、精英、Boss 门、物品和剧情先具备稳定 ID，避免后续存档返工。
2. **P0｜Boss 下行路线**：专用钥匙、唯一专门门、下行楼梯间、Boss 后电梯和生成验证形成一条垂直切片。
3. **P0｜12 精英正式 3D 化**：全局名册、唯一预约、原型档案迁移、成长与夺械。
4. **P0｜存档事务**：将 Boss 路线、精英和稳定卡 ID 纳入统一清单、幂等和迁移。
5. **P0/P1｜生成性质测试**：多种子扫描重叠、地洞、空气墙、通道、刷怪和可达。
6. **P1｜剧情触发框架**：使用上面完成的领域事件和存档事务实现三条切片。
7. **P1｜设施服务化**：工坊、占卜、保险、档案逐步移出 UI 和基地场景脚本。
8. **P2｜内容扩充与表现**：独立 Boss、12 精英正式资产、更多掉落与剧情内容。

## 11. 扫描结论

当前工程不是从零开始：玩家、战斗、模块化塔楼、普通怪物、基地和基础结算已经形成可运行正式 3D 链路；最大结构风险集中在“正式 3D 与兼容原型双轨”“运行时 ID 不稳定”“跨域存档未形成一个事务”。本次文档已把现状、新设计和补充施工拆开，下一阶段可以按 P0 顺序实施，不需要再次从旧文档猜系统边界。
