# v0.1 变更记录

## 0.1.0

- 确立 3D 塔楼向下探索为唯一正式主线。
- 冻结 5m 组件网格、30×25m 普通房、9m 层高和门净空契约。
- 统一玩家与环境灯光层：外部灯允许角色投影，三盏随身灯不产生自身投影。
- 将跨系统场景路径、渲染层和敌对房型收口到 `GameDesignConfig`。
- 将所有回归场景集中到 `tests/verification/`，增加 smoke/core/full 执行入口。
- 视觉测试输出与正式资产分离。
- 删除阶段文档、循环日志、历史输出、旧兔子制作版本和旧塔楼制作版本。
- 建立本套游戏设计文档，作为 0.1 版本唯一当前文档。
- 塔楼战斗层改为首触发时冻结整层布局计划，房间、门轴、通道与上下楼梯接口使用同一组 5m 组件坐标；房间实体继续按邻接关系流送。
- 将楼梯折返空间纳入占位校验，重排 98—96 层主环/支路和 95 层 Boss 区，消除延迟显现后与楼梯间穿模的问题。
- 补齐东西向小通道无门南墙的相机抬升标记。
- 水平通道改为按真实门距动态增加 5m 地砖和双侧实墙模块，修复 98 层长通道只有中段可见、其余区域被不可见碰撞阻挡的问题；重复模块改由 MultiMesh 批量提交，完整流程节点数保持在预算内。
- 修正动态通道实墙的垂直原点：可视 Mesh 按自身包围盒底面贴地，碰撞盒仍保持 4.5m 中心，消除左右墙体整体悬空 4.5m 的问题。
