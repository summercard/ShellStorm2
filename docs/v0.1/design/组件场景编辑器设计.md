# 组件场景编辑器

FeatureID：TOOL-SCENE-EDITOR；工程版本：0.1.0；契约修订：r6。
模块归属：`TOOLING`；分类：**工具类 / 场景美术制作**；Owner：`ShellStormSceneBuilder EditorPlugin`。
总设计：[游戏总设计 §20](../README.md)；分类与维护入口：[工具类总索引](../TOOL_INDEX.md)；统一追溯：[模块索引](../MODULE_INDEX.md)、[机器注册表](../feature_registry.json)。

来源：2026-10-29 用户要求在 Godot 内调度共享组件，载入白盒自由拼装、刷地表、移动灯光，通过迭代组件更新全部场景。

## 目标与所有权

编辑器作为 Godot EditorPlugin 提供右侧组件面板，复用原生 3D 视图、选择、移动、旋转、检查器、保存与撤销。正式 TSCN 拥有摆位；共享 PackedScene 拥有组件模型、材质、碰撞和原点。布局只保存组件实例引用，禁止展开或复制组件内部模型。工具代码不进入发行包。

## 数据与输出

- 组件目录直接读取 `assets/art/environments/tower_zones/shared/runtime/shell_component_catalog.json`，不建立第二套资产表。目录缺项或资源缺失须可见报错。套件/类型标签优先读取显式kit_tag/type_tag，存量按组件目录来源路径、slot_role与slug/category只读投影；不回写另一套资产账本。
- 白盒选择必须覆盖远征03房间rt、通道cr以及可供远征03制作参考的EGT共享白盒，统一按元数据发现并标明来源，支持搜索选择；共享库仍标明共享归属，检索远征03也须能找到。亦可选择任意白盒 TSCN；新建房间保存为独立美术 TSCN，不覆盖参考白盒。复制尺寸、轮廓与连接口声明，额外模板的白盒可视参考仅存在于编辑器中，不入存盘，不携带运行碰撞；r6实际房间的WhiteboxShell属于正式结构，须保留实际墙地及碰撞。
- 场景根记录 `template_id`、`variant`、`size_m`、`footprint_polygon_m` 与编辑器 schema。`ArtComponents` 下每个实例根保存 `component_id`、`slot_role` 和稳定资源引用；`Lighting` 保存可原生编辑的 OmniLight3D / SpotLight3D；`ConnectionPorts` 保存白盒参考的 Marker3D。
- 支持编辑现有 Node3D 场景。插件不接管作者原有自定义节点，不自动覆盖 TSCN。Ctrl+S 与另存为使用原生编辑器。
- 旧参考模板输出仅为美术布局；r6实际关卡房间输出沿既有静态场景入口按几何签名回接。两者均不修改关卡拓扑、刷怪、门状态机、存档或经济。

## 工作台与操作

主流程固定为“打开/新建场景 → 选择共享组件 → 在3D视图拼装 → 保存”。顶部是短场景工具栏：打开、新建、保存、更多，以及一行当前场景状态；打开场景不能藏在灯光/参考设置中，也不保留重复入口。场景未就绪时显示清晰引导，放置动作须提示前置条件。

主体面积优先分配给组件缩略图网格和可旋转3D预览，二者可调整比例，默认合计不少于常见900px高面板的60%。搜索、套件大标签、类型小标签与收藏采用紧凑控件；长名称用省略和悬停详情，不撑大面板。场景工具栏下方是选择、放置、笔刷、矩形、直线、擦除、点光、聚光八个小按钮，当前模式高亮，不使用操作下拉；底部仅保留收藏、旋转、吸附和选项。间距、标高、角度、笔刷、裁切、端口保护、参考和灯光在可折叠选项区分组显示，默认收起。工具使用独立深蓝灰底色、青绿色强调和明确的选中/禁用状态，仅影响本工具，不修改Godot全局主题。面板显示可核对的工作台修订号；脚本更新后能识别旧控件树并安全重建，不要求用户反复猜测是否已加载新版。

组件按“资产套件 → 组件类型”检索，支持名称/ID/别名搜索与收藏。卡片提供真实缩略图；选中后在隔离World3D预览中拖动旋转、滚轮缩放、复位。预览占主要空间，可展开或折叠。选中高成本资源、生成缩略图时有即时状态与数量反馈，不同步加载整库；快速换选只显示最后一次请求。加载失败保留可读原因和重试入口。

放置方式包括选择、单件、连续笔刷、两点矩形、两点直线、擦除与点光/聚光。Q/E按90度旋转，Esc返回选择；Alt+鼠标保留原生导航。显式网格吸附默认关闭，关闭时保留真实落点；格心/墙边仅改变已开启吸附的相位。标高与笔刷间距独立，连续笔刷按间距插值，每笔/每片只产生一条原生撤销。地砖支持替换、防重复；擦除仅作用于工具登记的组件。

有轮廓时按组件包络裁切，支持凹多边形；可保护端口净空。实际组件半透明轮廓用绿色/红色表示可放/受限，无scene owner。单批上限4096，超限拒绝而非截断。灯光放下后使用原生选择、移动与检查器编辑。

## 加载、反馈与升级

场景打开、白盒参考及组件预览通过后台资源请求和主线程完成阶段衔接：先绘制反馈，再读取资源；只在加载完成后获取结果，避免在未完成时阻塞等待。场景只有在原生编辑器确实切换到目标根后才显示成功；缺文件、非3D资源、加载失败或切换超时须显示原因、重试和返回入口。新请求替代旧请求，旧结果不能覆盖新选择。取消只取消工具的后续处理，不虚称中止引擎已经开始的读取。

场景列表先显示窗口与扫描状态，再在后台扫描只读文件元数据，主线程建树。索引有刷新、空结果与扫描失败反馈。场景切换期间限制拼装并保持当前场景；原生编辑器最终实例化仍由Godot拥有，显示单独“正在打开”阶段，不假报读取百分比或承诺可强制取消已经执行的原生操作。更新后的旧UI与失效服务需可重建，旧场景、摆位与原生撤销记录不随面板升级丢失。

## 已有场景浏览

“打开已有美术场景”显示可搜索的树形场景列表，按关卡/资产套件分组、按房间名称与ID索引，支持双击打开。默认从正式room_instances目录的房间场景、编辑器产出的美术场景及现有元数据发现；旧路径别名避免与正式关卡目录重复。白盒参考标记为白盒，默认与正式场景区分显示。显示名优先取登记或场景元数据，缺失时由关卡ID、房间ID与套件信息组合；稳定文件路径不重命名。顶部“新建”提供独立白盒模板列表：只显示白盒并默认可见，选中后进入美术场景另存流程，不能误把原白盒作为美术文件直接编辑。白盒导出的美术场景只携带参考路径、模板/壳ID、尺寸/轮廓/端口与来源声明，不继承whitebox标记；EGT来源的美术输出默认进入远征03美术目录，不保存到共享白盒库。文件选择作为补充入口，新建/另存后刷新列表。此列表只读索引现有文件，不建立第二套场景事实源。

折叠选项中的“参考”显示白盒参考状态：已加载、已隐藏、当前场景本身为白盒、未关联、路径不存在或资源无效。提供重载与关联/更换参考入口，关联变更可原生撤销；不会改动已有美术摆位。白盒透明度可调，显示开关与透明度独立；参考预览禁用脚本、处理、碰撞、导航、声音与粒子。

## 失败与撤销

场景非 Node3D、缺少组件、模板无效、不可写或目标已存在时拒绝对应操作并显示原因。新建路径不得覆盖现存文件。切场景、禁用插件、Esc与失焦时结束或取消当前笔画，不能把跨场景操作放进同一撤销历史。编辑辅助、落点预览和白盒参考没有 scene owner，保存时不进入 PackedScene。组件实例仅设置顶层根 owner，不递归改写 Prefab 内部 owner。

## 接入与验收

入口：项目设置 → 插件 → ShellStorm Component Scene Builder；启用后右侧“场景工坊”（原组件拼装），默认占用完整右侧栏目。插件随项目启用，发行预设排除插件目录。

独立验收覆盖：真实目录可解析、凹轮廓裁切、笔刷插值、替换与重复检测、4096预算、Prefab实例存盘与重开、owner边界、辅助节点不入盘、灯光属性保留；编辑器验收覆盖插件启停、场景切换、笔刷输入与原生撤销。真实 GUI 核对面板与3D放置预览，不把纯数据测试算作画面验收。

历史记录见 [2026-10-29 组件场景编辑器](../development/2026-10-29_component_scene_editor.md)；r5工作台与加载流程见 [工作台重构记录](../development/2026-10-29_scene_builder_workbench.md)。


## 实际关卡房间编辑（r6）

来源：用户明确要求打开游戏内已经运行的远征03房间再优化。主“打开”默认进入“关卡房间”，旧静态白盒仅属于“参考模板”，不能把目录存在误标为游戏采用。rt/cr与EGT静态导出均保留11.9m，游戏程序化壳体使用2.8m；不以缩放旧模板伪装同源。

按所选正式关卡场景和种子，在独立进程及隔离用户目录中运行该场景现有生成链；从实际DungeonRoom3D提取本地壳体、尺寸和端口，列表显示关卡/种子/房间ID与真实墙高。列表不假称是正在运行会话的实时镜像；需要复现某次地图时使用相同种子。读取有阶段/耗时、失败原因、取消、重试，不在编辑器主线程启动整关卡。

已有匹配美术TSCN优先打开；首次建立包含实际壳体的正式可编辑TSCN，提供ArtComponents、Lighting、ConnectionPorts分组，保留稳定Prefab引用及真实碰撞。禁止复制门FSM、敌人、掉落、触发器或全关卡脚本。由用户迭代正式场景，不覆盖已有手改；缓存只能刷新派生参考。

运行时沿现有static_layout_scene_path契约查找runtime_rooms/<房间ID>_<局部几何签名>.tscn；唯一签名实现位于运行时契约类，由房间实际尺寸、类型、局部门位/开口计算，排除世界位移、种子与对端ID。门位/尺寸不符时不使用该美术，沿既有白盒回退；不固定随机拓扑、不更改刷怪、门状态机或存档。源已经处于房间局部帧，不再次应用旧静态美术朝向猜测。

产出的正式TSCN记录来源关卡场景、种子、房间ID、几何签名和墙高；原型静态文件、既有art_std场景不自动迁移或覆盖。元数据和实际游戏载入同时验收，不能仅以生成成功签署回接完成。

原生保存沿用Godot编辑器与撤销历史；当前4.7.2通过save_scene_as(path,false)避免原生场景缩略图生成缺陷。工作台场景内Ctrl+S路由同一保存命令；脚本编辑及其他独占窗口保留原生快捷键。r6运行来源不得注入塔楼高墙相机门代理，并须恢复矮墙既有camera_lower_wall声明。
