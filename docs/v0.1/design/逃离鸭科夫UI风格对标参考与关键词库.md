## 1. 为什么对标《逃离鸭科夫》？（核心设计哲学）

传统搜打撤游戏（如《逃离塔科夫》《暗区突围》）采用硬核拟真军武风，UI 充斥着细碎的表格线、冰冷的直角金属框与极小字号的工业铭文，在俯视角/斜俯视角动作射击中极易造成视觉疲劳。

《逃离鸭科夫》之所以能与卡通/3D 风格完美融合，核心在于它做了一次**“硬核机制、轻量包装”**的降维：
1. **去掉全屏黑底，保留中央实景**：打开背包/搜刮时，画面中央的 3D 角色、聚光灯圈与周围环境依然清晰可见（仅外围做柔和暗角），玩家随时能感知身边风吹草动。
2. **圆角深灰蓝面板 + 灰白细描边**：用磨砂半透明的深板岩灰蓝（Slate Navy）替代死黑，用 `8px~12px` 圆角替代尖锐斜切角，既保留战术秩序感，又极其护眼。
3. **单元格内信息高度克制**：格子里**45° 斜放的等距高饱和 3D/2D 图标占满 80% 面积**，文字严格退守四角（左上配件点、右上绿条耐久、右下数量+底对齐单行短名称），绝不遮挡模型主体。

## 3. 《逃离鸭科夫》文字排版与布局规范拆解（Typography & Layout Spec）

为了把“鸭科夫味”精准转化到《弹壳风暴2》的 UI 代码（`UIPalette` / `UIStyleFactory` / `ItemSlot`）中，提炼以下 **6 条量化排版与布局法则**：

### 3.1 屏幕空间与三段式构图法则（Screen Composition）
| 区域 | 鸭科夫布局参数 | 视觉与交互作用 | 对标《弹壳风暴2》落地映射 |
|---|---|---|---|
| **左栏（自我域）** | 宽约 `28%~32%` 屏宽，距左边缘 `36px`，上下留白 | 承载**装备栏 + 随身背包 + 左下负重条**，顶部悬浮货币胶囊 | 对应 `InventoryUI` 左栏（装备/配件）或左移合并后的个人栏 |
| **中场（实景域）** | 占屏宽 **`35%~45%` 完全通透** | 保持 3D 角色与周边地面可辨认；顶部挂 5 图标导航，底部挂快捷栏 | 对应 `InventoryUI` 中央 3D 兔子角色预览与拖放丢弃留白区 |
| **右栏（外部域）** | 宽约 `28%~32%` 屏宽，距右边缘 `36px`，高度随行数自适应 | 承载**地面战利品容器 / 基地大仓库 / 自动售货机**，不用时完全隐藏 | 对应 `VaultMenu` 右栏仓库、`BaseVendingMenu` 货架 |

### 3.2 面板与容器四级结构（Panel Hierarchy）
1. **外层主面板（Main Card）**：深板岩灰蓝半透明 `rgba(30, 38, 49, 0.88)`，外描边 `1.5px solid rgba(255, 255, 255, 0.16)`，圆角 `10px`。
2. **斜纹分节标题条（Section Header Bar）**：高 `28px`，底色加深至 `rgba(18, 23, 30, 0.92)`，叠加 `45°` 暗色斜纹（stripe pattern），左侧内边距 `12px` 放置分节标题（如 `背包 (11/27)`），右侧内嵌小号浅色圆角功能按钮（如 `整理 / Sort`）。
3. **物品单元格（Item Slot Cell）**：基准正方形（约 `64×64` 或连续棋盘 `50×50`），底色 `rgba(42, 51, 64, 0.78)`，内描边 `1px solid rgba(255, 255, 255, 0.12)`，圆角 `6px`，格间距 `6px`。
4. **底部状态注脚条（Footer Pill）**：主面板底部外挂一条高 `26px` 的独立窄条（如 `负重 [━━━━────] 31.8/50kg`），将次要进度条剥离出主框，减轻主面板拥挤感。

### 3.3 单元格内文字与角标的“四角退让”铁律（Slot Micro-Typography）
在《逃离鸭科夫》中，**文字绝不横跨格子中央**，严格按以下四个角位锚定：
- **左上角（Top-Left）**：**结构/配件状态** —— 用一排 `4~6px` 的圆点 `••••○` 表示武器配件槽已装数量（无需写文字“配件 4/5”）。
- **顶边（Top-Edge）**：**耐久/充能状态** —— 紧贴格子上边框内侧画一条高 `3px` 的翠绿/亮黄进度条（无需写数字“耐久 85%”）。
- **右下角第二行（Bottom-Right, Line 1）**：**堆叠数量** —— 纯白粗体数字（如 `30`、`1058`），字号 `13~14px`，带 `2px` 黑色描边，右对齐。
- **底边居右/居中（Bottom-Edge, Line 2）**：**物品短名称** —— 浅灰白无衬线字（`#E8EEF5`），字号 `11~12px`，单行截断（`...`），紧贴下边框 `3px` 处，带深色描边。
- **格子正下方外部（Outside Bottom）**：**槽位固有属性名** —— 仅用于装备栏（如 `武器`、`身体`、`头部`、`背包`）或快捷栏键位白块 `[1]`~`[8]`，与物品本身的名字彻底分离，不会混淆“槽位名”和“物品名”。

### 3.4 字体与数字排版特征（Font & Numerals）
1. **UI 正文字体**：圆润、现代、高 x-height 的黑体/无衬线体（中文近似 **思源黑体 Bold / 鸿蒙黑体 Medium**，英文近似 **Rubik / Din Pro Rounded**），全部带柔和暗色阴影或细描边，杜绝细瘦锯齿字。
2. **标题与数量关系**：分节标题统一采用 `标题名 (当前值/上限值)` 格式（如 `背包 (11/27)`、`战利品 (10/10)`），括号与数字紧跟标题，不另起一行。
3. **HUD 时间专属字体**：左上角世界时钟强制使用 **7段数码管字体（7-Segment Digital Font）**，瞬间建立电子战术表盘感。
4. **键位提示（Keycap Badge）**：所有快捷键提示（`[T]`、`[O]`、`[1]~[8]`、`[V]`）一律渲染为**“纯白实心小圆角方块 + 深黑粗体字母”**，在深色画面中辨识度极高。

## 5. 对《弹壳风暴2》现有 UI 的直接迭代启发（差距对标表）

对比上面提取的《逃离鸭科夫》实机截图与《弹壳风暴2》2026-10-15 版 `InventoryUI` 实机截图（`inventory_1920.png`），可以立刻锁定以下 **5 个最具性价比的视觉升级点**：

| 序号 | 对比维度 | 《逃离鸭科夫》实机做法 | 《弹壳风暴2》当前做法 (`inventory_1920.png`) | 可直接落地的升级动作 |
|---|---|---|---|---|
| **1** | **分节标题栏区分度** | 采用 **深色底 + 45° 斜纹背景条** 包裹 `装备`、`背包 (11/27)`，区块边界一目了然 | 纯文字标题（如蓝字 `随身装备`、`背包装备`）直接写在同色底板上，上下区块容易粘连 | 为左栏分节与右栏 `背包`、`保险柜` 增加 `28px` 高的深色斜纹标题条 |
| **2** | **武器配件槽状态表达** | 武器格左上角直接画 **`••••○○` 6 个微型圆点**，一眼看出装了几个配件 | 武器格下方写小字 `命运 0/4`，配件槽单独占 6 个 `50×50` 方格写文字 `×瞄具`、`×枪口` | 在武器卡左上角增加配件/命运圆点矩阵；空配件槽改用半透明部位剪影图标 + 槽下外部小字 |
| **3** | **品质稀有度呈现** | 格子采用 **边缘向内衰减的彩色内发光（Inner Glow）+ 亮色细边**，通透且高级 | 仅靠边框颜色变化，格子内部底色全是一样的深蓝，高稀有度物品不够抓眼球 | 在 `ItemSlot` 中为稀有以上物品绘制四周向中心透明的径向/线性内发光渐变层 |
| **4** | **快捷键角标（Keycap）** | 统一采用 **白底黑字圆角小键帽 `[1]` `[2]` `[T]` `[O]`**，骑跨在槽位底边中点 | 左上角直接写灰白纯文本 `[1] 主武器`、底部写 `[3]空`，缺乏按钮实体感 | 封装通用键帽绘制函数：白底（`#F0F4F8`）+ 4px 圆角 + 深黑粗体字，用于快捷栏、武器槽与 HUD 提示 |
| **5** | **左上角时间与倒计时** | **7段数码管大字时间** + 下方独立圆角胶囊倒计时条 | 普通无衬线小字 `2075-01-01 09:00` 放在右上角 | 将世界时间或遭遇倒计时升级为数码管风格字形 + 胶囊底托，强化战术电子表质感 |
