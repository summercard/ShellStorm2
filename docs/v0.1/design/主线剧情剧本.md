# 主线剧情剧本

范围：开场主线01—05；工程版本：0.1.0；内容修订：2026-10-12。
来源：既有开场01、02、2.5、03，以及用户确认的02—05调整与分镜。后续章节尚未编排。

本文集中描述玩家看到的剧情：地点、事件、角色动作、台词、镜头和操作交还。系统实现与触发规则见配套的[剧情触发技术文档](../08_技术施工_剧情触发.md)。两份文档按相同剧情编号关联：修改剧情内容时维护本文，修改触发和执行规则时维护技术文档，同一改动涉及两者时同步更新。

## 剧情01｜苏醒与礼物

**地点与开始：** 新档开场，玩家进入98F起始房间的游戏画面后。

新存档的世界时间从2075年1月1日早上09:00开始。

角色起初倒在地上。镜头缓缓压低、推近角色；角色随后起身，左右张望，寻找周围的人影。

> 角色：“人呢”

镜头回到通常的游戏视角。角色转向房间内主人留下的礼物。

> 角色：“那是主人留下的礼物。。”

**结束：** 演出约18秒，结束后恢复操作，玩家继续探索。礼物为既有开场武器。

<a id="story-02"></a>

## 剧情02｜黑暗中的怪物

### 第二房间：手电引导

**地点与开始：** 98F第二房间，玩家从入口侧走到原有剧情触发位置。本文沿用用户称呼“办公室”；工程中的房间源名为“会议室”。

房间内出现原有的五只小僵尸。靠近第三房间的方向，另外分散站着三只小僵尸。新增三只出生前先检查地面与设施阻挡，在附近空旷位置分散落位。它们按普通怪进入原地警戒巡逻，受到玩家攻击后按普通怪反应；剧情不额外命令它们扑向玩家。它们仍可以被攻击和击杀。

镜头从玩家移向原有怪群，停留后移回玩家。角色察觉黑暗中有东西。

> 角色：“黑暗中是什么东西！”

> 系统提示：“打开你身上的手电，那里有危险！按F开启手电”

**结束：** 这一段锁定普通操作，并等待玩家按F开启手电；开启后结束演出，恢复操作。原有五只与新增三只均为一次性剧情怪物，击杀后不补刷。

### 第四房间：警察僵尸

**地点与开始：** 玩家经过第三房间通道，进入98F第四房间（门厅）。

房间内出现三只警察僵尸。角色进入后立即惊呼。

> 角色：“天啊！”

**操作与衔接：** 玩家始终可以操作，台词约停留3.4秒；随后继续向98—99F楼梯间前进。

<a id="story-2-1"></a>

## 剧情2.1｜我得找到主人

**地点与开始：** 玩家离开第四房间，进入通往99F的楼梯间入口附近。

演出接管角色。镜头向下压并推近，镜头路径须避开墙体与楼板；空间不足时收近镜头，角色走到楼梯下方，先向一侧看，再向另一侧看，最后看向上行的楼梯。

> 角色：“我得找到主人”

**已确认分镜：** 时间从本段触发起计算。

| 时间 | 画面与角色动作 |
|---|---|
| 0—1.2秒 | 锁定操作，镜头压低、推近角色 |
| 1.2—3.6秒 | 角色走到楼梯底部 |
| 3.8—5.4秒 | 角色左右张望 |
| 5.4—6.0秒 | 角色转向上行楼梯 |
| 6.0—9.5秒 | 说“我得找到主人”，台词停留3.5秒 |
| 9.5—10.5秒 | 镜头回到游戏视角；回位后恢复操作 |

**衔接：** 玩家重新操控角色，上楼前往99F。

<a id="story-2-2"></a>

## 剧情2.2｜外面的轰声

**地点与开始：** 玩家走到98—99F楼梯两段梯跑之间的中间平台。

突然传来一声“轰”，屏幕随之短暂震动。角色对外面的动静产生疑惑。

> 系统字幕：“轰！”

> 角色：“外面发生什么事情了？”

**节奏与操作：** 轰声、系统字幕与震动同时发生，震动约0.65秒；约0.8秒后角色说话。全程不锁操作，本段约4.4秒结束。

<a id="story-2-5"></a>

## 剧情2.5｜黑暗基地的前置

**地点与开始：** 玩家上到99F，接近基地东门外侧。

在玩家进入之前，基地内部灯光关闭，使接下来的进门画面保持黑暗。

**表现与操作：** 本段约0.3秒，无台词和运镜，不锁操作。玩家继续进入基地，衔接剧情03。

<a id="story-03"></a>

## 剧情03｜进入基地

**地点与开始：** 玩家从东门进入99F基地，向内走到触发位置。

基地内保持黑暗。角色停下来观察陌生的环境。

> 角色：“这是哪里？”

镜头随后移向东墙的灯光开关，并拉近，提示玩家开灯。

> 系统提示：“打开房间的灯光”

**结束：** 镜头回到角色，约8.4秒时演出结束并恢复操作。灯光仍关闭，由玩家自行操作开关。

基地门关闭后不播放“欢迎回到基地”的系统播报。

**衔接：** 玩家可在基地活动，之后从西侧门前往99—100F楼梯间。

<a id="story-04"></a>

## 剧情04｜楼梯间的僵尸

**地点与开始：** 玩家走出99F基地西侧门。

通往100F的楼梯间里出现三只小僵尸，分别位于下段、中间平台和上段。角色看到这些怪物后说道：

> 角色：“这么多！”

**操作与衔接：** 全程不锁操作，台词约停留3.4秒。三只均为一次性剧情怪物，玩家继续上楼到天台。

<a id="story-05"></a>

## 剧情05｜天台与吊桥前的胖子

### 天台怪群

**地点与开始：** 玩家从99—100F楼梯间出口到达100F天台。

楼梯间门口至吊桥之间的空间里，分散出现五只警察僵尸与十只小僵尸，共十五只。出生前须确认落点属于天台可行走地面，并避开设施、墙体和孔洞；不能落到下方基地。

**操作：** 这一段不锁操作，无新增台词；玩家可自行移动和战斗，继续接近吊桥。

### 吊桥前：胖子展示

**地点与开始：** 玩家绕过机房楼中楼、走在机房**北侧通道**上时触发——不是走到桥口才触发。这一段是 99F 上行楼梯口通往吊桥的必经通道，触发点离吊桥入口还有十几米。

吊桥前出现一只胖子僵尸与五只警察僵尸。这六只与前方的十五只怪群分别布置。

演出锁定操作。镜头从玩家身上平移到胖子僵尸，聚焦并停留一秒，再平移回玩家。

| 时间 | 画面与操作 |
|---|---|
| 0秒 | 锁定操作，吊桥前六只怪物出现 |
| 0.1—1.3秒 | 镜头平移并聚焦胖子僵尸 |
| 1.3—2.3秒 | 镜头停留1秒 |
| 2.3—3.5秒 | 镜头移回玩家 |
| 3.5秒 | 结束演出，恢复操作 |

本段没有新增台词。两处怪群均为一次性剧情怪物；当前剧本编排到镜头返回并恢复操作为止。

## 共同规则与文档关联

角色台词显示在角色头顶，系统提示与系统字幕显示在底栏。“检查点”在这些剧情中指经过时触发演出的位置；保存与复活规则由相应系统文档定义。

一次性剧情怪物击杀后不补刷。读档保留已生成且存活的剧情怪物，旧档中卡设施或掉到基地的相关怪物会校正到同层安全位置，血量与身份保持；完整体验可从新档开始，已完成剧情02的旧档不会追补新增的三只原地怪物。
