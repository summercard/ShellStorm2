# 时间日夜与画质｜功能设计 v0.1

功能ID：`TIME-DAYNIGHT`、`GRAPHICS-POSTFX`。工程版本：`0.1.0`；设计修订：r1（2026-09-24）。两功能各自独立，放在同页只因都影响画面；[15 时间技术施工](../15_技术施工_时间日夜与基地能源.md)、[13.1 画质技术施工](../13.1_技术施工_画质设置与后处理.md)分别维护实现细节。

## 时间、日夜：玩家目标与规则

**[既有设计]** 世界从`2075-01-01 17:00`开始，20真实分钟对应24游戏小时；暂停默认不走时，不按设备墙钟补离线进度。日出06:00、日落20:00；太阳东升西落，清晨偏橙、正午偏白、黄昏偏红，正午亮度峰值1.0，夜间为0。HUD在雷达下显示同一权威时间。基地能源每游戏小时恢复4点，但能源容量、消费和恢复舱规则由[电力系统](../15.1_技术施工_电力系统.md)拥有，不能由画质系统改变。

`GameTimeManager`写累计游戏秒，`WorldTimeDomain`纯计算日期/太阳，太阳、HUD、基地能源只读同一快照。时间写盘失败不等于已落档；重启从最后有效时间恢复，不产生离线收益。未来天气/周期设施接只读时间，不自建第二个时钟。验收覆盖起始时间、暂停/倍速、日出日落、能源同步、写盘失败/跨重启与真实渲染。当前强制写盘失败的跨重启专项和太阳真渲染**未完成**；见技术施工。

## 画质、后处理：玩家目标与规则

**[现行设计边界]** 玩家画质选项用于调整正式画面质量/性能，不改变命中、敌人、能源或存档数值；跨场景与重启保持已确认的选择。画质设置与游戏进度档分开。`GraphicsSettingsManager`拥有正式选项；`PostfxOverlay`拥有全屏颗粒/色相的运行表现；P键调参页目前是**开发调试工具**，并非已批准的正式玩家设置页。调试覆盖和调试JSON不可默认为玩家配置或进入`BaseData`。

**[待设计裁决]** 哪些调参值要成为正式玩家选项、预设档的具体视觉阈值、调参入口是否随发布保留，尚无用户冻结设计；未来不能仅因当前代码能调就升格。若转正，应先补玩家可见控制、可访问性、默认/重置、保存成功/失败回执与设备性能标准，再修改代码。当前 cfg 与调参JSON写盘都缺明确对外结果，不能提示“已保存”。

## 命令、数据、失败与验收

正式画质配置写`user://graphics_settings.cfg`，调试参数另存`user://postfx_tuning.json`；具体键与schema见技术施工。未知键、坏值、坏文件应拒绝或回退到安全默认且可诊断；未能写盘时运行值与持久值应被明确区分。验收入口：`verify_main_entry_realtime_sun_flow`、`verify_graphics_settings_ui_flow`、`verify_postfx_overlay_runtime`、`verify_postfx_autopersist`；正式画面、HUD/UI隔离、目标GPU与性能预算必须用真实渲染/设备证据，不能由headless断言代签。
