# 远征 01 武装平台首领

FeatureID 为 BOSS-STAGES / ASSET-PIPELINE / NARRATIVE。资产 ID 为 `ENM-BOSS-PLATFORM-SENTINEL-3D`，内容键为 `boss_exp01_platform_sentinel`。游戏版本 0.1.0。该首领与显示器首领分别拥有资产与账本，在远征 01 与测试关卡 99 的共同终局中接力。99 每局可测完整两阶段，不写正式主线的剧情历史或钥匙；走该关原有标准撤离点。

## 现行版本

### 首次挑战与重刷

1. 保留显示器首领的进场和首战；其满血为8000 HP，01与99共用同一配置。地板为未通电的平台，原路可达。显示器失去战斗能力后暂停结算，玩家在安全站位观看核心接管。显示器替身从演出开始固定于平台北侧，先以既有受击动画、短火花和音效明确落败，再进入眩晕待抓，不继承首战倒下的位置。首战只显示现有 HUD 首领条，隐藏该显示器的头顶血条；接管后同一 HUD 改为四臂分段。北臂启动时三块巨屏后撤；二阶段出舱开始时，平台边栏视觉与挡弹碰撞同步撤去，重开首战恢复。核心称它为办事不力的代理，显示器试图辩解。平台后方的大臂先出舱，抓住显示器后将其掷下深井。随后整屏通电，另外三只大臂与四边机枪出舱。临台两段楼梯断开，东西侧桥各向外平移 3.6 米，桥面、护栏和通行碰撞一起移开。
2. 接管完毕记录一次性剧情。新局再次挑战时，平台在玩家踏上甲板后直接出舱，跳过显示器与接管演出。已经取得稀土钥匙的旧档按重刷处理。首次挑战的稀土钥匙、保底箱、返航剧情仍走原结算链，由平台首领最终击败解锁。已通关的同一局再次进房保持结算完成。
3. 暂停或读档恢复时，房间控制器恢复本局接管、甲板和部件状态。意外中断接管时允许从演出起点重放，演出跳过直接进入出舱。只坍塌最外层；内侧 3×3 格（15×15 米）保留可见地面及连续承重。清场后由保留区东缘接出检修桥，接回既有撤离方向走道。奖励箱固定在正中央，通过原交互与奖励交易打开。

### 战斗和走面

- 平台尺寸 25×25 米，走面原点在平台中心。四边各四座机枪、一只大型机械臂。四臂各 2200 HP，只有机械臂实体可受击；臂段和低位腕部共用该臂生命与命中归属。掌拍在 30 fps 源动作 F36 结算 24 伤害。约 0.4 秒的压台动作后保持低位锁定，合计提供 1.2 秒腕部反击窗口，再收臂。机枪出舱后保持架起，由枪口在约 1.30 米高的平面发射慢速投射物。首领条四段对应四臂。
- 四只大臂摧毁后，枪阵收火并回收已发射的弹幕。只有外环 16 块依次颤动、故障熄屏和掉落；每批真实断地与火花、爆破和短震共用同一触发点，首批震感更强。亮线和内指箭头引导退入保留的九格。掉块关闭实际碰撞，站在其上的角色按原规则下坠。内圈全程保留，玩家站在安全区内用标准交互停机，进度 0.6 秒，可移动打断。停机后东侧桥滑回，0.8 秒时中央检修桥接通，房间按既有流程结算。
- 普通模型只共用精工金属、细腻哑光、清漆反光、柔和自发光四个材质，使用同一张公共色盘和 PaletteUV。红黑与冷灰蓝共用这四个材质。25 块屏幕共用一个专用材质，由实例 UV 和故障参数拼成一幅大图。通电演出仍使用原蓝色上线画面。二阶段通常交战时，地面屏保持原整幅 `SYSTEM ONLINE / PERIMETER ACTIVE` 图样、原 UV、尺度和图案密度；不放大图中的小雷达、柱图或波形。每 3.6 秒，一次局部条带错位先起，然后原图快速换到下一种冷色（原青蓝、冷蓝、蓝紫），不切图片、不整屏亮灭、不驱动灯光。地板与后壁三屏各走自己的节奏。结构预警黄色、临界红色、真实断地故障与熄屏优先，停机时不再播放装饰循环。保留原始冷灰蓝配色，远征 01 首领房使用与房间一致的红黑外壳。材质配色独立于战斗警色。
- 各机械臂、机枪、四分段底架和显示板使用独立视觉组件，地板、楼梯走面、受击目标和危险判定由遭遇控制器持有。纯视觉资源按 30 fps 交接，动作采用小写下划线，以 Blender 第 1 帧作为剪辑 F0。详见[动作清单](../../../art_source/enemies/bosses/enm_boss_platform_sentinel/source/v001/animation_manifest.json)。

### 结算与恢复契约

遭遇控制器 `PlatformSentinelEncounter3D` 持有阶段、攻击调度、部件受损、走面失效与停机交互。它通过 `health_changed`、`defeated` 和 `checkpoint` 向房间层发布变化。房间层只在最终胜利时提交既有门控、奖励和通关标记。一次性演出历史归剧情服务。关卡存档的遭遇段使用 schema 2 持久化阶段、四臂血量、坍塌计时及已经发生的断地，重新载入时为攻击提供完整预警，未完成停机重新开放交互。schema 1 的中央核心阶段迁为停机阶段，已通关旧档沿用通关状态。钥匙通过既有奖励箱来源交易发放。

## 遭遇节奏修订

本节定义 2026-11-19 深化后的运行契约和实打指标。玩家主动防御的是四只大臂和周界枪阵。坍塌沿用深井失败规则，战斗结束由中央停机交互提交。

### 玩家在和谁打

| 部位 | 向玩家发起攻击 | 玩家如何反制 |
| --- | --- | --- |
| 四只大臂 | 各自负责一侧，抬掌蓄力，拍击可达甲板 | 四个独立可毁目标。常态可攻击臂段，压台后腕部进入近战范围。同一臂的实体受击形状共用一份生命，同一发普通投射物只命中一次。 |
| 十六座枪架 | 四边各四座，单架点射接散射、对边交替散射、四边弹幕各有周期 | 枪阵不承受玩家伤害，不再有可打断供弹球；根据枪架朝向、机械声与弹道走位躲避。枪架随外环掉落。 |
| 中央核心 | 负责发出攻击指令。甲板失效后只保留停机交互 | 四臂的安全互锁解除、内圈稳定后，中央断路开关出现。玩家站上中央安全块按 E 停机，消耗 0.6 秒完成收尾。核心无额外血条，弹药用尽仍能结算。 |
| 甲板与临台梯段 | 走面断裂形成地形危险 | 先读到收缩方向，再走向内侧九格保留区。坠落用原有重力与失败处理。 |

首领血条分四段，每段对应一只臂的方位标志。臂摧毁后，同侧指示熄灭，字幕与场景灯同步反馈。血条不显示枪架。四段归零后改显示撤至中央与停机提示。数据库核心与巡防机构的关系在画面中由同侧线束、灯带与指令声说明。四臂失效触发支架卸载，临台楼梯与外框分离。独立供电的检修桥在收尾后接回既有撤离走道。

### 一场战斗的感官节拍

| 段落 | 玩家感知与操作 |
| --- | --- |
| 进入与显示器首战 | 保留现有主线进场。25 块甲板屏未通电，枪阵藏在边口下方。深井低频、桥面脚步和显示器语音为主，玩家可以先看清中央、楼梯和侧桥。 |
| 接管与夺权 | 保留 26.25 秒对白与顺序。用一个固定画面看清北侧击破、抓起、抛落，再看平台通电抬升。核心声用有方向感的干声加短回声，显示器声在被抓住时随身体移动并出现断续。对白完成后，后臂以解锁、伸出、悬停一拍、握紧、外甩五个动作展示重量。抛出时让玩家看到抓手放开和显示器离开画面方向。底噪断半拍，随后从脚下向四边接通。 |
| 首次出舱 | 通电从中央扩向全台，四周机壳抬升，机械臂与枪架依次展开；甲板高度和碰撞不随装饰机壳移动。抬升在固定镜头中开始，镜头还给玩法后，出舱完成才解锁操作及攻击。先用桥接头火花和机械启动声提示离台口即将打开，侧桥外移，临台梯段掉落。掌拍保留地面形状预警，枪阵保留机械蓄力与音效，不绘制地面长条。重刷用 3–4 秒完成出舱和断连，首个攻击前仍留移动窗口。 |
| 四臂在线 | 建立「看见来源、识别地面形状、换位、回击」的节奏。掌拍用环形压区和低沉液压声，枪阵用机械蓄力和短促扳机节拍。镜头保持可操作取景，地板大字退为低亮背景。 |
| 二臂及以下 | 两臂失效后屏幕由蓝切黄。活着的大臂和枪架接管调度，优先让有威胁的来源出手。被击破侧获得一拍空间，让玩家读懂自己拆掉了哪一侧。最后一只臂仍需给出完整预警和恢复，枪阵填补无有效拍击落点时的空档。 |
| 缩圈与停机 | 最后一臂失效，枪口停转，弹幕收束。最外圈出现加剧的颤振和屏幕干扰，内侧亮框及箭头标出退路。外圈各块错开失效，实际断地时喷火花、爆破、短震；内侧九格保持稳定。中央保留通用停机提示及安全灯。音乐在此收束属于后续音频细调。 |
| 战后落地 | 中央交互成功后屏幕短闪、断电，低频退尽，停约 0.8 秒后独立检修电源点亮东侧桥。奖励箱、桥和可达信标依次进入画面。保留玩家视角，只做环境提示与短音效。 |

战斗特效用形状和声源区分三种危险。掌拍为圆形加重落点，枪阵保留三次击发节拍，不再绘制预警窄条，断地为整块边界加朝内箭头。红黑外壳和蓝黄红大屏承担环境气氛。色觉差异、静音和低画质下，战斗仍靠轮廓、动势、短图标读得出来。命中只在落掌或枪响帧抬高亮度。落掌的力道主要来自短震、低频、碎屑和掌垫压台，站在无护栏边缘时避免自动击退把一次常规中招直接升级成坠亡。击退着地与视觉方向一致。

### 战斗调度与输出机会

| 项目 | 起始参数与规则 |
| --- | --- |
| 掌拍 | 约 1.17 秒前摇，最后 0.35 秒锁定实际落点，地面圆跟随到锁定后固定。半径先用 3.05 米，单次 24 伤害。触地约 0.4 秒并只结算一次，落掌后至少 1.2 秒可安全反打该臂。每臂两次起手至少间隔 6.5 秒。 |
| 三弹一扇 | 从告警开始锁轴，第 0.90、1.30、1.70 秒发三颗 8.4 米/秒单弹，各 8 伤害。第 2.25 秒沿同一枪轴打出五颗扇形散弹，7.4 米/秒，各 6 伤害。散射前保留原机械音效，不绘制亮线。该侧两次常规起手至少间隔 5 秒。 |
| 对边交替 | 三只或更少大臂在线时可用，四臂长期在线也可在战斗第 20 秒后出现。两对相反边轮换选用，技能内第一边 1.05 秒打出一排三弹扇，1.5 秒后对边发射。每边四座枪。技能冷却 14 秒。 |
| 全周三波 | 两只或更少大臂在线，最早在交战第 22 秒选用。四边所有在线枪架在 1.10、2.60、4.10 秒各发一波。16 座全在线时每波 80 颗可见散弹，速度 7.4 米/秒，各 5 伤害，每颗飞行 15.8 米。沿出弹间隙走位。技能冷却 24 秒。 |
| 全局节拍 | 掌拍、三弹一扇、对边交替、全周三波共用调度，同一技能的弹幕可以接续飞行。枪阵收招后至少等 0.85 秒且场上本次弹体退尽，才起下一技能。先检查动作、有效目标、冷却、路线，再选择来源。空档由独立随机序列给存活大臂和机枪臂分别选择已有扫描或伺服停顿动作；攻击、破坏及坍塌接管时打断，不改攻击时钟。 |
| 掌拍覆盖 | 每边有外侧落点以及肩轴转动后的向内落点。以实际触地姿势确认落点，玩家超出所有掌击区时由有通路的枪架接管。存活大臂按上次出手时间和能否覆盖玩家所在区参与选择。用真实渲染逐边复核起手至回位的护栏、枪身和关节净空。 |
| 公平反击 | 一个短程近战位和一个远程火线外输出位都要成立。手部暴露时，近战能在现有移动与攻击距离内接近；摇杆与键鼠均能明确选到发光受击点。击破、受击闪烁和命中声音从真正的受击部件发出。 |
| 缩圈 | 四臂全毁立即显示退往内侧的提示；默认 3.8 秒后外环开始断地，约 7.9 秒开放停机。不再安排第二圈坍塌。落地计时需按玩家走向九格安全区的实际路径核对，预留走位余量。短路电弧和碎片是演出，移动途中无枪击与掌拍叠加。玩家站在将掉块上按真实断地帧坠落。 |

早段的输出率允许不同装备处理机制。原 2200 HP/臂作为第一轮调参起点。以常见同关装备的有效输出测得知情重刷在平台战中约 65–100 秒，首见二阶段约 85–130 秒，均从出舱完毕计至停机。记录单臂击破用时、每分钟实际受击次数、紧邻下一次警告的最短可输出时间、到中央时剩余弹药。目标时间用于识别过长、过短及长时间无威胁的打法。

### 验收与实打指标

- [接线前探针](../development/2026-11-19_platform_sentinel_combat_design.md)记录原后两发相对预警最大横偏 5.71 米，及原固定掌拍最近边界距台心约 8.44 米。现按合法落点与真实可见投射物验证覆盖。实际验收包括速度、弹体飞行时间、同轴三弹、扇形散射、两类多枪轮次、桥面移动和断地演出。
- 恢复状态时重发足量预警，然后开放伤害。保留部件真实击破账和外环坍塌进度。旧档已进入中央核心阶段时，平台走面照实恢复，开放同一停机交互。避免读档或跳过演出后直接生成未提示伤害。
- 使用正式关卡与真实渲染覆盖第一次完成接管、一次剧情跳过、一次重新刷入，以及只剩任意一侧大臂的四种情况。测低移速近战、常规远程、无弹药收尾三套配置。验证四个角落都能只用普通移动撤入内侧九格，三次点射沿同一锁定轴线且不生成长条，读档不会偷伤，枪架不作为伤害或辅助瞄准目标。单独验证强命中反馈与减震设置下的地面可读性。
