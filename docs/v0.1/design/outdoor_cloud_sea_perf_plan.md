# 室外云海帧率专项优化方案

状态：规划稿（未执行，待主人批准后按阶段开工）。依据：[室外云雾设计](outdoor_cloud_sea.md) r4、v002 交付记录的"品质优先未专项优化"遗留项，与 2026-10-04 塔间高空俯视掉帧反馈（60→25fps）。前提：塔间地图布局未来固定，程序城市"每局随机"约束解除。目标：最坏视图（塔1-塔2 高空俯视云海）稳定回到 60fps 上限，视效不可辨差异；不降低默认品质换帧率。

## 基线与问题定义

实测口径：RTX 4060 Ti / Forward+ / 高画质。main 视角云增量 ~5.6ms（1280×720，2026-10-03 诊断）；俯视视图帧时间 16.7→40ms，云增量推算 `40 − 16.7 ≈ 23.3ms`（P0 探针确认后为准）。

俯视是本架构理论最坏情况：代理盒全屏覆盖 × 96 步 raymarch × 每步 8 次密度求值（1 主 + 4 光步 + 3 梯度），且缝隙处 alpha 难达 0.985 早停线，多数像素跑满全程。

帧预算公式：`帧ms = 场景其余 R + 云增量 C`，目标 `R + C ≤ 16.6ms`。R 待 P0 实测（按 main 视角外推预计 9~13ms）。

## P0 基线探针（先行，约半天）

新增俯视探针：塔1-塔2 高空相机固定机位，clouds on/off 对照，取 GPU 中位并分解场景其余成本；同时复测 main/tower3 作为回归基准。产出性能 JSON 存 docs/art/outdoor_clouds/perf_plan/。**未确认 23.3ms 归属前不改 shader。**

## P1 零结构三连（预期 C：23.3 → ~9ms）

| 项 | 做法 | 节省 | 视觉论证 |
|---|---|---|---|
| alpha 早停 0.985→0.95 | shader 一行 | ~12% | 残余贡献 `(1−0.95)×0.96 = 4.8%`，低于 8bit 可见阈 |
| 俯视自适应降步 96→40 | 相机高于云顶且俯角超阈值时切档；透射按世界长度积分，步数减半时步距加倍、积分量守恒 | ~55% | 云顶 alpha 快速饱和；既有 jitter 掩盖步距变化 |
| 避让降频（每 2 步一查 + 插值） | 渐隐带宽 4m vs 步长 ~2m | 避让份额 ~40% | 边缘位移 <1m，低于人眼可辨 |

P1 合计乘数 ≈ `0.88 × 0.45 × 0.8 ≈ 0.32`（作用于 C 的 march 主体）。

## P2 像素数削减（预期 C 再 ÷3~4）

- **首选 A｜棋盘 + TAA**：fragment 顶部按 2×2 抖动模式丢弃 75% 像素，靠 TAA 时间累积重建（工程已开 TAA）。工程量约 1 天。风险：快速摇镜时云轮廓 shimmer，必须 A/B 实测裁决。
- **备选 B｜半分辨率 SubViewport 合成**：云层渲到半分辨率视口再合成，需深度共享与透明排序方案。稳健，工程量 3~5 天。

云为低频软体，两条路视觉目标一致：100% 缩放盲测无差异。P1+P2 后 `C ≈ 23.3 × 0.32 × 0.28 ≈ 2.1ms`。

## P3 固定地图红利：全量避让合并烘焙（地图冻结后执行）

700 条路线边界 + 200 栋城市楼 + 地表地基一次性烘进**单张**距离场 3D 纹理，沿用 256×80×288 R8 网格、烘焙时取与运行时完全相同的 min 距离 → **可承诺像素级一致**。运行时每次密度求值的避让成本降为 1 次采样；删除 fallback 循环、候选体素机制、城市九宫格全部路径。节省 ~1.5-2ms，shader 显著简化。前置：城市 seed 冻结；冻结前现有布局哈希缓存机制保留作过渡。

## P4 达标核算与兜底

- 预期终态：`R + 1~2ms`。若 `R ≤ 14.5ms` 则稳锁 60fps。
- 若 P0 测出 R 本身 >14.5ms：剩余瓶颈在场景侧（城市绘制/SSIL/SSR/阴影），云海侧做完本方案即止，场景侧另立专项，不混入本次。
- 兜底自动档：棋盘密度 2×2→3×3 动态切换，挂 RuntimePerformanceManager 既有 `quality_changed` 通道。

## 验收与门禁

- **性能**：俯视/main/tower3 三视图 GPU 中位，预热 25 帧测 90 帧，沿既有方法；对比基线为 P0 产出，不再引用 v002 的 11.9ms 口径。
- **视觉**：沿用 04a3b7c0 的 30 组视角×时段对照法并新增俯视组。P1-alpha 与 P3 承诺像素级一致（changed_pixels=0）；P1 降步/降频与 P2 走 `MAE ≤ 1/255` + 100% 缩放盲测截图 + 12 秒实时漂动视频。
- **账本**：VFX-ENV-CLOUD-SEA-3D 升 v003，性能预算段落改写。
- **回滚**：每项独立开关。P1 三项各自可单独关闭；P2-A 为 shader 顶部一个 uniform；P3 保留旧路径作运行时开关。

## 风险

| 风险 | 缓解 |
|---|---|
| TAA 棋盘在快速摇镜下 shimmer | A/B 实测裁决，不过关转 P2-B |
| 降步在低角度引入条带 | 档位仅俯视启用，带迟滞区间与步数平滑过渡 |
| 俯视判定在云顶附近抖动 | 进入/退出阈值留 5m 迟滞带 |
| 地图尚未冻结 | P3 后置且不阻塞 P1/P2 |
