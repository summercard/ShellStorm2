# 战斗奖励与物品流转｜功能设计 v0.1

功能ID：`WEAPON-COMBAT`、`WEAPON-OWNERSHIP`、`INVENTORY-SLOTS`、`REWARD-SERVICE`、`WORLD-LOOT`。工程版本：`0.1.0`；设计修订：r1（2026-09-24）。本页是这些功能的**玩法规则与验收意图主设计**；[04 技术施工](../04_技术施工_战斗与局内成长.md)记录当前接口、schema、实现差距，不改变本页目标。数值和具体内容以[内容数据库](../01_内容数据库说明.md)为准。

## 玩家目标与范围

- **[用户设计]** 每把获得的枪是独立物品，永久 `weapon_instance_id` 随装备、背包、地面、商店、保险、结算和存档流转；命运槽、弹药、配件和子弹模块跟随原枪。普通枪基础8个线性、不可逆的武器命运槽；可更换装配不占槽。三类命运作用域分属武器、角色和世界，不能因换枪互相串值。
- **[现行方向]** 战斗、搜索、清房和剧情产出先确定奖励，再按目标发放；玩家能从命中反馈、掉落实体、拾取提示和背包变化判断结果。奖励报告与实际发放一致，不把一次尝试显示成已获得。
- **[用户设计]** 基础背包12格；装备背包占专用装备槽，提供扩展格。换成较小背包或卸下时保留基础格与低索引物品，高索引溢出物应落到当前世界，不能静默删除。成功撤离带回原物及原格位；死亡按保险规则处理。

## 所有者与衔接

| 事实 | 唯一写者/协调者 | 下游 |
|---|---|---|
| 伤害结果 | 战斗/受击领域，具体组件见技术施工 | 敌人死亡与反馈；奖励不得直接从 VFX 判定 |
| 奖励解析与发放结果 | `RuntimeRewardCoordinator` 协调 `RewardService/RewardSink` | 地面物、拾取、任务结果；报告只表达已确认的 `grants[]` |
| 背包/保险格位 | `InventoryModule/InsuranceModule` | UI、商人、结算读快照，不另存平行集合 |
| 武器换装 | `EquipmentTransactionService` 协调完整实例 | 装配树是所持枪的运行投影，不是第二把枪 |
| 世界地面物 | 所属关卡场景/房间 | 拾取后转入背包；房间快照负责跨重载恢复 |

正式链路：`攻击意图 → 命中/死亡 → 奖励解析 → 发放口 → 房间地面物 → 拾取 → 背包/武器实例 → 结算/长期档`。剧情刷物和商人购买分别从自己的内容源进入同一物品身份规则。`weapon_content_id` 是枪型，`weapon_instance_id` 是具体枪，`attack_instance_id` 是一次攻击；不可混用。

## 命令、查询与事件（设计约束）

| 交接 | 必备输入/输出 | 拒绝语义 |
|---|---|---|
| 解析奖励 | 来源ID、事件ID、奖励Spec、确定性上下文 → 已解析项 | 无效Spec不伪造发放；相同事件不得重复发放 |
| 发放地面物 | 已解析项、房间ID/坐标 → 实际生成结果 | 找不到有效房间、实例化失败时报告失败；不得先报 `grant` 成功 |
| 拾取/换装/缩容 | 完整物品实例ID、目标格位或地面上下文 → 新归属快照 | 重复实例、无容量、落地失败时原物归属可恢复，不复制、不丢失 |
| 伤害到奖励 | 攻击上下文、目标ID、死亡事件ID → 可追溯奖励事件 | 同一死亡只触发一次；统一 DamageContext schema **[设计待冻结]**，目前远近战接口不同 |

## 数据与生命周期

内容ID只定义类型；`item_instance_id/weapon_instance_id` 定义可流转实物；奖励事件ID定义一次产出。创建、移交、地面化、拾取、撤离/死亡、重载都保持实例身份。共享物品在一个时刻只能有一个有效所有者。全局所有权账本**[设计方向一致、未实现]**；现阶段的集合去重不能声称跨所有场景/长期档闭环。

## 失败与验收

正常路径须追踪从敌人/搜索/剧情到地面、拾取、换装、结算的同一个实例；失败路径须注入无效Spec、无房间、满背包、缩容地面生成失败、写盘失败和重试，断言原物、魂与归属不丢不重。当前地面实体内部仍有旧 item 字典桥，缩容逐件生成失败回滚未验；这些是[技术施工](../04_技术施工_战斗与局内成长.md)记录的实施缺口，不是本设计已完成。逻辑入口：`verify_reward_ground_handoff`、`verify_equipment_transaction_service`、`verify_backpack_equipment_flow`、`verify_weapon_instance_contract_matrix`；正式掉落和命中反馈还须真实渲染验收。
