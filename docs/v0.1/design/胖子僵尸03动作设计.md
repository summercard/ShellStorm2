# 胖子僵尸03：动作与时间轴设计

修订r8，2026-10-03。编号03；AssetID `ENM-NORMAL-FAT-ZOMBIE03`；内容标识 `fat_zombie03`。登记入口：[怪物设计](怪物设计.md)。本页为制作目标；13段动画已制作；玩法状态、转向与局部混合已接入，见[运行配置](胖子僵尸03运行配置.md)。

## 1. 游戏怪物标准

定位为阻挡路线、逼迫绕侧的厚血近战怪。慢在察觉、提步、蓄力与收势，打击段必须迅速；不把整条曲线放慢来表现笨重。体重大、重心低，脚先承重，髋带胸，肩带肘腕；腹部仅短暂滞后，不持续软弹。轮廓以宽胸腹、低垂双臂和自然张手为主，攻击时双手不得遮住整个面部。

游戏内站立身高2.2m，地面至头顶，暂按普通怪kind与variant倍率均1制作：源高=2.2/0.70=3.142857m。未来倍率变化须重新核算，不能叠加隐藏缩放。Blender +Y朝前、+Z朝上；Godot -Z朝前、+Y朝上；脚底0，模型/骨架/Prefab对象Scale=1。T姿势横向展开不是身体碰撞宽度；后续用待机姿势胸腹和腿的包围范围定碰撞，碰撞参数单独验收。

首版配置建议：生命为同层基础近战怪4倍，单次伤害1.6倍；巡逻0.30m/s（按本次短腿步幅标定）、追击0.60m/s（按重踏步幅标定）；攻击周期2.5s、判定距离从手的实测落点反推。已接入运行配置：基准生命696、伤害19、判定1.55m，完整周期约2.5s。厚血不等于免疫硬直：普通命中只做局部反应，达到玩法硬直条件才打断；不得每颗子弹都触发全身停顿。

使用项目36根核心骨命名与独立Root；允许保留原蒙皮需要的脊柱中间骨、无名指和末端骨。36根核心存在不代表静止姿态、骨长和签名与其他怪相同，不能直接共享Action。512×512 sRGB颜色贴图、1材质，保留UV；脸、拳头、领带与腹部在俯视镜头仍可读。制作模型/动作双母版，骨架ID与签名必须相同。

## 2. 时间与运动统一规则

30fps；F0为起始采样，时间t=F/30。循环动作在Fn放闭合键，播放区间[0,n)，不多播重复帧；单次动作播放至Fn后保持。下列距离与落地容差均指游戏空间，源空间除以0.70。Root固定，水平移动、转向、碰撞、伤害、死亡由玩法控制；Hip只做视觉重心偏移，不积累根运动。

蓄力使用缓入、清晰停顿；出拳用2—4帧加速，不沿用蓄力缓入。关键重击处允许1—2帧姿态压实，但不冻结游戏时间。落地以支撑脚锁地，身体下沉3—6cm；恢复有一次小幅回稳，禁止反复弹簧。腹部与头的跟随延迟2—3帧、幅度小于主动部位一半。双臂、腿、髋不伸长，非Root骨Scale固定1。

## 3. 六段必需动作

### idle｜压重待机，3.2s，F0—96，循环

双脚比肩略宽、膝微屈，胸前压约8°，肘松垂、手掌自然张开靠大腿外侧。F0—24慢吸气，胸抬1.5cm、腹部稍鼓，头仍压低；F24—48呼气，重心向右移2cm，右腿承重；F48—72回中再向左移2cm，左肩迟2帧下沉；F72—96回到F0。脚掌不移动、不做原地踏步；视线保持敌人方向。接入休眠时钉F0，不把呼吸当感知行为。

### walking｜沉重巡逻，2.0s，F0—60，循环

步幅小、双脚不同时离地，腰摆小于6°。F0左脚刚落地；F0—6双支撑，左腿接住重量；F6—18右脚提起并前摆，脚底最高6cm，上臂略抬、肘自然弯曲约35°，双臂反向摆动8°；F18—30右脚下降，F30落地，髋在摆动中抬起、落地时压低2.5cm，F30为重心交接。F30—60左右交换重复。接触帧F0/F30给脚步声与轻尘候选标记。身体沿真实速度移动，步频可在0.85—1.15倍调节；超过范围应重做步幅，不允许长距离滑脚。

### running｜低速压迫追击，1.2s，F0—36，循环

名称沿用追击契约，表现为张臂重踏，强调笨重而夸张的追赶。双上臂向外张开约55°，屈肘约45°、手掌自然展开，顶视角两臂与胸腹之间保留可读空隙。身体前倾约16°，胸肩侧摆约±9°、扭转约±10°，头部延迟2帧反向稳住视线，髋左右移重约4cm。禁止靠缩放骨骼制造软塌。

F0左脚重踏，髋压低；F0—4双支撑，胸肩仍沿上一拍方向惯性扭摆；F4—11右脚提起向前，最高9cm，髋抬起6cm，左臂前摆、右臂后甩约24°；F11—18右脚快速下降、身体压回，F18右脚接触。F18—36左右交换。肩胸、腰腹、头部依次错开1—2帧，允许一次压实回稳，禁止持续弹簧。保留双支撑、无腾空；参考速度0.60m/s，后续玩法按真实速度匹配播放倍率，不直接以旧1.0m/s套用。F0/F18为脚步声候选标记，未绑定声效。Root固定，所有摇晃集中在Hip与上半身。

### attack｜双手张开向内抱扑，2.5s，F0—75，单次

F0—12屈膝沉重预备，双肘向外抬；F12—26两臂大幅展开、手掌张开，胸肩稍后仰，形成顶视可辨的宽弧剪影。F26—30保持最大张臂4帧，预警结束，F30锁定攻击方向。腿脚承重不滑动，Root不突进，扑势由髋前移和胸肩前压表现。

F30—36用6帧爆发，髋先向前压约10cm，胸前倾约30°，双上臂向前绕合、小臂向内包围，双手在胸前远端以掌面相对拍合，手掌立起、手指朝前，肘部外撑，避免掌指互穿或穿入胸腹。F36（1.20s、48%）为首次命中采样，判定窗F36—40，每目标只结算一次。F36—38保持压实2帧；F38—44略向前下方压过命中姿态；F44—54保持沉重失衡暴露；F54—69收回双臂、髋后撤，F69—75恢复自然张手待机。首尾接idle F0，动作不循环，末帧保持。

仅制作视觉动作与候选时间标记；真实碰撞、伤害、击退和命中声效归玩法，未接入前不得声称有抓取或位移能力。玩家可利用大前摇绕侧，落空后有清晰恢复窗口。

### hurt｜重击硬直，0.8s，F0—24，单次

只在玩法进入stagger时使用。F0—3胸被打回8°、头迟1帧，拳张开但不飞散；F3—7髋后移4cm、后脚接住重量，颈保持连续；F7—11停在失衡峰值4帧；F11—19从腿与髋恢复，肩再回中；F19—24恢复自然张手并回待机。视觉不得推移角色根；真实击退由玩法控制。打断攻击时从当前姿态过渡3帧，不闪回T姿势；死亡随时可覆盖此段。

### dead｜跪塌前扑，2.6s，F0—78，单次末帧保持

死亡立即停止伤害与AI，动作仅负责倒地。F0—8失力，F8起解除脚底锁定；F8—28身体向前倒，髋带双腿翻转、脚跟离地，双臂前伸。F28—34胸腹加速砸地，F34为落地声候选。F34—40身体弹起约10cm，小腿惯性上甩，头肩稍迟跟随；F40—47重落地，F47—52仅约2cm余震；F52—60腿部落回、身体停稳，F60—78完全静止。双脚不得粘住站立位置，落地时腹部接触形态键压平底面并向两侧展开，抬起时部分恢复；不缩放骨骼制造弹性；Root固定、地面不得穿透。回收至少容纳2.6s，落地音不重复。

## 4. 基础补充动作

### awaken｜唤醒，1.2s，F0—36，单次

用于从休眠正式激活，需激活表现接口。F0—8先抬眼、头上提；F8—20双肩抬起、胸离开下垂姿势，膝伸直一半；F20—28双手保持自然张开、两脚保持原位；F28—36压回idle。不跳起、不吼叫拖长流程；途中受重击或死亡立即转对应段。

### alert｜察觉定身，0.6s，F0—18，单次

F0—3头朝目标迅速抬起；F3—7胸转向、右臂略抬；F7—12保持5帧辨识停顿；F12—18降低重心准备追击。与awaken区别是先看再压重，不重新站起。方向来自感知系统，不通过骨动画转玩法根。

### turn_l / turn_r｜原地换脚转向，各0.8s，F0—24，单次

以向左为例：F0—6右腿承重；F6—12左脚轻抬并朝新方向摆，髋跟随实际yaw；F12左脚落地；F12—19右脚收回站距；F19—24肩与头回中。右转镜像，但保留右拳较高的不对称。剪辑Root不写yaw，表现读取转角进度；跨越180°用连续换脚，不单帧扭腰。行走中小角度转向仍用移动动作。

### move_start｜起步，0.4s，F0—12，单次

F0—4髋前压3cm、胸压低；F4—8支撑脚锁地、另一脚抬起；F8—12落入walking F0的接触相位；接running需另行过渡。速度由导航加速，动作不移动根；连续短距离追击不重复触发起步。

### move_stop｜刹停，0.6s，F0—18，单次

F0—5前脚踏稳、髋下沉5cm；F5—10胸继续前压再由腰腿截住，拳向前惯性摆动一次；F10—14后脚归位；F14—18落回idle。支撑脚离目标过远时优先保留导航位置，禁止动画拖角色后退。

### hit_light｜普通受击，0.3s，F0—9，单次局部叠加

F0—2受击胸肩快速缩2—3°；F2—4停2帧，头跟随1°；F4—9回零。以Waist以上局部骨制作，当前为局部替换轨道，接入时需过滤混合；不直接当加法差量使用，Hip、脚和Root不参与；左/右来源使用对应肩侧权重，不翻转整个角色。连击重新采样局部反应但不叠大振幅；攻击F30—40期间只闪白/局部微反应，不覆盖挥拳轨迹。硬直条件满足才切hurt。

## 5. 状态、判定与交付

基础映射：dormant→idle F0；idle→idle；patrol→walking；chase/search/return→running；telegraph/attack/recovery→attack；stagger→hurt；dead→dead。alert可使用新增alert，否则明确回退idle；awaken、转身、起停和局部受击是表现扩展，不擅自新增AI状态。

attack分段采样保持项目48%边界：telegraph映射F0—36，attack执行玩法判定后钉F36，recovery从F36连续采样到F75。F36—40判定窗为本怪待接入设计；若当前实现只有瞬时判定，先保持唯一F36命中，扩展窗口需同步战斗验收。首版目标前摇1.2s、恢复1.3s，实际配置须匹配，不能把2.5s剪辑压成快速攻击。动画事件只提供表现标记，伤害由Enemy3D执行。

交付13段命名精确且独立的Action：六段必需及awaken、alert、turn_l、turn_r、move_start、move_stop、hit_light。三个移动/待机循环，其余单次；镜像转身必须检查骨侧与关节，禁止用复制idle冒充动作。AnimationPlayer按状态真实进度手动采样，切换默认3帧混合，重击命中点禁止混合抹平，死亡立即接管。

验收逐帧检查Root固定、骨长与权重不变、支撑脚误差≤1cm、地面无穿透；检查F30/F36/F40/F75、死亡落地与末帧。循环连续两轮无跳帧；俯视、正侧面均能读出预警和重击。运行测试须覆盖低速追击仍running、高速巡逻仍walking、空挥不伤人、单目标不重复受伤、受击不延迟伤害、死亡退组与回收。记录动画源/GLB哈希、骨架签名、时长、循环、事件与截图后方可转正。
