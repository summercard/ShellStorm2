# 远征全息城市交互

FeatureID：WORLD-ENTRY / BASE-FACILITY。版本：0.1.0，表现修订 r3。
来源：2026-09-29 用户参考图及本次明确要求。状态：运行时已接入，视觉待用户验收。

玩家在中央全息平台前按 E，玩法镜头连续移动到平台上方斜俯视近景；原全息投影收起，由盒形建筑从投影面分批升起。蓝青色轮廓、紫红重点、深色立体楼群、悬浮方块和楼顶导航构成可交互城市。建筑分布由中心密集向外围稀疏自然衰减；开场先升起并点亮主楼，再错开升起远征 01 与测试 99，周边楼群沿径向延迟展开，每栋建筑从底向上生长，常驻时继续独立错相起伏和扫描。

不使用全屏平面选关面板。关卡入口是城市中两座楼上的世界空间对象：`expedition_01` 与 `99`，名称及目的场景读取 GameDesignConfig。鼠标悬停/点击选择，WASD、方向键或手柄方向切换，确认进入；Esc/B 或城市返回标识退回，镜头沿原位连续恢复。过渡期间吞掉玩法操作，关闭后恢复此前 HUD、相机、原投影与输入。

RogueMapSelectMenu 保留设施生命周期适配器身份，是镜头、选择及退出状态的唯一所有者；HologramCity3D 只负责空间几何与动画。CanvasLayer 不含 Control，实际内容为同世界 Node3D。城市锚定被激活设施的投影中心，不移动作者设施。没有有效设施/相机时拒绝进入并释放适配器。

命令：set_facility / set_player / request_close / confirm_selection；查询：is_camera_override_active、当前选项及城市节点。状态顺序：opening → active → closing/entering。反复确认仅允许一次出发。退出或外部卸载必须释放临时世界节点、恢复相机与投影。

出发沿用已有落盘、解除检查点提供者、写入携带标记、GameEntryFlow 请求、ExpeditionLoadingScreen 的唯一链路，不复制入场规则。选中不写档；非法关卡拒绝；写盘或切场景失败恢复可操作状态并显示空间内错误提示。

验收：真实平台锚点、近景与两入口投影在视口内、无平面 Control、逐块动画、带窗口鼠标/键盘派发、关闭中重入拒绝、HUD/摄像机恢复、重复打开与出发 ID。真实渲染截图作为表现证据，headless 不代替输入及视觉验收。

## 动画节奏与 UI 特效归属

完整展开 4.4 秒，退出 3.6 秒，途中退出从当前进度连续反向，不重新播放或闪切。镜头先完成大部分靠近（进度 0—0.55），背景仅在进度 0.44—0.72 压暗；反向时先收楼，再恢复环境，最后拉回玩法视角。城市部署窗口提前一秒至进度 0.122727—0.772727，保留原动画速度。拉近前段继承玩法环境与后期，到全息已经展开后才渐变为城市环境。主体覆盖参考红框的大部分区域，外围追加高低错落的孤立建筑，不保留整圈空黑。

部署进度内主楼 0—0.272、入口 01 为 0.24—0.46、入口 99 为 0.46—0.68；外围依径向距离和固定随机种子延迟至 0.99 完成。楼群常驻保留独立错相波动与竖向扫描。升降前沿伴随六方块簇，完整展开和完全收回时粒子隐藏；退出倒序回收。原全息投影在近景阶段渐隐。

资产归属 UI，不进入战斗特效池或场景组件账本。沿用 UI-SCREEN-LEVEL-SELECT，文件入口 assets/art/ui/expedition_city/hologram_city.tscn；同目录 README 明确唯一源、着色器、运行时脚本及测试归属。账本标记“原型已接入”，不虚报参考图像素级一致或美术终验。
