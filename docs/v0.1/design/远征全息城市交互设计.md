# 远征全息城市交互

FeatureID：WORLD-ENTRY / BASE-FACILITY。版本：0.1.0，表现修订r9（2026-11-10居中锁头与后排入口放大）。
来源：2026-09-29 用户参考图及本次明确要求。状态：运行时已接入，视觉待用户验收。

玩家在中央全息平台前按 E，玩法镜头连续移动到平台上方斜俯视近景；原全息投影收起，由盒形建筑从投影面分批升起。蓝青色轮廓、紫红重点、深色立体楼群、悬浮方块和楼顶导航构成可交互城市。建筑分布由中心密集向外围稀疏自然衰减；开场先升起并点亮主楼，再按现行清单错开升起四个正式远征目标，周边楼群沿径向延迟展开，每栋建筑从底向上生长，常驻时继续独立错相起伏和扫描。

不使用全屏平面选关面板。关卡入口是城市中按登记与解锁状态列出的世界空间对象（正式顺序 `expedition_01`、`expedition_03`、`expedition_02`、`expedition_04`；99开发入口隐藏），名称及目的场景读取 GameDesignConfig。鼠标悬停/点击选择，WASD、方向键或手柄方向切换，确认进入；Esc/B 或城市返回标识退回，镜头沿原位连续恢复。过渡期间吞掉玩法操作，关闭后恢复此前 HUD、相机、原投影与输入。

RogueMapSelectMenu 保留设施生命周期适配器身份，是镜头、选择及退出状态的唯一所有者；HologramCity3D 只负责空间几何与动画。CanvasLayer 不含 Control，实际内容为同世界 Node3D。城市锚定被激活设施的投影中心，不移动作者设施。没有有效设施/相机时拒绝进入并释放适配器。

命令：set_facility / set_player / request_close / confirm_selection；查询：is_camera_override_active、当前选项及城市节点。状态顺序：opening → active → closing/entering。反复确认仅允许一次出发。退出或外部卸载必须释放临时世界节点、恢复相机与投影。

出发沿用已有落盘、解除检查点提供者、写入携带标记、GameEntryFlow 请求、ExpeditionLoadingScreen 的唯一链路，不复制入场规则。选中不写档；非法关卡拒绝；写盘或切场景失败恢复可操作状态并显示空间内错误提示。

验收：真实平台锚点、近景与四正式入口投影在视口内、无平面 Control、逐块动画、带窗口鼠标/键盘派发、关闭中重入拒绝、HUD/摄像机恢复、重复打开与出发 ID。真实渲染截图作为表现证据，headless 不代替输入及视觉验收。

## 动画节奏与 UI 特效归属

普通楼群及外围独立建筑的下沿使用 2×2 中等方块形成浅阶梯过渡：四块宽度均为楼宽的一半，底缘高低有限错落，保持轴向对齐和连续连接。过渡深度不超过楼宽的 48% 或楼高的 32%；不加入细碎悬浮残片。

完整展开 4.4 秒，退出 3.6 秒，途中退出从当前进度连续反向，不重新播放或闪切。镜头先完成大部分靠近（进度 0—0.55），背景仅在进度 0.44—0.72 压暗；反向时先收楼，再恢复环境，最后拉回玩法视角。城市部署窗口提前一秒至进度 0.122727—0.772727，保留原动画速度。拉近前段继承玩法环境与后期，到全息已经展开后才渐变为城市环境。主体覆盖参考红框的大部分区域，外围追加高低错落的孤立建筑，不保留整圈空黑。

原双入口部署分段为主楼0—0.272、01为0.24—0.46、99为0.46—0.68；现行正式四目标不再把99作为正式入口，入口最终展开遵循下文r8清单；外围依径向距离和固定随机种子延迟至 0.99 完成。楼群常驻保留独立错相波动与竖向扫描。升降前沿伴随六方块簇，完整展开和完全收回时粒子隐藏；退出倒序回收。原全息投影在近景阶段渐隐。

资产归属 UI，不进入战斗特效池或场景组件账本。沿用 UI-SCREEN-LEVEL-SELECT，文件入口 assets/art/ui/expedition_city/hologram_city.tscn；同目录 README 明确唯一源、着色器、运行时脚本及测试归属。账本标记“原型已接入”，不虚报参考图像素级一致或美术终验。

## 入口反馈与关闭时序（r4）

入口标记的悬停倍率取 1.32（原 1.09），并以每秒 14 的收敛率平滑逼近目标值，移开鼠标即原路复原，不做瞬时跳变。四条边框由 `hologram_frame.gdshader` 绘制：线宽由 0.032 加粗到 0.05（原宽度在近景下只有一两像素，流光跑起来看不出光带）；每条边按自身占周长的比例写入 `arc_span`、按在周长上的起点写入 `flow_offset`，合起来是一条以 0.42 圈/秒绕框环流的亮带，光头约占周长三分之一并向后拖出长尾。`hover` 只抬高流光与整体亮度（`energy = 2.0 + 1.2 × hover + flow × 9.0`），常态描边保持与旧 `_material(color, 2.0)` 相同的发光当量，因此不悬停时外观不退化。

### 焦点与选中必须分开

放大、流光、标签高亮由**焦点**（`HologramCity3D.focus`，-1 表示无）驱动，而 Enter/A 的确认目标由**选中项**（`RogueMapSelectMenu._selection`）承担。二者语义不同，不能合并成一个变量：

- **选中项在光标移开时故意保留** —— 否则把鼠标挪到一边再按 Enter 就没有目标了。
- **焦点必须如实反映"当前指着谁"，包括指向空白（-1）** —— 否则移开光标后入口会一直保持放大，直到悬停到另一个入口才换人缩小，正是"不悬停到别处就不复原"的毛病。

因此 `_input` 收到鼠标移动时，`_pick` 返回 0/1 就同时更新选中项与焦点、返回 2 或 -1 则只把焦点置 -1；键盘与手柄方向切换走 `_shift_selection()`，把焦点一并带过去（否则光标停在空白后按键看不出选中了谁）。城市每帧把 `focus` 同步给 `hover` 目标，焦点为 -1 时全部入口按 14/s 收敛回静止尺寸。

点击入口先触发 0.34 倍脉冲（`HologramCity3D.punch_marker`），脉冲按每秒 5 衰减回零，形成放大再回弹的手感。`change_scene_to_file` 会立刻接管画面，不留时间就只剩一帧脉冲，因此 `_enter_level` 保留 0.18 秒展示窗口后才执行原有出发交接；这段窗口只推迟展示，不改写盘、检查点提供者与 GameEntryFlow 的既有链路。

关闭不再复用 opening 的进度映射。按下 Esc/B 的瞬间记录当时的 `_progress`、城市部署值与相机缓动值，closing 改以归一化进度 `q`（按下为 1、结束为 0）连续收敛：相机 `eased = 按下值 × q^1.35`、楼群 `deployment = 按下值 × q^1.6`，指数大于 1 即"起步快、收尾慢"。原实现直接反向 opening 映射，使相机在按下后静止 1.62 秒、楼群静止 0.82 秒 —— 这正是"按 Esc 没反应"的来源。新曲线在按下当帧即产生位移，且起点等于按下时的真实状态，途中退出不跳变。closing 仍按当前进度比例计时（`_progress` 归零即释放），开场早期取消照旧是快的。

## 居中红锁与后排图标尺寸（r9）

来源：2026-11-10用户明确要求“锁头的标志可以直接在关卡图标中间，大一点；后面两个关卡的图标也可以大一点，但是不要比前面的大”。本修订只改视觉，不改变锁定、鼠标命中、键盘/手柄确认和永久进度Owner。

- 锁头位于入口牌面局部中心 `(0,0,0.25)`，整体等比放大到原几何的1.30倍；保留红色锁体、U形锁梁、扫描线和呼吸发光。锁定时用锁头占据牌面中心，关卡名称移到牌面下方、提示再往下，目标编号移到牌上方，避免大锁压住文字；解锁后隐藏锁头，名称/编号/提示恢复原牌内布局。
- 后排 `expedition_02`、`expedition_04` 的基础标记倍率由0.78提高至0.95，即线性尺寸增大 `0.95/0.78-1≈21.8%`；前排数据库和无限公馆保持1.00。统一基础世界比例仍为0.09，位置、城市生成随机流、相机推进和交互反馈曲线不变。相同交互状态下后排不大于前排；透视投影需用正式相机实拍检查。
- 红锁、扫描和呼吸属于 `UI-SCREEN-LEVEL-SELECT` 父资产内嵌程序表现，不新造不存在的道具Prefab。钥匙与台座按各自已有稳定ID登记；台座四槽、线路上扫、N/4常亮环和脉冲属于台座内嵌表现。
- 验收覆盖0/4三锁、1/4两锁、居中与放大、后排倍率上限、名称不遮挡、解锁后布局恢复，以及原有导航/输入/关闭恢复回归。截图需真实渲染，用户目录在Autoload前隔离。
