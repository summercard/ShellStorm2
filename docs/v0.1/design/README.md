## 按关卡编号归类的关卡设计

上面那张表按**功能**归类（一个 FeatureID 一页主设计）。**关卡是内容、功能是系统**，所以另有一条按「关卡编号」归类的轴，两者不互相替代：功能页回答「这个系统应当怎样工作」，关卡页回答「这一张关卡长什么样、玩家怎么走、改版图走哪条流程」。

**关卡设计页不是账本文档，也不替账本记账。** 资产事实（AssetID、版本、制作状态、源文件路径、GLB/Prefab、哈希、授权）的**唯一权威**是[美术资产账本](../../../assets/registry/README.md)及其 9 本分账本；关卡设计页只写「这一关需要什么、为什么这么摆」，需要时**转述**账本状态。转述一律经 AssetID 对接 —— **不靠中文名**，因为同名房间可能是不同资产、同一资产也可能被多关复用。转述表的同步由门禁盯住：账本一改，设计页必须同轮改。

反向也成立：账本**不记录**关卡意图。所以「这一关该有几间房、房间怎么连、内容怎么分配」只在设计页，「这个房间种类做到哪一步了」只在账本 —— 两边各答一半，缺一边都查不到全貌。
