# 天台参考组件库

功能ID：`ASSET-ROOFTOP`；主模块：`ASSET-PIPELINE`；设计修订：r2；工程版本：0.1.0。

来源：2026-09-17用户提供的天台组件与组合效果图，并明确要求外墙与通用墙同规格。归属`rooftop / 100F`。本批是可复用Blender组件库，不替换90×80m天台基础结构。当前用户已要求清空运行场景屋顶设施，组件库仍未接入。

## 范围和视觉

制作图中九类：五种地面、直/外角/内角女儿墙及挂藤版本、房间前后左右墙、三种房顶板、六种机电设备、五种管线、门灯和雨棚、四种绿化、门垫/排水口/壁挂通风箱。补充标准外墙实墙和带窗外墙。房间正背面是装配关系；空调、门、花箱保持独立。藤蔓保留独立包，另提供用户要求的挂藤墙体变体；变体可整合输出，但制作源中的叶片、茎和墙体仍可单独编辑。

用户追加要求：墙体需要带藤蔓版本，门口必须厚实且有可见进深。v002在原37包上增加外角/内角女儿墙、房间实墙/窗墙/门洞墙、外墙实墙/窗墙共7个挂藤变体；这些是稳定基础包的装饰变体，独立藤蔓也继续保留。门包增加厚1.10m的石材门柱、深1.16m的门楣和深1.55m的门槛，门扇及原门洞净空间保持。藤蔓超出的包围盒只作美术包络，外墙主体及未来阻挡规格不变；通过结构中心偏移吸附，不拿装饰包络决定墙体接点。

优先保留参考图灰色水泥分缝、压顶、深色窗、百叶、风扇护网、金属管卡与绿植；使用公共色盘冷灰列，不引入私有纹理。斑驳通过局部多边形色块表现，受纯色色盘限制，不声称等同照片级材质。植物、花箱和盆栽本批为固定展示附件，无拾取/装备语义。

## 尺寸与接口

- 坐标：Blender Z-up、米；可复用包XY居中、底面Z=0、正面-Y；正面与通用库+Y的差异以包元数据显式声明，装配不依赖隐含朝向。
- 外墙严格5×0.30×11.9m；逻辑及未来碰撞5×0.30×12m，底部基准不变。不把女儿墙当作12m阻挡。
- 房间墙同样遵守11.9m可见高度，以5m标准段装配；门墙完整占5m槽，门洞3.8×6.8m。参考房间装配20×20m，不作为正式游戏建筑的尺寸变更。
- 地板5×5×0.30m，半块2.5×5，角块2.5×2.5，内角为三个2.5m象限。独立制作底面Z=0；装配时Z=-0.30使完成面Z=0；未来运行时包装需显式锚点转换到既有厚度居中地砖契约。
- 女儿墙5m长、0.50m厚、1.8m高；转角用2.5m臂，压顶不越模块端面；角件端点和直件端点明确登记。
- 房顶板5m模数，厚0.30m，房间墙顶11.9、板底12.0，保留0.1m缝。
- 管道端面径向接口、房顶边缘/内角、外墙端面/顶底接点写入manifest；所有材质仅四种共享角色。

## 工程边界

事实所有者为组件库`catalog.json`及对应版本Blend；稳定父ID `ENV-ROOFTOP-REFERENCE-COMPONENT-LIBRARY`，子`package_id`标识几何变体。schema=1，记录版本、分类、局部原点、尺寸、正面、插槽、碰撞建议、依赖、导出状态与源路径。命令是版本化制作脚本，查询是catalog/manifest；无运行事件和存档字段。

无效尺寸、空包、多包归属、非唯一色盘、UV跨格/零面积均拒绝验收。生产失败保留旧源与游戏引用，重跑只发生在未发布的新版本；已发布几何更改升版。原天台v021、基地v026和通用组件库v003是范围外锁定文件，校验前后SHA256不变。

正式接入仍由`TowerFloorStage3D`/区块PackedScene拥有；本批不导出GLB、不生成Godot碰撞、不替换运行引用；旧聚落设施加载入口已按用户要求移除。下一阶段从独立包导出GLB且禁止内嵌色盘，由共享导入器绑定公共色盘。

## 独立验收

独立入口为版本`qa/`脚本：重新打开Blend检查包/目录/唯一归属、尺寸/原点/端点、锁区哈希；严格运行`validate_game_prop.py --all-meshes`检查所有制作源与输出；渲染固定参考镜头全景、俯视、房间近景与组件分类页。完整原始效果图作为参考保存；新建资产无旧几何前后对比，用同相机与灯光的结构素模、最终图检查轮廓和材质。登记`3D-场景通用`，保留既有运行资产状态。
