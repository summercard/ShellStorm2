# 武器构建链路文本本地化设计

功能ID：`UI-LOCALE-TEXT`（**跨功能横切模块，不单独占用 MODULE_INDEX 的 37 项 FeatureID**）；模块ID：`PRESENTATION`；工程版本：`0.1.0`；设计修订：r1。
设计来源：业主 2026-10-14 指示（「把 K 键的枪械构建链路用中文，后面的构建链路全部显示中文，可以切换语言，预留空间，单独一个模块，更新设计文档」）；状态：**已实现（中文实装）· 英文预留**；主设计位置：本页。

## 1. 玩家目标与范围

玩家在正式 3D 战局按 `K` 打开**武器表现页**，在基地走**工作台**与**枪械工坊**时，看到的武器装配信息必须是可读中文，不允许出现内部 ID（`GunBody_Pistol`）、英文枚举键（`MOUNT`/`MUZZLE`）、裸属性键（`damage`/`fire_rate`）或英文稀有度（`COMMON`）。

范围（本轮）：

| 界面 | 入口 | 覆盖内容 |
|---|---|---|
| 武器表现页 | 战局内按 `K` | 标题、身份行、命运轨道、属性总览、装配树节点行、空槽位、节点详情弹窗 |
| 工作台（武器改造） | 基地工作台交互 | 当前武器装配串、枪身/子弹/命运卡分区标题、选择反馈 |
| 枪械工坊 | 基地 `weapon_workshop` 设施 | 蓝图类别标题与说明、Tier 进度、解锁/失败文案 |

**不可破坏的已有规则**：

- 内部稳定 ID（内容 ID、节点名、槽位键、属性键、存档字段）**一律不改**：本地化只发生在「显示层」，不触碰 `WeaponInstance` / `assembly_snapshot` / `BaseData`。
- 调试与日志口径不变：`WeaponAssemblyTree.get_assembly_tree_string()` 与 `get_weapon_info()["tree_string"]` 继续输出内部英文 ID，**不被语言切换影响**；玩家可见串另走 `get_localized_assembly_tree_string()`。
- 命运卡、HUD、背包等其它系统本轮不改；它们的文案由各自设计页负责。

## 2. 所有者与依赖

- **唯一文案所有者**：`src/i18n/GameText.gd`（静态类，`class_name GameText`）+ 语言包 `GameTextPackZhCN.gd` / `GameTextPackEn.gd`。
- **只读消费者**：`WeaponAssemblyTreePanel`（K 页）、`WorkbenchPanel`、`WorkshopMenu`、`WeaponAssemblyTree.get_localized_assembly_tree_string()`。
- **依赖方向**：`UI / weapons → i18n`。`GameText` **不依赖任何 autoload、玩法类或场景**，可在纯脚本上下文调用。
- **内容名权威来源**：`ItemRegistry`（物品 `name`）与 `BlueprintRegistry.ASSEMBLY_NODE_ITEM_IDS`（节点名 → 内容 ID）。`GameText.node` 表是它们的显示层镜像，一致性由探针钉住。
- 独立入口：`tests/verification/probe_localization_contract.tscn`（单跑探针，不占注册表名额）。

## 3. 命令、查询与事件

全部为**静态方法**，无实例、无信号。

| 类别 | 接口 | 说明 |
|---|---|---|
| 语言 | `get_locale() -> String` | 当前语言 id |
| 语言 | `set_locale(id) -> bool` | 切换；未知 id 返回 `false` 且**不改状态**；同 id 幂等成功 |
| 语言 | `all_locales() -> Array[Dictionary]` | 全部已登记语言（含预留位），元素 `{id,label,ready,code}` |
| 语言 | `ready_locales() -> Array[Dictionary]` | 仅已实装语言（供玩家选择控件） |
| 语言 | `locale_meta(id = "") -> Dictionary` | 单条语言元数据 |
| 查询 | `text(key, args = []) -> String` | UI 语义键；`args` 用于 `%s/%d` 模板 |
| 查询 | `node_name(raw) / node_type_key_name(k) / slot_key_name(k) / stat_key(k) / stat_value(v) / rarity_name(id) / location_name(id) / tag_name(raw)` | 各分域查表 |
| 查询 | `node_path_text(nodes) -> String` | 装配路径拼接（`"A / B"`） |

**错误码语义（失败即稳定、可断言）**：

- 未知语言 id → 拒绝（`false`），当前语言不变，不产生任何副作用。
- 未知键 → **回退到键本身**（`text("__x__") == "__x__"`），绝不返回空串；UI 宁可显示内部 ID，也不出现空白。

## 4. 数据与生命周期

语言包是**只读常量字典**，分 9 个分区：`ui` / `node_type` / `slot` / `stat` / `stat_value` / `rarity` / `location` / `node` / `tag`，另加 `node_prefix` / `tag_prefix` 前缀规则（如 `FateAttachment_*` → `命运配件·`）。

**回退链（唯一规则，三选一即定）**：

```text
查询 → 当前语言包该分区
      → 默认语言包(zh_CN)该分区
      → 原始键本身
```

- `zh_CN`：`meta.ready = true`，全量实装。
- `en`：`meta.ready = false`，**预留位** —— 条目留空，因此查表回退中文。启用步骤（日后）：① 把 `meta.ready` 改 `true`；② 按 `zh_CN` 同名键补文案。不填任何键也不会让 UI 空白，回退链会兜住。

**生命周期**：语言选择是**进程内状态**（静态变量），不写存档、不参与版本迁移；新语言 = 新增一个 pack 脚本 + 在 `LOCALE_ORDER` 登记，不改任何调用点。

**预留空间（排版约束）**：

- 语言按钮由 `all_locales()` 驱动渲染：新增语言自动多一个按钮，行高固定、按钮定宽（52×22），不挤压下方内容 —— 这就是「预留空间」。
- 未实装语言渲染为**禁用灰按钮**并占位（tooltip「预留语言（结构就绪，文案待实装）」）。
- 节点行内属性标签沿用既有固定列宽位移；跨语言等宽变动由容器承载，禁止依赖文本像素宽度拼接。

## 5. 拒绝与回滚

| 场景 | 可观察结果 |
|---|---|
| 语言 id 不存在 | `set_locale` 返回 `false`，当前语言与所有 UI 不变 |
| 语言包某键未填 | 回退中文 → 仍未填则回退键本身；不抛错、不空白 |
| 内容节点未登记 | 回退到内部节点名（如 `GunBody_New`），并由探针报告契约缺口 |
| 语言切换时面板已打开 | 调用方切换后自行 `_refresh()`；K 页在面板内切换即原地重绘 |
| 面板不可见 | 下次 `toggle()` 时按当前语言重建，无残留旧语言文本 |

## 6. 验收标准

`tests/verification/probe_localization_contract.tscn` 断言四组：

1. **内容节点契约**：`ASSEMBLY_NODE_ITEM_IDS` 覆盖的每个节点名，`GameText.node_name` 必须非原样、且与 `ItemRegistry` 的物品名逐字相等（漂移即红）。
2. **枚举键契约**：`AssemblyNode.NodeType` / `SlotType` 全部键必须有中文；未知键回退到键本身。
3. **面板不泄漏内部 ID**：实例化武器表现页、绑定 `bp_rifle + mod_bullet_piercing`、展开后遍历全部 Label，文本中不得含 `GunBody_`/`Bullet_`/`Att_`/`Melee_`，也不得含 `MUZZLE`/`MAGAZINE`/`GUN_BODY` 等英文枚举键。
4. **切换与回退**：`en` 必须仍是 `ready=false`；切到 `en` 时 chrome 与节点名都回退中文；未知语言 id 被拒绝；能切回 `zh_CN`。

**反向对照（已验证）**：把 `GunBody_Rifle` 的中文改成「步枪X」→ 探针 `exit 1`，报 `文案漂移：GameText=步枪X / ItemRegistry=步枪`；还原后重跑 `exit 0`。即断言真的会红，不是摆设。

跑法（工程内，隔离 `user://`）：

```text
独享 APPDATA + 项目根临时 override.cfg（config/use_custom_user_dir=true）
--headless --path . --scene res://tests/verification/probe_localization_contract.tscn
```
