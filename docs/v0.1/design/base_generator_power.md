# 基地发电机总电源

功能ID：`POWER-SYSTEM`；版本0.1.0；设计修订r2；来源：2026-10-20用户要求。

100层天台中央房屋东门南侧的发电机，是99层基地唯一总供电入口。玩家靠近按E启动或关闭。开启后基地获得供电，关闭后基地照明与用电设施停止工作。开关采用机械操作，断电时仍能启动。

`BaseManager.data.base_generator_enabled`唯一持有持久状态，默认true，旧档缺字段也视为已启动，保持既有基地初始状态。`set_base_generator_enabled(bool)`先按旧状态结算游戏时间，再保存新状态；成功发布`base_power_changed(bool)`，失败保留原状态。重复设置不重复写盘。查询为`is_base_power_on()`和`get_base_energy_snapshot()`。

现有100点基地电量作为储能预算保留。运行时每游戏小时恢复4点；关闭后暂停恢复，储能保留但可用电量为0，消费与恢复舱命令拒绝执行。重新开启不会凭空充满，也不补发停机期间的电量。储能耗尽不阻止发电机驱动照明；恢复舱仍须等待预算足够。暂不增加燃料、线路寻路和持续负载计算。

基地墙面灯开关保留局部控制权，最终灯光状态为总电源和局部开关共同决定。停电中止开灯启动过程；恢复供电后恢复停电前的灯光意图。用电设施包括任务全息台、武器工坊、合成台、怪物档案终端、售货机与恢复舱，断电禁止打开/使用；售货、工坊升级、合成提交及恢复命令也在执行时检查电源。仓库、收藏和衣柜保留使用。太阳光、玩家自带手电、楼梯与手动通道不受基地总开关控制，避免玩家被断电困住。断电不删除仓库内容或改变角色状态。

验收入口：`verify_base_generator_power`；正式入口：100层天台发电机。覆盖开关、停机时间、存档恢复、写盘失败回滚、恢复舱拒绝、照明断电与复电。工程接线和结果见[开发记录](../development/2026-10-20_base_generator_power.md)。
