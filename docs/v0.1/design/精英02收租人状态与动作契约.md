# 精英02收租人状态与动作契约

FeatureID：ELITE-ROSTER / ENEMY-AI / ASSET-PIPELINE。版本：0.1.0，契约 r2。来源：2026-11-04 用户要求按显示器 Boss 的方式正式调整状态机，并修复移动瞬移、反向行走及行动与动画不一致。状态：已实现并通过专项；验收事实见[开发记录](../development/2026-11-04_arms_taker_state_binding.md)。

## 所有权与接入

`Enemy3D` 继续拥有十二态、感知、目标、物理移动、碰撞、生命和精英名册；`EliteArmsTakerCombat` 是其拥有的行动时间轴，提供 begin/cancel/tick/presentation_context，与显示器 Boss 控制器相同的单向接线。表现包装只采样动画，不决定伤害或转移状态。内容 ID、投放窗口、生命、伤害、成长、夺械弹幕规则保持既有来源。

## 状态与时间

| 状态 | 行动与动画 |
|---|---|
| dormant / idle | 原地 idle；可见邻房允许呼吸，不推进攻击 |
| patrol / chase / search / return | 物理位移为唯一世界位移；按实际速度选择 idle/walk/run，移动方向与身体正面一致；撤离仍复用 return+既有逃脱标志 |
| alert | 保留通用0.30–0.60秒转身、图标启动；采样 idle，暂不把5.4秒 roar 塞进短启动窗 |
| telegraph | attack_light 原生0–40/30秒，锁定起手方向，停止自主追击 |
| attack | 40/30–44/30秒；40/30秒挥击最大前伸处结算一次近战与既有夺械弹幕 |
| recovery | 44/30–80/30秒；同一剪辑与同一行动时钟继续收招，不重播、不切追击、不产生第二次命中 |
| stagger | hit 原生2.0秒；取消尚未命中的行动，保留受击推力，连续轻击不每帧重启同一段 |
| dead | death 原生4.6秒；立即移除战斗碰撞与活敌人身份，保留视觉直到段结束再回收 |

40/30秒命中点来自当前源剪辑左手最大前伸采样；完整片段长80/30秒。首段、判定、收招共用同一个 elapsed，不再套普通怪0.38秒前摇和单物理帧 attack。暂不创造 block/dodge/jump/heavy/slam 的新玩法；这些源动作保留待独立设计。

## 坐标、原地动作与采样

源模型正面及 walk/run 的净前进方向实际为 +Z，包装的 VisualGLB 固定绕Y转180度，统一到 Godot -Z；包装根保持单位缩放与零变换。walk/run 的 Hip 平移含每轮约3.285/3.610米的净位移，表现适配器对实例独立的动画曲线去掉首尾线性漂移，保留步态侧摆与竖向接地曲线；不修改GLB源、不反向写玩法根。

每帧只有一个手动采样入口：play+seek。跨移动状态保留步态相位，步频由真实速度、角色缩放与实测步幅决定；被墙挡住时回 idle。过渡只混合源剪辑采样姿势，不叠加外壳bob/压扁，也不同时advance和seek争夺播放头。

## 中断、恢复与失败

硬直、死亡、休眠、精英逃脱或外部离开行动状态均取消旧行动。丢失目标时取消尚未命中的起手；已出手继续完成收招。命中帧重新验证目标存活、范围、前方扇区与世界遮挡。房间休眠重建沿用公共快照，行动态读档退回alert，不补发旧攻击。

外部击退/牵引按速度直接施加，不作为每帧累加的冲量；投射物的短击退沿用基类原时窗，不随2秒hit段延长。攻击段禁止自主追击，但仍接受这些明确的外部位移。

缺失动画明确告警并回idle；无匹配精英内容时不挂此控制器。静态首只精英、普通怪和显示器Boss保持各自既有接线。

## 验收

逻辑入口 `verify_second_elite_state_flow`：十二态、真实行动链、完整收招、命中时刻/次数、遮挡与失去目标、中断/休眠/冻结/逃脱、存档恢复、死亡回收、坐标朝向与循环边界连续性。真实渲染入口 `verify_second_elite_state_visual`：可见取景、行走与奔跑循环、状态切换、攻击和死亡帧，截图与连续帧输出到工程外。既有精英、普通怪和显示器Boss专项做回归。
