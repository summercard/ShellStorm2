# 精英02收租人状态与动作契约

FeatureID 为 ELITE-ROSTER / ENEMY-AI / ASSET-PIPELINE / VFX-POOL / WEAPON-OWNERSHIP / INVENTORY-SLOTS。适用工程 0.1.0、目标契约 r15、运行包装 v003、模型和动作源 v002。本页只定义收租人的目标规则、所有权、提交边界与失败语义，不代表整体实现、整体通过或整体验收。既有证据仍分别见[状态接线记录](../development/2026-11-04_arms_taker_state_binding.md)、[连续遭遇记录](../development/2026-11-04_arms_taker_roaming.md)与本轮开发记录。r14 只改受击盒几何（见下文“v002 表现与受击”），r15 只改体型起点与上限（见“生命、等级与撤离”），两轮都不动状态机与所有权。

## 所有权与接入

`Enemy3D` 继续拥有十二态、感知、目标、物理移动、碰撞、生命和精英名册；`EliteArmsTakerCombat` 是其拥有的行动时间轴，提供 begin/cancel/tick/presentation_context，与显示器 Boss 控制器相同的单向接线。表现包装只采样动画，不决定伤害或转移状态。内容 ID、投放窗口、生命、撤离和名册成长沿用原有来源。本契约定义收租人独立的近战、屏幕放电和失联重定位。

`Dungeon3D` 持有 `RoamingEliteRunDirector`，后者是同局连续遭遇计划与生命账的唯一所有者，不持有敌人节点。命令为 configure/observe_room/bind_actor/capture_actor/stage_escape/stage_death，查询为 pending_in/owns/keeps_actor/export_snapshot，import_snapshot 拒绝身份、schema 和数值范围不符的数据。敌人实体由公共生成与流送入口装配；首次绑定冻结生命，后续绑定从账中恢复。

能力入口为关卡计划 `monster_rules.roaming_elite` 的 enabled/elite_id/room_types。`world_state.roaming_elite` 使用 schema_version=1，保存 session_id、seed、room_budget、appearance_limit、appearances、visited_rooms、next_visit、status、room_id、max_hp、hp、damage_taken；状态为 waiting/pending/active/finished/killed。实体另存本次受伤、撤离进度和夺取序号。既有战局 schema 仍为 runtime_player_state_v2，旧快照缺连续遭遇字段时按本局种子初始化；已有敌人的生命快照按原记录恢复，不通过回满进行迁移。

## 状态与时间

| 状态 | 行动与动画 |
|---|---|
| dormant / idle | 原地 idle；可见邻房允许呼吸，不推进攻击 |
| patrol / chase / search / return | 物理位移为唯一世界位移；按实际速度选择 idle/walk/run，移动方向与身体正面一致；撤离仍复用 return+既有逃脱标志 |
| alert | 保留通用0.30–0.60秒转身、图标启动；采样 idle，暂不把5.4秒 roar 塞进短启动窗 |
| telegraph | 锁定行动与方向。轻扫、重击、屏幕放电和消失分别消费各自的前摇。 |
| attack | 轻扫或重击只在指定动画帧判定一次。放电只发一枚母弹。消失进入独立的隐匿时段。 |
| recovery | 延续当前动作收招。重现用扫描干扰逐步显形，结束后恢复追击与受击。 |
| stagger | hit 原生2.0秒；取消尚未命中的行动，保留受击推力，连续轻击不每帧重启同一段 |
| dead | death 原生4.6秒；立即移除战斗碰撞与活敌人身份，保留视觉直到段结束再回收 |

### 攻击选择与判定

- 近身且有视线时优先近战。轻扫使用 `attack_light`，在 40/30 秒结算，44/30 秒开始收招，80/30 秒结束。每第三次近战出手换为重击。`attack_heavy` 的右手前伸帧为 8/30 秒，映射到实际 0.72 秒，0.86 秒开始收招，1.65 秒结束。重击扇区更宽，伤害为接触伤害的 1.35 倍，沿用近战夺取规则。
- 屏幕放电的施法距离为水平 4–12 米，包含边界。要求玩家存活、视线无遮挡、玩家和锁定地板相对收租人脚底的高度差各不超过 1.5 米。先锁定玩家当时的地板坐标，屏幕从暗转为青白，地面出现定位环。0.70 秒从头部发射一枚速度 14 米/秒的电荷母弹，1.20 秒完成收招。独立冷却为 8 秒，从母弹发射时开始计时，起手被打断时可重新尝试。冷却余量随实体房间快照保存，旧档缺字段时按可用处理。屏幕发光限于模型显示面的原始 UV，离场和重现使用同一套身体扫描材质。玩家离开标记点可以避开，母弹在空中保持既定方向。墙或非地面阻挡消耗母弹，母弹不直接伤害玩家。
- 母弹在地板真实碰撞点按 45° 等分散出 8 枚电属性子弹。子弹离地 0.26 米，速度 4.4 米/秒，生存时间 2.1 秒，每枚伤害为接触伤害的 50%，至少 1 点。命中造成有效生命伤害时定身 1 秒，电弧随玩家持续。飞行电弹和定身电弧的可见尺寸为首版的 2 倍，并带青蓝色局部补光。定身阻止走动、冲刺及水平击退，保留重力、瞄准与射击。无敌或伤害全部被吸收时不施加定身。

### 追击失联与重现

一次追击累计 6 秒未进入攻击前摇时，尝试消失。攻击启动和脱战清空计时，短暂搜索暂停计时。施法前先确认有可用落点，0.45 秒身体扫描干扰后完全隐藏。前摇仍可被击退、硬直或死亡打断。隐匿期间关闭受击盒、移动阻挡、血条和屏外指示，保留同一实体及其生命、撤离计数、遭遇次数和归属房间。

隐匿 3 秒后按最新玩家位置和实际相机视锥重选落点。落点须在原房间边界内、与玩家至少相隔 4 米、有同层支撑并容得下全尺寸圆柱，整身须在镜头外，或同时被玩家视线与镜头方向的场景遮挡。0.45 秒扫描干扰重建身体，随后恢复碰撞。显形结束的同一帧重新检查放电射程、高度、视线与 8 秒冷却。如果符合条件，立即转向玩家并接 0.70 秒的放电前摇。该衔接由独立精英行动触发，采用技能自身冷却，不占普通怪的攻击排期。条件不满足时恢复追击或搜索。相机移动导致暂无安全点时每 0.25 秒复查。房间休眠、撤离、死亡、卸载或读档中断这次技能，回收视觉与临时判定。房间读档沿用行动态退回警戒的口径。

## 坐标、原地动作与采样

源模型正面及 walk/run 的净前进方向实际为 +Z，包装的 VisualGLB 固定绕Y转180度，统一到 Godot -Z；包装根保持单位缩放与零变换。walk/run 的 Hip 平移含每轮约3.285/3.610米的净位移，表现适配器对实例独立的动画曲线去掉首尾线性漂移，保留步态侧摆与竖向接地曲线；不修改GLB源、不反向写玩法根。

每帧通过 play+seek 采样一次。跨移动状态保留步态相位。走路和跑步按各自的支撑脚回摆曲线换算播放速度，并随实际移动速度和角色缩放调整。相位之间平滑插值，被墙挡住时回 idle。动作时间轴继续单独采样攻击、硬直和死亡。

## v002 表现与受击

新版模型保留用户交付的 UV、蒙皮及基础色、法线和金属度／粗糙度三张贴图。41 根骨骼按名称、父子关系及两版绑定姿势重定向原有 18 段动作。待机时单独校正左右靴底的接地高度。角色物理接地期间，完成动作采样与混合后，以当前左右靴底中的最低点对齐实际支撑面以下 0.001 米。跑步也遵循此规则，另一只抬起的脚继续跟随动作。移动圆柱底缘相对玩法根上提世界距离 0.001 米。死亡与角色物理离地时继续采样对应姿势和物理高度。

移动使用脚底圆柱。玩家子弹通过独立代理的 17 个盒命中：16 个跟骨盒（头、躯干、分段四肢、双脚）加 1 根贴地躯干补底柱。补底柱横截面为 0.21 × 0.119 骨骼单位（z 沿用腰盒，x 比腰盒宽，理由见 §生命、等级与撤离 的第 2 条兜底），顶边接腰盒顶边、底边每帧取当前姿态最低的靴底，因此始终与支撑面齐平且不会插进地板；它固定为世界轴竖直，不跟躯干倾斜。这一根替代了 r13 的“两腿之间留空”：按 1.0 倍量到 1 级的两腿之间未覆盖宽度为 0.448 米，已大于弹体直径 0.24 米；玩家枪口（约 0.75 米）正好落在腰盒底之下，留空会让中心线上的子弹整条穿过去。r15 把 1 级抬到 1.5 倍后该空档线性长到 0.672 米，问题只会更重。补底柱在 0.111 时代实测（1 级 idle，y=0.8 米处）还剩两条侧缝 0.096 / 0.168 米；这两条会随体型线性放大，`M > 2.14` 时最宽那条就超过弹径，于是把 x 加宽到 0.21。加宽后 1 / 6 / 12 级在 y = 0.75 / 0.80 / 1.20 处实测侧缝均为 0，不再存在可穿弹的横向空洞。双脚盒在 r4 基础上小幅扩大，覆盖更多靴面和靴尖。双脚盒分别采样当前靴底蒙皮，最低点与各自靴底对齐。盒子随当前采样姿态及实例倍率变化，命中由 Enemy3D 扣血，命中火花取接触点。死亡和撤离结算时立即关闭代理。

## 血条与档案显示

血条和档案显示已接入。99F二楼双屏电脑可打开怪物档案。选中已遭遇精英时，右栏以独立视口展示正式模型和待机动作，并显示持久档案状态、最近结局与有记录时的上次遭遇生命。见[终端与连续遭遇验收](../development/2026-11-04_monster_archive_and_spawn_isolation.md)。

头顶血条宽 2.05 米、高 0.12 米；高度由此前 0.23 米收细，旧存档恢复时也采用当前内容库的显示规格。名称、颜色和读血逻辑沿用公共精英血条实现。

首次实际生成并成功确认遭遇后，档案室立即公开收租人卡片，显示当前等级、状态、完整持有物品名称与数量、夺取货币累计值及已有转译装备。没有物品时明确显示暂无。预约但尚未成功生成的精英不算已遭遇。显示只查询 EliteRosterService，不另建 UI 存档；成长与夺取提交成功后通过 roster_changed 刷新。旧档按遭遇次数、逃脱/死亡记录识别已遭遇。

**首遇会在 99F 基地被提醒（2026-11-04 用户设计）**：首次确认遭遇后回到 99F，绿苔 NPC 站到归航点边上，玩家走近 4 米内自动说出用户原话（「你遇到收租人啦？有没有被夺走东西呀？你可以去二楼的档案室里看看它的信息哦。」）并指向本节的档案终端，随后回到巡逻线，跨存档只播一次。判定只读 `encounter_count`（预约不算），落盘复用 `narrative_history` 的 `npc_beat:` 命名空间。契约与失败收口见[基地NPC §13](../20_技术施工_基地NPC.md)，验收 `verify_base_npc_story_beat`。本契约只负责"档案里有什么"，不负责这句提醒的触发。

## 生命、等级与撤离

收租人的初始最大生命、伤害、攻击频率和体型必须由等级成长规则计算，不能由表现倍率或旧版常量旁路覆盖。1 级体型系数固定为 `1.5`（世界身高 3.675 米），12 级封顶 `3.0`（世界身高 7.35 米）；后续等级的体型增量是目标规则的一部分，必须与生命、伤害和攻击频率一起由同一等级快照解释。等级影响最大生命、伤害、攻击频率与体型，等级上限和各级增量由精英内容定义统一提供。

体型公式（内容库 `body_scale_base = 1.5`、`body_scale_per_level = (3.0 - 1.5) / 11`、`level_cap = 12`）：

- 等级系数 `M(L) = 1.5 + (L - 1) x (3.0 - 1.5) / 11`，`L` 取 1 到 12；`M(1) = 1.5`、`M(12) = 3.0`；
- 世界身高 `H(L) = 3.5 m（模型 bind）x 0.70（全局表现倍率）x M(L)`，即 `H(1) = 3.675 m`、`H(12) = 7.350 m`；
- 移动圆柱世界半径 `R(L) = 0.816 x 0.70 x M(L)`（钳制前），即 `R(1) = 0.857 m`、`R(12) = 1.714 m`。

`M(12) = 3.0` 顶破了两条硬约束，代码侧各有一处兜底，**两者都是契约的一部分，不得单独撤销**：

1. **门洞**：`R(12) = 1.714 m` 超出可通行上限 `Enemy3D.MAX_COLLISION_RADIUS_M = 0.935 m` 达 83%。`Enemy3D._apply_presentation_scale()` 对收租人的移动圆柱做半径钳制（每次从 footprint 基值重算再 `min`，不累乘），钳后世界半径恒为 `0.935 m`。**只钳碰撞柱、不钳表现**：收租人的子弹判定走 17 个跟骨盒代理，与圆柱无关，任何一处打击面都不会因此变小。
2. **受击盒侧缝**：骨骼单位的腿间侧缝为 0.0261 / 0.0457，世界值 = 缝 x 3.5 x 0.70 x M(L)，随体型线性放大；弹体直径固定 0.24 m，`M > 2.14` 时最宽那条就超过弹径。故贴地补底柱的横截面由 0.111 加宽到 **0.21 骨骼单位**，1 / 6 / 12 级在 y = 0.75 / 0.80 / 1.20 处实测侧缝均为 0。

改 `body_scale_base`、`body_scale_per_level` 或 `level_cap` 时，必须同时复核上面两条；`verify_body_scale_curve` 已逐等级钉住"碰撞半径不超过 0.935"与"任何高度都没有大于弹径的空洞"。

无限公馆中的首次现身确定本次遭遇的最大生命，后续现身使用同一最大生命和剩余生命。每次现身分别累计实际受到的生命伤害，达到本次最大生命的 10% 时进入真实门边撤离流程；阈值只统计实际生命扣减，格挡、无敌、吸收和纯表现命中不得推进撤离。整数阈值向上取整。撤离中的闪现/转移表现必须完整结束，才能提交成功；表现未完成、落点无效或保存失败都不得报告成功。

当前生命、最大生命、等级、成长快照、本次累计伤害和撤离进度进入战局快照。换房、流送重建、重载和再次现身均从该快照恢复。重复现身属于同一个战局遭遇，名册跨局成长在最终撤离结算时提交一次。

## 阵营、目标与攻击归属

收租人可以与普通怪使用同一阵营标识，但目标选择拥有独立的主动攻击规则：收租人可将普通怪纳入主动攻击目标并对其造成伤害；普通怪不得仅因同阵营标识自动仇恨或改为攻击收租人。玩家、普通怪和其他精英的目标授权必须由来源与内容策略明确给出，不能用阵营相等直接短路。

## 无限公馆连续投放

远征03通过关卡数据的连续精英遭遇能力启用收租人。首次现身从前五间首次进入的可战斗内容房中随机选择，入口、通道、商店、宝箱、Boss与撤离房不计入候选。之后每次撤离，从后续首次进入的候选房随机选取再次现身的位置。种子决定本局计划，目标现身总数在 3–5 次之间。计划、已访问候选房、当前房、次数及剩余生命保存在同一战局状态中。

同一时间只保留一个收租人实例。重进房间和读取存档沿用已生成的计划，生成重试保留当前预约。玩家击杀收租人后终止后续现身。候选房不足或玩家提前结束行动时保留实际已完成次数。

收租人击杀玩家时，沿用既有精英胜出离场规则，同时将连续遭遇账设为 finished，原子保存终局档案与战局快照，再移除实体。本局计划随该终局提前结束，不能留下 active 状态而没有实体。

## 夺取、独立库存与独立档案

收租人的租物库存是独立于玩家背包、快捷栏和地面掉落的精英库存。近战挥击使玩家生命实际下降后，独立掷一次夺取判定；具体概率由内容规则提供。触发后从允许的玩家物品实例中选择，必须保留完整 `WeaponInstance` 属性，包括稳定实例身份、枪身内容、弹种、弹药、配件、品质、耐久及其他运行时字段；不得退化成只保存枪型 ID 或重新生成一把无属性武器。

成功提交前，租物只存在事务暂存区，不生成视觉实体。提交成功后，才按“从玩家当前位置抛落 → 飞向收租人”的顺序创建纯视觉租物实体，并挂接拖尾；实体只展示已提交的实例快照，不写入 `ground_loot_3d`，不直接操作 `InventoryModule`，不参与拾取事务。转移闪现/拖尾 VFX 必须完整播放至结束，提交成功信号不得早于该完成点。任一事务保存失败、动画启动失败或转移未完成，都回滚玩家库存、收租人库存与收据，不留下视觉或地面残留。

收租人独立库存中的治疗表现使用绿色血瓶样式并显示 `+N`。玩家与精英治疗数字统一复用既有 `VFX-HEAL-NUMBER-3D`，不得创建收租人专属治疗数字资产；治疗数字只表现实际恢复量。

收租人拥有两个悬浮枪挂点 `WeaponMountLeft` 与 `WeaponMountRight`。挂点只承载已提交的武器实例表现；只有进入下一关且目标关卡不是本关时，夺取的武器才可从完整实例快照恢复为真实装备并产生攻击。本关收取的武器不得在提交后立即转成真实攻击源。

XP 来源固定包括：攻击玩家、杀死玩家、杀死普通怪、成功撤退。每个来源使用幂等事件收据并绑定有效的战局/实例身份；XP 影响等级以及由等级规则派生的生命、伤害、攻击频率和体型，重复事件不得重复加成。

收租人生命小于等于最大生命的 20% 且未受到致死伤害时，掉落独立库存的 50%；每件被选中的库存物至少掉落 1 个。随后进入 `kneel` 跪地状态；战败不是死亡，不发送死亡击杀事实、不走普通死亡掉落、不占用普通死亡清房语义。跪地动作完成后实体消失，档案与库存结算保持幂等。

被夺物品、货币累计值、独立库存、成长经验与幂等收据归 EliteRosterService 的收租人档案所有。玩家扣除、精英账单、库存变化和战局快照一起提交到同一总档事务。写盘失败则整体恢复玩家库存、余额、收租人库存、成长与精英账单，允许后续安全重试。

档案字段至少包括 stolen_items、stolen_currency、rent_inventory、rent_receipts、xp、level 和 roaming_encounter。`collect_elite_rent` 生成含战局身份、实例身份、现身序号和夺取序号的 receipt_id；`EliteRosterService.commit_run_record` 拒绝重复收据；`BaseManager.commit_elite_and_runtime_checkpoint` 一次保存档案与战局镜像，失败整体恢复。中途撤离保留同一名册预约，最终撤离才结算一次跨局成长。致死保存失败在遭遇账中保存 pending_outcome 并重试；战败优先级和重试不会再次发奖励、击杀或 XP 事件。

## 独立于房间结算

唯一精英属于独立遭遇，排除在房间剩余敌人数、波次完成、清房奖励和清怪开门条件之外。普通敌群清空后，房间照常结算并允许开门，即使精英仍在场。精英实体继续存活、攻击、受击、撤离、跪地和保存。精英自身击杀普通怪、攻击玩家、击杀玩家、成功撤离和战败均进入独立的事件与成长出口，离场事件保持幂等。

## 中断、恢复与失败

收租人的模型、移动圆柱和跟骨受击盒统一按等级快照的体型系数计算；1 级必须为 `1.5`、12 级必须为 `3.0`，不能沿用旧的 2.5 倍设计值，也不能回退到 1.0。游戏实体读档重建时采用当前等级快照，已有生命、库存、XP 与遭遇进度按原快照恢复。

硬直、死亡、休眠、精英逃脱、跪地完成或外部离开行动状态均取消旧行动。战败状态必须与 `dead` 分离：进入 `kneel` 后关闭攻击和战斗目标，保留跪地表现，动作完成后再移除实体；不得发出死亡事件或复用普通死亡回收路径。近战丢失目标时取消尚未命中的起手。屏幕放电开始后锁定地面与施法目标，施法目标死亡或离场时取消未发射的母弹。已出手继续完成收招。近战命中帧重新验证目标存活、范围、前方扇区与世界遮挡。放电锁定世界落点后由弹体物理决定实际碰撞。房间休眠重建沿用公共快照，行动态读档退回alert，不补发旧攻击。

外部击退/牵引按速度直接施加，不作为每帧累加的冲量；投射物的短击退沿用基类原时窗，不随2秒hit段延长。攻击段禁止自主追击，但仍接受这些明确的外部位移。

缺失动画明确告警并回idle；无匹配精英内容时不挂此控制器。静态首只精英、普通怪和显示器Boss保持各自既有接线。
