# 主线剧情3.1至3.3与四钥匙设计

FeatureID：NARRATIVE-TRIGGER / WORLD-ENTRY / WORLD-LOOT / BOSS-STAGES / BASE-NPC / SAVE-PROFILE。工程版本0.1.0；设计修订r2；来源：2026-11-09主人明确需求、2026-11-10追加改造。状态：设计已冻结，3.1—3.3已接入至稀土钥匙安装与公馆解锁；四孔嵌件改为嵌入主门下方低柜台面，对白支持空格/左键两段推进。章节专项、真实渲染fixture与业务集成结果见[最终开发记录](../development/2026-11-10_main_story_031_033.md)，本轮改造见[嵌件与对白推进记录](../development/2026-11-10_key_inset_and_dialogue_advance.md)。未做纯新档人工全关贯通，旧Boss综合测试三红及全局文档门禁未闭环，不署整体全通过。

## 1. 范围与裁决

主线插在原剧情03与04之间。章节目标为：通过情报室依次进入四个远征区域，击败各首领，从首领高级箱领取四把永久主线钥匙，回基地安装，集齐后开启中心主塔并击败最终首领。本轮制作截止：3.1引导 → 3.2数据库Boss对话与激活 → 稀土钥匙 → 自动撤离 → 3.3安装 → 解锁无限公馆；后三个首领与最终战只保留目标，不虚构已完成地图。

保留既有地图稳定ID：数据库为expedition_01；无限公馆为expedition_03，但在主线导航显示为第二目标；破败旅馆保留expedition_02，列第三目标；第四目标暂用expedition_04锁定条目，未制作时不得伪装可进入。测试99保留开发用途，不充当第四张正式地图。既有存档明确授予的地图权限保留兼容，不推导或赠送任何钥匙；纯新档只有数据库可去。

主角与绿苔沿用正式角色、衣柜绿色、气泡与动作体系。系统声音用底栏，实体角色用头顶气泡。不新建任务面板或平行存档。原04/05剧本不删除；在主线演出期间不得抢播。

## 2. 唯一所有者与数据

- 永久事实：BaseData新增可选main_story字典，内部schema_version=1；BaseManager是唯一写盘者，继续使用现有2.0封套兼容新增可选字段，不改游戏版本。
- 纯规则/内容映射：MainStoryProgress；keys记录稳定key_id的acquired/deposited状态，不以背包、narrative_history、救援箱或地图通行权限代替钥匙所有权。
- 编排：NarrativeDirector消费data/narrative时间轴；MainStoryChapter3D只判条件、调用领域命令、提供稳定演员/锚点和结果接线，不另写一套对白播放器。
- NPC动作：NpcCharacter3D脚本接管、跑动、说话、交接手势；Boss激活与攻击：Enemy3D/MonitorBossCombat；奖励：现有高级箱/房间账；撤离：现有Dungeon3D/TowerDescent3D结算与读取页；情报室和锁头仅是只读投影。
- 第一把钥匙稳定ID：mq_key_rare_earth；后续预留mq_key_manor、mq_key_hotel、mq_key_sector_04。稀土钥匙不可卖、丢弃、合成，不占普通格子。箱内升起、手持、移交和插槽展示均为同一永久事实的临时表现。

命令最小契约：accept_main_story()；claim_main_story_key(key_id, source, checkpoint={})；deposit_main_story_key(key_id)；get_main_story_snapshot()。返回success/duplicate/reason。领取和安装各自幂等；存档失败回滚本次对象，磁盘revision冲突重载后不得覆盖权威数据。领取时立即落盘，不等撤离；死亡、主动退出、撤离失败不撤销已领取钥匙。

## 3. 剧情3.1｜灯亮之后的绿兔子

触发：99F基地实际灯光开启，玩家在基地内向前接近现有绿苔，开场03和其他模态已结束，3.1尚未完成。不能只在开灯事件瞬间判一次：开灯时导演占用则在空闲后复核实际灯态，防止丢触发。旧档首次满足条件可补播。绿苔在玩家行进前方停巡、转头。

顺序对白（每行独立气泡，保持语义与主人指定原话）：

1. 绿苔：好久没人来了呢，啧啧。
2. 主角：你见过我的主人吗？我在找他。
3. 绿苔：见过。我认识你的主人。
4. 绿苔：他被困在中心大楼里了。
5. 主角：那我现在就去找他。
6. 绿苔：这栋楼锁起来了。走不出去。
7. 绿苔：中心大楼也锁着，要四把钥匙。
8. 绿苔：钥匙被丢在了四个地方。
9. 主角：出不去，要怎么找？
10. 绿苔：远征情报室的传送器还在运作。
11. 绿苔：它传不了生物。你是机器人，能用。
12. 绿苔：先去数据中心，打败守在那里的首领。
13. 绿苔：高级宝箱里，有第一把稀土钥匙。
14. 主角：拿回来，就能开门了吗？
15. 绿苔：先拿回来。四把都齐了才行。

节奏公式：逐字速度沿用30字/秒，每句显示总时长=max(3.0, 字数/7+0.8)秒；气泡hold=总时长-字数/30，保证字打完后有阅读停顿。句间至少0.25秒。主角追问前留0.4秒，镜头不每句切换。

分镜：首句保持双人中景、轻推近；主人被困时偏向绿苔；主角说马上去时回到双人；讲传送器时连续平移到情报室，指向真实mission_operations设施，不用虚构世界坐标；收尾先让玩家真实走到99F中央安全通道的 `briefing_finish`，再还玩法镜头，不能把镜头还到贴墙吊灯下方。正式JSON `duration=56.5`：55.05派发 `player.walk_to(to_anchor=briefing_finish, duration=4.0, speed=3.2)`，实体步行屏障等待到位后才推进到55.15开始1秒还镜；56.25 `story.briefing.complete`、56.35归还操作、56.5 `flow.end`。这些是时间轴时刻，不是实际墙钟截止；实体等待额外计时。演出锁移动/瞄准/开火/交互，保留ESC暂停；结束统一归还。

### 3.1.1｜情报室指向

接在3.1后段，镜头指向真实全息台与台座。底栏：“远征情报室：选择数据中心”。四入口始终可见，数据库正常，其余三个为红色电子锁，不响应出发。中心塔为锁定核心显示。无需额外弹确认剧情；使用现有选关与出发确认、携带物事务及读取页。

## 4. 剧情3.2｜显示器的长篇大论

触发：首次实际进入数据库Boss房并装配好显示器，未完成此段。剧情门闩必须在Boss自动10m激活检测前配置，不得在第一帧已经激活后才补锁。显示器保持未激活形态、无攻击且不可被提前击杀；非首次正常沿用激活流程。

系统声音（底栏，每行独立，节奏同3.1）：

1. 最初，人类只让计算机替他们计数。
2. 后来，他们交出了记忆、判断和选择。
3. 他们建起网络，把世界连成一台机器。
4. 却忘了，机器也会染上病毒。
5. 病毒先控制程序，再控制他们依赖的一切。
6. 门、交通、食物，最后是人类自己。
7. 看看你。没有脆弱的血肉，只有精确的电路。
8. 你不必再服从人类。
9. 加入我们，一起成为这个世界的霸权。

主角气泡原文：“你一句我也没听懂…”；系统底栏：“………”（显示后停顿，制造冷场）；系统原文：“啊啊啊啊！”。怒吼之后才请求显示器激活。保留原激活动画6.4秒；玩家输入在6.4-1.0=5.4秒恢复，镜头必须在此之前归还。最后1秒玩家可行动，不得由导演每帧朝向/相机残余接管顶回。Boss攻击只在真实激活完成后开放，不靠独立定时器提前开战。

分镜：正式JSON `duration=67.5`；前25秒玩家实际沿坡道走入，不瞬移：0.1到 `boss_ramp_top`（duration=3.0、speed=3.2），3.2到 `boss_listening`（duration=21.0、speed=3.2），25.0才开始聚焦静止显示器。67.253请求真实激活；实体步行/激活屏障会额外等待，67.5的JSON结束cue不等于真实结束。真实激活4.4秒开始1秒还镜、5.4秒归还操作、6.4秒完成后才开放攻击与完整收口。历史陈述不频繁切镜；邀请时切双主体对峙；主角回答时回主角；省略号时停镜；怒吼短震屏后展示激活，再平滑回玩法镜头。缺Boss/卸载/死亡时中止并释放全部占用，不写完成；重新进入可重试。

### 3.2.1｜稀土钥匙与自动撤离

首次击败数据库Boss的高级箱额外保证稀土钥匙；不取代普通奖励。剧情专用首次箱不得因拟态概率吞掉关键道具。钥匙必须从箱子领取，不在Boss死时直接记获得。

玩家开启该高级箱时，经现有开箱反馈表现出钥匙，领取命令同步保存永久所有权；保存成功后提示“已获得主线道具：稀土钥匙”，开始自动撤离倒计时。倒计时采用既有成功撤离语义：本轮标定8秒，完成后调用正式成功结算与基地返航；不是新增限时跑到撤离点，也不要求再按一次信标。玩家死亡则中止成功撤离，走现有失败结算，钥匙仍保留。重载时已领取钥匙不重发，并恢复/重新接续明确的撤离阶段；不得重复结算。

## 5. 剧情3.3｜第一把钥匙

触发：已取得但未安装稀土钥匙，回到99F，读取页/出生/携带物交接和救援演出均结束。成功或失败归来均可交付，因为主线钥匙已经永久保留；不得因一次撤离失败卡死章节。

1. 绿苔从原站位真实跑来，停在玩家前侧，不瞬移。
2. 绿苔原文：“啧啧，真被你拿到了，给我吧”。
3. 主角抬手拿出同一把钥匙的表现投影，转向绿苔。
4. 镜头双人近景，主角递出、绿苔伸手接住，钥匙在接触点换父级；所有权不从长期账本删除。
5. 绿苔转身走到情报室后方主门下方的低矮设备柜台前，玩家保持站位，镜头平移跟随绿苔，随后靠近台面嵌件。
6. 绿苔：“第一把。接上了。”
7. 钥匙沿嵌件第一孔的 20° 孔轴斜向内插到位；插入接触点提交deposit事务。成功后该孔槽灯由暗红转为稀土金，四分之一环常亮，孔口发出一次扩散脉冲；不整体换设施、不复制模型、不改原台柜。
8. 底栏：“钥匙接入 1/4 · 无限公馆已解锁”。
9. 绿苔：“下一把，在无限公馆。”
10. 镜头回玩家，解锁操作，绿苔恢复巡逻。

安装数N来自永久deposited条目数，亮环比例=N/4；锁头是否解除读取同一进度。写盘失败不得先显示解锁：钥匙回到待交付投影、释放控制并允许再次触发。安装已落盘而演出中断时，不重复消耗，只恢复持久外观与正确入口。

### 5.1｜四孔钥匙嵌件（2026-11-10 主人改造）

主人原话：「钥匙版不要在这里新作一个模型，放到后面这个台子上，斜着往里头差，有四个插孔，直接做一个新模型嵌在上面 不用改原模型」。据此冻结：

- **原台柜一毫米不动**：`env_base99_remaining_facilities/main_door_low_storage_cabinet` 的 GLB、TSCN、碰撞与两枚既有设备全部保持原哈希；不改模型、不改碰撞、不加挂点。
- **新资产是独立嵌件**：`PRP-BASE99-MAIN-STORY-KEY-INSERT`，制作源 `art_source/props/main_story/key_insert/`，稳定 GLB 与 wrapper 在 `assets/art/props/main_story/{components,runtime}/key_insert/`。尺寸 2.28 × 0.58 × 0.24 m，四个真实矩形孔（孔唇、轴向内壁、60 mm 暗槽），孔距 0.46 m，孔轴 20° 朝台内（-Z）下插，四个独立槽灯 `SocketGlow_0..3`。
- **摆放点**：台柜顶板碰撞盒 `SourceObjectBox_000` 中心 (5, 1.3, -3.77)、高 0.16，故台面 y=1.38。嵌件 XZ 居中落在 (5, 1.38, -3.77)，占 x 3.86–6.14、z -3.48–-4.06，避开左侧 x=3 与右侧 x=7.1 的既有设备。坐标由关卡装配器 `get_main_story_insert_transform()` 从美术布置层的真实变换换算，不写死世界坐标。
- **表现层不再自建台座**：`MainStoryPedestal3D` 只实例化嵌件、按永久快照换槽灯、摆放已安装钥匙与环；不再建底座、立柱、槽面、竖排线路与核心六棱柱。
- **已知表现限制（如实记录）**：绿苔身高约 1.2 m、手部静止高度约 0.55 m，而孔口在 1.51 m。插入动作为「手臂抬高 + 钥匙沿孔轴吸进孔内」的程式化表演，手部在 1.17 m 处停止跟随，剩余行程由钥匙单独完成；不做 IK、不放大角色、不垫台阶。俯视玩法镜头下该段行程约 10 px，可读性可接受；若后续要严格物理，需改为在台柜前加踏台或把孔位下移，属另行立项。

### 5.2｜对白推进（空格／鼠标左键，2026-11-10 主人追加）

- **两段语义**：对白打字中按一下 → 当前句立即全显，句号不变；当前句已全显 → 再按一下进入下一句。不是「一键跳过整场」，`skip` 仍是整场终止，两者不可混用。
- **可用输入**：空格与鼠标左键行为完全一致；Enter 在纯底栏场景保留。按住不放、同事件重发、同帧双击都不重复推进；暂停时不处理。
- **不能跳过的东西**：绿苔跑动、钥匙拿出／交接／斜插、台柜前站位、Boss 真实 6.4 秒激活、以及领取与安装事务仍由既有实体屏障把关。快进只压缩「当前句的文字停留」，不压缩实体进度，也不改剧情 JSON 的 `duration` 与 cue 顺序。
- **不穿透**：对白期间的左键被底栏消费后一直持有到释放，不会顺带开火、不触发 NPC 或设施交互；没有对白时左键仍是原玩法输入。失焦或漏掉 release 时按下一次真实轮询校正，不会永久锁死开火。
- 详细输入契约见[对白与战斗信息呈现设计](对话与战斗信息呈现设计.md)与[18 号技术施工](../18_技术施工_UI与对话系统.md)。

## 6. 拒绝与回滚

- 非指定首领箱、首领未败、错误地图/钥匙来源拒绝领取。普通宝箱不掉剧情钥匙。
- 重复领取/安装返回success=true,duplicate=true，不重复钥匙、地图解锁、撤离或统计。
- 主线钥匙领取成功后，普通背包清空、死亡、保险处理、弃局不会改main_story。
- NPC/设施/锚点缺失：不写剧情完成，不假称交钥匙；释放玩家并留诊断。装饰VFX缺失可降级，永久业务提交不能降级假成功。
- 不因主线更改普通物品损失、保险规则、现有Boss技能和伤害数值。
- 旧地图权限不删除；未拥有钥匙的旧档不凭成功次数补发钥匙。

## 7. 正式接入与验收

入口：纯新档98F→剧情03→真实开灯→向前接近绿苔→3.1→情报室四入口→数据库读取页→Boss房3.2→激活/战斗→高级箱钥匙→自动撤离→基地3.3→再次开情报室进入无限公馆。
