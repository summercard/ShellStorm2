- **FeatureID**：`AUDIO-MUSIC`
- **子域**：BGM 使用清单
- **工程版本**：`0.1.0`
- **文档状态**：当前音乐使用目标与现有曲目清单
- **更新日期**：2026-10-13

本文只回答三个问题：**是什么歌曲、在哪里播放、是否循环**。
音乐系统的播放生命周期、淡入淡出、A/B 选曲、总线和验收见[音乐系统与配乐资产](../14.8_音乐系统与配乐资产.md)。

## 1. 播放清单

| 歌曲 ID | 歌曲 | 播放位置 | 播放条件 | 是否循环 | 选曲方式 |
|---|---|---|---|---|---|
| `base_passion` | 基地热血激情 | 99F 基地大厅、备战区 | 进入基地且不是本地收音机独占播放状态 | 是 | A/B 随机 |
| `rooftop_relax` | 天台放松 | 100F 天台、楼顶休息区 | 进入天台休息区 | 是 | A/B 随机 |
| `descent_suspense` | 下塔探索悬疑 | 塔楼连续爬楼的普通探索层（低于100F、非Boss层） | 进入普通探索层 | 是 | A/B 随机 |
| `boss_intense` | Boss 战激烈 | 塔楼连续爬楼的Boss层，例如95F、90F、85F | Boss战开始 | 是 | A/B 随机 |

## 2. 不播放背景音乐的场景

| 场景 | 规则 |
|---|---|
| 远征关卡01 `expedition_01` | 整关不播放全局背景音乐 |
| 远征关卡02 `expedition_02` | 整关不播放全局背景音乐；沿用远征关卡的静音规则 |
| 99F 收音机 | 不启动全局基地BGM；收音机本地播放 `base_passion` 的A/B版本，并按距离衰减 |
| 读取界面、失败页面、结算页面 | 不新增页面专属BGM；使用进入前的音乐状态或保持静音，由场景生命周期决定 |

## 3. 使用规则

1. 场景只请求 `music_id`，不直接加载音乐文件。
2. 所有清单歌曲均循环播放；歌曲播放结束后自动选择下一版A/B，不停在空白段。
3. 同一 `music_id` 重复请求不重新打断当前曲目。
4. Boss音乐只属于塔楼连续爬楼路线；远征关卡的整关静音优先级更高。
5. `base_passion` 的全局基地版本与99F收音机版本是两个播放位置，不能同时叠加。
