## 1. 核心规则

- 78张指78个稳定卡种，正逆不另算卡种。每关新增身份如下表，后关继承前关身份；累计21/33/45/57/69/78。
- 01关主线只出指定21种正位，02关只出累计33种正位。回玩也按所在关卡，不因账号已通关06而解锁逆位或其他身份。
- 同次三张候选按stable_card_id不重复；不同次可重复，服务叠加构筑。不是单局抽过便永久移出池。
- 03开始少量开放简单逆位（优先已学过的魔术师、战车、权杖·侍从）；04扩大，05充分展开，06开放全部。03—05具体逆位白名单、比例及新牌加权数值待调参，不沿用全池50/50冒充教学方案。
- 06允许全部身份和方位，不意味着每个房间均可抽到任何卡；仍检查来源、剩余兑现机会与内容实现状态。
- 关卡内其他随机获卡入口同样经过本关规则，不能通过奖励、占卜或愚者绕过白名单。独立训练场可展示全量已实现卡，不能反写正式关卡解锁。
- 已持有武器的历史命运不因进入低关而删除或翻正；本规则限制新获取。旧进行中局的已冻结候选保持原快照，新局才采用新版投放，迁移不得重掷或重复扣款。
- design_only卡不得进入正式随机池。缺执行器的关卡标为部分实现，不拿其他身份凑满目标总数。

## 3. 01关的21张与购卡节奏

构成固定为12张枪械卡（魔术师至权杖·王后）、6张角色卡（女祭司至圣杯·二）、3张房间/收益卡（节制、皇后、星币·五）。教学语义使用枪械/角色/房间，天体标签互换不在本次施工范围。

| 阶段 | 目标与验收 |
|---|---|
| 前1—2次购卡 | 至少展示一次可执行且可负担的魔术师或战车；此前提供可选来源武器，包含近战教学机会 |
| 第3—5次 | 出现与已有主轴兼容的尺寸、双波、燃烧或冻结卡；兼容性不足不得暗中吞掉效果 |
| 第6—8次 | 允许重复主轴卡，展示横排叠加与顺序；提供可读的构件顺序查看/调整机会（调整能力尚需核验） |
| 最后两次 | 优先立即可用于Boss战的效果，过滤没有后续容器/房间可兑现的卡 |

每次仍是三张各自报价，玩家可购买或离开，不强制选择。稀有度/报价与教学保底应统一求解：现魔术师为传奇、战车为史诗，不能既用早期稀有度门槛排除它们，又声称前两次有保底。教学候选的解锁、资金来源及报价调整属于后续经济接入项，禁止简单塞进候选但维持不可支付的价格；不在本次暗改稀有度。**（2026-10-18 已解决：稀有度门槛整体下线，21身份全量抽取；保底改为「三张全买不起时把最低价那张压到当前余额」。）**

核心组合例：魔术师→重复魔术师→尺寸变化；战车→选近战来源→元素或弹道变化。先前构筑进入后续来源快照，后续修改不反写旧副本；嵌套深度限制仍生效。组合例需验证实际相容性，不能把描述当测试结果。

皇后使用追加候选、择优留一的当前容器规则说明收益，不能承诺地面多掉几件。星币·五提高品质。两者只在仍有容器可兑现时提供。

## 4. 单卡完善方向与进入教学池的条件

- 力量保留滚石、弹速减半与降射速目标。正位必须补足可读收益；优先评估滚动连续撞击不同敌人，伤害/穿透次数仍待平衡。当前未实现该收益，不把建议当现状。逆位保留碎裂范围击退。
- 皇帝、星币·王牌、星币·四须建立明确额外回报，不能售卖纯加难度；具体回报待设计，不撤销其目标身份。
- 权杖·五/六明确区分返航触发条件；星币·二/五需区分正位价值，避免后关只增加同质卡。
- 02利用走廊教穿透和返航；05涉及支路/钥匙的牌必须有实际使用目标；06世界必须与有压力的撤离段配套。
- 后关提高新卡与已有构筑搭配卡的可见机会，不把78张完全等权混抽；具体权重待实测。

- 现有Dungeon3D门事务继续拥有冻结offer；快照增加policy_id/revision并保留cards/orientation/roll/quotes/purchased。UI只展示快照；购买沿用Bridge来源重验、原支付与回滚链，不产生第二套扣费Owner。
- 内容ID不存在/未实现/无来源/无后续目标时拒绝该候选；不足三张不得跨关补入未开放卡，可显示不足数量及可退出状态。资金不足、目标失效、取消来源选择不应用效果并按既有事务返还。
- 正式入口：关卡门后购卡、关卡内随机奖励和占卜统一查询；训练场显式使用独立策略。保存/读档不重新抽取；关卡切换只影响之后新生成的offer。

## 8. 01范围判定实施边界（2026-10-18）

本批实施01的21身份白名单与仅正位，唯一运行数据为`data/fate/level_pools.json`，只读策略为`FateOfferPolicy`。02与03—06投放、教学保底/报价、条件兑现过滤仍待后续。

**2026-10-18 修订（业主口径）**：池子就是21张，每门随机出3张，保底至少1张买得起。
1. 抽牌只在白名单内做无放回随机，**不再按已解锁稀有度收窄候选**——旧门槛会把初期池子压到2张普通卡，直接违背"每门3张"。
2. 门后保底：三张全部买不起时，把报价最低的那张压到当前余额（只降不升、只动一张；余额被花到0时该卡价为0）。压价写进冻结报价，随快照恢复，不重算。
3. `FateEconomyService.max_unlocked_rarity()` 与解锁阈值仅保留为统计快照，不再参与抽取或定价。
4. **门位置（业主订正）**：安全屋→`room_01` 是入口交通门，不弹命运卡；第1次抽卡点在**清完 `room_01` 之后**开门时。门序号`k`对应"清完`room_k`"的收益作为报价基准；旧的"第1门=安全屋出门"假设已修正，此前报价整体错位一间房。
5. **加怪不加价（业主口径「可以加怪，但不要影响卡片价格和本身逻辑」）**：怪**不写进关卡编成**——编成收益就是卡价的分母，加编成怪会让卡价同比例上涨（实测 ×1.25/×1.5 时全程仍只买到 10 张，与不加怪完全相同）。改为在第一波刷出后按差额补齐：`room_01` 固定 **15 只**、`room_02` 固定 **12 只**（2026-10-19 业主指定），其余战斗房按 `现有 + clamp(round(现有 × 0.25), 1, 8)`。卡价、抽牌、冻结报价零变化，玩家实际多赚金币。Boss 与交通房不加。见[命运塔罗 §7.1.1](../../14_技术施工_命运塔罗牌组.md#711-编成外增援2026-10-18业主口径可以加怪但不要影响卡片价格和本身逻辑)。

策略输入level_id/pool/roll，过滤后才无放回抽牌；门、工作台、占卜、愚者随机奖励共用。运行地图从Bridge已绑定玩家的祖先宿主解析，不能从后台残留场景猜测。无关卡策略的基地/训练及其他图保持原规则。门快照记录policy_id/revision，旧已冻结候选保留，不重抽；下一门应用新策略。此迁移例外不允许新局生成越界牌。
