# Phase 4：命运卡片系统

## 目标
实现命运卡片——对枪身、子弹、配件、节点关系进行改造的规则卡。

---

## 卡片分类
| 类型 | 功能 | 示例 |
|---|---|---|
| 组合卡 Combine | 把两个节点连接起来 | 子弹上挂枪、枪上装枪 |
| 强化卡 Enhance | 提升数值或触发频率 | 子弹变大、射速提升 |
| 变种卡 Mutate | 改变模块行为 | 直线弹变回旋弹 |
| 复制卡 Copy | 复制节点或效果 | 复制一把副枪 |
| 融合卡 Fuse | 两个模块合成新模块 | 火焰子弹 + 毒子弹 |
| 诅咒卡 Curse | 强力但带副作用 | 伤害翻倍但换弹爆炸 |
| 规则卡 Rule | 改变触发规则 | 每第七发子弹携带一把枪 |
| 视觉卡 Visual | 改变表现，少量改变属性 | 巨大化、长脚 |

---

## 卡片品质
| 品质 | 特点 |
|---|---|
| 白色 | 简单强化，稳定安全 |
| 蓝色 | 改变某个行为，收益明显 |
| 紫色 | 产生组合关系，构筑核心 |
| 金色 | 改变武器树结构，强力稀有 |
| 红色 | 诅咒或失控型效果，极强但危险 |

## 命运卡片标签
`Fate.Combine` `Fate.Enhance` `Fate.Mutate` `Fate.Copy` `Fate.Fuse` `Fate.Curse`

## 组合结果类型
| 结果类型 | 说明 |
|---|---|
| AddModifier | 给目标节点加修正器 |
| AddChildNode | 给目标节点加子节点 |
| ReplaceNode | 替换目标节点 |
| CreateHybridNode | 创建混合节点 |
| AddTrigger | 增加触发器 |
| AddVisualNode | 增加表现节点 |
| AddRisk | 增加副作用 |

## 核心卡片示例

### 组合类
| 卡名 | 效果 |
|---|---|
| 枪上加枪 | 选择一把枪身，将其挂到当前枪身上，开火时副枪也有概率开火 |
| 子弹背枪 | 选择一个子弹和一个枪身，之后该子弹飞行时会携带这把枪并自动射击 |
| 配件寄生 | 选择一个配件，使它寄生到子弹上，子弹命中时触发配件效果 |

### 强化类
| 卡名 | 效果 |
|---|---|
| 变大了 | 选择一个节点，体型与碰撞范围增加，伤害提升，速度降低 |
| 超频 | 选择一个枪身，射速提升 80%，但每次射击后累计受击伤害倍率（overheat_penalty=1.5：射击越多，受伤越痛） |
| 死命贴住 | 黏性子弹附着时间增加，期间每秒触发一次命中效果 |

### 变种类
| 卡名 | 效果 |
|---|---|
| 活过来 | 选择一个子弹，变成活体子弹，会轻微追踪敌人 |
| 不想飞 | 子弹落地后变成小炮台 |
| 回家看看 | 子弹飞出后返回玩家，返回途中继续造成伤害 |

### 诅咒类
| 卡名 | 效果 |
|---|---|
| 管不住了 | 所有挂载在子弹上的枪自动射击，但不一定瞄准敌人 |
| 火力暴食 | 子弹每命中一次就变大，但也会降低玩家移速 |
| 过度嫁接 | 枪身可挂载数量增加，但每次开火有概率卡壳 |
