# PH18 怪物视觉生态与行动语言

**状态：已完成**  
**日期：2026-07-11**

## 问题审计

现有六类基础怪已有不同数值、`ai_type` 与简单多边形，但实际房间生成流没有把 `enemy_type` 稳定映射回 `enemy_shape`，因此大量怪物仍是同一三角形叠加不同 emoji。体型、碰撞半径、重心、步态与攻击前摇没有形成同一套战斗语言；玩家必须靠颜色或名字辨认，并且自爆/埋伏行为缺少公平的可读窗口。

## 本轮方向

用一个可独立替换的 `EnemyAvatarRenderer` 建立六套代码原生视觉，并让 `EnemyBase` 成为类型、碰撞、状态与表现的单一同步点。旧 `Shape` 保留为颜色/状态兼容通道，旧 `Emoji` 不再参与正式渲染。

## 六类战术语言

| 类型 | 体型/重心 | 轮廓关键词 | 移动节奏 | 攻击预警 |
|---|---|---|---|---|
| 小菌猪 / Chaser | 小、低趴、前倾 | 楔形头甲、双獠牙、后腿 | 快速短步、追击时拉长 | 冲刺前轮廓收紧 |
| 孢子射手 / Ranged | 中型、高重心 | 菌伞、三叶炮口、细柄 | 悬浮摆动、弧线侧翼 | 炮口蓄光+瞄准线 |
| 蜂巢怪 / Summoner | 大、宽、缓慢 | 六边蜂巢、孔洞、卫星孢子 | 低频漂移、周期呼吸 | 召唤前卫星加速环绕 |
| 壳甲卫兵 / Tank | 最大、极低重心 | 多层壳甲、正面盾板、重足 | 慢、左右重踏 | 盾击前重心后移与前缘高亮 |
| 炸弹果 / Bomber | 中大、膀胀、不稳定 | 球囊、裂纹、爆芯 | 弹跳式追赶，越近越急 | 0.62 秒停步膀胀+半径危险环 |
| 地刺虫 / Trapper | 小、贴地、埋伏 | 土丘、三根倒刺、地下眼 | 未触发静止，触发后短促扑击 | 0.38 秒破土高亮后才突进 |

## 数据与替换契约

1. `EnemyShape.shape_for_kind(enemy_type, ai_type)` 是配置名称到六类轮廓的唯一映射。
2. `EnemyShape.get_profile()` 返回视觉缩放、碰撞半径、接触半径、步频与战术标签；不在刷怪器中散落表现常量。
3. `EnemyAvatarRenderer` 只读取父节点的类型、速度、状态颜色与预警相位，不扣血、不改 AI、不发奖励；日后可被 Sprite2D/AnimationTree 原位替换。
4. 精英缩放与词缀缩放乘在基础类型体型之上，但不会把小型职责伪装成另一类轮廓。

## 验收标准

1. 六种 `enemy_type` 从 `MonsterInjector` / `RoomWaveSpawner` / `CoreCombatMode` 任一生成路径进入后都得到唯一正确的 `enemy_shape`。
2. 每种怪都存在语义化 `AvatarRenderer`，旧 `Shape` / `Emoji` 不可见；六类渲染轮廓签名不重复。
3. 体型档位与碰撞圈一致：Tank > Summoner > Bomber/Ranged > Trapper > Chaser，血条位于各自轮廓上方。
4. Ranged 射击有预警；Bomber 进入爆炸半径后不少于 0.6 秒才结算；Trapper 触发后不少于 0.35 秒才移动。
5. 命中会驱动轮廓压缩/闪白，暴击更强；死亡继续只派发一次奖励信号并清理整个角色。
6. 专项怪物生态验证、代表性战斗画面检查和全量回归无报错。

## 刻意延后

- 本轮先建立六类基础战术语言；Boss 保留 PH15 的独立高阶渲染器，不强行套用普通怪模板。
- 不在本轮大幅重写技能数值；只修复会破坏公平可读性的自爆/埋伏时序。

## 实施结果

- `EnemyShape` 新增六类中央 Profile 和 `shape_for_kind()` 映射；房间、街机波次和精英数据都能经 `set_enemy_data()` 回收到正确职责轮廓。
- 新增 `EnemyAvatarRenderer`，六类分别使用獠牙楔形、孢子炮口、蜂巢卫星、宽壳盾板、膀胀裂纹与低伏地刺。旧 Polygon/Emoji 保留为数据兼容节点但不再可见。
- 渲染器每帧读取速度、朝向、类型状态和隐藏 Shape 的元素颜色，统一表现步态、悬浮、重踏、膀胀、破土、冰冻/DOT 染色、受击压缩与死亡碎片。
- 体型与碰撞圈改为同源更新，并修正巨大化词缀错误调用 `Node2D.apply_scale(Vector2)` 的旧问题；巨大化现在同步外观、接触圈、物理圈和血条位置。
- Ranged 新增 0.28 秒蓄光/瞄准；Bomber 进圈后停步 0.62 秒并显示真实爆炸半径；Trapper 修复工厂速度为 0 导致永远不扑击的错误，破土 0.38 秒后再进入高速扑击。
- 新增 `EnemyEcologyGallery.tscn`，将六类体型、轮廓、血条和职责放在同一 1280×720 对照板中，供后续正式美术资产逐类替换。

## 验证证据

- `verify_enemy_ecology_flow.tscn` 通过：六类映射与唯一轮廓、体型/碰撞序列、隐藏旧视觉、受击反应、巨大化同步、三类蓄力时序与实际投射物全部成立。
- 使用 Godot OpenGL Movie Writer 离屏渲染 1280×720 对照板：六类在黑色剪影、尺度和色相上可独立辨识，Tank 与 Summoner 的体型压力明显高于 Chaser/Trapper。
- `Main.tscn` 连续运行 360 帧，Boss 闭环、第一章导演、实时安全专项均通过。
- Godot 4.6.2 全工程扫描、`git diff --check` 与 23 个场景回归全部无 `ERROR` / `SCRIPT ERROR` / `Parse Error`。
