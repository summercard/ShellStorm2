# 开发日志：2026-07

## PH15 核心闭环与视觉可读性重构（2026-07-10）

### 解决的问题

- Boss 房此前没有实体碰撞体，且子弹给 Boss 传入三参命中数据时接口不兼容；实战子弹无法击败 Boss。
- Boss 实体扣血、地图进度、奖励和撤离解锁之前没有同一条可靠的运行时桥接。
- 局内生命同时存在 `GameManager` 与 `Player` 两套来源，导致濒死祝福无法根据真实受伤触发。
- 纯黑 `CanvasModulate` 吞没了低照度环境中的地面和轮廓；玩家组件仍在展示 emoji/色块占位资产。

### 本次交付

- 将 Boss 的碰撞、伤害、死亡和 Boss 撤离收敛为可回归测试的闭环；新增 `verify_boss_completion_flow.tscn`。
- `VisionSystem` 与命运卡改为 `RefCounted` 数据/计算服务；武器装配树在换枪和结束局时递归释放未进入 SceneTree 的数据节点。
- 新增独立的程序化 `PlayerAvatarRenderer` 与 `BossAvatarRenderer`；它们是语义化的 `AvatarRenderer` 挂点，可直接被正式精灵或动画替换。
- HUD 改为统一的深色指挥台表现：生命数值、弹匣、机动、火力、战绩和深度的信息层级更清晰，且在迷雾上方渲染。
- 降低环境暗角至蓝灰基调，修复 Boss 击败闪屏非法层级。

### 验证

- Godot 无头编辑器扫描通过。
- 21 个场景流程验证与命运卡池验证通过。
- 新增 Boss 回归确认“玩家子弹 → BossActor → BossRoomDirector → BOSS_KILL 撤离”完整通过。

- 出生广场加入维护标记、裂纹、线缆与电力箱；基地玩家外观只在表现层放大，不改变碰撞。

## PH20 最终成品验收与生命周期收口（2026-07-11）

### 解决的问题

- 严格退出日志发现若在动画、刷怪或陷阱计时中切场景，`SceneTreeTimer` 与 `await tween.finished` 可能短暂持有协程资源。
- Boss 阶段 Director 在 Idle 也会自主处理，并可能在激活首帧同时触发多个定时技能。
- 相邻增援批次共享可变敌人池，快速触发时存在后批配置覆盖前批队列的风险。

### 收口

- 波次、增援和陷阱均改为场景节点自有 Timer；增援数据在入队时冻结。
- Boss Director 只在 Combat 运行，初始技能错峰并加入全局技能间隔；Dead/Idle 均停止处理。
- 白闪、飘字、Boss 胜利动画与演示转场改为 Tween 回调链，场景销毁不再悬挂协程。
- 建立 `VerificationClock` 与 `VerificationQuitter`，让专项测试延迟由节点拥有，并在异步入口完全退栈后退出。

### 最终证据

- Godot 全工程扫描干净。
- 24/24 验证场景严格无警告、无错误。
- 5/5 核心场景持续 600 帧无警告、无错误。
- 基地、靶场、战斗 HUD、怪物生态板与玩家六态板完成 1280×720 当前版本复核。
