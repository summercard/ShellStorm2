# PH39｜一米角色视觉与碰撞统一

## 一、改造目的

PH38 将塔楼镜头调整为角色正上方8米。现有 bunny01 v004 的完整可见高度为
2.475米，玩法碰撞体高度为1.80米；在5×5米地砖与8米俯视镜头下，角色占地和
屏幕比例都明显偏大。

PH39 将角色的 Blender 母版、Godot 分体模型、挂点、动画位移与玩法碰撞统一到
同一套1米基准，避免只缩放显示节点后出现碰撞、枪械和动作错位。

## 二、统一尺寸契约

1. bunny01 完整静态可见高度为 `1.000m`，计算范围包含双耳、头、身体和脚。
2. 玩法碰撞体使用不可见 `BoxShape3D`，尺寸为
   `0.477778×1.000000×0.400000m`，中心标高为 `Y=0.500000m`。
3. 碰撞体顶部与完整视觉顶部同为 `Y=1.000m`；耳朵不再位于碰撞体上方。
4. 头顶（不含耳朵）标高由 `1.820592m` 等比缩放为 `0.735593m`。
5. Blender 与 Godot 继续使用米制；Blender源朝向 `+X`、Godot运行朝向 `-Z`
   的轴向契约保持不变。
6. v004 不覆盖。新增 v005 Blender母版、七个 pivot-local GLB 和 v005 Godot
   刚性节点根场景；沿用原 AssetID，只做版本递增。

## 三、分体、挂点与动作规则

- 统一线性缩放系数为 `1 / 2.475 = 0.404040404`。
- body、head、ear、hand_l、hand_r、foot_l、foot_r 的网格尺寸和关节位置都按
  该系数缩放，组件原点及父子关系不变。
- `WeaponSocket`、左右握持手目标、ReloadProgress3D、可穿戴物尺寸与局部位置
  同步按该系数缩放。
- Idle、Moving、Dashing、Hurt、Locked、Dead 以及 Reloading、Firing、
  Charging、Knockback 的角度、时长、状态机不变；所有以米为单位的平移幅度按
  该系数缩放。
- 持枪模型作为角色表现子节点同步按该系数缩放，枪械数据、伤害、射程、弹丸大小
  与地面/UI母资产不变；仍保证手与 WeaponSocket 的相对姿势契约。
- 碰撞体只存在于 `Player3D/VirtualCollisionBox`；Blender与Avatar视觉层级中
  不得导出任何碰撞节点。

## 四、验收条件

- Blender v005 场景属性 `target_height_m=1.0`，静态包围盒高度误差不超过
  `0.001m`，地面最低点为0。
- v005 七个 GLB 均为 pivot-local，Godot装配后完整视觉高度为1米。
- `Player3D` 碰撞体高度严格为1米、中心Y为0.5米，顶部与完整视觉顶部一致。
- v005 为正式 Player3D 外观，组件诊断返回 `assembly_version=v005` 与
  `authored_scale_m=1.0`。
- 手枪单手、长枪双手、移动、冲刺、受击、换弹、射击、蓄力和击飞专项通过；
  不出现手掌、枪械、耳朵或脚部因绝对位移未缩放而脱离。
- 塔楼8米镜头、上下楼、当前层鼠标投影、门禁、命运与性能回归不受影响。
