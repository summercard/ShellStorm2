# Phase 3：武器装配树

## 目标
实现完整的武器装配树数据结构与可视化界面，让玩家能拼装枪身 + 子弹 + 配件。

---

## 装配树结构
```text
主枪身 GunBody_A
├── 子弹 Bullet_A
│   ├── 子弹挂载槽 MountSlot_1
│   │   └── 枪身 GunBody_B
│   │       └── 子弹 Bullet_B
│   └── 配件 Attachment_X
├── 枪口配件 Attachment_Muzzle
└── 弹匣配件 Attachment_Magazine
```

---

## 装配流程
```
玩家打开装配界面
→ 选择主枪身
→ 选择子弹
→ 选择配件
→ 系统检查槽位、标签、冲突规则
→ 生成武器装配树
→ 计算基础预览数值
→ 进入战斗
```

---

## 装配界面 UI 结构
```
左侧：背包模块列表
中间：武器装配树（可视化节点）
右侧：当前属性与触发说明
底部：命运卡片可用操作
```

---

## 节点执行逻辑

### FireContext（每次射击生成）
- 发射者
- 发射位置
- 瞄准方向
- 当前武器树
- 伤害倍率
- 命运修正
- 随机种子

### HitContext（命中时生成）
- 命中目标
- 命中位置
- 伤害类型
- 触发源节点
- 是否暴击
- 是否击杀
- 后续触发队列

---

## 关键限制（防止组合爆炸）
| 限制项 | 建议值 |
|---|---|
| 武器树最大深度 | 3-5层 |
| 单次射击最大生成投射物数量 | 软上限 |
| 单个投射物最多挂载枪身数量 | 1-3把 |
| 召唤物数量上限 | 按模块控制 |
| 递归触发衰减 | 每层伤害递减 |

---

## 美术表现原则
- 子弹上粘了一把枪 → 子弹 Sprite 上挂一个缩小的枪 Sprite
- 子弹上粘了三把枪 → 三个枪 Sprite 围绕子弹旋转
- 枪身被变大 → 直接放大枪身节点
- 子弹变异成活体 → 子弹加眼睛和小脚动画
- 枪管反向 → 枪 Sprite 旋转180度，并真的向后开火

---

## 核心组合示例
| 组合 | 效果 |
|---|---|
| 子弹上挂枪 | Bullet + GunBody + 命运卡片「子弹背枪」|
| 枪身上挂枪 | GunBody + GunBody + 命运卡片「枪上加枪」|
| 子弹装子弹 | Bullet + Bullet + 命运卡片「弹中弹」|
| 配件寄生子弹 | Bullet + Attachment + 命运卡片「配件寄生」|
| 枪弹融合 | GunBody + Bullet + 命运卡片「枪弹合一」|
