# PH23｜2D 玩法完整 3D 等价迁移与性能治理

> 当前规则更新（PH27，2026-07-22）：本页的 96°玩法前锥描述属于阶段验收历史。现行逻辑视野是 21m 内 360°、仅物理遮挡；96°扇形仍按原采样和外观表达目光/探照灯方向。

## 目标

3D 版本不是独立简化模式。原 2D `RoomGameMode`、`RoomData`、`InventoryModule`、`WeaponAssemblyTree`、`LootModule`、`MonsterInjector` 和撤离结算定义玩法真值；3D 只替换空间、碰撞、表现和输入适配层。

## 性能预算

- 开局只同步创建当前房间壳和内容；开门时构造并预热相邻房，远端房连外壳都不创建。
- 走廊仅在边已开启且与当前房相连时启用渲染和碰撞；垂直走廊按真实高差生成斜坡。
- 只有当前房敌人运行完整 AI；离开房间后冻结，重返恢复；不可见房关闭渲染、物理处理和灯光。
- 每个房间只保留 1 个中央顶灯，默认关闭；墙面开关只切换当前房灯。玩家另有 1 个表现层探照灯允许投影，但不计入玩法可见性。
- 玩家视野射线按固定频率批量更新，逻辑显隐与柔边地面视野复用同一批结果；`SpotLight3D` 只跟随表现朝向，不作为判定源；稳定状态不重复重建网格。
- 投射物与短命特效进入对象池；同一枪弹材质和网格复用，禁止每发创建独立网格/材质。
- 死亡/释放的敌人必须同步清理房间索引，跨房流送不得访问失效对象。
- 自动验收阈值：最重主题开局 ≤500ms、单房流送构造尖峰 ≤120ms、同时活动房 ≤5、活动局部灯 ≤14、全探索节点 ≤3500；96 发投射物第二批不得新增分配。

## 分阶段验收

1. 房间/门/钥匙/流式激活形成可跑闭环。
2. 背包、地面拾取、容器与怪物掉落接入原模块。
3. 武器树驱动 3D 射击与工作台，遍历 56 组基础组合。
4. 视野锥、墙体遮挡、探索可见性和灯光预算通过遮挡场景测试。
5. 六怪+精英+Boss、掉落、撤离、死亡/成功结算通过端到端测试。
6. 四主题、靶场和随机种子回归；性能门槛与 2D↔3D 功能矩阵全部为绿后才可宣称完成。
