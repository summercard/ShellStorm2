# 游戏愿景与核心循环

## 一句话定位

一款以顶视角 3D 射击为操作基础、以“向下爬楼”为空间主线、融合搜打撤风险选择与肉鸽枪械组合的动作游戏。

## 核心体验

- 射击必须直接、可读，走位、冲刺、换弹和受击反馈服务于战斗判断。
- 搜刮不是清单劳动，而是决定继续深入、调整构筑或提前撤离的风险筹码。
- 枪身、子弹和命运卡组合应产生可见的规则变化，而不只是数值叠加。
- 塔楼空间应让玩家持续理解“我在哪一层、下一步往哪里、门后风险是什么”。

## 单局循环

```text
楼顶出生
→ 进入 99 层基地准备区
→ 选择装备、契约与风险
→ 打开下行门并进入 98 层
→ 清理房间、搜刮、获得钥匙和构筑资源
→ 在楼梯、门与撤离设施之间选择继续或离开
→ 深入 97、96、95 层
→ 击败 Boss 或使用满足条件的撤离设施
→ 成功带出资源，或失败结算损失
→ 下一局用基地长期进度解锁更多组合
```

## 关键决策

| 决策 | 玩家问题 | 设计要求 |
|---|---|---|
| 战斗 | 当前构筑适合清群、控场还是单体？ | 怪物行为和弹道必须可读 |
| 构筑 | 继续强化现有武器还是赌规则突变？ | 组合结果要在表现与数值上同时可感知 |
| 探索 | 用钥匙开哪条路线、搜哪间房？ | 门、楼梯、小地图和房间状态必须一致 |
| 撤离 | 当前收益是否值得继续冒险？ | 撤离条件、倒计时和风险必须明确 |

## 单局节奏目标

- 0–5 分钟：建立基础武器组合，学习本局房间路线。
- 5–15 分钟：构筑产生明显规则变化，遭遇精英与条件门。
- 15–25 分钟：高价值搜刮、Boss、撤离防守和损失压力集中出现。
- 25 分钟后：只服务于极限构筑与高风险收益，不无限拖长普通局。
