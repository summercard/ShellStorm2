# 关卡与场景设计

## 当前场景路线

```text
TowerDescent3D（正式入口）
├─ 楼顶：出生、视觉定向、首个下行入口
├─ 99 层：30×30m 基地与常驻 STANDARD 撤离信标
├─ 98 层：入口教学、钥匙门与战斗房
├─ 97 层：路线深化与更高风险组合
├─ 96 层：精英、资源与撤离压力
└─ 95 层：Boss 与最终撤离
```

`BaseWorld3D`、`Dungeon3D` 和 `TrainingRange3D` 仍是可运行的独立场景，分别承担兼容基地、主题副本和训练验收。旧 2D 场景归入兼容层，不作为新增关卡模板。

## 空间规范

| 项目 | 冻结值 |
|---|---:|
| 世界单位 | 1 unit = 1m |
| 网格单位 | 5×5m |
| 普通战斗房 | 30×25m（6×5 格） |
| 基地核心 | 30×30m（6×6 格） |
| 标准层高 | 9m |
| 标准地砖 | 5×5×0.30m |
| 标准实墙 | 5×0.30×9m |
| 标准门净空 | 2.2×2.5m |

所有组件坐标由 `TowerGeometry3D` 计算并对齐网格。奇数格组件中心允许落在半格，判断标准是组件边界而不是节点原点必须为 5 的整数倍。

## 组件装配规则

- 地砖、实墙、门墙、女儿墙、楼梯总成和可交互设施必须是独立可复用 Mesh/Scene。
- 墙和地砖不能用隐藏大平面或不可见碰撞补洞。
- 门墙的墙体、门扇、触发区和碰撞均使用同一组件局部坐标。
- 拐角只解决两段墙的连接，不额外生成超出 5m 接口的碰撞体；两条墙臂使用独立碰撞，四角只把沿世界 X 轴的水平墙臂注册为镜头交互面。
- 所有墙体从地面 `0m` 延伸到 `9m`；运行时批量实例必须用 Mesh 包围盒底面自动对齐楼面，不能把可视 Mesh 原点放到碰撞盒的 4.5m 中心高度。只有楼顶女儿墙使用 1.5m 高度。
- 所有沿世界 X 轴的水平共享墙都注册为镜头交互面，实际是否触发由角色向固定镜头后方的射线决定；因此同一面 north 墙在玩家穿门后会成为连接格的南墙，而东西侧墙不会误触发。
- 东西向房间连接通道的无门南侧实墙也必须拥有独立 `camera_lower_wall` 碰撞标记，不能依赖两端房间门墙代偿；南北向通道只有东/西墙，不参与抬镜。
- 水平通道必须依据两端真实门组件坐标动态求长，模块数 `N = 门间距离 / 5m`；可视层必须完整生成 `N` 块地砖和左右各 `N` 块实墙。允许双侧碰撞各合并为一个连续盒体来避免拼缝卡顿，但碰撞长度不得超过或短于可视模块覆盖范围，禁止再次出现“中间只有一块墙、两端是空气墙”的结构。
- 水平通道的重复地砖和墙体使用 MultiMesh 批量实例化；每个实例仍保留独立的 5m 坐标，不允许通过拉伸单个 Mesh 冒充模块拼接。这样整层一次冻结布局时，长通道可以随门距增长而不突破节点预算。
- north/south 门洞都必须配置完整覆盖 5×9m 墙位的相机专用代理碰撞；门扇开启、实体碰撞关闭后仍须触发镜头抬升与收回。该代理只供相机探针查询，不得阻挡角色、怪物、子弹或导航，也不得再用开放门洞全局旁路跳过墙体检测。
- 楼梯间位于世界南侧的满高围护墙遵循同一镜头规则。四面楼梯围护直接从各自可视 Mesh 生成同形碰撞，禁止用整段路径包围盒或其他不可见大盒体代替。99 层基地西侧入口和东侧出口分别用 15m、20m 的 5m 地砖/实墙模块拼成封闭走廊，走廊侧墙保留实体碰撞，禁止使用不可见墙限制路线。
- 镜头墙探针必须从角色前侧穿过角色向后检测，并使用三条横向采样；贴墙时允许探针从碰撞体内部命中。角色完全贴墙时仍须保持镜头抬升至 8.3m，并收回到墙内侧约 0.15m 后移位置。
- A/B 两套墙材质和地砖材质按网格奇偶交替，作用是快速识别装配方向，不改变碰撞或导航。

## 灯光与材质

- 太阳和房间灯使用世界层与玩家层，照亮玩家、怪物和环境，并允许产生正常投影。
- 玩家随身主聚光、环境溢光、角色柔光不得对玩家自身投影；主聚光同时使用 `light_cull_mask=layer1` 与 `shadow_caster_mask=layer1`，环境溢光只照世界层，角色柔光不启用阴影。
- v0.1 随身灯曝光预算：主聚光能量 7.2、环境溢光 0.7、角色柔光 2.8；不得通过提高曝光或自发光补偿可见性。
- Compatibility 渲染器下主聚光固定使用阴影偏移 `0.18`、法线偏移 `1.6`、模糊 `1.2`，用于消除远处斜角墙面的规则横纹；该修正只影响主聚光的阴影采样，不改变能量、范围、光照层或自身投影隔离。
- 玩家、穿戴物和手持枪保留 `cast_shadow=ON` 并位于 layer2；太阳与室内灯的阴影投射掩码包含 layer1|layer2，因此仍能产生正常外部投影。
- 地砖和墙材质采用低金属度、高粗糙度，禁止通过高曝光补偿室内暗部。
- 墙体材质始终保持不透明；镜头碰撞不得改写墙体 alpha、材质覆盖或节点可见性，遮挡角色时只显示角色轮廓。
- 99 层基地灯光总开关固定在楼顶来向的西侧入口墙，沿墙距门 4m，确保进门可见且不会与开门交互重叠。基地四盏 `failing=false` 顶灯必须保持固定能量，不进入故障灯的慢波/微波调制；开关只在已加载房间内切换 `0 / 配置能量`，不得反复移除并重挂 Compatibility 渲染器中的 `OmniLight3D` 实例。重新开启必须在同一帧恢复配置能量、照射范围与阴影状态，且固定机位的地面采样应与初始开灯一致。
- 99 层常驻 STANDARD 撤离信标在待机和锁定状态使用固定局部光；只有正式启动撤离倒计时时允许光能量脉冲，避免与基地总开关形成错误的地板明暗反馈。
- 雾只表达距离与氛围，不能替代真实遮挡或单位可见性。

## 生成不变量

战斗层第一次被触发时，必须以整层为一个布局事务，一次冻结该层全部房间组件坐标、门轴、水平通道、下层入口大厅和上下楼梯接口。房间 Mesh 与内容仍按“当前房 + 已开启邻房”流送，流送只能改变显隐、碰撞和运行状态，不能重新随机或移动已经冻结的楼层布局。

敌对房的首波怪物必须在连接门开启、目标房进入“已显现邻房”状态的同一次流送中创建。玩家进房前暂停该房 AI，但怪物实例已存在并可交由视野系统判定显隐；玩家进入时只激活同一批实例，禁止二次生成或靠距离触发突然刷怪。

整层布局必须同时检查房间矩形占地和导入楼梯 Mesh 的实际投影占地。楼梯大厅是对应接口的唯一例外；任何普通房、随机支路、Boss 区或电梯接入房都不得侵入楼梯折返区。98—96 层入口后的主环通过 25m 模块化直走廊退出楼梯占位，再进入 30×25m 房间环。

每次生成必须验证：房间边界闭合、房间实际矩形互不重叠、房间不侵入楼梯保留区、地面无非设计洞口、门中心落在墙段、入口到出口可达、敌对房间有敌人来源、清房条件可达、楼梯上下端连接到真实门槽、不可见装饰不带碰撞。
