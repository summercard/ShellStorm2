## 模块化边界

- 角色：逻辑根、碰撞、视觉根、身体、头、耳、左右手、左右脚、穿戴物和武器插槽分离。
- 怪物：逻辑根与视觉根分离；不同生态通过配置和组件复用。
- 武器：枪身逻辑、弹体逻辑、世界模型、手持模型、UI 图标分离但共享逻辑 ID。
- 道具：世界拾取模型与 UI 表现来自同一 AssetID，不重复维护两套语义。
- 场景：地砖、墙、门墙、拐角、楼梯、家具和设施使用可复用组件，不把整层烘焙为唯一 Mesh。
- 材质：共享材质使用 `.tres`；运行时临时材质只用于状态反馈，不承担资产定义。
- 动画：动作状态由稳定 ID 驱动；程序动画和资源动画都不能修改玩法碰撞。
