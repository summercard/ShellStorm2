## 交付结论

项目入口、固定基地、四张主题副本、种子随机关卡、独立训练靶场、角色、七类敌人、枪械、弹丸、伤害反馈、家具、搜索容器、服务终端、危险区、Boss 解锁和撤离结算已经形成统一的 3D 可玩闭环。原有玩法 ID、蓝图目录、基地存档和主题配方继续作为单一数据源，3D 层没有复制一套平行规则。

当前定位是“高质量可玩原型”：空间、光照、材质响应、状态动态、玩法闭环和资产边界已经可严格验收；程序生成 PrimitiveMesh 仍按资产规范标记为程序占位，可在后续替换为正式 DCC 模型而不改玩法脚本。

## 玩家可体验内容

- 从 `BaseWorld3D` 启动，在连续废土道路上使用 8 个基地设施与 4 个 3D 副本入口。
- 进入冷钢边境、锈蚀铸造厂、孢子深层或深渊档案库；每张地图有独立雾色、环境光、主色、危险色、灯色、家具倾向、房间序列和敌人池。
- 同种子复现同一拓扑；不同种子改变支路位置与可选房间。原 `MapThemeProfile` 强制的商店、升级、仓储等支路仍会出现。
- 房间有小、中、大三档，保留门洞和连接走廊；大件家具锚定空间，中件形成工作/掩体区，小件承担细节与搜索点。
- 使用一只悬空手和独立枪械挂点。角色整体随瞄准朝向，手始终保持身体局部位置，枪只做局部后坐力，不再出现手与身体脱节。
- 遭遇追猎、远程、召唤、盾甲、自爆、伏击与 Boss 七类敌人；预警、攻击、硬直和死亡都有独立 3D 动态。
- 搜索物资、使用补给/改造/事件终端、击败 Boss 解锁信标，并保持在撤离范围完成结算。
- 在独立 3D 靶场组合 7 种枪身与 8 种弹药模块，共 56 种组合；测试标准、装甲、移动三类靶标，重置靶标与弹药后返回基地。训练过程不写入 `BaseData`。

## 状态机与战斗规则

- 玩家继续使用六态白名单：`idle / moving / dashing / hurt / locked / dead`；Dead 仍为终态。
- 玩家 Low HP、无敌等继续作为叠加表现，不增加互斥主状态。
- 敌人统一使用九态：`idle / patrol / alert / chase / search / telegraph / attack / stagger / dead`。
- 盾甲敌人的正面护甲、装甲靶减伤、召唤增援、远程实体弹、自爆范围和 Boss 弹幕/召唤均由统一伤害入口处理。
- 子弹支持普通、黏滞、反弹、穿透、爆炸、追踪、黑洞与气球标签；模型和弹丸颜色由 canonical ID 配置。

## 废土光照与空间语言

- 房间进入时默认无中央照明，玩家依靠前向探照灯与柔边真实视野辨认空间；探照灯投射阴影，但不参与敌人、掉落或交互物的可见性判定。
- 每个房间只生成一盏正中央的真实 `OmniLight3D` 顶灯和一个墙面开关；按 `E` 切换本房照明。室内不再生成路灯杆、悬臂或透明假光池。
- 室外与靶场仍可使用同一灯具根的 `street` 配置；故障节奏保持低频且仅在活动空间运行。
- 四主题分别使用冷蓝、锈橙、病绿和档案洋红/紫色，并配合独立雾密度、环境光与危险色。
- 房间中央保留战斗走位，门洞保留约 3.8 m 清宽；家具沿墙和角落分层，服务终端与撤离信标保留独立交互半径。
