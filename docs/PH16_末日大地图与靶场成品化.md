# PH16 末日大地图、战斗表现与训练靶场成品化

**状态：实施中**  
**日期：2026-07-11**

## 最终目标

把当前可运行的射击肉鸽框架打磨成具备独立气质的完整体验：玩家从一座仍在勉强运转的末日基地出发，沿破败大路进入不同污染区；稀疏、故障的照明承担导航和情绪，怪物通过轮廓、体型、运动与技能预警即可辨认，角色和 UI 对状态变化提供一致的高品质反馈；基地内提供独立训练靶场，允许无成本测试全部枪械、弹药与组合，离场时不带走任何测试物品。

## 完成范围

1. **大地图与氛围**：基地—荒野连续地图具备破败道路、废墟、路障、残骸、冷暖污染区、稀疏故障灯和屏幕空间尘雾；灯光既是气氛也是导航语言。
2. **场景灯光**：基地冷白安全灯、铸造区故障钠灯、孢子区病绿色、深渊区紫红警戒光形成分区；纯黑不得吞没移动与交互信息。
3. **怪物表现**：类型在形状、体型、重心、速度、蓄力与受击反馈上可辨，不依赖名字或单纯换色。
4. **角色状态表现**：移动、冲刺、受伤、低血、死亡与交互锁定均有独立动画/颜色/残影层，状态机是表现触发的唯一入口。
5. **UI 成品化**：建立统一字号、颜色、面板、动效与输入焦点规范；基地、战斗、结算和训练靶场共享视觉语言。
6. **训练靶场**：作为基地可进入的独立房间；进入后隔离正常装备上下文并清空测试角色，提供全部枪身、弹药和组合开关、可重置靶标与实时伤害统计；退出时销毁测试配置，不写入背包、保险库或局外成长。

## 本轮方向：大地图末日氛围垂直切片

### 为什么先做它

大地图是启动游戏后的第一视觉承诺，也是所有设施和副本入口的共同背景。当前地图功能完整但主要由大块纯色多边形组成，缺少材质尺度、局部光源、废墟叙事和视觉导航；继续增加 UI 或功能会被薄弱的世界呈现抵消。

### 玩家可感知变化

- 基地仍是可读的冷蓝安全区，但只剩少量维持运转的灯。
- 向东离开基地后，路面出现断裂、补丁、车骸、路障、废弃地基和散落残片。
- 四个副本入口分别由钢蓝、锈橙、孢子绿、深渊紫红光引导，而不是依赖彩色大方块。
- 灯具会轻微抖动或间歇熄灭；屏幕边缘有克制的蓝黑雾化和尘埃感，但 HUD 始终清晰。

### 技术边界

- 新增独立 `BaseWorldAtmosphere` 表现节点，只读取固定世界坐标，不持有基地功能、存档或入口逻辑。
- 程序化绘制使用固定种子，保证每次进入布局一致；未来可用 TileMap、Sprite 或正式美术逐层替换。
- 灯光、覆盖层和世界装饰不增加碰撞，不改变现有道路、设施、入口与返回点契约。

### 验收标准

1. `BaseWorld` 启动时存在语义化的 `Atmosphere` 节点、环境调色与不少于 8 个稀疏光源。
2. 大地图从基地到第四入口沿途至少包含道路破损、废墟轮廓、残骸/路障三类程序化细节。
3. 四个入口区域具有可区分的灯光色相，故障灯能在运行时改变能量但不会产生高频闪烁。
4. 屏幕空间氛围层位于世界之上、基地 HUD 之下，不阻挡输入。
5. `verify_base_world_flow` 扩展验证上述契约，节点量继续低于既有上限；全部现有验证保持通过。

## 后续循环

1. 独立训练靶场：已完成，详见 `PH17_独立训练靶场.md`。
2. 怪物视觉生态：六种基础怪物体型/轮廓/动作节奏与预警包装。
3. 玩家状态表现：状态机驱动的移动、冲刺、受伤、低血与死亡层。
4. UI 成品化：基地导航、战斗 HUD、靶场控制台与结算动效统一。

## 本轮刻意延后

- 不在大地图中常驻任何战斗副本或靶场模拟，避免破坏独立场景生命周期。
- 不在本切片中重做设施交互逻辑；设施与入口的造型包装将在共享氛围稳定后继续深化。

## 2026-07-11 大地图氛围切片实施结果

- 新增 `BaseWorldAtmosphere` 独立表现层，使用固定种子生成 42 组路面裂纹、14 块修补路面、96 个散落残片、8 处废弃地基，并手工组织车骸、路障、警告牌与枯树叙事点。
- 部署 13 盏低频故障灯：基地冷蓝、边境钢蓝、铸造锈橙、孢子病绿、深渊紫红；故障灯使用长周期短熄灭，不制造高频闪烁。
- 加入世界色彩分级与屏幕空间尘雾/暗角，覆盖层位于世界之上、基地 HUD 之下且不接收输入。
- 出生广场补充紧急维护环、磨损分区线、地面裂缝、供电线缆和临时电力箱；基地专用玩家表现放大 1.28 倍，碰撞保持不变。
- `BaseFacilityRenderer` 将七个基地功能从彩色矩形替换为破败装甲掩体；`DungeonEntranceRenderer` 将四个入口替换为带装甲肋、深色门洞、故障灯与路障残片的废弃地堡。
- 设施说明改为靠近时显示，常态只保留高对比名称，降低基地画面文字噪声。

### 验证证据

- Godot 4.6.2 编辑器脚本扫描无解析或加载错误。
- `verify_base_world_flow.tscn` 通过，验证氛围节点、13 盏稀疏灯、四类分区色、屏幕覆盖层和程序化细节；场景共 183 个节点，低于既有 220 节点上限。
- 21 个场景流程验证与独立命运卡池验证均未出现 `SCRIPT ERROR`、`Parse Error`、`Invalid call` 或 `ERROR`。
- 使用 Godot 实机窗口检查 1280×720 基地画面：基地照明、掩体轮廓、玩家与 HUD 层级可读；下一轮将以独立训练靶场作为功能/表现垂直切片。
