# Phase 2：模块化武器系统

> 本阶段进行中

## 目标
将武器拆分为可组合的节点：枪身（GunBody）、子弹（Bullet）、配件（Attachment），并定义统一接口。

---

## 枪身 GunBody

### 核心属性
| 参数 | 说明 |
|---|---|
| fire_rate | 每秒发射次数 |
| projectile_count | 一次发射几颗子弹 |
| spread | 扩散角度（度） |
| reload_time | 装填时间（秒） |
| magazine_size | 弹匣容量 |
| charge_type | 充能方式（点射/连射/蓄力/爆发） |

### 基础标签
`Gun.Auto` `Gun.Burst` `Gun.Shotgun` `Gun.Sniper` `Gun.Launcher` `Gun.Floating` `Gun.Charge`

---

## 子弹 Bullet

### 核心属性
| 参数 | 说明 |
|---|---|
| speed | 飞行速度 |
| lifetime | 存在时间（秒） |
| damage_multiplier | 伤害倍率 |
| collision_size | 碰撞判定大小 |
| hit_behavior | 命中行为（穿透/爆炸/弹跳/黏附/召唤） |
| damage_type | 伤害类型（物理/火焰/毒/冰/电/诅咒） |

### 基础标签
`Bullet.Sticky` `Bullet.Explosive` `Bullet.Bounce` `Bullet.Pierce` `Bullet.Homing` `Bullet.Living` `Bullet.Mountable`

---

## 配件 Attachment

### 配件类型
| 类型 | 作用 |
|---|---|
| 枪口 Muzzle | 修改出弹数量、角度、弹速 |
| 弹匣 Magazine | 修改装填、弹量、连发节奏 |
| 瞄具 Scope | 修改暴击、追踪、弱点 |
| 枪托 Stock | 修改后坐力、移动惩罚 |
| 外挂物 External | 增加自动射击、护盾、召唤物 |

### 基础标签
`Attachment.Muzzle` `Attachment.Magazine` `Attachment.Scope` `Attachment.Stock` `Attachment.Mutator` `Attachment.External`

---

## 武器装配树节点类型
| 节点类型 | 职责 |
|---|---|
| GunBodyNode | 处理开火节奏与发射行为 |
| BulletNode | 处理投射物移动、命中、生命周期 |
| AttachmentNode | 修改目标节点属性或行为 |
| FateCardNode | 在运行时插入特殊规则 |
| MountSlotNode | 提供可挂载位置 |
| VisualNode | 负责显示拼接结果 |
