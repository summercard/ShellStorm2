# Phase 6：怪物系统

## 目标
实现 10 种基础怪物 + 词缀系统，逼迫玩家改变走位和武器组合策略。

---

## 基础怪物分类
| 类型 | 作用 | 示例 |
|---|---|---|
| 近战追击型 | 压迫走位 | 小菌猪、裂口爬虫 |
| 远程弹幕型 | 制造弹幕空间 | 孢子射手、毒囊花 |
| 召唤型 | 制造持续压力 | 蜂巢怪、机械母巢 |
| 护盾型 | 保护其他怪 | 壳甲卫兵、镜面水母 |
| 自爆型 | 逼迫拉扯 | 炸弹果、膨胀鼠 |
| 潜伏型 | 打断搜刮节奏 | 地刺虫、影子蘑菇 |

---

## 精英词缀
| 词缀 | 效果 |
|---|---|
| 巨大化 | 体型、血量、碰撞范围增加 |
| 分裂 | 死亡后生成小怪 |
| 反弹 | 周期性反弹子弹 |
| 寄生 | 死亡后附着在其他怪身上强化它 |
| 抢枪 | 短暂复制玩家当前枪械的一部分效果 |
| 吞弹 | 吃掉投射物并转化为自己的攻击 |

---

## 怪物词缀系统
通过 `EnemyModifier` 组合，不改怪物本体代码：
```text
EnemyBase（怪物AI）
    └── EnemyModifier[]（词缀数组）
```

---

## 解耦结构
| 模块 | 职责 |
|---|---|
| EnemyBase | 基础AI、属性、死亡事件 |
| EnemyModifier | 词缀效果（独立组件） |
| LootModule | 掉落表（与怪物AI解耦） |
| SpawnDirector | 生成器（根据房间标签注入） |
