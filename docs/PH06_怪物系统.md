## 🏔️ 楼层强度曲线（Floor Scaling）
*（v4 新增 — 代码级事实，PH06 之前版本未录入）*

怪物数值不靠固定模板，而是通过 `FLOOR_SCALING` 在 `MonsterInjector` 中统一控制：

```gdscript
const FLOOR_SCALING := {
    1: { "hp_mult": 1.0, "damage_mult": 1.0, "loot_mult": 1.0 },
    2: { "hp_mult": 1.4, "damage_mult": 1.2, "loot_mult": 1.3 },  # 第二关：显著提升
    3: { "hp_mult": 1.5, "damage_mult": 1.3, "loot_mult": 1.5 },
    4: { "hp_mult": 1.8, "damage_mult": 1.5, "loot_mult": 1.8 },
    5: { "hp_mult": 2.2, "damage_mult": 1.8, "loot_mult": 2.2 },
}
```

### 生效位置
| 调用方 | 作用 |
|---|---|
| `MonsterInjector._generate_basic_enemy()` | 普通怪物 HP/Damage 缩放 |
| `EliteSpawnDirector._build_elite_spawn_data()` | 精英 HP/Damage 缩放（叠加 growth_stats） |

### 第二关数值感受
- 怪物 HP × 1.4（+40%），Damage × 1.2（+20%），掉落 × 1.3
- 基础怪 HP 25 × 1.4 = 35，Damage 5 × 1.2 = 6
- 精英怪在此基础上再叠加 `growth_stats` 和 `tier`

## 精英怪专属主动技能（v3 — 本轮新增）

### 问题
精英怪物只有词缀系统（巨大化/分裂/反弹/寄生/抢枪/吞弹），缺少精英专属主动技能。相比基础6种怪物的完整技能树（冲刺猛击/散射弹幕/召唤小怪等），精英怪的攻击手段过于单一。

### 解决方案
新建 `src/enemy/components/EliteActiveSkillComponent.gd`，为精英怪物注入专属主动技能层，与基础怪物的 `EnemySkillComponent` 解耦。

### 精英专属主动技能

| 技能ID | 精英词缀 | 效果 | tier影响 |
|---|---|---|---|
| `elite_charge` | 巨大化 | 快速冲向玩家，接触伤害+击退 | 冲锋速度+40/ tier |
| `shield_reflect` | 反弹 | 激活护盾，持续时间内反射投射物 | 持续时间+20%/tier |
| `elite_rally` | 分裂 | 召集范围内友军，移速+伤害加成 | 范围+30px/tier，buff+5%/tier |
| `elite_enrage` | 寄生/巨大化 | 低血量时狂暴化，移速+50%，伤害+40% | 提升幅度+tier |
| `skill_countershot` | 抢枪 | 被命中时18%概率沉默玩家1.5秒 | 反制概率+6%/tier，沉默+0.3s/tier |
| `elite_teleportstrike` | 寄生 | 传送到玩家背后并造成范围伤害 | 传送距离+20px/tier，伤害+25%/tier |

### EliteActiveSkillComponent 设计
- `tick(delta)` 由 EnemyBase 在 `_physics_process` 中调用
- 注册：`register_elite_skill(skill_id, cooldown, config)`
- 执行：每个主动技能有独立 cooldown timer，到期触发
- tier（1-3）影响技能强度参数
- 技能工厂 `inject_elite_skills(enemy, modifier_id, tier)` 由 RoomWaveSpawner 在生成精英怪物时调用（通过 `call_deferred` 调用 `EnemyBase._inject_elite_active_skills()`）

### 实际调用链路（v4 — 本轮修正）
```
EliteSpawnDirector._build_elite_spawn_data()
  → spawn_data["tier"] = mini(3, (level - 1) / 2 + 1)
  → spawn_data["modifier"] = "Elite.Huge" 等
RoomWaveSpawner._spawn_enemy_instance()
  → enemy._is_elite = true
  → enemy.call_deferred("_inject_elite_active_skills", modifier, tier)
EnemyBase._inject_elite_active_skills()
  → EliteActiveSkillComponent.new(enemy, tier)
  → add_child(comp)
  → comp.inject_elite_skills(enemy, modifier_id, tier)  ← 静态工厂
  → 词缀 → 6种精英专属主动技能之一注入完成
```

### 注入时机说明
- `inject_elite_skills()` 是静态工厂方法，原本计划由 EliteSpawnDirector 调用
- 实际运行时通过 RoomWaveSpawner 在 `_spawn_enemy_instance()` 中，以 `call_deferred` 调用 EnemyBase 的 `_inject_elite_active_skills()` 实例方法，再间接调用静态工厂
- tier 计算规则：`level 1-2→tier1，3-4→tier2，5+→tier3`
- `add_modifier()` 注入词缀（`EnemyModifier`），`_inject_elite_active_skills()` 注入主动技能（`EliteActiveSkillComponent`），两者互补

### 实现证据

```
├── tick() — 每帧评估主动技能 cooldowns
├── _exec_elite_charge — 冲锋+击退
├── _exec_shield_reflect — 护盾反射激活+视觉
├── _exec_elite_rally — 召集令（友军buff）
├── _exec_elite_enrage — 低血狂暴化

```
