# PH42｜统一太阳与物理遮光室内照明

## 一、目标

塔楼只使用一套连续的室外自然光环境。玩家从楼顶进入室内时，不再通过楼层号
降低太阳亮度或切换一套“室内太阳”；墙、上层楼板、天花板、关闭的门和楼梯间
墙体负责真实遮挡太阳直射。室内可读性由房间灯具与角色探照灯承担。

本阶段不制作带窗洞的墙体模块。现有自发光窗面与模拟窗光聚光灯全部移除，
外墙继续使用完整的五米实墙模块。后续制作真实窗墙时，太阳光只能通过实际窗洞
进入室内。

## 二、光照契约

1. 塔楼全程只有一盏主要 `DirectionalLight3D`：
   - 能量、颜色、方向和阴影状态不随楼层变化；
   - 楼层切换只更新楼层状态、远景城市显隐、室内灯与角色探照灯状态；
   - 自然光是否抵达表面完全由可见几何和阴影决定。
2. `WorldEnvironment` 使用固定低强度环境底光：
   - 环境底光只用于避免未照明区域压成纯黑；
   - 不使用高环境光伪造室内曝光；
   - 背景、环境光、雾和曝光不随楼层瞬间跳变。
3. 楼板、外墙、9米内墙、门与楼梯间墙继续参与太阳阴影：
   - 当前层上下最多两层保持物理壳体加载；
   - 上层楼板同时是当前层天花板；
   - 关闭的门应阻断自然光视觉与玩法射线。
4. 本阶段禁止任何假窗光：
   - 不生成 `TowerWindow_*` 自发光面板；
   - 不生成 `TowerWindowNaturalLight` 聚光灯；
   - 不在完整实墙表面绘制会误导玩家的发光窗。

## 三、室内灯与探照灯

1. 房间顶灯继续使用真实局部灯光，默认关闭，由墙壁开关控制。
2. 基地设施层顶灯可保持常亮；战斗房、走廊和楼梯间允许按关卡设计保持断电、
   部分供电或故障闪烁。
3. 角色进入室内后启用探照灯，返回楼顶时关闭；探照灯不参与敌人和掉落物的
   玩法显隐。
4. 1.5米角色的探照灯源点必须落在胸口/武器附近，不能继续使用高于角色头顶的
   2.25米旧安装高度。
5. 主探照灯保留阴影；近身环境溢光与角色正面补光不投影，避免增加不必要的
   阴影开销。

## 四、性能边界

- 统一太阳不会增加方向光数量，仍只有一盏主要阴影方向光。
- 只有当前房间和必要的相邻空间启用局部灯光；远房随流送停用。
- Compatibility渲染器下避免让同一网格同时受到过多局部灯影响；后续增加灯具
  阵列前，应先把335米整层的大型MultiMesh按空间区块拆分。
- 窗户在真实模块完成前保持封闭，不使用额外窗口聚光灯占用灯光预算。
- 光照只负责表现。`PlayerVision3D` 继续使用距离与物理遮挡判定，不读取任何
  太阳、房间灯或探照灯状态。

## 五、验收标准

1. 楼顶、99层和任意战斗层的太阳能量、颜色与阴影状态完全一致。
2. 楼层切换时环境光、雾密度和曝光不发生跳变。
3. 室内因为上层楼板和9米墙体遮挡太阳而变暗，不是因为脚本降低太阳能量。
4. 运行时不存在 `TowerWindow_*` 或 `TowerWindowNaturalLight`。
5. 房间顶灯关闭时保持暗室；开灯后明显照亮房间，且墙壁开关仍可用。
6. 角色探照灯源点不高于1.5米角色头顶，主光束能照亮前方并产生阴影。
7. 玩法视野、门遮挡、楼梯双向通行、怪物刷新、命运卡与性能预算无回退。

## 六、实施与验收结果

- `TowerAtmosphere3D` 已改为固定太阳：全楼层能量0.72、固定暖色、阴影开启；
  环境底光固定为0.07，雾密度固定为0.0012，楼层切换不再修改光照参数。
- `DungeonRoom3D` 已删除自发光 `TowerWindow_*` 面板及
  `TowerWindowNaturalLight` 聚光灯生成路径；现阶段所有外墙均按实墙处理。
- 1.5米角色探照灯安装高度由2.25米降至1.15米，近身溢光与角色补光同步回到
  角色身体范围内；主聚光灯阴影与玩法视野解耦契约保持不变。
- 塔楼专项实测楼顶、99层和98层太阳/环境/雾参数一致；五段9米楼梯双向通行、
  命运门、电梯、怪物、Boss和最多5层流送全部通过，完整塔楼节点数3242。
- 房间暗室、墙壁开关、真实阴影顶灯与角色探照灯专项通过；Compatibility实机已
  保存楼顶、基地、98层关灯、98层开灯和楼梯间五张PH42预览。
- 性能回归通过：生成193.1ms、最重房间7.6ms、全探索2950节点、持续帧段
  6.88ms；移除假窗光后没有增加活动局部灯。
