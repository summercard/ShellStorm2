## 最终健康收口

- 将玩家冲刺闭包定时器改为状态内物理计时，解除状态脚本资源持有。
- 波次与额外增援改为节点自有 Timer 队列；每批敌人数据在入队时冻结，避免相邻增援批次相互覆盖。
- 陷阱警告与落石窗口改为场景节点 Timer，切房时自动销毁。
- Boss 阶段管理器只在 Combat 状态运行，技能有初始错峰和全局间隔，不再在 Idle 或同一帧同时释放全部技能。
- 白闪、飘字、胜利提示和演示转场改为可随节点销毁的 Tween 回调链，消除场景切换时悬挂的 `await tween.finished`。
- Headless 环境跳过真实合成播放，但保留可注入 FakeSynth 的音频降级契约验证。

## 后续资产替换原则

替换正式美术时只替换语义化 Renderer 或对应 UI 主题资源，不改状态名、信号、碰撞 Profile、训练隔离契约和专项验证器。任何替换都应先在两张 Gallery 做同构截图，再运行本轮全部验证。
