# Phase 7：精英怪成长系统

## 目标
精英怪持久化成长、装备继承、复仇登场，制造长期威胁感。

---

## 核心体验
- "这只怪我上局没打死，它又回来了。"
- "它身上好像挂着我上次掉的枪。"
- "它已经成长成一个小Boss了。"
- "我到底是现在撤离，还是冒险把它杀掉拿回东西？"

---

## 精英怪生命周期
```
本局生成精英怪
→ 玩家遭遇精英怪
→ 玩家击杀 / 放跑 / 撤离 / 死亡
→ 系统记录精英怪结果
→ 精英怪进入档案池
→ 根据成长规则更新属性、词缀、装备、仇恨
→ 后续局中按权重再次出现
→ 再次遭遇时携带历史成长
```

---

## 精英怪状态
| 状态 | 说明 |
|---|---|
| 新生 | 第一次生成，只有基础词缀 |
| 逃脱 | 玩家没有击杀它，它从本局活着离开 |
| 战利品持有者 | 它捡走了玩家掉落或遗留的装备/模块 |
| 进化中 | 它在局外获得了成长词缀 |
| 复仇者 | 它记住了玩家，优先追击玩家 |
| 区域霸主 | 多次逃脱后变成区域级强敌 |
| 准Boss | 成长到一定阶段后可晋升为特殊Boss事件 |
| 已击杀 | 被玩家彻底击杀，从档案池移除或转为纪念记录 |

---

## 成长来源
| 成长来源 | 触发条件 | 成长结果 |
|---|---|---|
| 存活逃脱 | 玩家撤离、死亡或离开房间后精英怪未死 | 获得基础属性成长 |
| 击杀玩家 | 玩家死于该精英怪或其召唤物 | 获得高额成长和仇恨标记 |
| 吃掉掉落 | 玩家死亡后掉落装备，精英怪附近存活 | 拾取玩家装备或模块 |
| 吸收环境 | 精英怪所在地图层级较高 | 获得地图主题词缀 |
| 受到特定伤害 | 被火、毒、冰、电等伤害大量命中但未死 | 进化对应抗性或反制能力 |
| 目睹武器组合 | 玩家用特殊组合攻击它但未击杀 | 学习部分组合逻辑 |
| 吞噬其他怪 | 精英怪在战斗中击杀或吸收小怪 | 获得召唤、分裂、巨大化等成长 |

---

## 精英怪装备玩家模块规则
| 玩家模块 | 转化结果 |
|---|---|
| GunBody | 精英怪获得一个周期性射击技能 |
| Bullet | 精英怪远程技能获得该弹体行为 |
| Attachment | 精英怪技能获得修饰器 |
| FateCard | 精英怪获得一个简化版规则词缀 |

限制：精英怪最多装备1-3个玩家模块，装备模块按精英怪等级解锁槽位，数值缩放避免过强。

## 解耦模块
| 模块 | 职责 |
|---|---|
| EliteArchiveModule | 保存精英怪档案、历史和状态 |
| EliteGrowthModule | 根据战斗结果计算成长 |
| EliteSpawnDirector | 决定本局是否让旧精英怪登场 |
| EnemyEquipmentAdapter | 把玩家模块转成怪物技能或词缀 |
| BountyModule | 管理悬赏、奖励和情报 |
| EncounterResultRecorder | 记录玩家是否击杀、逃离、死亡、掉落 |
