# 基地二楼重点深化 v019

源文件：`source/art/blender/base_facility_layout/source/base_facility_runtime_layout_hq_v019.blend`。以v018为输入，v017和v018均保留。

授权范围为原17个完整名称资产包和 `116_二楼地板色彩深化_资产包`。18包内保留隐藏的可编辑制作组件、默认显示的游戏输出。新增物件均归入相应包内部。未修改游戏代码、碰撞、楼梯、栏杆、墙体或楼层接口。

## 重点深化

- 床正面：床垫和宽枕的圆润软包、连续床罩与垂边、窄滚边、床下盖缝和提手、木质双床头柜；床前小桌、打开的书、盆栽、坐墩和织物毯形成完整组合。
- 沙发与上方：三组独立软包、倾斜靠背、斜放彩色抱枕与包扣、针织垂毯；原工位包内上墙旅行海报重画，并加入笼式暖壁灯。灯具几何与真实暖光同属工位包。
- 地板：36排共324块错缝长条木板，有浅倒边、低对比顺纹和邻近胡桃木色差；标高约6.09m保持不变。源木板可独立编辑，输出按三排一组整为12个模块，加1个原标高底层，避免逐板输出造成过多绘制对象。
- 配角：EXPLORE深底金字、填充山峦与越野车；工具板使用低面孔位和不同工具剪影；植物有舒展叶面、交替叶序、下垂藤茎与盆口结构。
