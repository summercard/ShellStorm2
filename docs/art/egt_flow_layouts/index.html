由 EgtFlowAssembler.assemble_flow() 真实跑出来的坐标（seed=4100）， 不是手绘示意。六张骨架共 114 间房， 全部通过「不重叠 / 每条边都落门 / 门位合法 / 同种子可复现」的断言。
看图看什么：
褐色通道＝房间之间的走廊（5m 净宽，画成实体不是细线）；橙点＝门，成对出现在走廊两端。
《挺进地牢》的地图和 flow 图不是一一对应的 —— Boris 原话 "there's these weird corridor rooms"， 实际地图上会多出 flow 里没有的走廊房间；两房直接共墙、门对开的情况也存在，两种混着才像。
连接房（conn）是窄长房：长轴沿行进方向，横向走廊式穿过去 —— 对应原文 "often long, thin rooms, so picking one with a sensible orientation is vital"。 它用的是哪份模板（横/竖）写在每张图的图注里。
