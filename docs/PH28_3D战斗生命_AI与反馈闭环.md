# PH28 · 3D 战斗生命、AI 与反馈闭环

## 目标体验

本轮不是增加新的美术身份，而是修正已有 3D 玩法与表现的连接：怪物应当能可靠发现、追踪和攻击玩家；生命值要承接 3D 战斗节奏而不是被旧 2D 数值覆盖；玩家移动、照明、拾取与钥匙奖励都必须给出清晰且不会阻塞流程的反馈。

## 玩法规则

- Enemy3D 保留九态 `idle/patrol/alert/chase/search/telegraph/attack/stagger/dead`。无遮挡目标可以被射线命中目标本体，不能把目标本体误判为墙；遮挡后仍保留最后已知位置和 2.4 秒搜索。
- 旧 MonsterInjector 仍负责楼层、主题和精英倍率；Enemy3D 的各类型 3D 基础 HP 负责实际战斗基线。两者以“旧数据相对旧基础值的倍率”组合，不再直接用 10–40 HP 覆盖 3D 基线。
- 开局手枪 + 标准弹普通伤害为 26。满血基础怪不得被普通一枪击杀；爆炸怪至少 2 枪，追猎/远程/伏击怪约 2–3 枪，召唤怪约 3 枪，盾甲怪约 5 枪。楼层、主题与精英倍率继续生效。
- 玩家继续使用六态 `idle/moving/dashing/hurt/locked/dead`，死亡为终态。`moving` 有独立的位移驱动循环：身体弹性、头部反相滞后、围巾滞后、握持手与武器挂点同相移动；停止移动后回到 idle 呼吸。
- 玩家灯光拆为三层：前方主聚光只照环境、近身环境溢光只照环境、角色正面柔光只照角色与手持枪。角色头顶不再出现 Omni 热点；灯光开关不参与 360°逻辑显隐。
- 房间中央灯仍由墙面开关控制，开启时能量提高约 22%，仍保持每房间唯一中央顶灯。
- 普通掉落和房间钥匙在逻辑拾取成功后播放约 0.32 秒的上弹、旋转、缩小动画，再回收节点；背包满时不播放成功动画。
- 所有已肃清且应奖励钥匙的房间都能自愈检查钥匙奖励。钥匙生成在玩家当前位置向房间中心约 2.2 米处，并限制在房间安全边界内；重复进入不会生成第二把。

## 验收标准

1. 无墙时 Enemy3D 视线返回真，0.28 秒警觉后进入追击；插入 layer 1 实体墙后视线返回假。
2. 六类基础怪与 Boss 从 MonsterInjector 数据配置后，HP 不低于各自 3D 基线；26 点普通伤害不能击杀任何满血基础怪。
3. 玩家状态机仍只有六个顶层状态和显式转换白名单；moving 中组件位置/缩放随循环变化，手与枪械挂点相对距离保持不变。
4. 玩家灯具快照为 2 盏 SpotLight3D + 1 盏 OmniLight3D；只有主聚光投影。环境灯使用 render layer 1，角色正面柔光使用 layer 2。
5. 中央灯开启后的配置能量比 PH27 基线至少提高 20%，暗室默认关闭不变。
6. 普通掉落与钥匙拾取后不是同帧消失；动画期间碰撞关闭，结束后节点回收。
7. large/arena 房间在玩家靠近边缘肃清时，钥匙与玩家距离为 1.6–3.6 米且位于安全边界；重复清房/返回不重复；遗漏奖励可在进入房间时补发。
8. 专项、核心流程、性能预算与真实 GPU 视觉验收全部通过，无脚本解析错误、无表格公式错误、无重复资产 ID。

## 性能与复用边界

- 每个玩家固定三盏真实灯，不为每个组件或道具复制灯；只有环境主聚光投影。
- 拾取动画复用现有模型节点和 Tween，不创建粒子系统或逐帧贴图。
- 不新增怪物、角色、钥匙、灯具或掉落 AssetID；更新既有根资产的行为、状态和验收描述。
- 敌人 HP 缩放只在配置时计算一次，AI 视线维持单射线查询，不引入导航烘焙或全局逐帧扫描。

## 延后风险

- 正式模型与 PBR 材质接入后，需要重新校准角色正面柔光的颜色、能量和角度，但 render layer 契约保持不变。
- 当前随机房间仍使用局部直线追踪与碰撞滑动；复杂迷宫若出现长距离绕行需求，再评估 NavigationServer3D，不在本轮增加常驻导航成本。

## 实施与验收结果

- `verify_3d_enemy_behavior_flow.tscn`：玩家本体射线命中、实体墙遮挡、九态响应、六基础怪/Boss 3D HP 基线、种类行为与轮廓碰撞通过。
- `verify_base_world_flow.tscn`：玩家六态白名单、死亡终态、位移驱动 moving 循环和手/枪挂点固定关系通过。
- `verify_3d_vision_input_flow.tscn`：三层真实灯组、render layer 隔离、360°遮挡显隐与 96°定向表现通过。
- `verify_3d_combat_progression_flow.tscn`：中央灯增强、大房间近距钥匙、唯一奖励、返回补发、钥匙/普通掉落 0.32 秒动画通过。
- 枪械命运、实际背包装备、核心等价迁移、四主题完整流程全部回归通过；峰值完整流程节点数 686。
- 性能专项通过：生成约 95.6ms、单房构建峰值约 5.8ms、全探索约 2820 节点、持续段约 6.89ms、稳定视野重绘 0 次。
- Apple M1 OpenGL/Metal 真实 GPU 1280×720 暗室、开灯与背包画面通过目检；环境溢光不再制造玩家头顶热点，角色正面柔光与中央灯覆盖可读。
