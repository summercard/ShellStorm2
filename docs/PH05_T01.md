# Phase 5 任务 T01：随机地图生成器

## 目标
实现基于节点图的随机地图生成系统，支持多层级、多种房间类型。

## 执行内容

### T01.1：节点图结构 (NodeGraph.gd)
- 管理房间节点列表和连接关系
- 支持添加节点（房间）、连接边（门）
- 提供图遍历方法（深度优先、广度优先）
- 支持节点权重（影响随机生成）

### T01.2：房间数据 (RoomData.gd)
- 房间类型枚举（普通/精英/商人/改造/事件/撤离/Boss）
- 房间属性：位置、连接、层级、尺寸
- 房间标签（用于内容注入）

### T01.3：地图生成器核心 (MapGenerator.gd)
- `generate(floor: int) -> NodeGraph`：生成指定层级的地图
- 层级的深度与房间数成正比
- 起始房间 → 中间路径 → Boss房
- 支持撤离点插入

### T01.4：房间工厂 (RoomFactory.gd)
- 根据房间类型生成对应的场景节点
- 支持房间预制件实例化
- 房间内容（怪物、道具）由外部表格注入，不在此模块内硬编码

### T01.5：路径与门管理 (PathDirector.gd)
- 管理房间之间的门（单向/双向）
- 连接两个房间的路径
- 处理门开启/关闭状态

## 文件清单
```
src/map/
├── NodeGraph.gd      # 图结构：节点+边+遍历
├── RoomData.gd       # 房间数据：类型+属性
├── MapGenerator.gd   # 主生成器：楼层→节点图
├── RoomFactory.gd    # 房间实例化工厂
└── PathDirector.gd  # 房间连接与门管理
```

## 验收标准
- MapGenerator.generate(1) 能生成一个有效的房间图
- 起始房间在图中，Boss房在路径末端
- 房间之间通过 PathDirector 连接
- 所有房间都有 RoomData 标记类型
