## 1 边界

**管什么**
- 段落结构：一段曲子分几段、每段多长、怎么接
- 循环点：哪里循环、循环是否无缝
- 切换规则：什么条件换曲、淡入淡出多久
- 情绪映射：哪个场景配哪种氛围

**不管什么**
- 具体音效 → 归 [音效](包装-04_音效.md)
- 总线音量 → 归 [音效](包装-04_音效.md) 的混音基线

**判据**：音乐独立于音效，但**必须与音效共用一个混音总线**，否则两边音量为敌。

## 3 制作流程（流程文档 + 交付标准文档）

### 3.1 六步

| 步 | 输入 | 动作 | 工具 | 产物 | 判据 |
|---|---|---|---|---|---|
| 01 定情绪映射 | 场景设计文档 | 列场景 → 情绪 → 大致速度/调式 | 手写 md | `音乐情绪映射表.md` | 每个主要场景有一行 |
| 02 定段落结构 | 情绪映射表 | **先定段落时长**（例如 32 秒 × 3 段），再写旋律 | 手写 md | 段落结构表 | 每段有明确时长与功能 |
| 03 生成 / 制作 | 结构表 | 用脚本生成或手工制作 | `generate_bgm.py` | wav 文件 | 时长与结构表一致 |
| 04 定循环点 | wav | 找无缝循环点，确认无爆音 | 剪辑软件 / ffmpeg | 循环版 | 循环三次听不出接点 |
| 05 接入切换 | 循环版 | 配 `MusicManager` / `MusicCatalog` / `MusicTrigger` | Godot 4.6 | 可切换音乐 | 切换有淡入淡出，不突兀 |
| 06 归档 | 成品 | 写交付记录 + 更新播放清单 | 手写 md | `development/` + 播放清单 | 清单里有这首歌 |

**02 步不能跳**：先写旋律再想段落，最后一定发现切不进去。

### 4.3 插件 / 扩展

- **Godot**：工程内**没有** `addons/` 目录，无第三方插件，纯原生 4.6。导出只靠 `export_presets.cfg` 的三个 preset，不依赖插件。

- **版本纪律**：所有 `tools/blender/` 脚本按 `v001…v025` 递增命名，**不覆盖旧版本**；`validate_*` / `audit_*` / `register_*` 三类脚本必须同版本号配套出现。

## 8 常见坑

| 坑 | 后果 | 怎么防 |
|---|---|---|
| 先写旋律后定段落 | 写完发现切不进去 | 02 步强制先定结构 |
| 循环点有爆音 | 每轮循环都"咔"一下 | 04 步必须听三次 |
| 只有一首曲子 | 全游戏一个氛围 | 至少覆盖 5 个主要场景 |
| 切换无淡入淡出 | 换曲像断电 | 05 步配淡化时长 |
| 音乐音量与音效抢 | 打起来听不见音效 | 共用总线 + 闪避规则 |
| 不看场景情绪 | 紧张场景配悠扬曲 | 01 步先做情绪映射 |
