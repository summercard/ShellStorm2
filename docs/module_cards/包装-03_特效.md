## 1 边界

**管什么**
- 粒子：发射、生命周期、运动、颜色曲线
- Shader：材质表现、扫描线、噪波
- 后处理：Bloom、色差、暗角、屏震
- 节奏：什么时候出现、持续多久、什么时候消失

**不管什么**
- 动作什么时候打到 → 归 [动画](包装-02_动画.md)（特效挂打击帧）
- 声音 → 归 [音效](包装-04_音效.md)
- 模型长什么样 → 归 [美术](包装-01_美术.md)

**判据**：特效负责"打击的形"，音效负责"打击的力"。两者必须同时对同一个打击帧触发。

## 3 制作流程（流程文档 + 交付标准文档）

### 3.1 六步

| 步 | 输入 | 动作 | 工具 | 产物 | 判据 |
|---|---|---|---|---|---|
| 01 定节奏 | 动作打击帧帧号 | 写清：起、盛、消三个时间点（毫秒） | 手写 md | 特效节奏表 | 三个时间点都是数字，不写"快速" |
| 02 灰度版 | 节奏表 | 只用白色/单色做形状，看节奏对不对 | Godot GPUParticles | 灰度特效 | 节奏对了才上色 |
| 03 上色 | 灰度版 | 加颜色曲线、透明度、叠加方式 | Godot Shader | 正式特效 | 颜色不过曝、层次分得开 |
| 04 性能测 | 正式特效 | 测粒子数、drawcall、帧率影响 | Godot profiler | 性能记录 | 在预算内（需先定预算表） |
| 05 接入 | 特效 | 挂到动画打击帧，与音效同步 | Godot | 接入后的场景 | 打击帧一响，形与声同时到 |
| 06 归档 | 成品 | 写交付记录 + 账本条目 | 手写 md | `development/` | 记录含粒子数与帧率影响 |

**02 步是分水岭**：一上来堆颜色，节奏错了全白做。灰度版做完再上色，返工率差一个量级。

### 4.3 插件 / 扩展

- **Godot**：工程内**没有** `addons/` 目录，无第三方插件，纯原生 4.6。导出只靠 `export_presets.cfg` 的三个 preset，不依赖插件。
- **Blender**：`tools/blender_addons/install_shellstorm_level_builder.ps1` 装自定义插件 `shellstorm_level_builder`。脚本默认 `-BlenderVersion "4.5"`，**与 3 号机实际的 5.2.2 不一致，装之前必须手动传 `-BlenderVersion 5.2`**。
- **Blender MCP**：`blender-mcp-bridge`（`.codex/skills/blender-mcp-bridge/SKILL.md`，12455 B）负责把 Blender 挂成可被 AI 调用的服务；不用 MCP 时一律 `blender --background --python`。
- **版本纪律**：所有 `tools/blender/` 脚本按 `v001…v025` 递增命名，**不覆盖旧版本**；`validate_*` / `audit_*` / `register_*` 三类脚本必须同版本号配套出现。

- **伤害数字分层**：`HEAVY_AMOUNT_THRESHOLD 40`
- **两套伤害数字并存**：`src/fx/CombatDamageNumber3D.gd`（45 行）与 `src/vfx/VfxDamageNumber3D.gd` 同时在，**容易改错文件**

## 8 常见坑

| 坑 | 后果 | 怎么防 |
|---|---|---|
| 一上来堆颜色 | 节奏错了全部重做 | 02 步强制灰度版 |
| 不看性能预算 | 十个特效一起放，帧率崩 | 04 步强制测，且要先有预算表 |
| 特效和音效不同步 | 打击感散掉 | 05 步同时对同一打击帧 |
| 同类特效散在多文件 | 改一个要翻五处 | 先合并同类，再做索引 |
| 只在编辑器里看 | 真机表现不一样 | L3 必须实跑 |
| 特效时长不对齐动作 | 打完还在放烟花 | 01 步节奏表对齐打击帧帧号 |
