## 0 这套卡片怎么用

| 场景 | 怎么做 |
|---|---|
| **开工** | 先读第 1 节边界 + 第 2 节目录（2026-10-20 实测树），确认东西在哪 |
| **每一步怎么做、看哪份文档** | 看第 3 节制作流程：3.1 六步 → 3.3 流程文档 → 3.4 交付标准 |
| **用什么工具、什么版本、什么插件** | 看第 4 节：工具清单 / 版本（实测）/ 插件 / 落在哪台机器 |
| **要打开哪个 skill 文件** | 看第 5 节：工程内 `.codex/skills/<name>/SKILL.md` 与本机 `workshop-skills/<name>/SKILL.md` 的完整路径 + 字节 |
| **怎么算做对** | 看第 6 节：6.1 工程验收文档 + 6.2 资料库个人品味文档 + 6.3 L1–L4 + 6.4 评判维度 |
| **找 AI 关键词 / 参考视频 / 参考图** | 看第 7 节制作资料 |
| **要换模型 / 判断该找谁** | 看第 4.4 节，含四条升级判据 |
| **返工前** | 看第 8 节常见坑，多数问题在这里已经写过 |
| **交接给别人 / 未来自己重做** | 看第 9 节复刻清单，逐条勾 |
| **改了这个模块** | 第 10 节迭代记录追加一行，**不覆盖旧行** |
| **新建一个模块** | 复制 `_模板_模块卡片.md`，改 ID 与内容，回本页登记 |

**硬规则：卡片是模块的唯一说明书。代码改了、卡没改 = 没改完。**

**第二条硬规则：六个格子必须都填得出东西——目录 / 制作流程 / 工具 / skill / 评判标准 / 制作资料。哪一格空着，这个模块就有一块不可复刻。**

## 2 卡片之间的依赖（谁卡谁）

```
创意中心
   ↓
功能 ──┬── 数据（内容表、存档字段）
       ├── 3C（输入与状态）
       └── 交互体验（界面读同一份数据）
   ↓
美术 ──→ 动画 ──→ 特效
                ↘
音效 ←───────────┘        音乐（独立，只依赖场景情绪）
   ↓
测试（覆盖以上全部） → 打包（最后一道）
```

**读懂这张图的用处：**
- 改 `数据` 的字段 → `功能` `交互体验` 都要回归
- 改 `美术` 的骨骼/命名 → `动画` `特效` 都要重验
- `打包` 永远最后做，但它的问题往往在前面（资源没裁剪、路径大小写）

## 3 模型分工总表（跨卡片统一口径）

| 任务性质 | 模型 | 出现在哪些卡片 |
|---|---|---|
| 核心体验、手感、空间、质感、可读性判断 | **GPT** | 3C、美术、动画、音效、音乐、交互体验 |
| 跨 3 模块以上推理、穷举互相影响的失败分支 | **GPT 上浮** | 功能（命运卡、枪械组装）、特效（复杂 shader） |
| 结构化写作、机械批量、可验证的查错 | **DeepSeek** | 功能常规、测试、打包、数据 |

**四条升级判据（任一命中即升 GPT）：**
1. 跨 3 个以上模块推理
2. 穷举互相影响的失败分支
3. 需要看图 / 判空间 / 判风格
4. 同一件事返工两次还不对 → 是理解问题，不是执行问题

## 4 命名与迭代规则

### 文件名
`{分类}-{序号}_{模块名}.md`，例：`玩法-03_测试.md`、`包装-06_交互体验.md`
分类只有两个：`玩法` / `包装`；序号两位；模块名用中文，不加空格。

### 卡片 ID
`MOD-{英文缩写}`，例：`MOD-FUNC`、`MOD-3C`、`MOD-ART`、`MOD-UX`
**ID 一旦分配不改**，显示名可以改。

### 版本
- `v0.x` = 结构或链路有变
- `v0.x.y` = 只补细节、改措辞
- 每次改动**追加一行**到第 10 节，不覆盖旧行

### 什么情况必须改卡片
| 变更 | 要改哪节 |
|---|---|
| 目录增删、文件数变了 | 第 2 节 + 第 10 节 |
| 换了工具、版本、插件、机器 | 第 4 节 + 第 10 节 |
| 新增/废弃 skill | 第 5 节 + 第 10 节 |
| 流程多一步/少一步 | 第 3 节 + 第 10 节 |
| 验收标准变了 | 第 6 节 + 第 10 节 |
| 新增参考视频 / 参考图 | 第 7 节 + 第 10 节 |
| 踩了新坑 | 第 8 节 + 第 10 节 |
| 模型分工变了 | 第 4.4 节 + 第 10 节 |

## 5 新建模块的步骤（复刻一个同类模块）

1. 复制 `_模板_模块卡片.md` → 改名 `{分类}-{序号}_{模块名}.md`
2. 填 ID 与第 1 节边界
3. 第 2 节**去工程里实测目录树**，不凭印象写
4. 第 3 节写六步 + 流程文档 + 交付标准文档（缺的写「缺」）
5. 第 4 节填工具与**实测版本**、插件清单、落哪台机器
6. 第 5 节填完整 skill 路径（工程内 + 本机两套）
7. 第 6 节填验收文档 + 资料库品味文档 + L1–L4
8. 第 7 节填 AI 关键词 / 参考视频 / 参考图（缺就写缺）
9. 第 9 节写出复刻清单——**这一步写不出来，说明链路还没想清楚**
10. 回本页第 1 节表格加一行，在第 2 节依赖图里标出它卡谁、被谁卡
