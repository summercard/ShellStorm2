# Phase 1：基础可玩闭环

> 本阶段已完成（2026-05-22）

## 目标
搭建可运行的最小射击游戏闭环：玩家能动、能射击、有敌人、有 HUD。

---

## 完成内容

### 玩家控制
- 八方向移动（WASD / 方向键），速度 350px/s
- 鼠标瞄准
- 左键射击
- 冲刺（Shift，0.3秒，100px，3秒冷却）
- ESC 暂停菜单

### 射击框架
- `WeaponController`：4发/秒射速，600px/s 子弹速度，50发对象池
- `Bullet`：Area2D + CollisionShape2D，碰撞检测

### 敌人
- `EnemyBase`：追击玩家（80px/s），30HP，接触造成 10 点伤害
- 敌人生成器：每 2 秒在屏幕边缘生成 1-3 只敌人

### HUD
- 左上角：HP 显示
- 右上角：分数显示
- ESC 弹出暂停菜单

### 核心单例
| 文件 | 职责 |
|---|---|
| `GameManager.gd` | 游戏状态（playing/paused/game_over）、分数 |
| `BulletPool.gd` | 50 发子弹预创建池 |
| `Global.gd` | 全局常量/快捷访问 |
| `GameEvents.gd` | 事件总线 |
