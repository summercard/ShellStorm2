# PH32 · 3D 角色 DIY 组件与动态表现

> 历史阶段说明：PH33 已将当前 3D 主角升级为方形猫体型，并把正式模块调整为头、身体、单手、脚；本页继续保留 PH32 胶囊体方案作为开发记录。

预览截图：`outputs/019f8417-e7f4-7bc3-aded-c62dfd1d1462/PH32_3D角色DIY预览场.png`。

## 目标

让 `player_capsule01` 在不复制角色根、不改变玩法的前提下，可独立装配身体、头部、唯一握持手、帽子与眼镜，并在原有六态和动作覆盖层中保持一致的角色表现。

## 装配契约

- `Player3D.set_avatar_customization(slot, variant)` 是唯一公开入口；可设置 `body / head / hand / hat / glasses`，返回的字典仅表达外观，不参与碰撞、枪械树、伤害或状态迁移。
- 身体、头和手各含三种程序化材质/轮廓变体；帽子含软帽、安全帽、密封兜帽，眼镜含单目镜、双目护镜、宽面护目镜。它们全部是 `CHR-PLY-CAPSULE01-3D` 的子变体，不是新角色根。
- 帽子和眼镜动态挂在 `VisualRoot/Head/Wearables`，随头部的移动滞后、后坐、受击回摆和死亡倾倒一起运动；不制作人脸、嘴巴或第二只手。
- 所有帽子与眼镜网格固定在角色专用 render layer 2，禁用投影与 GI；它们仍接收 `AvatarFrontFill` 的柔光，但不能遮挡角色头壳、传感器、手持枪或环境的真实灯光表现。
- 唯一手与 `weapon_socket` 的基础位置内收为 `(0.58,1.20,-0.27)` / `(0.58,1.24,-0.39)`，视觉上更接近握把；移动、换弹、射击、蓄力和击飞对两者施加相同的位置和旋转，因此相对向量始终不变。

## 表现增强

- 移动状态增加躯干的反相小摆、头壳回摆、围巾延迟翻摆和手部抓握压缩。
- 射击让手部抓握收紧、躯干前探、头壳跟随后坐；蓄力增加下压张力；击飞保留方向位移、压缩和弹性回正。
- 所有新网格只在 `_ready()` 一次性构建，之后仅切换可见性/材质和变换，不在战斗帧分配新节点或材质。

## 预览和验收

- `Player3DStateGallery` 增加 DIY 装配面板与下拉选择：身体、头部、手部、帽子、眼镜；另有切换帽子、切换眼镜、恢复默认按钮。
- `verify_player3d_diy_flow.tscn` 验证变体存在、真实角色换装、帽子/护目镜可见、内收握持点、移动和射击时手/挂点不分离、以及恢复默认。
- 既有角色预览图使用钴蓝身体、琥珀头壳、青绿手、安全帽、双目护镜，作为暗场视觉复核。
