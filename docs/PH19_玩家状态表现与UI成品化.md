# PH19 玩家状态表现与 UI 成品化

**状态：已完成**  
**日期：2026-07-11**

## 问题审计

玩家已有 `idle / dashing / dead` 三态状态机、程序化角色、冲刺残影、HP 尾迹和低血暗角，但正常移动仍藏在 `idle`，受伤和交互锁定只是布尔标记，死亡后武器控制器仍可能在结算前短暂接收射击。同时 Idle 进入会提前清除受伤无敌，Dashing 退出也会早于 `InvincibleTimer` 解除无敌，与注释的契约不一致。HUD 虽有数值动效，但不知道角色当前是移动、受创、被锁定还是沉默。

## 设计方向

将顶层互斥状态扩展为 `idle / moving / dashing / hurt / locked / dead`，低血、沉默和无敌作为可与移动并存的叠加状态。`StateMachine.state_changed` 通过 Player 翻译为稳定的表现信号，角色渲染、冲刺残影、战斗 HUD 和低血提示读取同一条信号链。

## 状态表现矩阵

| 状态 | 输入/物理 | 角色表现 | HUD 表现 |
|---|---|---|---|
| Idle | 可移动/冲刺 | 低频呼吸、稳定背包灯 | `姿态 · 待命` 钢青 |
| Moving | 持续移动/冲刺 | 两步步态、方向倾斜、短地面划痕 | `姿态 · 机动` 青蓝 |
| Dashing | 强制位移、计时无敌 | 轮廓拉伸、背喷口、青色残影 | `姿态 · 突进` 短促闪白 |
| Hurt | 0.14 秒受创恢复 | 压缩、红闪、装甲震动 | HP 面板震动、尾迹追随 |
| Locked | 输入和战斗停止 | 安定圆环、降亮、手部收纳 | `姿态 · 交互锁定` 琥珀 |
| Dead | 永久停止 | 倾倒、面罩熄灭、不再显示枪/瞄准 | `生命终止` 暗红，转入结算 |
| Low HP（叠加） | 不改变输入 | 胸口红色急救脉冲、外环呼吸 | 状态栏显示 `CRITICAL` 与实时百分比 |
| Silenced（叠加） | 禁止射击 | 面罩干扰线、紫色脉冲 | 状态栏显示 `JAMMED` 与短闪 |

## 契约

1. 冲刺冷却在 Idle、Moving、Hurt 和 Locked 都继续推进，不因菜单或受创冻结。
2. 受伤无敌只由 `InvincibleTimer` 解除；普通状态切换不直接改写计时结果。
3. 所有顶层状态进入都更新 `presentation_state`，但不反向调用 UI；UI 只订阅信号。
4. `PlayerAvatarRenderer` 继续是唯一语义化角色资产挂点，物理圈、武器树和移动速度不依赖它。
5. 基地、靶场和战斗场景使用同一 Player 状态契约；基地关闭战斗不等于死亡。

## 验收标准

1. 状态机注册 6 个顶层状态，可验证 Idle↔Moving、任意机动态→Dashing→机动态、受伤→Hurt→机动态、Locked→解锁、任意存活态→Dead。
2. 受伤进入 Hurt 后仍在 0.22 秒内拒绝第二次伤害，不因 Hurt 提前结束而失效。
3. 死亡立即禁用瞄准、枪械与射击输入；角色渲染进入 Dead 状态。
4. 低血阈值为 30%，跨越阈值只发出一次进入/退出信号；治疗跨回阈值后角色与 HUD 均恢复。
5. GameHUD 存在语义化 `PlayerStatePanel`，能同步六个顶层状态、Low HP 和 Silenced，且不挡住小地图、弹药或 Boss 血条。
6. 玩家专项验证、HUD 专项验证、主场景实机/离屏检查和全量回归无报错。

## 本轮不改

- 不改变玩家基础移速、冲刺速度、时长、冷却和伤害结算数值；本轮是状态正确性和表现品质收口。
- 不用一个巨大的屏幕特效代替角色轮廓反馈；暗角、闪屏与震屏保持辅助层级。

## 实施结果

- 玩家顶层状态扩展为六态，并新增统一的 `presentation_state_changed`、低血、受伤、锁定和状态效果信号；移动、受创、交互与死亡不再隐含在布尔分支中。
- 冲刺和受创无敌由 `InvincibleTimer` 唯一解除；Dashing 改用状态内部物理计时，消除了闭包定时器对 Player/State 脚本资源的退出持有。
- `PlayerAvatarRenderer` 完成六态姿态、推进尾迹、步态、受创压缩、低血核心、沉默干扰、锁定圆环和死亡熄灭表现，并保持单一可替换资产挂点。
- `GameUIManager` 新增语义化 `PlayerStatePanel`：六态标题、正常遥测、`CRITICAL` 百分比和 `JAMMED` 剩余时间均由 Player 信号驱动；状态切换、受伤和危急状态有独立短动效。
- 移除会参与 `VBoxContainer` 布局的旧描边 Label 副本，改用统一字体阴影，修复楼层读数被挤入生命条的问题。
- `UIFX` 正确保存并中断按钮 Tween；抖动恢复为单次 0.18 秒反馈，不再意外循环四轮。
- 新增 `PlayerPresentationGallery.tscn`，提供六态同构视觉对照板，未来替换正式角色资产时可直接做前后验收。

## 验证结果

- `verify_player_presentation_flow.tscn`：六态注册与信号、Idle/Moving/Locked/Dashing/Hurt/Dead、冲刺/受伤独立无敌计时、低血进入退出、沉默、死亡禁枪、HUD 同步与布局全部通过，日志无警告或错误。
- 六态对照板以 1280×720 离屏渲染检查：状态轮廓、低血和沉默叠加层均可读。
- `Main.tscn` 1280×720 实际 HUD 离屏检查：右侧五层战斗遥测无互相遮挡，状态面板在暗场和视野锥中保持可读。
