# Phase 5 任务 T02：地图层级与房间内容注入分离

## 目标
地图生成只负责生成房间图与房间标签，具体怪物、掉落、事件由对应表格根据房间标签注入，实现解耦。

## 执行内容

### T02.1：内容注入接口 (ContentInjector.gd)
- 定义房间内容注入的接口协议
- `inject(room_data: RoomData) -> Dictionary`：返回该房间的内容配置
- 支持多种注入器（怪物、道具、事件）

### T02.2：怪物注入器 (MonsterInjector.gd)
- 根据房间类型和层级生成怪物配置
- 表格驱动（不做死数据）
- 支持普通/精英/Boss不同配置

### T02.3：撤离点管理 (ExtractionDirector.gd)
- 管理基础撤离点（地图生成时存在）
- 精英撤离点（击败精英后开启）
- Boss撤离（击败Boss后出现）
- 信标撤离（消耗道具召唤）

### T02.4：Boss房管理 (BossRoomDirector.gd)
- 管理Boss房的状态和进入条件
- Boss击败后的奖励结算
- Boss撤离点开启逻辑

### T02.5：地图管理器 (MapManager.gd)
- 整合 MapGenerator + RoomFactory + 各Director
- 管理当前地图的实例化
- 处理房间切换逻辑

## 文件清单
```
src/map/
├── ContentInjector.gd      # 内容注入接口
├── MonsterInjector.gd     # 怪物配置注入
├── ExtractionDirector.gd  # 撤离点管理
├── BossRoomDirector.gd    # Boss房管理
└── MapManager.gd          # 地图总管理器
```

## 验收标准
- MapManager 可以生成完整地图（包含房间节点和内容注入配置）
- 各注入器根据房间标签正确返回内容配置
- ExtractionDirector 可以管理多种撤离点
- BossRoomDirector 可以处理Boss房逻辑
