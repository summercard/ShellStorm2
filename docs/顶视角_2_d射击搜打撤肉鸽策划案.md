# 顶视角2D射击搜打撤肉鸽游戏策划案

## 1. 项目定位

### 1.1 游戏一句话概念
一款以顶视角2D射击为基础、融合搜打撤风险决策与肉鸽随机成长的枪械组合进化游戏。玩家在随机地图中搜刮武器模块、命运卡片与资源，通过“枪身 + 子弹 + 配件”的自由拼装，制造大量离谱但可读的武器化学反应，并在战斗、搜刮、撤离、Boss挑战之间持续做风险选择。

### 1.2 核心体验关键词
- **爽快射击**：移动、闪避、开火、清怪的即时反馈直接。
- **随机组合**：每局都能获得不同枪械模块、命运卡片、地图事件与敌人组合。
- **搜打撤压力**：玩家既要打怪拿资源，也要判断什么时候撤离，是否继续深入高风险区域。
- **无厘头武器进化**：不是传统数值叠加，而是把枪、子弹、配件用节点方式粗暴拼起来，产生夸张可见的效果。
- **可维护系统化设计**：枪身、子弹、配件、命运卡片、怪物、地图、掉落、撤离全部解耦，方便持续扩展。

### 1.3 参考体验边界
基础战斗体验接近顶视角双摇杆射击肉鸽：随机房间、随机武器、怪物波次、Boss战、局内成长。但本项目的主要差异不是“更多枪”，而是“枪械模块与命运卡片能组合出新规则”。

---

## 2. 核心游戏循环

### 2.1 单局循环
```text
基地准备
→ 选择携带初始装备 / 契约 / 风险等级
→ 进入随机地图
→ 探索房间与搜刮资源
→ 遭遇怪物 / 精英 / 事件 / 商人 / 改造台
→ 获得枪械模块与命运卡片
→ 组合武器，产生新攻击方式
→ 选择撤离或继续深入
→ 挑战Boss / 特殊撤离点
→ 成功撤离带出资源，失败损失部分携带物
→ 回到基地解锁新模块、新卡片、新地图层级
```

### 2.2 核心决策
玩家每局需要持续做三类选择：

1. **战斗选择**：当前武器组合适合清群怪、打Boss、控场，还是远程安全输出？
2. **构筑选择**：命运卡片是强化当前枪，还是赌一个奇怪组合？
3. **撤离选择**：当前背包收益是否足够？继续探索可能获得进化关键件，也可能死亡丢失战利品。

### 2.3 单局节奏目标
| 阶段 | 时长目标 | 玩家状态 | 主要内容 |
|---|---:|---|---|
| 前期 | 0-5分钟 | 弱，资源少 | 找到第一套可用武器组合 |
| 中期 | 5-15分钟 | 组合成型 | 命运卡片开始让武器产生明显变化 |
| 后期 | 15-25分钟 | 高风险高收益 | 精英、Boss、撤离冲突、资源取舍 |
| 极限阶段 | 25分钟后 | 混乱爽感 | 大量怪物、离谱武器、撤离压力达到峰值 |

# 第一部分：基础模块玩法

## 3. 基础战斗模块

### 3.1 玩家控制
#### 功能目标
提供简单、即时、低学习成本的顶视角射击操作。

#### 核心功能
- 八方向移动。
- 鼠标或右摇杆瞄准。
- 主武器射击。
- 副技能或主动道具。
- 翻滚 / 冲刺 / 短暂无敌。
- 拾取、开箱、交互、撤离确认。

#### 可配置参数
- 移动速度。
- 冲刺距离。
- 冲刺冷却。
- 受击硬直。
- 生命值、护盾值。
- 背包容量。
- 撤离读条时间。

#### 解耦建议
玩家控制只负责输入、移动和交互，不直接处理武器逻辑。武器由 `WeaponController` 挂载，受击由 `HealthComponent` 处理，背包由 `InventoryComponent` 管理。

---

### 3.2 射击基础模块
#### 功能目标
所有枪械最终都通过统一射击框架发射“投射物节点”，方便后续组合。

#### 核心概念
- **枪身 GunBody**：决定开火方式。
- **子弹 Bullet**：决定弹体行为。
- **配件 Attachment**：决定修饰效果。
- **武器装配树 Weapon Assembly Tree**：把枪身、子弹、配件按节点拼成一棵可执行结构。

#### 基础射击流程
```text
玩家按下射击
→ GunBody 计算本次开火参数
→ Bullet 生成投射物
→ Attachment 修改射击参数或投射物参数
→ 命运卡片效果介入
→ 投射物进入场景
→ 投射物命中、爆炸、分裂、生成子节点攻击
```

#### 解耦建议
- 枪身不关心子弹具体长什么样，只调用 `IBulletEmitter`。
- 子弹不关心是谁发射，只读取 `ProjectileContext`。
- 配件不直接写死目标，而是通过标签系统选择影响对象。
- 命运卡片不直接改武器原始数据，而是生成一层 `Modifier` 或 `MutationNode`。

---

## 4. 随机地图模块

### 4.1 地图结构
地图由多个房间或区域组成，采用节点图方式随机生成。

#### 房间类型
| 房间类型 | 功能 |
|---|---|
| 普通战斗房 | 基础清怪与掉落 |
| 精英房 | 高风险高奖励，掉落高品质模块 |
| 搜刮房 | 箱子、资源、隐藏容器 |
| 商人房 | 购买模块、命运卡片、撤离道具 |
| 改造房 | 免费或付费进行一次武器组合 |
| 事件房 | 随机事件、诅咒、赌局、交易 |
| 撤离房 | 可选择结束本局并带出物资 |
| Boss房 | 阶段目标，胜利后可进入深层或撤离 |

### 4.2 地图层级
- **浅层**：怪物弱，撤离点多，资源一般。
- **中层**：出现精英怪、陷阱、特殊事件，组合材料质量提升。
- **深层**：Boss频繁，撤离点稀少，稀有命运卡片与核心模块掉落。
- **污染层 / 异化层**：怪物和地图规则都发生变种，适合作为后期高风险地图。

### 4.3 搜打撤地图节奏
每张地图至少存在一个基础撤离点，但高级撤离点需要达成条件：
- 击败精英怪后开启。
- 携带撤离信标召唤。
- 找到钥匙卡。
- 支付资源。
- 在Boss战后短时间开启。

#### 解耦建议
地图生成只负责生成房间图与房间标签。具体怪物、掉落、事件由对应表格根据房间标签注入。

---

## 5. 怪物模块

### 5.1 怪物设计目标
怪物不是单纯增加血量，而是逼迫玩家改变走位、组合武器和撤离策略。

### 5.2 怪物分类
| 类型 | 作用 | 示例 |
|---|---|---|
| 近战追击型 | 压迫走位 | 小菌猪、裂口爬虫 |
| 远程弹幕型 | 制造弹幕空间 | 孢子射手、毒囊花 |
| 召唤型 | 制造持续压力 | 蜂巢怪、机械母巢 |
| 护盾型 | 保护其他怪 | 壳甲卫兵、镜面水母 |
| 自爆型 | 逼迫拉扯 | 炸弹果、膨胀鼠 |
| 潜伏型 | 打断搜刮节奏 | 地刺虫、影子蘑菇 |
| 精英变种 | 加入词缀 | 火焰、分裂、狂暴、吸附 |

### 5.3 怪物词缀
怪物可通过词缀系统变种：
- **巨大化**：体型、血量、碰撞范围增加。
- **分裂**：死亡后生成小怪。
- **反弹**：周期性反弹子弹。
- **寄生**：死亡后附着在其他怪身上强化它。
- **抢枪**：短暂复制玩家当前枪械的一部分效果。
- **吞弹**：吃掉投射物并转化为自己的攻击。

#### 解耦建议
怪物基础AI、怪物属性、词缀效果、掉落表分离。词缀通过 `EnemyModifier` 组合，不改怪物本体代码。

---

## 5.4 精英怪成长 / 宿敌系统

### 5.4.1 设计目标
精英怪不是一次性的随机怪物，而是可以在多局之间持续成长、记仇、携带战利品并再次登场的“局外活体威胁”。

玩家如果没有击杀某只精英怪，它不会简单消失，而是可能在后续局中重新出现，并带着上一次遭遇后的成长结果回来。它可能变强、变异、抢走玩家遗失的装备，甚至学会玩家曾经使用过的武器组合。

这个系统的目标是制造以下体验：
- “这只怪我上局没打死，它又回来了。”
- “它身上好像挂着我上次掉的枪。”
- “它已经成长成一个小Boss了。”
- “我到底是现在撤离，还是冒险把它杀掉拿回东西？”

---

### 5.4.2 精英怪定位
精英怪介于普通怪和Boss之间：

| 类型 | 是否持久化 | 是否成长 | 是否唯一 | 作用 |
|---|---|---|---|---|
| 普通怪 | 否 | 否 | 否 | 提供基础战斗压力 |
| 精英怪 | 是 | 是 | 半唯一 | 制造长期威胁和复仇目标 |
| Boss | 通常否，特殊Boss可持久化 | 阶段成长 | 是 | 关卡目标与构筑检验 |

精英怪不是每局完全重新生成，而是从“精英怪档案池”中抽取。新精英怪会被创建，旧精英怪也可能带着历史状态再次登场。

---

### 5.4.3 精英怪生命周期
```text
本局生成精英怪
→ 玩家遭遇精英怪
→ 玩家击杀 / 放跑 / 撤离 / 死亡
→ 系统记录精英怪结果
→ 精英怪进入档案池
→ 根据成长规则更新属性、词缀、装备、仇恨
→ 后续局中按权重再次出现
→ 再次遭遇时携带历史成长
```

### 5.4.4 精英怪状态
每只精英怪拥有自己的持久化档案。

| 状态 | 说明 |
|---|---|
| 新生 | 第一次生成，只有基础词缀 |
| 逃脱 | 玩家没有击杀它，它从本局活着离开 |
| 战利品持有者 | 它捡走了玩家掉落或遗留的装备 / 模块 |
| 进化中 | 它在局外获得了成长词缀 |
| 复仇者 | 它记住了玩家，优先追击玩家 |
| 区域霸主 | 多次逃脱后变成区域级强敌 |
| 准Boss | 成长到一定阶段后可晋升为特殊Boss事件 |
| 已击杀 | 被玩家彻底击杀，从档案池移除或转为纪念记录 |

---

### 5.4.5 成长来源
精英怪成长不只是简单加血加攻，而是根据本局事件获得成长。

| 成长来源 | 触发条件 | 成长结果 |
|---|---|---|
| 存活逃脱 | 玩家撤离、死亡或离开房间后精英怪未死 | 获得基础属性成长 |
| 击杀玩家 | 玩家死于该精英怪或其召唤物 | 获得高额成长和仇恨标记 |
| 吃掉掉落 | 玩家死亡后掉落装备，精英怪附近存活 | 拾取玩家装备或模块 |
| 吸收环境 | 精英怪所在地图层级较高 | 获得地图主题词缀 |
| 受到特定伤害 | 被火、毒、冰、电等伤害大量命中但未死 | 进化对应抗性或反制能力 |
| 目睹武器组合 | 玩家用特殊组合攻击它但未击杀 | 学习部分组合逻辑 |
| 吞噬其他怪 | 精英怪在战斗中击杀或吸收小怪 | 获得召唤、分裂、巨大化等成长 |
| 抢夺撤离物 | 玩家撤离时放弃部分战利品 | 精英怪可能获得其中一个模块 |

---

### 5.4.6 精英怪可成长属性
#### 基础属性成长
- 生命值提升。
- 护甲提升。
- 移动速度提升。
- 攻击频率提升。
- 技能冷却降低。
- 召唤数量提升。
- 对某类伤害获得抗性。

#### 行为成长
- 学会闪避玩家高伤害子弹。
- 学会绕开玩家放置物。
- 低血量时主动撤退。
- 主动追击正在搜刮的玩家。
- 守在撤离点附近伏击。
- 优先攻击玩家的召唤物或炮台。

#### 词缀成长
- 巨大化。
- 分裂。
- 吸血。
- 护盾。
- 反弹。
- 召唤。
- 元素附着。
- 武器寄生。
- 装备盗取。
- 死后逃逸。

#### 装备成长
精英怪可以获得、装备或寄生玩家遗失的模块。

| 装备类型 | 精英怪表现 |
|---|---|
| 枪身 | 身上长出对应枪械器官，周期性开火 |
| 子弹 | 攻击弹体获得该子弹的行为 |
| 配件 | 获得配件对应修饰效果 |
| 命运卡片残效 | 获得一条不完整但危险的组合规则 |
| 消耗品 | 登场时触发一次特殊效果 |

示例：
- 精英怪捡到了“蜂窝机枪”，下次出现时背上长出一排小枪口。
- 精英怪吸收了“黏黏弹”，它吐出的弹会黏在玩家身上持续伤害。
- 精英怪获得“三叉枪口”，它的远程攻击变成三向分裂。
- 精英怪被“黑洞弹”多次攻击后未死，下次出现时获得短时间吸引玩家子弹的能力。

---

### 5.4.7 精英怪装备玩家模块规则
为了保证可读性和可控性，精英怪不完整复制玩家武器树，而是按规则截取部分节点。

#### 可被精英怪获得的内容
- 玩家死亡掉落的未保险模块。
- 本局战斗中被精英怪吞噬的临时投射物节点。
- 玩家撤离时放弃的高价值模块。
- 精英怪击杀玩家后，从玩家当前武器装配树中抽取一个节点影子。

#### 装备转化规则
```text
玩家模块
→ 精英怪适配器 EnemyEquipmentAdapter
→ 转化为怪物技能 / 词缀 / 器官 / 投射物行为
```

| 玩家模块 | 转化结果 |
|---|---|
| GunBody | 精英怪获得一个周期性射击技能 |
| Bullet | 精英怪远程技能获得该弹体行为 |
| Attachment | 精英怪技能获得修饰器 |
| FateCard | 精英怪获得一个简化版规则词缀 |

#### 限制规则
- 精英怪最多装备1-3个玩家模块。
- 装备模块按精英怪等级解锁槽位。
- 玩家模块被怪物使用时数值缩放，避免过强。
- 不允许无限递归组合。
- 命运卡片只转化为简化词缀，不完整复制玩家构筑。
- 玩家击杀该精英怪后，可以夺回部分被它持有的模块。

---

### 5.4.8 精英怪再次登场规则
精英怪不会每局必定出现，而是通过权重系统决定。

| 条件 | 再登场权重变化 |
|---|---|
| 上局玩家没击杀它 | 权重上升 |
| 它击杀过玩家 | 权重大幅上升 |
| 它持有玩家装备 | 权重上升 |
| 玩家进入相同地图主题 | 权重上升 |
| 玩家携带与它仇恨相关的武器 | 权重上升 |
| 它连续多局未出现 | 权重小幅上升 |
| 它等级过高 | 转为特殊事件，不进入普通精英池 |

### 5.4.9 登场方式
| 登场方式 | 说明 |
|---|---|
| 精英房固定出现 | 作为该房间核心敌人 |
| 普通房乱入 | 战斗中突然破门出现 |
| 撤离点伏击 | 玩家撤离读条时出现 |
| 搜刮房埋伏 | 玩家开高价值箱子时出现 |
| Boss前拦截 | 作为Boss前的小考验 |
| 地图事件 | NPC提示某只精英怪正在该区域游荡 |

---

### 5.4.10 击杀收益
持久化精英怪越强，击杀收益越高。

| 精英怪状态 | 击杀收益 |
|---|---|
| 新生精英 | 普通高品质掉落 |
| 逃脱过1次 | 额外模块、成长素材 |
| 击杀过玩家 | 返还部分遗失物，额外仇恨奖励 |
| 持有玩家装备 | 掉落它持有的装备或其变异版本 |
| 区域霸主 | 掉落专属命运卡片、稀有蓝图 |
| 准Boss | 掉落Boss级材料与专属模块 |

### 5.4.11 玩家夺回装备
如果精英怪携带了玩家遗失的装备，玩家击杀它后可以选择：
- 直接取回原装备。
- 将原装备转化为被污染的变异版本。
- 分解为稀有材料。
- 用命运卡片洗掉污染副作用。

示例：
```text
你上局遗失的“蜂窝机枪”被精英怪吞掉。
本局击杀它后，你可以获得：
1. 蜂窝机枪，耐久下降。
2. 寄生蜂窝机枪，射速更高，但换弹时会召唤敌对小蜂。
3. 蜂巢枪身蓝图碎片。
```

---

### 5.4.12 精英怪成长上限与失控处理
精英怪持续成长很有趣，但必须避免玩家被滚雪球惩罚。

#### 成长上限
- 精英怪等级上限。
- 持有玩家装备数量上限。
- 抗性上限。
- 连续复仇出现次数上限。
- 准Boss数量上限。

#### 失控处理
当某只精英怪成长过强时，不再作为普通精英随机出现，而转为特殊追猎事件。

玩家可以选择：
- 避开该事件。
- 支付资源买情报。
- 带入克制道具。
- 组队式NPC支援。
- 接取悬赏任务后再挑战。

### 5.4.13 反挫败设计
为了避免“越打不过越打不过”，系统需要给玩家补偿和准备机会。

| 问题 | 解决方式 |
|---|---|
| 精英怪太强 | 出现前给情报提示 |
| 被抢装备很不爽 | 只抢未保险物，核心装备不永久丢失 |
| 反复被同一只怪追杀 | 连续失败后降低其登场权重 |
| 成长不可读 | 精英怪登场时展示成长标签 |
| 玩家没有克制手段 | 商人或事件提供针对道具 |
| 击杀成本太高 | 悬赏奖励随精英等级提高 |

---

### 5.4.14 精英怪档案系统
基地中可以设置“怪物档案室”，记录玩家遇到过的精英怪。

档案内容：
- 精英怪名字。
- 初始种类。
- 当前等级。
- 成长次数。
- 击杀玩家次数。
- 逃脱次数。
- 持有装备。
- 当前词缀。
- 已知弱点。
- 最近出没区域。
- 悬赏奖励。

### 5.4.15 命名系统
为了增强记忆点，成长型精英怪应该拥有半随机名字。

命名格式：
```text
称号 + 怪物名 + 后缀
```

示例：
- 背枪的裂口爬虫。
- 吞弹者·毒囊花。
- 抢走机枪的蜂巢怪。
- 三次逃脱的弹壳巨兽幼体。
- 黏弹仇敌·小菌猪王。

名字会根据它的成长经历变化：
- 捡过枪：获得“背枪的”“枪械寄生”称号。
- 击杀过玩家：获得“仇敌”“猎手”称号。
- 多次逃脱：获得“狡猾的”“不死的”称号。
- 获得元素抗性：获得“焦黑的”“带毒的”“冰壳的”称号。

### 5.4.16 与搜打撤的结合
精英怪成长系统和搜打撤天然绑定。

#### 撤离时的压力
玩家可以选择：
- 现在撤离，保住已有收益，但放走精英怪。
- 继续追杀精英怪，拿更高奖励，但死亡风险上升。
- 放弃部分战利品吸引精英怪，换取撤离时间。
- 用撤离信标诱导精英怪进入伏击点。

#### 死亡后的后果
如果玩家死在精英怪附近：
- 精英怪可能拿走一个未保险模块。
- 精英怪获得“击杀玩家”的成长记录。
- 后续出现时拥有更高仇恨。
- 玩家可在基地看到悬赏情报。

#### 成功复仇
如果玩家后续击杀该精英怪：
- 夺回部分遗失资源。
- 获得额外悬赏。
- 解锁它的成长样本。
- 可能获得专属命运卡片。

### 5.4.17 与命运卡片的结合
命运卡片也可以影响精英怪。

#### 玩家可用卡片
| 卡片 | 效果 |
|---|---|
| 标记猎物 | 本局锁定一只精英怪，击杀奖励提高 |
| 夺回命运 | 对持有玩家装备的精英怪造成额外伤害 |
| 反向寄生 | 精英怪身上的玩家模块有概率掉落复制品 |
| 悬赏翻倍 | 精英怪强度上升，但击杀奖励翻倍 |
| 断绝成长 | 击杀精英怪后阻止其转化为污染变种 |

#### 精英怪可获得的命运残效
精英怪不直接使用完整命运卡片，而是获得残缺版本。

示例：
- 残缺的“子弹背枪”：它的部分弹幕会携带小枪，但射击不稳定。
- 残缺的“变大了”：低血量时体型变大，但移动变慢。
- 残缺的“弹中弹”：死亡时释放一圈小弹。

### 5.4.19 系统解耦建议
精英怪成长系统应拆成独立模块，不要写死在怪物AI里。

| 模块 | 职责 |
|---|---|
| EliteArchiveModule | 保存精英怪档案、历史和状态 |
| EliteGrowthModule | 根据战斗结果计算成长 |
| EliteSpawnDirector | 决定本局是否让旧精英怪登场 |
| EnemyEquipmentAdapter | 把玩家模块转成怪物技能或词缀 |
| BountyModule | 管理悬赏、奖励和情报 |
| EncounterResultRecorder | 记录玩家是否击杀、逃离、死亡、掉落 |

#### 推荐事件流
```text
精英怪生成
→ EliteArchiveModule 创建或读取档案
→ EnemyModule 生成怪物实例
→ EnemyEquipmentAdapter 注入装备技能
→ 战斗结束后 EncounterResultRecorder 记录结果
→ EliteGrowthModule 结算成长
→ EliteArchiveModule 保存新档案
```

这样普通怪物AI仍然只负责战斗行为，精英怪的“长期成长”“装备继承”“复仇登场”由外部系统管理，后期维护和扩展会更安全。

## 6. Boss战模块

### 6.1 Boss设计目标
Boss战用于检验玩家当前武器组合，同时给出高价值模块与撤离选择。

### 6.2 Boss结构
每个Boss由以下部分组成：
- 基础移动模式。
- 阶段转换条件。
- 技能组。
- 可破坏部位。
- 对玩家武器组合的反应机制。
- Boss专属掉落。

### 6.3 Boss示例
#### Boss：武器寄生树
- 阶段一：召唤藤蔓与小怪，持续封锁走位。
- 阶段二：吸收地上的掉落枪械，长出随机枪管，对玩家开火。
- 阶段三：复制玩家当前武器装配树中的一个节点，形成反制攻击。
- 掉落：寄生类命运卡片、枪身嫁接槽、高阶子弹模块。

#### Boss：废铁枪匠
- 阶段一：投掷零件地雷。
- 阶段二：拆解场上武器节点，使玩家某个配件短暂失效。
- 阶段三：召唤三把漂浮枪，每把有不同枪身逻辑。
- 掉落：枪身融合卡、配件复制卡、机械枪身模块。

#### Boss：弹壳巨兽
- 阶段一：滚动冲撞，留下弹壳障碍。
- 阶段二：吸入玩家子弹，吐出变大版本。
- 阶段三：全场弹壳反弹，考验走位与持续输出。
- 掉落：巨化子弹卡、反弹子弹模块、弹壳护盾配件。

#### 解耦建议
Boss技能采用独立技能节点；阶段管理器只决定何时启用或禁用技能，不写死技能细节。

## 7. 搜打撤模块

### 7.1 设计目标
让玩家在每局中产生“已经赚了，要不要走”的压力，同时不破坏肉鸽爽感。

### 7.2 带入与带出
#### 可带入
- 初始枪身。
- 少量基础子弹模块。
- 一个低阶配件。
- 消耗品。
- 撤离信标。
- 基地解锁的祝福。

#### 可带出
- 未消耗资源。
- 蓝图碎片。
- 模块样本。
- 命运卡片残页。
- Boss材料。
- 可用于基地升级的货币。

#### 死亡损失规则
推荐采用“轻度搜打撤”，避免挫败过高：
- 局内临时组合全部丢失。
- 背包中未保险的资源部分丢失。
- 带入装备不永久丢失，或仅损失耐久。
- 稀有资源可通过保险格保留。

### 7.3 撤离机制
| 撤离方式 | 条件 | 风险 |
|---|---|---|
| 固定撤离点 | 地图生成时存在 | 位置较远，可能被怪物围堵 |
| 随机撤离门 | 清理房间后概率出现 | 开启时间短 |
| 信标撤离 | 消耗道具召唤 | 读条期间刷怪 |
| Boss撤离 | 击败Boss后出现 | 需要先打Boss |
| 交易撤离 | 向NPC支付资源 | 牺牲收益换安全 |

### 7.4 搜刮压力
- 背包容量有限，模块占格。
- 枪身、子弹、配件体积不同。
- 未鉴定命运卡片占格但可能有惊喜。
- 重型模块会降低移动速度。
- 携带越多，死亡掉落越痛。

### 7.5 与肉鸽的融合方式
搜打撤不是替代肉鸽，而是增加局内选择：
- 肉鸽负责“当前局内变强”。
- 搜打撤负责“当前收益能不能安全带走”。
- 基地养成负责“长期解锁更多组合可能”。

#### 解耦建议
搜打撤系统只处理背包、撤离、带入带出和结算；不直接参与武器运行。武器模块作为物品存在，进入装配后由武器系统接管。

# 第二部分：特色玩法

## 8. 模块化武器系统

## 8.1 设计目标
把武器拆成可组合、可变异、可视化拼接的模块，让玩家每局都能创造新攻击方式。

### 8.2 三大模块
#### 8.2.1 枪身 GunBody
枪身决定“怎么开火”。

| 参数 | 说明 |
|---|---|
| 射速 | 每秒发射次数 |
| 弹道数量 | 一次发射几颗子弹 |
| 后坐力 | 连续射击的偏移 |
| 扩散 | 子弹散布角度 |
| 充能方式 | 点射、连射、蓄力、喷射、爆发 |
| 装填方式 | 弹匣、过热、能量、冷却 |
| 基础标签 | 霰弹、狙击、激光、榴弹、召唤、近战 |

##### 枪身示例
| 枪身 | 特点 |
|---|---|
| 豌豆手枪 | 稳定、基础、易组合 |
| 散射喷壶 | 一次发射多弹丸 |
| 蓄力萝卜炮 | 蓄力越久子弹越大 |
| 蜂窝机枪 | 高射速低伤害 |
| 弹弓狙击 | 低射速高穿透 |
| 反胃榴弹筒 | 发射抛物线爆弹 |
| 漂浮副枪 | 不在手上，围绕角色自动射击 |

---

#### 8.2.2 子弹 Bullet
子弹决定“打出去的东西是什么”。

| 参数 | 说明 |
|---|---|
| 飞行速度 | 子弹移动速度 |
| 生命周期 | 存在多久 |
| 命中行为 | 穿透、爆炸、弹跳、黏附、召唤 |
| 伤害类型 | 物理、火焰、毒、冰、电、诅咒 |
| 碰撞大小 | 命中判定 |
| 可挂载点 | 子弹上是否能挂其他节点 |
| 基础标签 | 黏性、爆炸、穿透、追踪、分裂、活体 |

##### 子弹示例
| 子弹 | 特点 |
|---|---|
| 普通豆弹 | 无特殊效果，稳定 |
| 黏黏弹 | 命中后附着目标，持续伤害 |
| 回旋镖弹 | 飞出后返回 |
| 钻头弹 | 持续穿透并造成多段伤害 |
| 气球弹 | 变大但飞行慢 |
| 蜂卵弹 | 命中后孵化小飞虫 |
| 黑洞弹 | 缓慢飞行并吸引敌人 |
| 反弹弹 | 碰墙弹跳 |

---

#### 8.2.3 配件 Attachment
配件决定“如何修饰枪身或子弹”。

| 配件类型 | 作用 |
|---|---|
| 枪口 | 修改出弹数量、角度、弹速 |
| 弹匣 | 修改装填、弹量、连发节奏 |
| 瞄具 | 修改暴击、追踪、弱点 |
| 枪托 | 修改后坐力、移动惩罚 |
| 外挂物 | 增加自动射击、护盾、召唤物 |
| 奇物配件 | 提供特殊规则，如反向射击、复制子弹 |

##### 配件示例
| 配件 | 特点 |
|---|---|
| 三叉枪口 | 子弹分裂成三发 |
| 橡皮枪托 | 子弹获得弹跳 |
| 肉质弹匣 | 换弹时回血或掉血增伤 |
| 放大镜瞄具 | 暴击时子弹变大 |
| 小风扇 | 子弹轨迹被旋风偏转 |
| 胶水挂钩 | 允许子弹挂载一把枪 |
| 复制贴纸 | 随机复制一个已装配节点的弱化版本 |

## 8.3 武器装配树

### 8.3.1 基本结构
武器不是一个固定对象，而是一棵树。

```text
主枪身 GunBody_A
├── 子弹 Bullet_A
│   ├── 子弹挂载槽 MountSlot_1
│   │   └── 枪身 GunBody_B
│   │       └── 子弹 Bullet_B
│   └── 配件 Attachment_X
├── 枪口配件 Attachment_Muzzle
└── 弹匣配件 Attachment_Magazine
```

### 8.3.2 节点类型
| 节点类型 | 职责 |
|---|---|
| GunBodyNode | 处理开火节奏与发射行为 |
| BulletNode | 处理投射物移动、命中、生命周期 |
| AttachmentNode | 修改目标节点属性或行为 |
| FateCardNode | 在运行时插入特殊规则 |
| MountSlotNode | 提供可挂载位置 |
| VisualNode | 负责显示拼接结果 |

### 8.3.3 节点执行逻辑
每次射击生成一个 `FireContext`，其中包含：
- 发射者。
- 发射位置。
- 瞄准方向。
- 当前武器树。
- 伤害倍率。
- 命运修正。
- 随机种子。

投射物命中时生成一个 `HitContext`，其中包含：
- 命中目标。
- 命中位置。
- 伤害类型。
- 触发源节点。
- 是否暴击。
- 是否击杀。
- 后续触发队列。

### 8.3.4 美术表现原则
美术不追求复杂写实，而追求直接、粗暴、可笑、可读。

示例：
- 子弹上粘了一把枪：就在子弹Sprite上挂一个缩小的枪Sprite。
- 子弹上粘了三把枪：三个枪Sprite围绕子弹旋转。
- 枪身被变大：直接放大枪身节点。
- 子弹变异成活体：子弹加眼睛和小脚动画。
- 枪管反向：枪Sprite旋转180度，并真的向后开火。
- 子弹背着炮台：子弹飞行时自动朝附近敌人开火。

### 8.3.5 关键规则：限制无限递归
为了避免组合爆炸导致性能和数值失控，需要设定硬限制：
- 武器树最大深度：建议3-5层。
- 单次射击最大生成投射物数量。
- 单个投射物最多挂载枪身数量。
- 自动射击节点需要有独立冷却。
- 召唤物数量上限。
- 递归触发需要衰减倍率。

## 9. 命运卡片系统

### 9.1 设计目标
命运卡片是武器组合进化的主要入口。它不是普通被动技能，而是“对枪身、子弹、配件、节点关系进行改造的规则卡”。

### 9.2 命运卡片定位
命运卡片负责以下事情：
- 组合两个模块。
- 强化某个模块。
- 改变模块形态。
- 增加挂载槽。
- 复制节点。
- 放大或缩小节点。
- 改变触发条件。
- 让不合理的组合变得合理。

### 9.3 卡片分类
| 卡片类型 | 功能 | 示例 |
|---|---|---|
| 组合卡 | 把两个节点连接起来 | 子弹上挂枪、枪上装枪、配件寄生 |
| 强化卡 | 提升数值或触发频率 | 子弹变大、射速提升、暴击翻倍 |
| 变种卡 | 改变模块行为 | 直线弹变回旋弹，普通枪变自动枪 |
| 复制卡 | 复制节点或效果 | 复制一把副枪，但伤害降低 |
| 融合卡 | 两个模块合成新模块 | 火焰子弹 + 毒子弹 = 腐燃弹 |
| 诅咒卡 | 强力但带副作用 | 伤害翻倍但换弹会爆炸 |
| 规则卡 | 改变触发规则 | 每第七发子弹携带一把枪 |
| 视觉卡 | 主要改变表现，少量改变属性 | 巨大化、长脚、长眼、旋转 |

### 9.4 卡片品质
| 品质 | 特点 |
|---|---|
| 白色 | 简单强化，稳定安全 |
| 蓝色 | 改变某个行为，收益明显 |
| 紫色 | 产生组合关系，构筑核心 |
| 金色 | 改变武器树结构，强力稀有 |
| 红色 | 诅咒或失控型效果，极强但危险 |

### 9.5 命运卡片目标选择
卡片不直接写死作用对象，而是通过条件选择目标：

```text
目标条件示例：
- 选择一个 Bullet 节点
- 选择一个带有“黏性”标签的子弹
- 选择一个 GunBody 节点
- 选择当前主武器根节点
- 选择最近一次获得的模块
- 选择一个有空挂载槽的投射物
- 随机选择一个已装配节点
```

### 9.6 命运卡片执行流程
```text
获得命运卡片
→ 卡片读取当前武器树
→ 检查可作用目标
→ 玩家选择目标或系统随机目标
→ 生成 Modifier / MutationNode
→ 插入武器树或附加到目标节点
→ 更新数值、运行逻辑、视觉表现
```

### 9.7 命运卡片示例
#### 组合类
| 卡名 | 效果 |
|---|---|
| 枪上加枪 | 选择一把枪身，将其挂到当前枪身上，开火时副枪也有概率开火 |
| 子弹背枪 | 选择一个子弹和一个枪身，之后该子弹飞行时会携带这把枪并自动射击 |
| 配件寄生 | 选择一个配件，使它寄生到子弹上，子弹命中时触发配件效果 |
| 枪口嫁接 | 把另一把枪的枪口逻辑嫁接到当前枪上 |
| 弹丸巢穴 | 子弹命中后生成一把临时小枪，持续数秒 |

#### 强化类
| 卡名 | 效果 |
|---|---|
| 变大了 | 选择一个节点，体型与碰撞范围增加，伤害提升，速度降低 |
| 超频 | 选择一个枪身，射速提升，但过热更快 |
| 加料 | 选择一个子弹，附加随机元素伤害 |
| 死命贴住 | 黏性子弹附着时间增加，期间每秒触发一次命中效果 |
| 多长一个枪口 | 当前枪身额外获得一个枪口挂载点 |

#### 变种类
| 卡名 | 效果 |
|---|---|
| 活过来 | 选择一个子弹，变成活体子弹，会轻微追踪敌人 |
| 倒着来 | 选择一个枪身，使其每次开火时向反方向额外射击 |
| 不想飞 | 子弹落地后变成小炮台 |
| 回家看看 | 子弹飞出后返回玩家，返回途中继续造成伤害 |
| 越打越歪 | 射击散布逐渐增加，但子弹数量也逐渐增加 |

#### 复制类
| 卡名 | 效果 |
|---|---|
| 复印失败 | 复制一个随机节点，但大小、伤害、速度随机变化 |
| 影子副枪 | 复制当前枪身为一把半透明副枪，伤害降低 |
| 弹中弹 | 子弹命中时复制自身一次，复制体伤害降低 |
| 多一个我 | 随机复制一个配件到另一个合法节点上 |

#### 融合类
| 卡名 | 效果 |
|---|---|
| 硬塞进去 | 强行融合两个不同类型节点，生成一个混合节点，附带随机副作用 |
| 元素搅拌 | 两种元素子弹融合为复合元素 |
| 枪弹合一 | 选择一个枪身和子弹，将枪身缩小并嵌入子弹，子弹飞行时按冷却自动射击 |
| 配件融化 | 牺牲一个配件，把它的效果永久写入目标子弹 |

#### 诅咒类
| 卡名 | 效果 |
|---|---|
| 管不住了 | 所有挂载在子弹上的枪自动射击，但不一定瞄准敌人 |
| 火力暴食 | 子弹每命中一次就变大，但也会降低玩家移速 |
| 失控复制 | 每次暴击复制一颗子弹，但复制体有概率攻击玩家附近区域 |
| 过度嫁接 | 枪身可挂载数量增加，但每次开火有概率卡壳 |

## 10. 枪 + 子弹化学变化系统

### 10.1 设计目标
让枪和子弹不是简单数值组合，而是在命运卡片介入后产生“结构变化”和“行为变化”。

### 10.2 化学变化来源
化学变化来自三类输入：
1. **模块标签**：例如“黏性”“爆炸”“霰弹”“活体”“激光”。
2. **命运卡片类型**：组合、强化、变种、复制、融合、诅咒。
3. **装配关系**：枪装在枪上、枪装在子弹上、子弹装在枪上、配件寄生到子弹上。

### 10.3 组合关系示例
#### 关系一：子弹上挂枪
```text
Bullet_A + GunBody_B + 命运卡片「子弹背枪」
= 每一发 Bullet_A 都会携带 GunBody_B 的缩小版本。
Bullet_A 飞行期间，GunBody_B 自动寻找附近敌人开火。
```

表现：子弹Sprite上挂一个小枪Sprite，小枪会转向并射击。

平衡：
- 挂载枪伤害为原枪的30%-60%。
- 挂载枪有独立射击冷却。
- 子弹消失时挂载枪也消失。
- 若子弹数量很多，挂载枪触发频率递减。

---

#### 关系二：枪身上挂枪
```text
GunBody_A + GunBody_B + 命运卡片「枪上加枪」
= 主枪开火时，副枪有概率同步开火。
```

表现：主枪旁边粗暴绑一把小枪。

适用体验：火力增强，视觉喜感强，容易理解。

---

#### 关系三：子弹装子弹
```text
Bullet_A + Bullet_B + 命运卡片「弹中弹」
= Bullet_A 命中或到达生命周期末端时释放 Bullet_B。
```

表现：大子弹裂开，里面弹出小子弹。

---

#### 关系四：配件寄生子弹
```text
Bullet_A + Attachment_X + 命运卡片「配件寄生」
= 子弹命中时触发配件效果。
```

示例：
- 三叉枪口寄生在子弹上：子弹命中后向三个方向分裂。
- 放大镜寄生在子弹上：子弹暴击后变大。
- 小风扇寄生在子弹上：子弹周围产生吸引或偏转气流。

---

#### 关系五：枪弹融合
```text
GunBody_A + Bullet_B + 命运卡片「枪弹合一」
= 子弹拥有枪身的部分开火能力，枪身拥有子弹的命中特性。
```

示例：
- 机枪 + 黏黏弹：黏在敌人身上的小机枪持续扫射。
- 狙击枪 + 回旋镖弹：穿透敌人后返回，再次造成高伤害。
- 榴弹筒 + 蜂卵弹：爆炸后孵出小蜂群。
- 黑洞弹 + 霰弹枪：黑洞飞行时持续喷出散弹。

---

# 第三部分：系统解耦与维护框架

## 13. 总体系统架构

### 13.1 核心原则
1. **模块只负责自己的行为**：枪身管开火，子弹管飞行，配件管修饰，卡片管规则变换。
2. **组合靠数据表驱动**：新增组合尽量不改代码。
3. **效果通过事件系统触发**：开火、命中、击杀、撤离等统一派发事件。
4. **表现与逻辑分离**：视觉节点只读装配树，不决定真实伤害。
5. **数值与内容分离**：武器基础数据、成长倍率、掉落权重都放配置。

## 16. 武器装配与运行流程

### 16.1 装配流程
```text
玩家打开装配界面
→ 选择主枪身
→ 选择子弹
→ 选择配件
→ 系统检查槽位、标签、冲突规则
→ 生成武器装配树
→ 计算基础预览数值
→ 进入战斗
```

### 16.2 命运卡片改造流程
```text
玩家获得命运卡片
→ FateCardModule 读取卡片目标规则
→ WeaponModule 提供当前装配树可选节点
→ 玩家选择目标
→ FateCardModule 生成变更命令
→ WeaponAssemblyTree 应用命令
→ StatResolver 重新计算数值
→ VisualAssembler 更新外观
```

### 16.3 战斗运行流程
```text
输入开火
→ WeaponController 调用根 GunBodyNode
→ GunBodyNode 根据上下文发射 BulletNode
→ AttachmentNode 修改发射参数
→ ProjectileModule 生成投射物实例
→ 投射物根据 BulletBehavior 运行
→ 命中后派发 HitEvent
→ TriggerSystem 检查所有相关触发器
→ 可能生成新的子弹、小枪、爆炸、召唤物
```

## 17. UI设计框架

### 17.1 主HUD
- 生命 / 护盾。
- 当前武器图标。
- 弹药 / 过热条。
- 小地图。
- 背包容量。
- 当前撤离状态。
- 当前危险等级。

### 17.2 装配界面
核心目标是让玩家看懂“这把枪现在到底怎么怪”。

界面结构：
```text
左侧：背包模块列表
中间：武器装配树
右侧：当前属性与触发说明
底部：命运卡片可用操作
```

### 17.3 装配树可视化
- 枪身作为根节点。
- 子弹显示为从枪身延伸出的节点。
- 配件显示在对应槽位。
- 命运卡片效果显示为发光边或特殊图标。
- 非法组合显示红色断线。
- 高风险组合显示警告标识。

### 17.4 组合结果说明文本
尽量用玩家能理解的话，而不是纯数值。

示例：
- “你的黏黏弹现在会背着一把小机枪。飞行时，小机枪会自动朝附近敌人开火。”
- “你的子弹变大了，打得更痛，但飞得更慢。”
- “你的枪口长出了第二把枪。每次开火时，它有35%概率一起开火。”
- “这个组合不太稳定。每次换弹有10%概率卡壳。”

## 18. 数值与平衡框架

### 18.1 平衡目标
允许玩家做出离谱组合，但避免任何组合无限递归、无成本清屏或性能崩溃。

### 18.2 核心限制
| 限制项 | 建议 |
|---|---|
| 武器树深度 | 3-5层 |
| 单发子弹挂载枪数 | 1-3把 |
| 单屏投射物上限 | 软上限 + 合并显示 |
| 召唤物上限 | 按模块和稀有度控制 |
| 触发递归 | 每层伤害、触发率衰减 |
| 自动枪伤害 | 原枪30%-60% |
| 复制体伤害 | 原效果20%-50% |

### 18.3 威力预算 Power Budget
每个节点有威力成本，组合总成本越高，副作用或资源消耗越明显。

| 内容 | 成本来源 |
|---|---|
| 高射速 | 增加威力预算 |
| 多弹丸 | 增加威力预算 |
| 自动寻敌 | 大幅增加威力预算 |

| 复制 | 高幅增加威力预算 |
| 挂载枪 | 高幅增加威力预算 |
| 诅咒副作用 | 降低预算压力 |

### 18.4 副作用池
当组合超预算时，可以引入副作用：
- 射速降低。
- 弹速降低。
- 换弹变慢。
- 有概率卡壳。
- 子弹不稳定偏移。
- 自动枪不一定瞄准最近敌人。
- 过热更快。
- 玩家移动速度降低。
- 撤离读条时武器不稳定。

# 第五部分：MVP版本建议

## 22. MVP目标
第一版不要追求海量内容，而要证明“武器装配树 + 命运卡片改造 + 搜打撤选择”成立。

### 22.1 MVP内容量
| 内容 | 数量 |
|---|---:|
| 枪身 | 6个 |
| 子弹 | 8个 |
| 配件 | 10个 |
| 命运卡片 | 30张 |
| 普通怪物 | 10种 |
| 精英词缀 | 8种 |
| Boss | 3个 |
| 地图主题 | 2个 |
| 房间类型 | 8种 |
| 撤离方式 | 3种 |

### 22.2 MVP必须验证的特色组合
1. 子弹上挂枪。
2. 枪上加枪。
3. 子弹命中后释放子弹。
4. 配件寄生到子弹。
5. 子弹变大、变慢、变强。
6. 自动枪节点独立寻敌开火。
7. 组合超预算后产生副作用。
8. 成功撤离带出资源。
9. 死亡损失部分未保险资源。
10. Boss会反制或复制玩家武器节点。

### 22.3 MVP核心风险
| 风险 | 解决方式 |
|---|---|
| 组合太复杂，玩家看不懂 | 装配树可视化 + 口语化说明 |
| 性能失控 | 投射物上限、触发衰减、节点深度限制 |
| 平衡困难 | 威力预算 + 副作用池 |
| 搜打撤过于惩罚 | 轻度损失，保留核心装备 |
| 美术工作量大 | 节点拼接、缩放、旋转、简单挂点表现 |
| 内容维护困难 | 标签 + 规则表 + 事件系统 |

# 第六部分：设计总结

## 24. 核心卖点总结
本项目的核心不是单纯“射击肉鸽 + 搜打撤”，而是通过模块化武器和命运卡片，把每局构筑变成一场可视化的疯狂拼装实验。

玩家最期待的瞬间应该是：
- “我把一把机枪粘在了子弹上。”
- “这颗子弹飞出去之后自己会开火。”
- “我的枪上又长了一把枪。”
- “Boss复制了我的怪枪，我被自己的离谱构筑打爆了。”
- “我现在身上东西太值钱了，要不要赶紧撤？”

最终目标是形成三层乐趣：
1. **即时乐趣**：顶视角射击清怪很爽。
2. **构筑乐趣**：枪身、子弹、配件、命运卡片能组合出奇怪效果。
3. **风险乐趣**：搜刮越多越想撤，继续探索又可能获得关键进化。

只要武器装配树和命运卡片系统足够稳定，后续内容就可以通过新增模块、卡片、怪物、Boss和地图事件持续扩展。
