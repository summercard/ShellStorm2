# Phase 5：随机地图模块

## 目标
实现节点图方式随机生成的地图，支持多种房间类型和地图层级。

---

## 房间类型
| 房间类型 | 功能 |
|---|---|
| 普通战斗房 | 基础清怪与掉落 |
| 精英房 | 高风险高奖励，掉落高品质模块 |
| 搜刮房 | 箱子、资源、隐藏容器 |
| 商人房 | 购买模块、命运卡片、撤离道具 |
| 改造房 | 免费或付费进行一次武器组合 |
| 事件房 | 随机事件、诅咒、赌局、交易 |
| 撤离房 | 可选择结束本局并带出物资 |
| Boss房 | 阶段目标，胜利后可进入深层或撤离 |

---

## 地图层级
| 层级 | 特点 |
|---|---|
| 浅层 | 怪物弱，撤离点多，资源一般 |
| 中层 | 出现精英怪、陷阱、特殊事件，组合材料质量提升 |
| 深层 | Boss频繁，撤离点稀少，稀有命运卡片与核心模块掉落 |
| 污染层/异化层 | 怪物和地图规则都发生变种，高风险 |

---

## 撤离点规则
- 基础撤离点：地图生成时存在，位置较远
- 精英撤离点：击败精英怪后开启
- 信标撤离：消耗道具召唤，读条期间刷怪
- Boss撤离：击败Boss后出现
- 交易撤离：向NPC支付资源

---

## 搜刮压力
- 背包容量有限，模块占格
- 枪身、子弹、配件体积不同
- 未鉴定命运卡片占格但可能有惊喜
- 重型模块会降低移动速度
- 携带越多，死亡掉落越痛

---

## 地图数据结构
```
MapGenerator
├── NodeGraph（房间节点图）
├── RoomFactory（房间生成器）
├── PathDirector（路径与门管理）
├── ExtractionDirector（撤离点管理）
└── BossRoomDirector（Boss房管理）
```

---

## 解耦要求
地图生成只负责生成房间图与房间标签。具体怪物、掉落、事件由对应表格根据房间标签注入。
