# PH33 · 方形猫角色原型与组件节点规范

## 目标

在不复制 `CHR-PLY-CAPSULE01-3D` 玩家根、不改变碰撞和玩法的前提下，将当前 3D 原型改为参考概念图的方形橙猫。主图形语言使用 Godot 原生 `BoxMesh` 与三角锥体：方头、方身、方手、方脚；仅圆短尾保留圆团轮廓。

## 节点契约

```text
CapsuleAvatar3D
├─ VisualRoot
│  ├─ Body
│  │  ├─ BodyShell
│  │  ├─ BellyPatch
│  │  └─ TailStub
│  ├─ Head
│  │  ├─ HeadShell
│  │  ├─ Eyes
│  │  │  ├─ EyeL
│  │  │  └─ EyeR
│  │  ├─ Ears
│  │  │  ├─ EarL/Inner
│  │  │  └─ EarR/Inner
│  │  └─ Wearables
│  ├─ Hand
│  │  └─ Glove
│  ├─ Feet
│  │  ├─ FootL
│  │  └─ FootR
│  ├─ WeaponSocket
│  ├─ Scarf (隐藏兼容节点)
│  └─ StateVFX
└─ ReloadProgress3D
```

- 四个主模块固定为 `Body / Head / Hand / Feet`；外观 DIY 不得改变碰撞或状态机。
- `Eyes` 必须恰好有两个简单深色矩形眼睛；`Ears` 必须恰好有两个三角耳；不添加嘴巴和鼻子。
- `TailStub` 归属 `Body`，使用小型圆团，仅做轻摆，不得改成长尾或独立第五主模块。
- 只显示一只悬浮握持手；`Hand` 和 `WeaponSocket` 在移动、换弹、射击、蓄力与击飞中保持相同动作变换。
- `Feet` 是一个可替换主模块，内部双脚在 moving 周期交替抬起；整体冲刺、受击和死亡仍由 `VisualRoot` 负责。
- 玩家与手持枪继续使用 render layer 2，只接收角色正面柔光；帽子和眼镜禁用投影与 GI。
- 所有角色模型网格（头、身体、单手、脚、耳、眼、短尾、配件与手持枪）都必须 `cast_shadow = OFF`、`GI_MODE_DISABLED`：角色可以接收 `AvatarFrontFill`，但绝不能让头身互相遮住角色正面光。

## 首版几何

- `HeadShell / BodyShell / Glove / FootL / FootR / EyeL / EyeR`：`BoxMesh`。
- `EarL / EarR`：三边 `CylinderMesh` 锥体；内耳为缩小同类几何。
- `TailStub`：紧凑 `SphereMesh`，作为方形主语言中的唯一圆尾例外。
- 当前全部属于程序化几何原型；最终模型需要在不改节点路径和挂点契约的前提下替换。
