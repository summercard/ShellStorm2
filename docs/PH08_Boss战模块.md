# Phase 8：Boss战模块

## 目标
实现 3 个 Boss，用于检验玩家当前武器组合，同时给出高价值模块与撤离选择。

---

## Boss 通用结构
- 基础移动模式
- 阶段转换条件
- 技能组
- 可破坏部位
- 对玩家武器组合的反应机制
- Boss 专属掉落

---

## Boss 示例

### Boss：武器寄生树
| 阶段 | 行为 |
|---|---|
| 阶段一 | 召唤藤蔓与小怪，持续封锁走位 |
| 阶段二 | 吸收地上的掉落枪械，长出随机枪管，对玩家开火 |
| 阶段三 | 复制玩家当前武器装配树中的一个节点，形成反制攻击 |
| 掉落 | 寄生类命运卡片、枪身嫁接槽、高阶子弹模块 |

### Boss：废铁枪匠
| 阶段 | 行为 |
|---|---|
| 阶段一 | 投掷零件地雷 |
| 阶段二 | 拆解场上武器节点，使玩家某个配件短暂失效 |
| 阶段三 | 召唤三把漂浮枪，每把有不同枪身逻辑 |
| 掉落 | 枪身融合卡、配件复制卡、机械枪身模块 |

### Boss：弹壳巨兽
| 阶段 | 行为 |
|---|---|
| 阶段一 | 滚动冲撞，留下弹壳障碍 |
| 阶段二 | 吸入玩家子弹，吐出变大版本 |
| 阶段三 | 全场弹壳反弹，考验走位与持续输出 |
| 掉落 | 巨化子弹卡、反弹子弹模块、弹壳护盾配件 |

---

## 解耦要求
- Boss 技能采用独立技能节点
- 阶段管理器只决定何时启用或禁用技能，不写死技能细节
- `BossSkillNode` 与 `BossPhaseDirector` 分离
